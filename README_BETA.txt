[ 게임 소개 ]
PingFighter는 보스 배틀, 파워업, 특수 능력이 포함된 
아케이드 스타일의 탁구 액션 게임입니다.

[ 실행 방법 ]
1. PingFighter.exe 파일을 더블클릭하여 실행
2. Windows Defender 경고가 나타날 경우 "추가 정보" → "실행" 클릭

[ 조작법 ]
- 이동: 방향키 (←→) 또는 A/D
- 대시: Space
- 차지샷: Shift 누르고 있기
- 일시정지: ESC
- 아이템 관리: TAB

[ 게임 모드 ]
1. 스토리 모드 - 6개 스테이지 보스 대전
2. 아카데미 모드 - 스킬 트리 시스템
3. 가챠 모드 - 아이템 획득

[ 주요 특징 ]
- 6개의 독특한 보스와 스테이지
- 50개 이상의 다양한 아이템
- 스킬 트리 시스템
- 트레이드 포인트 별 수집
- 다양한 난이도 선택

[ 시스템 요구사항 ]
- OS: Windows 10/11 (64-bit)
- RAM: 4GB 이상
- 저장공간: 500MB 이상
- DirectX: Version 9.0c 이상

[ 알려진 문제 ]
- 첫 실행 시 로딩이 다소 오래 걸릴 수 있음
- 일부 백신 프로그램에서 오탐지 가능
