# Localization QA Checklist

1. **언어 전환 동작 확인**
   - 옵션 메뉴(`option.py`)에서 언어를 `ko → en → ja` 순서로 변경하며 UI 텍스트가 즉시 갱신되는지 확인합니다.
   - 변경 후 `settings.txt`와 `settings.json`에 동일한 언어 코드가 저장됐는지 검증합니다.
2. **UI 시스템 검증**
   - `Settings UI` 탭 이름이 현재 언어로 표시되는지 확인하고, 각 탭에서 항목 선택/조정 시 예기치 않은 문자열 깨짐이 없는지 확인합니다.
   - 마우스/키보드/컨트롤러 설정 버튼이 올바른 라벨과 동작을 유지하는지 점검합니다.
3. **폰트 커버리지 테스트**
   - 한국어/영어/일본어 텍스트가 NanumSquare/ Pretendard 폰트 조합으로 모두 정상 렌더링되는지 수동으로 확인합니다.
   - 일본어 문구가 포함된 화면에서 글리프 깨짐이나 자간 문제(특히 옵션 제목/버튼)를 체크합니다.
4. **리소스 번들링 검증**
   - `PyInstaller` 빌드(`PingFighter.spec` 등)를 실행하고, 생성된 출력물에 `localization/*.json`이 포함되는지 확인합니다.
   - 빌드한 실행 파일에서 언어 전환이 정상 동작하는지 샘플 테스트를 수행합니다.
5. **회귀 테스트**
   - 언어 변경 후 게임을 재시작하여 기본 언어가 선택한 값으로 유지되는지 확인합니다.
   - 언어 전환과 무관한 옵션(볼륨, 화면 모드, 조작)이 기존과 동일하게 저장/로드되는지 비교합니다.
