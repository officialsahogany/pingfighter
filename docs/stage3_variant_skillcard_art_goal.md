## 0. Fable이 확정한 원인 `[확인]`

`stage3_boss_skill_hud_assets.gd:4-8`

```gdscript
const SKILLCARD_ID_TO_INDEX := {
	"tear_shower": 0,
	"curse_chest": 1,
	"psycho_ball": 2,
}
const SKILLCARD_ATLAS_COLUMNS := 4
```

**환묘 연묘의 스킬 3종만 등재돼 있다.** 변형 보스의 스킬 id 는 이 표에 없다.

| 보스 | 스킬 id | 표 등재 |
|---|---|---|
| 환묘 연묘 | `tear_shower` `curse_chest` `psycho_ball` | ✅ |
| **테디베어** | `cotton_throw` `cotton_bomb` `deadly_hug` `heart_beam` | ★**없음** |
| **엘리스** | `mirror_world` `size_shift` `rabbit_projectile` | ★**없음** |

조회가 실패하면 `stage3_boss_skill_hud_renderer.gd:150-155`가 텍스처 대신
**폴백 색 사각형**을 그린다. 사용자가 본 화면이 정확히 그것이다.
`:140`의 초록 테두리(`Color(0.48, 0.84, 0.64, 0.90)`)는 준비 상태 색이며
정상 동작이다.

**엘리스도 같은 결함이다.** 사용자는 테디베어만 보고했지만 표에 없기는 같다.
**둘 다 고쳐라.**

## 1. 착수 전 판정 ★먼저

### 1-1. 아틀라스에 빈 칸이 있는가

`SKILLCARD_ATLAS_COLUMNS := 4`인데 등재된 것은 3종이다. **아틀라스에 이미
그려진 칸이 더 있는지** 실제 이미지를 열어 확인하라.

- 남는 칸에 변형 보스용 그림이 이미 있으면 **색인만 추가**하면 끝난다.
- 비어 있으면 **아트 생성이 필요**하다. 그때는 후보를 제시하고 멈춰라.

★**치수에서 격자를 추론하지 마라.** `SKILLCARD_ATLAS_COLUMNS := 4`가 선언값
이고, 실제 행 수와 총 칸 수를 이미지에서 **눈으로 확인**하라
(AGENTS "Atlas sheet grid authority").

### 1-2. 회귀인지 미구현인지

사용자는 "옛날에 몇 번 발생했다가 회귀"라고 했다. **git 이력에서 그 표에
변형 보스 id 가 있었던 적이 있는지** 확인하라.

- 있었다가 사라졌으면 **어느 커밋이 지웠는지** 지명하라. 같은 사고가
  세 번째다.
- 처음부터 없었으면 미구현이다. 그렇게 보고하라.

이 판정을 보고서 맨 앞에 적어라.

### 1-3. 다른 스테이지도 같은 구조인가

스테이지 2가 최근 같은 계열 결함을 겪었다(두더지왕·아라크네 HUD 키 계약).
**스테이지 2·5·6·7·8의 카드 색인표도 변형 보스를 덮는지** 교차 확인하라.

⚠ **단일 검색어로 판정하지 마라.** `SKILLCARD_ID_TO_INDEX`, `ID_TO_INDEX`,
`skillcard`, `skill_card` 를 각각 훑어라. 스테이지마다 이름이 다를 수 있다.

## 3. 계약

### S2. 색인 확장

- 표에 변형 보스 스킬 id 를 추가하고 아틀라스 인덱스를 배정한다.
- ★**폴백을 없애지 마라.** 자산이 빠져도 화면이 죽지 않아야 한다.
  지금의 색 사각형 폴백은 안전장치로서 정상이다. 문제는 폴백이 뜨는 것이지
  폴백 자체가 아니다.
- 색인이 아틀라스 범위를 넘지 않는지 확인하라. 넘으면 엉뚱한 칸이 잘려
  나온다. **런타임 오류가 아니라 조용한 오작동**이다.

### S3. 아트 생성 (필요할 때만)

- 기존 3종과 **같은 계열**이어야 한다. 아틀라스를 열어 화풍·팔레트·프레임을
  맞춰라.
- 테디베어 4종, 엘리스 3종이다.
- 후보를 제시하고 **승인 뒤에만 승격**하라.
- ★**아틀라스를 확장하면 `SKILLCARD_ATLAS_COLUMNS` 와 실제 격자가 어긋날 수
  있다.** 열·행·총 칸 수를 함께 갱신하고 보고서 표로 남겨라.

### S4. 씰 ★이 목표의 핵심

**같은 사고가 반복되고 있다. 씰이 유일한 방어선이다.**

- 스테이지 3의 **모든 보스와 변형**이 내보내는 스킬 id 를 수집하고,
  **전부가 색인표에 있는지** 단언하라. 하나라도 빠지면 RED 다.
- 색인이 **아틀라스 실제 칸 수 안에** 있는지 단언하라.
- **id 를 하나 지우면 RED 가 나는** 반증 레그를 둬라.
- §1-3에서 다른 스테이지도 같은 구조로 확인됐다면, **가능하면 그 씰을
  스테이지 공통으로 만들어라.** 스테이지마다 따로 만들면 다음 스테이지에서
  또 빠진다.
- 이 씰이 **새 변형 보스를 추가할 때 자동으로 잡아주는지** 확인하라.
  하드코딩된 id 목록을 씰에 적으면 그 목록이 또 낡는다. **런타임 상태에서
  실제로 방출되는 id 를 수집**해야 한다.
