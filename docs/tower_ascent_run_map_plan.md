# 탑 등정 런 지도 개편 기획서 (v1)

- Status: 설계 v1 확정 (2026-08-16) · 코드 미착수 · 구현 주체 = Codex
- 이 문서가 본 개편의 설계 정본이다. 런타임 계약(리셋·프리웜·오디오·GRT)은
  기존 오너 체크리스트가 계속 이긴다. 이 문서는 "무엇을 만들 것인가"를 소유한다.
- 레퍼런스 문법: Slay the Spire(전도 공개 분기 지도·엘리트 표시·경로 손익),
  Peglin(런 구조·크루시블 난이도 축), Hades(패배 결산의 영속 소득 명시).
- 차별화 핵심: 노드 선택을 메뉴 클릭이 아니라 **공 발사**로 수행한다.

## 1. 목적

기존 "스테이지 클리어 → 상자 → 결과화면 → 광장 → 다음 스테이지" 선형 루프를
런 기반 등정 지도 루프로 개편한다.

- 스테이지 사이 무결정 구간(결과화면, 광장 왕복)을 제거하고 결정 밀도를 올린다.
- 무작위성을 계획 재료로 바꾼다. 경로 선택 = 손익 계산.
- 반복 플레이 동기를 만든다. 해금, 기록(최고 도달 층), 리그(광폭화 스케일).

## 2. 핵심 루프

```
스토리 프롤로그 (아라울의 첫 승부)
→ 1밴드 풀 보스 1종과 전투 (7점제)
→ 승리: 상자 1개 드랍 (3종 중 1)
→ 지도: 다음 행 후보 2개에 공 발사 → 닿은 노드로 캐릭터 이동
→ 노드 수행 (전투 / 상점 / 수련장 / 파계승 / 휴식 …)
→ 반복하며 고도 상승 → 밴드 전환 ("~진입" 연출)
→ 최상층 보스 → 런 클리어 결산

패배: 기회의 보석 1개 소모 → 동일 노드 재도전
      보석 소진 시 런 종료 → 패배 결산 (전량 손실 + 영속 소득 병기)
```

## 3. 확정 설계

### 3.1 지도 구조

- 단일 탑, 1페이즈. 아래에서 위로 오르는 등정 구도.
- 데이터 구조는 처음부터 `phases: []` 배열로 잡고 1원소 특수 케이스로 시작한다.
  후속 페이즈 분할(로스터 12종 + 최상층 전용 보스 확보 시)의 마이그레이션 비용을 0으로.
- 전도 공개(StS식): 지도 전체와 노드 아이콘을 처음부터 보여준다.
  활성(공을 맞출 수 있는 대상)은 다음 행의 후보 2개뿐.
- 목업 이미지는 사용자 제공분을 레포로 반입해 이 문서 옆에 둔다 (반입 전).

### 3.2 공 발사 선택 계약

- 노드 종료 후 다음 행 후보 2개가 표적화된다.
- 발사 횟수 무제한. **노드에 닿은 경우에만 그 노드로 확정**된다. 빗나감 = 무효.
  물리 튕김이 원치 않는 선택을 만드는 것은 금지 (조준선 표시, 사실상 결정적 선택).
- 연출은 물리, 결정은 확정. 튕김의 재미는 선택이 아니라 보너스에 배치한다.
  (옵션) 지도 장식 오브젝트 타격 시 소량 재화. 선택 확정과는 완전 분리.

### 3.3 밴드 = 기존 스테이지의 재배치

- 고도 구간(밴드)마다 기존 스테이지의 보스 풀과 전투 배경을 그대로 재사용한다.
  예: 1밴드 = 현행 S1 풀(달지·각시탈·포도대장), 다음 밴드 = S2 풀(청린귀·두더지왕·아라크네 계열).
- 밴드 전환: 지도 타일·공기 톤이 바뀌고 "~진입" 배너가 뜬다. 이후 전투는 해당
  스테이지 배경에서 치른다.
- **밴드 경계 = 수문장 보스 행 (회피 불가 확정 전투).** 밴드당 최소 전투를 보장하고
  중간 절정 리듬을 만든다.
- **회피 규칙: 선택지에서 지나친 보스는 그 런에서 재등장하지 않는다.**
  회피 = 그 보스의 상자를 영구 포기. 라우팅을 손익 계산으로 만드는 핵심 규칙.

### 3.4 전투 포맷

- **전 노드 7점제 듀스 유지.** 실측 판당 3~4분, 듀스 5분 (사용자 제공).
- 티어 구분은 포맷이 아니라 모디파이어와 보상으로 한다. 별도 단축 포맷 없음.
- 런 예산: 전투 약 7판 + 비전투 노드 = 36~40분 목표. 행 수 상수로 조정 가능.

### 3.5 광폭화 = 정예 티어 + 리그 축

- 원본 핑파이터의 광폭화 보스(스킬 강화 + 덩치 증가, 10% 출현, 신화리그 100%)를
  포팅한다. 패리티 레퍼런스 = 원본. 덩치 증가는 수비 면적이라는 실 게임플레이 변수.
- 지도에 표기되는 확정 광폭화 노드(보상 상향) + 일반 보스 노드의 소확률 광폭화(양념).
- 리그(승천 축) 상승 시 소확률이 상향된다. 신화리그 = 100% 패리티 유지.

### 3.6 승리 보상: 상자 통일

- 승리 시 **점수 무관 1상자**: 일반상자 / 절세무공상자 / 비전초식상자 중 1.
- 가중치 스케일은 성과(점수차)가 아니라 **선택한 위험**에 붙는다.
  정예·광폭화·수문장 = 상위 상자 가중 상향(또는 +1 드랍), 밴드 상승 = 가중 상승.
- 상자(공짜·무작위 도박 경로)와 파계승(무혼 소비·선택 경로)은 보완 관계로 유지.

### 3.7 무혼 경제: 전투는 모으는 곳, 노드는 결정하는 곳

- 전투 중 무혼 = **축적 전용**. 전투 중 선택 모달 금지. 수집 미니게임(수비 위치
  이탈 리스크)은 유지한다.
- 노드 소비처:
  - **파계승**: 무혼으로 초식 획득(2~3택 제시), 초식 제거·스왑(획득보다 고가,
    기존 초식 슬롯 스왑 시스템 재사용).
  - **수련장**: 무혼으로 능력치 수련.
- 기존 전투 내 초식 오퍼 개방 게이트(35%)는 **은퇴 대상**이다. 재튜닝하지 않는다.

### 3.8 기회의 보석 = 런의 목숨

- 런 시작 시 3개 고정. **런 스코프 자원** (영속 재고화 금지, 런 종료 시 잔량 소멸).
- 패배 시 1개 소모 후 동일 노드 재도전. 소진 시 런 종료.
- 회복은 희소하게: 휴식 노드 회복, 상점 고가 판매. 상한 3.
- 검토 항목: 보석 1개를 소모하고 해당 노드를 무보상 우회하는 후퇴 선택지
  (매치업 벽에서 런 강제 종료를 피하는 안전판).

### 3.9 패배와 결산

- 런 종료(클리어·패배 공통) 시 결산 화면. 미시 루프(노드 사이)에는 결과 화면 없음.
- 패배 결산은 잃은 것(런 빌드) 아래에 **영속 소득을 반드시 병기**한다:
  해금 재화, 도감 신규 등록, 수호령 친밀도, 기록 갱신(최고 층 등).
  "모든 걸 잃는다"와 "매 런이 남는다"의 공존이 재시작 동기다 (Hades 문법).

### 3.10 해금 (영속층)

- **풀 확장형**: 해금된 무공·초식·아이템이 등장 풀(상자·파계승·스폰·상점)에 추가된다.
- 아이템 측 훅: `unlocked_items` (현행 기본 전부 해금 → 잠금 전환 + 해금 진행 연결).
- 도감 = 해금 진척의 전시장.
- 노드 종류 해금도 카드로 열어둔다 (예: 파계승은 N층 최초 도달 시 해금).

### 3.11 액티브 아이템: 현행 유지

- 현행 수명 규칙이 이미 런 단위 보유다. 스테이지 전환 시 유지
  (`godot/scripts/core/match_reset_controller.gd`의 의도적 skip 계약),
  풀 리셋 시 전량 소거. **"풀 리셋 = 런 종료"로 매핑만 한다.**
- 전투 중 스폰 유지 (픽업은 모달이 없어 흐름을 끊지 않는다).
  획득처: 필드 스폰 + 상점 노드 + 일반상자.
- 포지션 = StS의 포션: 슬롯에 담아 런 내내 보유, "지금 쓸까 광폭화까지 아낄까"의
  런 단위 자원 결정.

### 3.12 귀속표 (완결)

| 런에서 잃는 것 | 영속으로 남는 것 |
|---|---|
| 무공·초식 빌드, 무혼, 액티브 아이템, 상자 내용물, 기회의 보석 잔량 | 해금(풀 확장), 도감, 수호령 로스터·친밀도, 해금 재화, 기록(최고 층·클리어 횟수·리그) |

## 4. 지도 아트 방향 (확정, 2026-08-16)

- 컨셉: **프롤로그(아라울의 첫 승부) 화풍의 연장.** 한지 바탕, 먹선, 주홍·금 팔레트.
  프롤로그 → 지도 → 로딩 방여도가 한 시각 언어로 묶인다.
- 노드 아이콘 = **인장(낙관) 모티프**: 전투=병기 인장, 상점=엽전, 휴식=찻잔,
  파계승=목탁 또는 파계 인장, 광폭화=붉은 귀면 인장. 한지 위 붉은 도장은 가독성과
  화풍을 동시에 만족한다.
- 경로 = 붓선 점선. 밴드 전환 = 먹 농담과 지질(종이 톤) 변화로 고도감 표현.
- ⚠ 기술 주의: 이 화풍은 고휘도(아이보리) 바탕이다. ADD 계열 발광 FX는 밝은
  바탕에서 죽는다 (GRT-047의 역변종, 프롤로그 V4 팔레트 반전에서 실측된 사안).
  노드 강조·광폭화 오라·현재 위치 표시는 먹번짐 애니메이션, 멀티플라이/스크린
  계열, 또는 국소 다크 비네트 위 발광으로 설계할 것.

## 5. 구현 가이드 (Codex 핸드오프)

- **기존 플로우 무손상 개발**: 신규 flow owner 모듈을 기능 플래그 뒤에 만들고,
  광장 R3에서 검증된 원자적 전환 방식으로 프로덕션 승격한다. 결과화면·광장 진입
  루트 제거는 승격 커밋에서 원자적으로 수행한다.
- `scenes/main.gd`는 오케스트레이션 전용 유지. 신규 오너 모듈의 소유권은
  아키텍처 문서와 모듈 원장에 기록한다.
- **런 상태 스냅샷 저장 필요**: 36~40분 런의 중단·이어하기. 세이브 스키마에 런
  상태(지도 시드·현재 노드·빌드·보석·무혼)를 신설한다. `user://` 정책과
  `config/name="pingfighter"` 호환 계약을 준수한다.
- 광장 R3 자산(교감·부화·강화 UI 등)은 폐기가 아니라 노드 모달로 재사용할 것.
- 지도 씬은 기존 런타임 계약 준수: 게임 좌표 오버레이 클리핑, 스폰 프레임
  리포지션 글라이드(GRT-039), 모달 개폐 계약(GRT-058), 프리웜(콜드 진입 측정).
- 표준 게이트: 포커스 스모크(역방향 레그 포함), 헤드리스 로드, 워닝 스캔,
  `git diff --check`, 가시 작업 픽셀 QA. 플레이 가드 계약 준수.

## 6. 미결

- 최상층 앵커: 단기 = 최상위 밴드 로테이션, 장기 = "왕" 전용 보스 1종 (왕의 시련 서사).
- 노드별 상세 스펙: 수련장 수치, 파계승 가격표, 휴식 회복량, 이벤트 노드
  존재 여부와 내용.
- 지도 생성기 규칙: 행 수, 분기 폭, 노드 출현 가중, 시드 정책
  (연출 난수와 게임플레이 RNG 분리 계약 준수).
- 재화 체계: 상점 재화가 무혼 단일인지 별도 재화 병행인지. 해금 재화의 정의와 단가.
- 기존 아이템 강화 시스템 거취: 해금형 영구 강화로 전환 vs 은퇴.
- 런 시작 로드아웃 확정 시점: 캐릭터·수호령 선택 UI가 런 시작에 어떻게 붙는지.
- 플레이어 표면 용어: "런", "밴드", "노드"는 내부 용어. 한국어 표면 명칭
  (층, 구역, 관문 등) 확정 필요. 한국어 카피 엠대시 금지 계약 준수.
- 리그(승천) 단계 설계 상세.
