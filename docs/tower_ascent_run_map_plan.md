## 1. 목적

기존 "스테이지 클리어 → 상자 → 결과화면 → 광장 → 다음 스테이지" 선형 루프를
런 기반 등정 지도 루프로 개편한다.

- 스테이지 사이 무결정 구간(결과화면, 광장 왕복)을 제거하고 결정 밀도를 올린다.
- 무작위성을 계획 재료로 바꾼다. 경로 선택 = 손익 계산.
- 반복 플레이 동기를 만든다. 해금, 기록(최고 도달 층), 리그(광폭화 스케일).

## 2. 핵심 루프

```
스토리 프롤로그 (아라울의 첫 승부)
→ 1층 풀 보스 1종과 전투 (7점제)
→ 승리: 하이라이트 → 보상 픽 (새 카드 4장·무혼 구매·무리롤, §3.6)
→ 전투 씬 그대로 서브: 다음 행 표적(2개=좌우, 1개=중앙, 실제 노드 이름 라벨)
→ 노드 수행 (전투 / 상점 / 수련장 / 파계승 / 수호의 샘터 / 휴식 …)
   비전투 노드도 전투 씬 경유: 전투 정지 + 미니창 (§3.14)
→ 명중한 노드로 확정 → 지도 화면에서 간선 따라 이동 → 도착 노드 화면 진입
→ 반복하며 고도 상승 → 층 전환 ("~진입" 연출)
→ 9층 가짜 엔딩 보스 → **진엔딩 판정 (결산보다 먼저, §3.9)**
   미충족: STANDARD_CLEAR 종결 커밋 → 클리어 결산
   충족: FAKE_ENDING_PRESENTATION (비종결 연출, 런 상태 유지) → 10~12층 연장

패배: 기회의 보석 1개 소모 → 동일 노드 재도전
      잔량 0에서 패배 → 런 종료 결산 (전량 손실 + 영속 소득 병기)
```

## 3. 확정 설계

### 3.1 지도 구조 (v1.7 개정 — 노드 페이즈 2분할, 사용자 확정 2026-08-18)

- 아래에서 위로 오르는 등정 구도. **노드 지도는 2개 페이즈로 분할**한다
  (`phases: []` 배열의 2원소화 — v1.6까지의 1원소 특수 케이스에서 승격):
  - **노드 페이즈 1 = 인간계** (현행 거대 궁궐 컨셉): 1~9층.
    **9층이 페이즈 1의 꼭대기**이며 평시 런의 엔딩이다.
  - **노드 페이즈 2 = 신선계** (구름·절벽·암석 컨셉): 10~12층.
    진엔딩 돌입이 확정된 런에서만 진입한다 — 9층 클리어 → §3.9 판정
    (첫 클리어=가짜 엔딩 고정, 이후 선택 모달) → 등정 선택 시 페이즈 2
    지도로 전환되어 10층이 시작된다.
- **지도는 전체화면**이다. 전투 씬 플레이필드 창 안이 아니라 화면 전체
  (레터박스 영역 포함)를 덮는 전용 표면으로 그린다. 열람(M) 지도와 이동
  연출 지도 모두 동일.
- **지도 내용도 뷰포트에 비례한다 (v1.12)**: 표면뿐 아니라 **내용**(노드 열 폭,
  아이콘 크기, 상하 인셋, 여백)이 뷰포트 크기에 비례해야 한다. **절대 상한을
  두지 않는다.** 상한이 있으면 큰 화면에서 표면만 넓어지고 내용은 가운데
  좁은 기둥으로 남아 "전투창 안에 갇힌 것처럼" 보인다. 확대는 크롭이나
  스크롤이 아니라 **전 노드 동시 가시성을 유지하는 비례 재산출**이다(전도 공개).
  검증 해상도는 반드시 실 뷰포트(2020x1246)를 포함한다. 1280x800만으로는
  상한 포화가 관측되지 않는다.
- **노드 이동 전환 계약 (v1.12, 사용자 확정 2026-08-18)**: 경로 확정 후 도착
  까지를 6구간으로 연출한다. 새 페이즈를 만들지 않고 `MAP_TRANSITION` 진척
  곡선을 구간으로 해석한다. 시계는 물리 틱에 둔다.
  1. 전투 화면 암전 (전투 화면을 계속 그린 채 위에 암전)
  2. 전체화면 지도 등장 (캐릭터는 출발 노드에 정지)
  3. **SD 캐릭터 이동** — 등속이 아니라 가속 후 감속(smoothstep)
  4. 도착 소멸 (스케일 축소 + 알파 감소)
  5. 지도 암전
  6. 도착 표면 등장 — 비전투 노드만 페이드인. **전투 노드는 추가 페이드를
     넣지 않는다** (스테이지 로딩 화면이 이미 암전과 페이드인을 소유하므로
     이중 암전이 된다).
  - 각 구간 길이는 전부 `TEMP_*` 상수. 페이드는 셰이더 없이 단일 알파 rect로
    그리고 **필러와 레터박스까지 덮는 스크린 공간 패스**에 둔다.
  - 이동체는 도형이 아니라 **선택 캐릭터의 SD 스프라이트**이며, 신규 작화 없이
    기존 전투 워킹 시트를 재사용한다.
- 지도 비주얼은 **아래에서 위로 올라가는 성(城) 디자인**이어야 한다 — 스토리
  아트 컨셉(아라울 프롤로그 계열)의 연장선. 현행 임시 생성물(추상 노드 그래프)
  은 스캐폴딩이며 이 구도로 교체된다.
- **노드(선택지)마다 그림이 있어야 한다**: 보스 노드는 보스 비주얼, 시설
  노드는 시설 비주얼. 실물 아트 반입 전에는 종류별 플레이스홀더 그림 슬롯을
  구조로 먼저 확보한다 (GRT-004: 미존재 아트 경로를 퍼프레임에 배선하지 말 것).
- 전도 공개(StS식): 현재 페이즈의 지도 전체와 노드 아이콘을 처음부터
  보여준다. 활성(공을 맞출 수 있는 대상)은 다음 행의 후보 2개뿐.
  페이즈 2는 진엔딩 돌입 전에는 잠금 표기(§3.3)로만 존재를 암시한다.

### 3.2 경로 서브 계약 (2026-08-18 라이브 개정 — 사용자 확정)

- **별도 발사 화면을 만들지 않는다.** 승리 연출(하이라이트 리플레이 → 보상
  픽, §3.6)이 끝난 **그 전투 씬 그대로** — 보스가 패배 시트를 재생 중인 상태 —
  다음 행 후보 표적이 등장하고, **플레이어 캐릭터가 실제 서브 공을 발사하는
  것**이 선택 행위다. 검증판식 지도 위 조준 화면은 폐지한다.
- 표적 배치: 후보 2개면 좌/우, 1개면 중앙. 표적에는 **실제 다음 노드 이름
  라벨**을 단다 (예: 왼쪽 청린귀 / 오른쪽 수호의 샘터).
- **서브의 불확실성이 정체성이다.** 결과가 보장되지 않아야 하며, 보스 회피
  규칙(§3.3)은 전략이 아니라 **서브가 만드는 운의 드라마**로 작동하는 것이
  의도다.
- **각도 게이지 (v1.11 개정, 사용자 확정 2026-08-18)**: 플레이어 캐릭터 바로
  위에 **부채꼴 각도기**를 띄우고 화살표가 좌우로 왕복한다. 발사 입력(마우스
  좌클릭) 시점의 **각도로 서브가 나간다.** 즉 불확실성의 원천이 "순수 물리"에서
  **"왕복 타이밍 맞추기"** 로 바뀐다.
  - v1.6의 "조준선·조준 커서·확정 선택 UI를 만들지 않는다" 조항은 이 게이지로
    **대체된다**. 폐기 사유였던 "사실상 결정적 선택"은 왕복 게이지에서는
    성립하지 않는다. 정지 조준·스냅·자동 보정은 여전히 금지한다.
  - 각도 범위·왕복 속도·발사 초속은 전부 `TEMP_*` 튜닝 상수.
  - **진입 발사 봉인 (v1.12)**: ROUTE_AIM 진입 직후 짧은 arm 창(`TEMP_*`) 동안
    발사를 봉인한다. 직전 화면의 클릭이 폴링 리더의 에지 재합성으로 첫 프레임에
    발사로 소비되는 것을 막기 위함이다. 봉인 중에도 **진자와 좌우 이동은 계속
    돌아야 한다** — 화면을 통째로 얼리면 정지 조준과 이동 동결을 만든다.
    홀드된 입력은 **버린다**. 미뤘다가 만료 시 발사하면 그것이 곧 자동 서브다.
  - **게이지 렌더 방식 (v1.12 supersede)**: `docs/tower_live_feedback_r3_goal.md`
    §1.5가 지시한 "절차 `_draw`로 그린다"를 **대체**한다. 생성 비트맵 텍스처를
    정본으로 하고 절차 팬은 텍스처 부재 시 폴백으로만 남긴다.
- **플레이어는 발사 화면에서 좌우로 자유롭게 이동한다** (v1.11 명시). 위치와
  각도의 조합이 플레이어가 쥐는 두 변수다.
- 표적 명중까지 서브는 무제한이며, **명중한 표적의 노드로 확정**된다.
- **자동 서브 금지 (v1.7)**: 경로 서브 대기 중에는 시간 경과에 의한 자동
  발사가 없다. 서브는 오직 플레이어의 발사 입력으로만 나간다 (일반 전투의
  자동 서브 타이머는 이 국면에 적용하지 않는다).
- **상단 벽 반사 (v1.7)**: 발사된 공이 표적을 빗맞히고 상대(상단) 벽에
  닿으면 즉시 재서브 상태로 리셋하지 않는다. 공은 벽에서 **튕겨 되돌아오며**
  좌우 벽 반사도 동일하게 유지된다. 되돌아온 공은 플레이어 패들로 다시 쳐서
  재조준할 수 있고, 비행 중 표적에 닿으면 그 시점에 확정된다. 공이 하단
  경계 밖으로 나가면 그때 재서브 대기(수동)로 돌아간다.
- 명중 → 지도 화면 전환 → 캐릭터가 간선을 따라 이동 → 도착한 노드의
  화면(전투 진입 또는 §3.14 업무 모달)으로 이어진다. 지도(전도)는 열람과
  이동 연출 전용이다.
- (옵션) 지도 장식 오브젝트 타격 시 소량 재화. 선택 확정과는 완전 분리.
  **파밍 방지 계약 (필수)**: 장식별 지급은 **런 1회**. 지급된 장식 id는
  `claimed_decoration_ids`로 런 스냅샷에 저장한다. 지도 방문(노드 사이 발사
  세션)당 지급 총량 상한을 별도로 둔다. 발사 무제한 + 반복 지급 조합은 무한
  파밍이므로 금지.

### 3.3 층 구조 = 12층 탑 (사용자 확정 2026-08-16)

- 탑은 **12층**. 층마다 보스 풀을 정의하고, 전투 배경은 층이 아니라 **그 보스의
  원 스테이지 배경**을 쓴다 (배경 아트 전부 재사용).
- **1~9층 = 표준 런이며 9층 클리어 = 가짜 엔딩.** 진엔딩 돌입 시 10~12층으로
  연장된다 (돌입 조건 = §3.9 확정: 첫 클리어는 가짜 엔딩 고정, 재클리어 런부터
  9층 선택 모달).
- **노드 페이즈 매핑 (v1.7, §3.1)**: 1~9층 = 노드 페이즈 1(인간계) 지도,
  10~12층 = 노드 페이즈 2(신선계) 지도. 진엔딩 등정 확정 시 페이즈 2 지도로
  전환된 뒤 10층이 시작된다. 층 자체의 정의·보스 풀·진행 규칙은 불변이다.
- 층 전환: 지도 타일·공기 톤이 바뀌고 "~진입" 배너가 뜬다.

  | 층 | 보스 풀 | 포팅 상태 |

  | 1층 | 달지 · 각시탈 · 포도대장 | 전원 완료 (현행 S1) |
  | 2층 | 청린귀 · 두더지왕 · 아라크네 | 청린귀 완료 / 두더지왕·아라크네 = 원본 핑파이터 존재, 미포팅 |
  | 3층 | 환묘 연묘 · 테디베어 · 엘리스 | 환묘 연묘 완료 / 테디베어·엘리스 = 원본 존재, 미포팅 |

  | 5층 | 홍련 + 임시 보스 2 | 홍련 완료 / 임시 2 = 껍데기 신설 |
  | 6층 | 테트리서 + 임시 보스 2 | 테트리서 완료 / 임시 2 = 껍데기 신설 |

  | 8층 | 미노타우로스 + 임시 보스 2 | 미노타우로스 완료 / 임시 2 = 껍데기 신설 |

- **임시(껍데기) 보스**: 지도 생성·선택지·회피 규칙이 12층 전체에서 작동하도록
  슬롯을 채우는 플레이스홀더. 우선 껍데기만 만들고 실체는 후속 트랙에서 교체
  (상세 스펙 = 미결: 기존 보스 로직 재사용 범위, 임시 명칭·실루엣, 도감 등재 여부).
- 미포팅 4종(두더지왕·아라크네·테디베어·엘리스)은 **원본 핑파이터 포팅 트랙**으로
  진행한다 (포팅 체크리스트 준수).
- 11층 4천왕은 한 노드에서 보스 4명과 연속으로 싸우는 건틀릿 형식이다.
  **연전 내부 경계 계약 (2026-08-17 확정)**:
  - 대전 사이 = **노드 내부 매치 리셋**: 액티브 아이템 쿨다운은 초기화하고,
    신화 아이템 스테이지 진행은 **증가시키지 않는다** (한 노드이므로).
    필드 아이템·무공·초식·FX 상태는 유지한다.
  - 연전 중 패배 = 보석 1 소모 시 **해당 대전부터** 재개 (4연전 처음부터 아님).
  - 판 사이 회복·중간 보상 없음. 보상 픽은 4연전 완주 시 1회(화면 1회 계약
    유지), 위험 가중 최상 등급.
  - `node_resolution_id`는 노드 단일 + `encounter_index`를 스냅샷에 저장
    (크래시 재개 = 해당 대전부터).
- **층 경계 = 수문장 보스 행 (회피 불가 확정 전투).** 층당 최소 전투를 보장하고
  중간 절정 리듬을 만든다.
- ⚠⚠ **미배선 경고 (v1.9 실사 확인, 감사 §0): 지도의 보스 선택이 아직 전투에
  도달하지 않는다.** 지도 이동이 끝나 전투 노드에 도착하면 탑 플로우는 도착
  노드의 보스 정보를 전투 씬에 넘기지 않고 그대로 종료해 레거시 스테이지 진행에
  넘긴다. `boss_slot_id`는 탑 모듈 밖 소비자가 0건이고, 탑 플로우는
  `current_stage`를 읽기만 한다. 따라서 표적에 어떤 보스 이름이 붙어 있든 실제
  상대는 레거시 진행이 정한다. **아래 회피 규칙, §3.5 광폭화 노드, §3.6
  비전초식 확정 등장이 전부 이 배선 위에 서 있으므로, 보스 배선이 이 개편들의
  선행 작업이다.** (부수: 슬라이스 종료 시 지도 시드가 0으로 되돌아가 같은 런
  두 번째 전투부터 시드 0 지도가 생성된다.)
- **회피 규칙: 선택지에서 지나친 보스는 그 런에서 재등장하지 않는다.**
  회피 = 그 보스의 보상 픽(비전초식 확정 등장 기회 포함)을 영구 포기.
  라우팅을 손익 계산으로 만드는 핵심 규칙.
  회피(소멸) 보스 목록은 런 스냅샷에 저장한다.

### 3.4 전투 포맷과 시간 예산

- **전 노드 7점제 듀스 유지.** 실측 판당 3~4분, 듀스 5분 (사용자 제공).
- 티어 구분은 포맷이 아니라 모디파이어와 보상으로 한다. 별도 단축 포맷 없음.
- 런 예산 정의 (코덱스 리뷰 반영): **36~40분 = 무패 클리어 기준 설계 중앙값**,
  패배 포함 상한(보석 재도전 최대 3판) 약 50~55분.
- ⚠ **12층·가짜엔딩 9층 구조(§3.3 확정)로 예산 재산정 필요**: 판당 3~4분 기준
  9층 런의 전투 수 상한은 약 10~12판. 층당 행 수·전투 노드 수 배분을 이 상한에서
  역산해 확정한다 (층당 평균 전투 약 1.1~1.3판 수준이어야 함 — 지도 생성기
  규칙과 함께 미결).
- **진엔딩 루트 예산은 별도 정의 필요** (2차 리뷰 P2): 10~12층은 최소 6전 추가
  (10층 1 + 4천왕 4 + 12층 1) = 무패 기준 약 +18~24분, 전부 듀스면 최대 +30분.
  진엔딩 루트 전체는 전투만 약 54~64분 이상이 된다. 표준 런과 진엔딩 런의 목표
  시간을 분리해 확정할 것 (미결).

### 3.5 광폭화 = 정예 티어 + 리그 축

- 원본 핑파이터의 광폭화 보스(스킬 강화 + 덩치 증가, 10% 출현, 신화리그 100%)를
  포팅한다. 패리티 레퍼런스 = 원본. 덩치 증가는 수비 면적이라는 실 게임플레이 변수.
- 지도에 표기되는 확정 광폭화 노드(보상 상향) + 일반 보스 노드의 소확률 광폭화(양념).
- 리그(승천 축) 상승 시 소확률이 상향된다. 신화리그 = 100% 패리티 유지.

### 3.6 승리 보상: 보상 픽 계약 (v1.8 — 상자 은퇴, 사용자 확정 2026-08-18)

- 전투 노드 클리어 시 상자 대신 **보상 픽 화면**이 한 번 열린다. 흐름:
  승리 연출(하이라이트 리플레이) → **보상 픽** → 경로 서브(§3.2).
  페글린식 "랜덤 경로 + 전투마다 보상 픽 + 시설 노드" 조합의 채택이다.
- **매 화면 완전히 새로운 카드 4장.** 화면 간 이월은 없다.
- **화면 안 소진(무리롤)**: 카드를 구매하면 나머지 카드는 리롤 없이 그대로
  남고, 무혼이 허용하는 한 추가 구매가 가능하다 (구매 상한 = 무혼 잔고).
  기존 "1장 선택 시 전체 재추첨" 방식은 이 화면에 적용하지 않는다.
  계속하기로 떠나면 안 산 카드는 버려진다.
- **구매 연출 (v1.11, 사용자 확정)**: 구매한 카드는 "구매 완료" 표시로 남지
  않는다. 카드를 뽑아 드는 듯한 모션과 함께 **플레이어 쪽으로 흡수**되고,
  그 자리는 **카드 흔적이 전혀 없는 빈 공간**이 된다. 잔여 카드는 자리를
  옮기지 않는다 (슬롯 인덱스 안정 — GRT-030).
- **화면 구성 = 기존 퍽 선택 화면과 동일 (v1.12, 사용자 확정 2026-08-18)**:
  위에서부터 **카드 열 → 현재 무공 슬롯 원장 → 능력치 띠**. 카드에는 마우스
  호버 반응이 있어야 한다. 카드를 구매하면 슬롯 원장과 능력치 띠가 **즉시**
  갱신된다.

    보여주는 프리뷰는 기존 퍽 선택 화면에도 없으므로 "동일 구성"에 포함되지
    않는다. 프리뷰가 필요하면 별도 신규 기능으로 요청한다.
- **보상 픽과 노드 모달은 스크린 공간 패스에 둔다 (v1.12)**: 현재 둘 다
  플레이필드 변환 패스에서 그려져 (1) 카드가 퍽 모달보다 작게 나오고
  (2) 노드 모달의 어둡게 처리가 게임좌표에만 걸려 **직전 보스와 필러 크롬이

  `boss_slot_id`이며 판정 함수는 한 곳으로 통합한다 (현재 두 파일에 복제되어
  있고 `current_stage`만 본다 — 같은 층 다른 보스를 구분하지 못해 회피한 보스의
  초식이 등장한다). 회피한 보스의 비전초식은 확정 등장 후보에서 제외한다.
  단 §3.3의 보스 배선(아래 경고)이 착지하기 전까지는 1~3층 한정 임시 계약으로
  범위를 축소하고 `current_stage` 기반 판정을 임시 유지한다.
- **소멸 상태의 오너 (v1.9, 감사 §P1-B)**: 소멸 목록은 `TowerAscentRunState`의
  진행 필드이며 `skipped_boss_ids`와 동급으로 캐리오버 allowlist에 등재한다.
  flow owner의 새 배열에 두면 다음 승리 한 번에 지워져 비전초식이 재등장한다.
  소멸 커밋 시점은 "카드를 그렸을 때"가 아니라 "구매 또는 계속하기를 확정했을
  때"이며 해금 필터를 통과한 뒤다.
- **만석이어도 소멸한다 (v1.10, 사용자 확정)**: 초식 슬롯이 만석이라 사지
  못한 경우에도 그 런에서 소멸한다. 초식은 교체가 가능하므로 "살 수 없어서
  못 샀다"가 성립하지 않기 때문이다. 따라서 **비전초식 카드는 만석일 때 스왑
  경로를 함께 제시해야 한다** — 파계승 스왑 패턴을 따라 사전에 스왑 대상
  후보를 산출해 카드에 표기하고, 구매 확정 시 스왑 선택과 확정까지 한
  트랜잭션으로 몰고 가며 롤백에서 pending 스왑을 취소한다. 스왑 경로 없이
  만석 구매를 실패시키면 소멸 계약이 부당해진다.
- **픽 화면의 소속 (v1.9, 감사 §P1-C)**: 픽은 탑 플로우의 신규 페이즈가 아니라
  **현행 승리 전리품 페이즈 자리를 그대로 대체**한다. 탑 플로우가 활성인 동안
  입력 컨트롤러가 모든 입력을 먼저 소비하므로, 픽을 탑 페이즈로 만들면 카드
  클릭이 무증상으로 사라진다. 전리품 자리를 쓰면 물리 게이트 등재, 쿨다운
  팬아웃, 루프 오디오 정지(GRT-034), resume safety, `ball_active` 강제 false,
  필드 스폰 차단, 즉시퍽 제외를 그대로 상속한다.

- **사실 정정 (v1.9, 감사 §P1-D)**: 현행 일반 상자 3% 잭팟의 프로덕션 산출물은
  신화 액티브 아이템이 아니라 **절세무공 선택 창**이다(`PerkConversionFlags`
  부팅 ON). 따라서 잭팟의 후계는 **절세무공 카드의 저확률 등장**이 담당하며,
  "액티브 카드의 저확률 신화 등급 등장으로 흡수한다"는 v1.8 문장은 철회한다.
- **액티브 아이템 카드는 이번 범위에서 제외한다 (v1.9, 감사 §P1-E)**: 런 골드
  생산자가 프로덕션에 없어 골드 가격 카드는 착지 즉시 영구 비활성이다. 카드
  4장은 무공·수련·비전초식·절세무공 풀로 채운다. 골드 생산자 착지는 별도 트랙.
- 순수 재화 지급형 카드는 두지 않는다 — 재화 소스는 전투 중 드랍으로 충분하며,
  무료 카드는 결정이 아니라 소음이다.
- **4장 구성 순서와 사전 게이트 (v1.9, 감사 §P1-I)**: 슬롯 1은 확정 카드
  (적격 보스 직후의 비전초식)가 우선 점유하고, 잔여 슬롯에만 저확률
  lane(절세무공)을 굴린 뒤, 남은 자리를 기본 풀(무공·수련)로 채운다. 같은 카드
  중복 등장 금지. 확정 카드가 저확률 lane에 밀려나는 순서는 허용하지 않는다.
  구매 가능한 재고가 없으면 그 카드는 등장시키지 않는다. **카드 세트는 화면
  진입당 정확히 한 번만 굴려 캐시한다** — update나 draw에서 재굴림하면 저확률이
  프레임 누적으로 사실상 확정이 된다 (GRT-011).
- 위험 프리미엄(정예·광폭화·수문장·층 상승)은 **카드 등급 가중 상향**으로
  반영한다 (v1.7 상자 등급 가중 계약의 이관. 수량 +1은 여전히 채택하지 않음).
- **상자 시스템 은퇴**: 3종 kind(`chest_normal`/`chest_supreme_art`/
  `chest_secret_chosik`) 계획, 점수 비례 수량, `boss_vision_offer_id` 치환
  로직(`victory_loot_phase_state.gd:456`)은 모두 은퇴한다. 은퇴 시 승리 점수
  파생 임계값·상자 소비자를 GRT-054 요령으로 전수 감사할 것.
- 픽 확정·구매는 §3.9 노드 해소 트랜잭션에 귀속된다 (픽 커밋 후 서브).
  픽 화면은 물리차단 모달 계약(GRT-058)을 따른다.
- **단가 통일 + 장수 차별화 (v1.10, 사용자 확정 2026-08-18)**: 노드와 픽의
  **무혼 단가는 동일**하다. 노드의 가치는 가격이 아니라 **선택의 폭**이다.
  - 보상 픽 = **4장**, 종류 혼합, 후보 무작위.
  - 수련장 = **수련 카드 6장** 제시. 단 **방문당 구매 2회 상한 유지**
    (`TEMP_PHASE_C_TRAINING_USES_PER_VISIT := 2`). 6장 중 2장을 고르는 것이
    노드의 재미이며, 상한을 풀면 능력치 수련만 슬롯 제한이 없어 무제한
    인플레가 된다.
  - 파계승 = **무공·초식 카드 6장** 제시. 초식·무공은 슬롯 상한이 자연
    제약이므로 방문당 구매 상한을 별도로 두지 않는다.
  - 이에 따라 페이즈 C 노드 가격을 새 단가로 재정렬한다: 체질 수련 5 → **1**,
    무공 서가 10 → **2**, 파계승 초식 획득 8 → **3**. 목록에 없던 노드 비용은
    같은 비율(×0.375)로 내려 TEMP로 둔다: 초식 스왑 10 → **4**,
    초식 제거 12 → **5**, 샘터 강화 6 → **2**.
- **무공합일 카드의 모달 중첩 계약 (v1.10)**: 융합 모달은 이미 퍽 선택 모달
  자리를 넘겨받는 구조다(`is_perk_fusion_modal_active`가 표준 카드 드로우보다
  먼저 라우팅. 신비의 주사위도 같은 패턴). 따라서 무공합일 카드는 새 시스템이
  아니라 **기존 융합 모달로 넘기는 카드**다. 융합이 끝나면 **잔여 카드·소진
  플래그·무혼 잔고가 보존된 픽 화면으로 복귀**해야 하며, 복귀 실패는 그 자리에서
  무리롤 계약을 깨뜨린다. 복귀를 봉인 대상으로 명시한다.
- 보상 픽(전투 직후·랜덤 후보 경량 소비처)과 노드 시설(같은 단가·더 넓은
  선택지, §3.7)은 보완 관계다: 픽은 후보가 무작위 혼합, 파계승·수련장은
  한 카테고리를 6장에서 고른다.

### 3.7 무혼 경제: 전투는 모으는 곳, 노드는 결정하는 곳

- 전투 중 무혼 = **축적 전용**. 전투 중 선택 모달 금지. 수집 미니게임(수비 위치
  이탈 리스크)은 유지한다.
- 노드 소비처:
  - **파계승**: 무혼으로 초식 획득(2~3택 제시), 초식 제거·스왑(획득보다 고가,
    기존 초식 슬롯 스왑 시스템 재사용). 광장 아카데미(초식 습득·교환)의 기능 후계.
  - **수련장**: 무혼으로 능력치 수련.
  - **수호의 샘터**: 런 내 최초 방문 = 영혼소환술 획득, 이후 방문 = 수호령
    강화·교체·흡수 + 보관 알 처리 (§3.15 스펙 확정). 소비 재화 = **무혼**
    (§3.16).
- 기존 전투 내 초식 오퍼 개방 게이트(35%)는 **은퇴 대상**이다. 재튜닝하지 않는다.

### 3.8 기회의 보석 = 런의 목숨

- 런 시작 시 3개 고정. **런 스코프 자원** (영속 재고화 금지, 런 종료 시 잔량 소멸).
- **규칙 정의 (명확화)**: 보석은 재도전 비용이다. 패배 시 잔량 ≥ 1이면 1개
  소모 후 동일 노드 재도전. **잔량 0에서 패배하면 런 종료.** 즉 런당 재도전
  최대 3회, 패배 허용 최대 4회.
- 회복은 희소하게: 휴식 노드 회복, 상점 고가 판매. 상한 3.
- **구현 계약 (P1 — 현행 구조 재사용 금지)**: 현행 패배 흐름은
  `battle_defeat_flow_resolver.gd:117`이 registry의 보석 스토어를 읽고
  `plaza_save_store.consume_chance_gem()`(`plaza_save_store.gd:177`)이 **소비
  즉시 영속 `save()`** 한다. 이를 그대로 재사용하면 새 런이 이전 런 잔량을
  물려받는다. 보석 소유권은 메타 세이브가 아니라 **`run_state.chance_gems`**
  가 갖고, 저장은 이어하기용 런 스냅샷에만 한다. 기존 plaza 스토어 필드는
  마이그레이션 후 은퇴.
- 검토 항목: 보석 1개를 소모하고 해당 노드를 무보상 우회하는 후퇴 선택지
  (매치업 벽에서 런 강제 종료를 피하는 안전판).

### 3.9 노드 해소 트랜잭션 (결과화면 제거의 대체 경계)

- 현행 결과화면 종료는 미지급 보상 지급 + 스테이지 진척 반영 + 씬 전환을 묶는
  트랜잭션 경계다 (`stage_clear_result_finish_action_data.gd:40`
  `finish_next_stage` = `grant_pending_rewards` → `apply_stage_clear_progress`
  → reset). 결과화면을 제거하면 이 경계가 사라지므로, 신규 flow owner가
  동등한 경계를 소유해야 한다 (P1).
- ⚠ **현행 `node_resolution_id`는 런 안에서 유일하지 않다 (v1.9 실사 확인,
  감사 §P1-A).** 매 승리 `prepare_vertical_slice_combat`가 노드 id를 페이즈
  엔트리 노드로 되돌린 뒤 id를 조립하므로, 한 런의 모든 전투가
  `<run_id>:<엔트리 노드>:combat_victory`를 발급한다. 지금 충돌이 드러나지 않는
  유일한 이유는 해소 id 집합이 매 승리 초기화되기 때문이다. 픽 구매를 이 축에
  그대로 귀속시키면 두 번째 전투의 픽이 이미 커밋됨으로 판정되어 무혼도 깎이지
  않고 카드도 나오지 않는 무증상 실패가 된다. **픽 착수 전에 승리 회차 또는
  도착 노드 id를 포함한 유일 id 축을 먼저 신설한다.**
- 카드형 보상은 재화 3종 전용인 `reward_bundle`이 아니라 `apply_once`의
  effect/rollback 콜백 경로로 보낸다 (선례 = 상점 구매). 픽 커밋과 서브 진입
  사이에는 실패 가능 지점을 두지 않는다.
- **노드 해소 파이프라인 (멱등 계약)**:
  1. 전투 승리 판정 → 전리품 확정 (`node_resolution_id` 발급)
  2. 보상 1회 지급 (같은 `node_resolution_id`로 재실행해도 중복 지급 없음)
  3. 노드 완료를 런 스냅샷에 커밋
  4. 지도 진입 (다음 행 활성화)
- 크래시·강제종료 후 재개 시 pending 보상은 `node_resolution_id` 기준으로
  지급 여부를 판별한다. 보상 복제와 소실 둘 다 금지.
- **9층 가짜 엔딩 순서 계약 (2차 리뷰 P1)**: 진엔딩 판정은 반드시 결산보다
  먼저다. 미충족 시 STANDARD_CLEAR로 종결 커밋 후 결산. 충족 시
  FAKE_ENDING_PRESENTATION(비종결 연출)만 실행하고 빌드·보석·무혼·RNG·run_id를
  유지한 채 10층으로 진입한다. 판정 결과는 스냅샷에 저장해 크래시 재개 시
  9층 보상·판정·결산이 중복 실행되지 않게 한다.
- **진엔딩 돌입 조건 (2026-08-17 확정)**:
  - **첫 9층 클리어는 무조건 가짜 엔딩**: STANDARD_CLEAR 종결 커밋 → 결산.
    결산 직전 "왕의 시련은 아직 끝나지 않았다" 계열 티저 연출 1회.
    영속 기록에 가짜 엔딩 클리어를 기록한다.
  - **재클리어 런부터**: 9층 승리 시 판정 시점에 **선택 모달** — "하산한다
    (STANDARD_CLEAR 결산 확정)" / "더 오른다(비가역, FAKE_ENDING_PRESENTATION
    비종결, 10층 진입)". 선택 결과는 스냅샷에 저장한다.
  - 무패(보석 무손실) 진엔딩 클리어는 돌입 조건이 아니라 **기록·도감의 훈장**.
  - 인장 수집형 돌입 조건은 고리그용 후속 확장 카드로 보류.
- 런 종료(클리어·패배)에만 결산 화면. 가짜 엔딩 연출은 결산이 아니다.
  패배 결산은 잃은 것(런 빌드) 아래에
  **영속 소득을 반드시 병기**: 해금 재화, 도감 신규 등록, 기록
  갱신. "모든 걸 잃는다"와 "매 런이 남는다"의 공존이 재시작 동기다 (Hades 문법).

### 3.10 해금 (영속층)

- **풀 확장형**: 해금된 무공·초식·아이템이 등장 풀(보상 픽·파계승·스폰·상점)에 추가된다.
- **구현 계약 (P2 — `unlocked_items`는 Godot 훅이 아님)**: 그 이름은 동결된
  Python 레거시 전용이며 Godot 런타임에 존재하지 않는다 (레거시 경로 수정
  금지). **Godot용 해금 스토어를 신설**하고(plaza/lingpet save store 관례를
  따르는 독립 스토어), 필드 스폰·보상 픽·상점·가챠·파계승 오퍼 등 **모든 획득
  소비자가 동일한 단일 필터 함수를 관통**하도록 설계한다.
- 도감 = 해금 진척의 전시장.
- 노드 종류 해금도 카드로 열어둔다 (예: 파계승은 N층 최초 도달 시 해금).

### 3.11 액티브 아이템: 현행 유지

- 현행 수명 규칙이 이미 런 단위 보유다. 스테이지 전환 시 유지
  (`godot/scripts/core/match_reset_controller.gd`의 의도적 skip 계약),
  풀 리셋 시 전량 소거. **"풀 리셋 = 런 종료"로 매핑만 한다.**
- 전투 중 스폰 유지 (픽업은 모달이 없어 흐름을 끊지 않는다).
  획득처: 필드 스폰 + 상점 노드 + 보상 픽 액티브 카드(§3.6).
- 포지션 = StS의 포션: 슬롯에 담아 런 내내 보유, "지금 쓸까 광폭화까지 아낄까"의
  런 단위 자원 결정.

### 3.14 노드 업무 흐름 = 전투 씬 상주 (사용자 확정 2026-08-16)

- **모든 노드는 전투 씬을 경유한다** (Peglin 방식). 별도 상점 씬·샘터 씬을
  만들지 않는다.
- 비전투 노드(상점·수호의 샘터·파계승·수련장·휴식) 진입 시: 전투 씬이 정지된
  상태에서 해당 업무의 **미니창(물리차단 모달)** 이 뜬다. 업무 종료 후 같은
  전투 씬에서 §3.2의 서브 표적이 등장하고, 서브로 다음 노드를 정한다.
- **업무 모달은 해당 노드에 도달(지도 이동 완료)했을 때만 연다 (2026-08-18
  교정).** 전투 승리 직후 현재 자리에서 임의 노드 업무 모달을 여는 것은
  수직 슬라이스 데모 잔재이며 금지한다. 순서는 항상: 승리 연출 → 보상 픽 →
  서브 → 지도 이동 → 도착 노드의 전투 또는 업무.
- §3.7 "전투 중 선택 모달 금지"와의 관계: 금지 대상은 **랠리 진행 중** 모달이다.
  노드 업무 미니창은 랠리 밖(전투 정지 상태)이므로 이 금지에 저촉되지 않는다.
- 구현 계약: 기존 물리차단 모달 계약을 그대로 따른다 — 개폐 훅 중앙
  pause/resume fanout (GRT-058), 모달 중 루프 오디오 정지 (GRT-034),
  재개 시 볼 프리즈·실점 차단.
- **ROUTE_AIM 상태 신설 (2차 리뷰 P1 — 모달 닫힘 = 전면 재개 금지)**: 현행
  물리 게이트는 이진 구조라 모달 블록이 해제되면 일반 전투 업데이트 전체가
  재개된다 (`battle_physics_gate_coordinator.gd:95`). §3.14 흐름을 그 위에
  그대로 얹으면 경로 조준 중 보스 AI·득실점·스킬/아이템 타이머·전투 RNG·루프
  오디오가 함께 재개된다. 신규 flow owner는 최소
  `COMBAT → NODE_MODAL → ROUTE_AIM → MAP_TRANSITION` 상태를 명시하고,
  ROUTE_AIM에서는 선택용 공·표적 충돌·redraw만 실행하며 전투 공·득실점·보스·
  전투 RNG·쿨다운·루프 오디오는 계속 정지를 유지한다. 기존 GRT-034/058은
  완전 정지 모달 계약이지 부분 시뮬레이션 계약이 아니다. 전투 공을 재사용할
  경우 볼 소유권 체크리스트(`docs/godot_port_checklist.md`)를 적용한다.

### 3.15 수호령 귀속 = 런 귀속 확정 + 샘터 스펙 (사용자 확정 2026-08-16)

- **결정: 수호령은 런 귀속이다 (A안 계열).** 현행 코드 계약
  (`lingpet_guardian_run_state.gd:70` `reset_for_new_run()`, `lingpet_save_store.gd:39`
  휘발 스냅샷 삭제)과 방향이 일치하므로 영속 전환 스키마·마이그레이션은 불필요.
  영속으로 남는 것은 도감·최초 발견 기록뿐.
- **친밀도 시스템은 수호령 시스템 개편으로 폐지 (사용자 확정).** 이 문서의 설계는
  친밀도를 어디에도 사용하지 않는다. 코드에 남아 있는 친밀도 잔존분(교감 키,
  affinity 스토어·UI 등)의 정리는 별도 폐지 슬라이스로 진행한다.
- **수호의 샘터 런 내 스펙**:
  - **런 내 최초 방문**: **영혼소환술 획득** (런의 수호령 시스템 진입 획득물).
  - **이후 방문**: **수호령 강화 / 수호령 교체 / 흡수** 수행.
  - **수호령 알**: 전투 중 추가 획득한다. 알이 깨지면 **어떤 수호령인지 정체만
    공개**하고, 교체·유지·흡수 결정은 즉석에서 하지 않는다 (현행 즉석 결정
    제거). 공개된 수호령은 **봉인 상태로 보관**됐다가 **수호의 샘터에서
    교체·유지·흡수를 진행**한다 (사용자 확정 2026-08-16).
  - **캐릭터 정보창 수호령 탭**: 공개된 수호령이 탭에 추가되되 **봉인 상태**로
    표시된다. 봉인은 표시 전용이다 — 컴패니언 런타임(스킬·바디히트·HUD 슬롯)에
    등록되지 않아야 한다 (VISIBLE ≠ LIVE 계열 트랩 주의, GRT-015/016).
- **영속 도감 저장 오너 신설 (3차 리뷰 P1)**: 현행 `collected_pet_ids`는 런
  컬렉션 상태라 새 런에서 초기화되고 (`lingpet_collection_state.gd:37`), 기존
  수호령 저장소는 휘발 런 스냅샷을 영속 저장하지 않으므로
  (`lingpet_save_store.gd:39`) 영속 도감 오너로 쓸 수 없다. **독립
  `guardian_codex_store`** (또는 §3.10 Godot 해금 스토어의 별도 섹션)를 신설한다:
  - 런의 collected/sealed/active 목록과 메타 `first_seen_pet_ids`를 분리.
  - 발견(정체 공개) 이벤트는 멱등 ID를 갖고 **공개 시점 즉시 영속 커밋**
    (런 종료 대기 금지 — 도감 정본 `docs/hwangyeokjeon_codex_design.md` §2.2의
    크래시 세이프 관례 준수). 따라서 **패배 결산에서도 새 발견은 남는다.**
- 런 스냅샷 추가 필드: 영혼소환술 획득 여부, 현재 수호령 상태(강화 포함),
  봉인 수호령 목록(공개된 정체 포함).
- 상세 미결: 영혼소환술의 정확한 내용(첫 수호령 획득 방식·선택지 유무), 봉인
  수호령 보관 상한, 강화·교체·흡수의 수치.

### 3.16 재화 체계 (사용자 확정 2026-08-16)

- **런 내 재화는 골드 + 무혼 2종으로 고정.** 규칙: "몸에 남는 것은 무혼,
  손에 쥐는 것은 골드."
  - **무혼** (전투 수집): 파계승(초식), 수련장(능력치 + 무공 서가), 샘터(수호령
    강화·교체·흡수).
  - **골드** (전리품 — 장식 보너스·처치 보상): 상점 아이템·캡슐 뽑기,
    기회의 보석.
- **환전 금지**: 한 재화로 다른 재화를 사는 경로를 만들지 않는다 (은행 은퇴로
  자연 충족). **제3의 런 재화 금지**. 해금 재화는 런 밖 메타 층으로 별개.
- **골드 소유권 계약 (3차 리뷰 P1)**: 런 골드의 소유자는 **`run_state.gold`**
  이며 저장은 런 스냅샷에만 한다. 현행 `plaza_save_store.add_plaza_gold()`
  (`plaza_save_store.gd:228` — 변경 즉시 영속 `save()`)와 시설 결제 경로는
  재사용 금지. 보석(§3.8)과 동일한 런 간 잔량 누수가 재발한다. 골드 획득·구매는
  `node_resolution_id` 트랜잭션(§3.9)에 포함한다.
- **스타포인트 = "즉시 무공 선택" 의미론만 폐지 (3차 리뷰 P1 정밀화)**:
  `starpoint`는 이미 플레이어에게 진홍 무혼 불꽃으로 표시되는 **호환 런타임
  ID**다 (`common_starpoint_visual_host.gd:3`). 폐지 대상은 수집 →
  `collect_star_points()` → 즉시 무공 선택 모달이라는 **의미론뿐**이다 (§3.7
  전투 중 선택 모달 금지와 충돌). 등정 모드에서 수집량은 `run_state.muhon`으로
  적립한다. `starpoint` 리소스·셰이더·스테이지 훅과 기존 무혼 비주얼
  파이프라인은 호환 ID로 유지·재사용하고 **광범위 리네이밍 금지** (CLAUDE.md
  호환 식별자 계약). 필드 드랍 외 결과 상자·신화 폴백 등 `collect_star_points()`
  **생산자 전체를 감사**한다 (`stage_clear_reward_resolver.gd:423` 등).
  무공 획득은 보상 픽 무공·절세무공 카드(랜덤 후보·무혼 구매) + 수련장 무공
  서가(확정 선택)의 이중 경로로 재편.
- **상점 선반 구성**: 일반 액티브 3~4종 진열(확정 선택) + 전설·신화급 액티브
  독점 고가 슬롯 1개 + 가챠 캡슐 뽑기(구 가챠샵 흡수) + 기회의 보석(고가).
- **액티브 아이템 등급 분리 + 필드 스폰 희소화**:
  - 필드 스폰 = **일반 등급 한정, 판당 기대 0.5~1개** (매 판 나오지 않음).
    무혼이 전투 픽업 질감을 전담하므로 부작용 없음. 스폰 굴림은 기회당 1회
    (GRT-011 준수). 고유 가치 = 즉시성(그 판 투입 가능).
  - **스폰 예산 계약 (3차 리뷰 P2)**: 현행 스케줄러는 20~50초 반복 타이머가
    기회를 만들고 아이템 `chance`는 종류 선택 가중치일 뿐 판당 총량을 제어하지
    않는다 (`active_item_field_spawn_scheduler.gd:6`). 판당 기대치는 **매치
    시작 시 결정되는 `regular_spawn_budget`이 소유**하고 판당 최대 스폰 수를
    캡한다. 수호령·캐릭터 스킬이 생성하는 전용 아이템은 예산에서 제외.
    보석 재도전 시 예산·RNG는 재굴림 (재도전 파밍은 보석 비용이 자연 차단).
    수치는 후속 튜닝이되, 예산 소유자 구조는 rarity 스키마 작업 전에 확정.
  - 보상 픽 액티브 카드 = 일반~희귀 테이블(저확률 신화 잭팟 흡수). 상점 =
    확정 선택 + 전설·신화 독점.
- **재고 현황과 확충 트랙**: 현행 액티브 카탈로그(`active_item_catalog.gd`)는
  빌드 항목 약 34종(필드 스폰 순서 27종)에 rarity 필드가 사실상 없고(플랫
  1등급), 신화 액티브는 대성영단
  1종뿐(스폰 가중 0.001, 챔피언/신화 리그 게이트 — 게이팅 선례로 재사용).
  전설 액티브는 0종. 필요 작업: ① 카탈로그 rarity 스키마 정식화(필드 스폰
  풀·보상 픽 카드 테이블·상점 선반이 같은 필드를 필터), ② 전설·신화 액티브 확충
  콘텐츠 트랙(초기 목표: 전설 3~4종 + 신화 2~3종, 이후 해금 트랙의 간판
  보상으로 성장). 유물(법보) 시스템 신설은 무공(퍽)과 역할 중복이라 보류 —
  무공이 못 하는 규칙 파괴형 콘텐츠(계약형 저주·세트 효과)가 필요해질 때
  재검토.

## 4. 지도 아트 방향 (확정 2026-08-16 · v1.7 페이즈별 보강 2026-08-18)

- 컨셉: **프롤로그(아라울의 첫 승부) 화풍의 연장.** 한지 바탕, 먹선, 주홍·금 팔레트.
  프롤로그 → 지도 → 로딩 방여도가 한 시각 언어로 묶인다.
- **구도 = 아래에서 위로 올라가는 성(v1.7 사용자 확정)**: 지도 화면은 등정
  구도의 성/탑 전경이 세로로 서 있고 노드가 그 위에 얹히는 형태다. 전체화면
  표면(§3.1) 기준으로 설계한다.
- **페이즈별 무대(v1.7)**: 페이즈 1 = 인간계 거대 궁궐(현행 컨셉 유지),
  페이즈 2 = 신선계 — 구름 바다, 절벽, 암석 위 선계 건축. 팔레트·지질 전환으로
  "인간계를 벗어났다"는 고도감을 준다.
- **노드별 그림(v1.7)**: 인장 아이콘에 더해 노드마다 실제 그림(보스/시설
  비주얼)이 붙는다. 실물 반입 전에는 플레이스홀더 슬롯만 구조로 확보.
- 노드 아이콘 = **인장(낙관) 모티프**: 전투=병기 인장, 상점=엽전, 휴식=찻잔,
  파계승=목탁 또는 파계 인장, 광폭화=붉은 귀면 등. 한지 위 붉은 도장은 가독성과
  화풍을 동시에 만족한다.
- 경로 = 붓선 점선. 층 전환 = 먹 농담과 지질(종이 톤) 변화로 고도감 표현.
- ⚠ 기술 주의: 이 화풍은 고휘도(아이보리) 바탕이다. ADD 계열 발광 FX는 밝은
  바탕에서 죽는다 (GRT-047의 역변종, 프롤로그 V4 팔레트 반전에서 실측된 사안).
  노드 강조·광폭화 오라·현재 위치 표시는 먹번짐 애니메이션, 멀티플라이/스크린
  계열, 또는 국소 다크 비네트 위 발광으로 설계할 것.

## 5. 구현 가이드 (Codex 핸드오프)

- **기존 플로우 무손상 개발**: 신규 flow owner 모듈을 기능 플래그 뒤에 만들고,
  광장 R3에서 검증된 원자적 전환 방식으로 프로덕션 승격한다. 결과화면·광장 진입
  루트 제거는 승격 커밋에서 원자적으로 수행한다.
- **1차 수직 슬라이스 권장 범위 (2차 리뷰 승인 범위)**: 기능 플래그 뒤에서
  고정 그래프 + 현행 보스 fixture로 "전투 1회 → 비전투 모달 1회 → ROUTE_AIM
  1회 → 지도 이동" 한 사이클만 관통한다. §3.15 결정, 신규 보스 설계, 지도
  생성기 가중치, 재화 수치는 이 슬라이스의 전제 조건이 아니다.
- `scenes/main.gd`는 오케스트레이션 전용 유지. 신규 오너 모듈의 소유권은
  아키텍처 문서와 모듈 원장에 기록한다.
- **런 스냅샷 (이어하기) 계약 — 필수 필드 (P1 보강)**:
  - `run_id`, 스냅샷 스키마 버전, 지도 생성기 버전
  - 지도: 전체 그래프 직렬화 **또는** 시드 + 결정론적 파생 규칙(생성기 버전
    고정 전제). 어느 쪽인지 구현에서 명시적으로 선택·문서화
  - 진행: 현재 노드, 완료 노드 목록(`node_resolution_id` 포함), 회피(소멸)
    보스 목록, pending 보상
  - 경제: `run_state.gold`, `run_state.muhon`, `run_state.chance_gems`,
    생성된 상점 재고, 구매 기록, `claimed_decoration_ids`
  - 빌드: 무공·초식·액티브 아이템·신화 상태 (현행 런타임 상태의 직렬화 경계 신설)
  - 수호령: 영혼소환술 획득 여부, 현재 수호령 상태(강화 포함), 봉인 수호령 목록 (§3.15)
  - RNG: 게임플레이 RNG 상태 (연출 난수와 분리 계약 준수)
  - **저장 가능 시점 = 노드 커밋 완료 후 안정 경계로 제한** (전투 중·보상 지급
    중 저장 금지)

- 지도 씬은 기존 런타임 계약 준수: 게임 좌표 오버레이 클리핑, 스폰 프레임
  리포지션 글라이드(GRT-039), 모달 개폐 계약(GRT-058), 프리웜(콜드 진입 측정).
