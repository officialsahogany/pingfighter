설계 = Claude / 배선·검증 = Codex.
기준선: `57182ac02` (V3 `f95270ac9` → 모션 `93fe02f6b` → 정리 커밋 체인 위의

## 0. 스코프 — 신규 텍스처 0장 (엄격)

## 1. 절차 레이어 3종

### 1.1 부유 먼지 (전경)
- 20~35개, 독립 RNG + CINEMATIC_ID 해시 고정 시드(캡처 재현성).
- 크기 2~5px@1080, 알파 0.05~0.16, 색 = **온화한 호박색·저채도**(촛불 미광).
  ⚠️**청록 금지** — 청록은 령 전용 시각 어휘다. 먼지가 청록이면 서사 언어가 오염된다.
- 느린 상승 + 수평 드리프트. 촛불 앵커 주변 밀도 가중.
- C1 구간(26.25~29.6)은 밀도 50% 감쇠 — 스파크와 중복돼 소음이 된다.
- MIX 저알파로 충분(ADD 필요 시 별도 CanvasItem — immediate material 스왑 no-op).

### 1.2 촛불 광류
- 플레이트별 촛불 앵커 좌표(상수 또는 매니페스트)에 미세 halo 펄스 + 느린
  수직 일렁임. 반경·알파 소폭(halo 반경 ≤18px@1080, 알파 ≤0.10).
- B 패밀리는 촛불이 원경이라 생략 가능.

### 1.3 전경 차등 이동 (유사 시차의 본체)
- 절차 레이어(먼지·광류)는 **카메라 오프셋 × 1.4~1.7 배율**로 이동.
- 기존 fx 4종은 현행 좌표 유지 + 베이스 팬 대비 소폭 차등(±0.2~0.4%) 허용 —
  단 각 fx의 핸드오프 지점(와이프 완료·광선 인계·령편 도착)에서는 차등 0으로
  수렴해야 베이크드 픽셀과 이음새가 맞는다.
