## ★왜 비반사를 다시 시도하는가

Z9 비교에서 후보 B(비반사 56px)는 "큰 텍스처 위상 단절·왜곡"으로 기각됐다.
**그 기각 사유가 지금은 무효일 수 있다.**

1. 당시 아트는 상·하단에 밝은 gutter(15~26px)가 있었다 → **Z11 이 인접 내부
   복제로 평탄화했다.** 경계 위상 점프가 그때보다 훨씬 약하다.
2. 당시 폭은 56px — 지금은 16px. 단절이 보여도 좁은 디졸브 밴드다.
3. 반사를 쓴 원래 이유가 "가장자리 gutter 를 밟지 않으려 안쪽으로 접기"였다.
   **gutter 가 사라졌으니 반사의 존재 이유도 사라졌다.**
