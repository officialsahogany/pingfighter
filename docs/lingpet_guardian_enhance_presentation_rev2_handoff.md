## 2. P0 결함 조치 (커밋 1 — 아트와 독립, 먼저 간다)

### 2.1 벽시계 쿨다운 누수

**근거**: `runtime_perk_choice_finish_flow.gd:69-71`의 post-choice blocker는
`_has_angel_blessing_post_choice_blocker` **하나만** 등록되어 있다. 수호령강화 컷인은
미등록이므로 `runtime_perk_choice_completion.gd:162`의 `fully_closed` 판정이
**컷인 시작 프레임에 true**가 되어 `_resume_skill_cooldowns_for_choice` +
`_try_arm_resume_safety`가 컷인이 화면에 떠 있는 채로 발동한다. 그동안 물리는
`battle_scene_modal_gate_controller.gd:165`로 계속 차단되므로, **컷인 길이만큼
벽시계 쿨다운·발동창·예약시각이 공짜로 흐른다.**

CLAUDE.md "Godot 물리차단 모달 개폐 계약 트랩"의 교과서 사례다.

**조치 (2경로)**

1. **퍽 경로**: post-choice blocker에 수호령강화 컷인을 등록한다. 천사의 축복 선례
   (`runtime_perk_state.gd:1746` ↔ `runtime_perk_angel_blessing_runtime_state.gd:302`)를
   그대로 복제 — blocker가 살아 있는 동안 choice가 닫히지 않으므로 resume+safety가
   **컷인 종료 시점**에 정확히 1회 발동한다. 순서 위험이 없어 이 방식을 우선한다.
2. **흡수 경로** (`trigger_guardian_enhancement_from_absorption`, `lingpet_egg_runtime.gd:618`):
   choice가 없으므로 blocker가 안 걸린다. 미스틱 다이스 선례
   (`runtime_perk_mystic_dice_runtime_state.gd:185`/`:201`)대로
   `_pause_skill_cooldowns_for_choice` ↔ `_resume_skill_cooldowns_for_choice` +
   `_try_arm_resume_safety` 쌍을 컷인 start/end·cancel에 배선한다.
   - **선행 확인**: 흡수는 오버플로우 선택 오버레이 뒤에 이어지므로, 그 오버레이가
     이미 pause를 소유하고 있는지 먼저 대조하라. 소유하고 있으면 이중 pause가 되지
     않도록 인수인계 지점을 명시할 것.

**주의**: 시각만 밀고 **길이 금지**. 팬아웃은 드라이버
`_pause/_resume_runtime_perk_modal_time` 한 곳이고, 등재는 드라이버 키 목록과
상태의 pause/resume **양쪽** 다 해야 한다(하나만 하면 조용히 no-op).

### 2.2 죽은 오디오 정리 훅

## 4. 연출 기획 (커밋 3~4 — 본체)

### 4.0 미술 방향 — 이 패널에서 임팩트는 "빛"이 아니라 "먹과 인장"이다

기판이 밝은 한지(휘도 ≈0.85)다. 여기에 밝은 플래시를 얹으면 화이트 클리핑으로
형태가 사라진다. CLAUDE.md "VFX 리브랜드 발광 예산 트랩"의 **역방향** 사례다.

- **패널 안쪽 = MIX만.** 임팩트는 진한 먹(어두움)과 주사(붉음)로 준다. 밝은 종이
  위 어두운 획 = 최대 대비. **ADD 금지.**
- **패널 바깥(0.72 검은 베일 위) = 밝은 요소가 유일하게 읽히는 곳.** 금박 림 플레어는
  여기에만 둔다.
- ⚠️ 이 호스트는 배틀씬 단일 Node2D의 immediate `_draw`다. **`canvas.material` 스왑은
  no-op**(CLAUDE.md 트랩 — 픽셀이 자릿수까지 동일했던 실측 사례). 블렌드를 바꾸려면
  자식 `Sprite2D`를 만들어야 하고, 그러면 전역 물리 보간 스폰-글라이드 트랩
  (`physics_interpolation_mode = OFF` 명시)이 따라온다.
  **권장: 자식 노드 없이 immediate draw + MIX만으로 완성한다.** 아래 스펙은 전부
  MIX로 성립하도록 설계했다. status dict에 `blend_mode:"add"` 같은 거짓 계약을 싣지 말 것.

### 4.1 타임라인

현재 2페이즈(ROLL 0.58s → REACTION 시트 1회)를 5페이즈로 확장한다.

| Phase | 길이 | 내용 |
|---|---|---|
| `INTRO` | 0.14s | 베일 α 0→0.72, 패널 scale 0.94→1.00 + α 0→1 (ease-out cubic) |
| `ROLL` | 0.75s | 엔소 붓획 진행 + 후보 아이콘 리일 + 롤 텍스트 |
| `STAMP` | 0.22s | 낙관 도장 착지 + 먹 번짐 방사 + 패널 오버슛 + 림 플레어. 펫은 프레임 0 유지 |
| `REACTION` | 시트 1회 (기본 98f×0.036 = 3.53s) | 리액션 재생 + 결과 문구 확정 표시 |
| `OUTRO` | 0.16s | 역페이드 (패널 scale 1.00→0.97, α→0, 베일 α→0) |

총 ≈ 4.80초 (현재 4.11초). **스킵(클릭/ESC)은 전 페이즈에서 즉시 종료** — OUTRO 중에도.

`STAMP`를 REACTION 앞의 독립 페이즈로 두는 이유: 결과가 먼저 확정되고 **펫이 그
결과에 반응하는** 순서가 되어야 인과가 읽힌다. 지금처럼 동시에 시작하면 리액션이
결과와 무관한 재생으로 보인다.

### 4.2 벽시계 의존 제거 (전제 조건)

현재 `_draw_roll_glow`의 회전·맥동과 롤 텍스트 점 애니메이션이 모두
`Time.get_ticks_msec()`를 읽는다. 그래서 ① 패널이 열릴 때 호의 시작 각도가 매번
다르고 ② 씰이 시각 상태를 결정론적으로 단언할 수 없다.

**전부 페이즈 경과 시간 기반으로 교체한다.** 이건 선택이 아니라 4.5절 씰의 전제다.

### 4.3 ROLL — 엔소를 실시간으로 그린다

핵심 아이디어: 아트에 이미 그려진 붓 원상 위에, 진한 먹획이 **실제로 원을 그려
나간다**. 획이 닫히는 순간이 곧 결과 확정 순간이 된다 — 별도의 신호가 필요 없다.

- `draw_arc`, 반경 = 3.1절 확정 안쪽 링 반경.
- 시작각 `-PI*0.5`(12시), 끝각 = 시작각 + `2PI * ease_out_cubic(roll_progress)`.
- 색 = `INK_COLOR`, α `0.55 → 0.72` (진행에 따라 진해짐).
- 폭 = `4.5 → 2.5` 테이퍼(붓이 빠지는 느낌). `draw_arc`는 폭 애니메이션이 안 되므로
  각도 구간을 4~6분할해 폭을 달리한 호를 이어 그린다.
- 획 **선두**에 붓 눌림 blob: `draw_circle(tip, 3.2, INK α 0.62)`.
- 기존 `_draw_roll_glow`의 폭 1.6px 회전 호 2개는 **삭제**한다(대체 대상).

부수 요소:
- 원상 안쪽으로 먹물이 수렴하는 느낌 — 중심을 향하는 짧은 획 6개, 길이
  `0.06h → 0.01h`, α `0.20 → 0`, ROLL 후반 60%에서만.
- ⚠️ `draw_colored_polygon`을 쓸 경우 `Geometry2D.triangulate_polygon` 가드 필수
  (CLAUDE.md 삼각분할 트랩). 위 스펙은 arc/circle/line만으로 성립하므로 폴리곤을
  쓰지 않는 편이 안전하다.

### 4.4 ROLL — 후보 아이콘 리일

기대감의 실체는 "무엇이 나올지 모른다"를 **보여주는** 것이다. 지금은 그게 없다.

- 위치: 기존 결과 아이콘 앵커 `(0.235w, 0.815h)` 그대로. 아트의 그려진 원 안.
- 롤 중 후보 아이콘이 교체된다. 교체 간격 `0.075s → 0.20s` (ease-out 감속),
  ROLL 종료 시 **실제 결과 아이콘에 정지**.
- α 0.75, 위치 흔들림 없음(정렬 고정 — 흔들면 싸구려로 읽힌다).
- 아이콘 없는 후보(스탯 계열)는 기존 절차적 스탯 심볼(`_draw_result_icon`의
  `kind == "stat"` 분기)을 재사용.

**데이터 배선**: 스냅샷에 `display_candidate_icons: Array[String]` (최대 8개)를 싣는다.
`complete_guardian_enhance_roll`이 이미 결과를 확정한 뒤 호출되므로, 후보 목록은
**표시 전용**이고 결과에 영향을 주지 않는다(3R의 "연출은 표시일 뿐" 계약 유지).

- 소스: `build_guardian_enhance_live_candidates()`의 사전 필터 결과.
- ⚠️ **프리웜된 아이콘만 싣는다.** `has_cached_result_icon()`으로 걸러라. 미캐시
  경로가 리일에 들어가면 프레임마다 파일시스템을 재-stat 한다
  (CLAUDE.md "Missing Reserved-Asset Per-Frame Re-Stat 트랩").
  호스트 `prewarm_assets()`가 이미 전 스킬 아이콘을 캐시하므로 추가 비용은 0에 가깝다.
- 후보가 1개뿐이면 리일 없이 결과 아이콘을 α 램프로만 표시(가짜 긴장 금지).

### 4.5 STAMP — 낙관이 찍힌다

결과 아이콘 배경으로 현재 그려지는 평평한 크림색 원(α 0.44)을 **주사색 낙관**으로
교체하고, 그것이 찍히는 것이 결과 확정 임팩트다. 앵커가 이미 아트에 그려져 있고
결과와 시각적으로 직결되므로 새 자리를 만들 필요가 없다.

- 도장 모션: scale `1.6 → 1.0`, 0.10s, **ease-in 강하게**(가속해서 내리꽂힘).
  착지 프레임에 0.06s 홀드.
- 인장 렌더: `VERMILION_COLOR` 원반 α 0.88 + 안쪽 전각 테두리 2px.
  도장 특유의 거친 가장자리는 알파 노이즈가 아니라 **반경 미세 요철**로
  (`sin(θ*12) * 1.2px`) — 절차적으로 싸게 나오고 종이 질감과 맞는다.
- 착지 후 결과 아이콘이 인장 **위에** 얹힌다(현재 순서 유지).

동시 발생 (전부 STAMP 0.22s 안에):

| 요소 | 스펙 |
|---|---|
| 먹 번짐 방사 | 원상 중심에서 링 1개, 반경 `0.18h → 0.42h`, α `0.34 → 0`, 폭 `3 → 10`, MIX 먹색 |
| 패널 오버슛 | scale `1.03 → 1.00`, 0.14s ease-out |
| 베일 심화 | α `0.72 → 0.80` 0.10s 후 복귀 (시선 집중) |
| 림 플레어 | 패널 경계 4변, 금박 `(0.86, 0.72, 0.38)` α `0.55 → 0`, 폭 `6 → 0`, 0.18s. **패널 바깥에만** |

⚠️ `energy`가 결과에서 0.36으로 **내려가는** 현재 동작은 반드시 뒤집는다. 결과가 피크다.

### 4.6 결과 문구

- STAMP 착지 프레임에 α `0 → 1` (0.08s) + y 오프셋 `+4px → 0`.
- 강조 분절 로직(`_draw_result_feedback`)은 유지. 강조 부분만 착지 후 0.12초 동안
  주사색 → 밝은 주사색 펄스 1회.
- 롤 텍스트("강화 공명 중 …")는 유지하되 점 애니메이션을 `roll_progress` 기반으로.

### 4.7 INTRO / OUTRO

- 패널 스케일은 `_build_panel_rect` 결과 rect를 **중심 기준 lerp**. 이 오버레이는
  히트테스트가 없고 입력이 "스킵" 하나뿐이라
  CLAUDE.md "공유 레이아웃 빌더 요소-추가 트랩"(그린 자리 ≠ 클릭 자리)에 걸리지 않는다.
  단 향후 버튼이 생기면 그 순간 정본 1곳 규칙이 발동하므로 주석으로 남길 것.
- OUTRO 중 스킵 입력은 즉시 종료(대기 없음).
- OUTRO 종료가 곧 모달 해제 시점이다 — 2.1절 resume이 **여기서** 걸려야 한다.

### 4.8 스킵 힌트

STAMP 종료 +0.8초에 편액 우측 하단(노리개 왼쪽 여백)에 작게 표시.
문구는 다국어 7언어 동기화 대상이다(`translate_text()` 관통, 하드코딩 금지).
