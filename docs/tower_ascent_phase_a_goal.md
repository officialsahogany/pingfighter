## 1. 범위 (이 페이즈에서 하는 것)

정본 절 번호 기준. 각 항목 = 독립 커밋 단위 후보.

1. **run_state 정식화** (§3.8, §3.16, §5): `run_id`·스키마 버전·`gold`·`muhon`·
   `chance_gems`를 소유하는 런 상태 모듈과 스냅샷 직렬화. 저장 가능 시점은
   노드 커밋 완료 후 안정 경계로 제한. `phases: []` 배열 전제 유지.
2. **노드 해소 트랜잭션 실전화** (§3.9): 슬라이스의 `node_resolution_id`
   준비/커밋 경계에 실제 보상 지급을 연결. 같은 id 재실행 = 중복 지급 0.
   크래시 재개 시 pending 판별. 보상 복제·소실 둘 다 금지.
3. **기회의 보석 이관** (§3.8): 타워 경로의 패배 흐름이 `run_state.chance_gems`를
   소유(런당 3, 잔량 0 패배 = 런 종료). `plaza_save_store` 보석 경로는 레거시
   (플래그 OFF) 전용으로 보존. 마이그레이션·은퇴는 이 페이즈 범위 아님.
4. **Godot 해금 스토어 신설** (§3.10): `unlocked_items`(Python 전용) 미사용.
   plaza/lingpet save store 관례를 따르는 독립 스토어 + 모든 획득 소비자가
   관통할 단일 필터 함수. 이 페이즈에서는 스토어·필터·소비자 연결까지만
   (해금 재화·단가는 미결 — 기본 전부 해금 상태로 시작).
5. **guardian_codex_store 신설** (§3.15): 런 collected/sealed/active ↔ 메타
   `first_seen_pet_ids` 분리. 발견(정체 공개) = 멱등 ID + **공개 시점 즉시 영속
   커밋** (`docs/hwangyeokjeon_codex_design.md` §2.2 관례). 패배 결산에도 유지.
6. **상자 3종 계약** (§3.6): `chest_normal` / `chest_supreme_art` /
   `chest_secret_chosik`, 수량 항상 1, 위험 = 등급 가중, 비전초식 적격·폴백
   다운시프트. 현행 점수 비례 수량(3/2/1)과 `guaranteed_mythic` 독립 kind는
   **플래그 ON 경로에서만 대체**하고 OFF 레거시는 보존. 승리 점수 파생 임계값
   소비자는 GRT-054 요령으로 감사해 보고서에 목록화.
7. **스타포인트 의미론 전환** (§3.16): 타워 경로에서 수집량을
   `run_state.muhon`으로 적립. `collect_star_points()` **생산자 전수 감사**
   (필드 드랍·결과 상자·신화 폴백 등, `stage_clear_reward_resolver.gd:423` 포함)
   후 목록을 보고서에 기재. `starpoint` 호환 ID·리소스·셰이더·무혼 비주얼
   파이프라인은 유지, **광범위 리네이밍 금지**.
8. **rarity 스키마 정식화** (§3.16): `active_item_catalog.gd`에 등급 필드를
   정식화하고 필드 스폰 풀·상자 테이블·상점 선반이 같은 필드를 필터하는 구조.
   `regular_spawn_budget` 소유 구조(매치 시작 결정·판당 캡·스킬 생성 아이템
   제외·재도전 재굴림)까지. 등급 배정값과 예산 수치는 튜닝 상수(§3).

## 3. 발명 금지 + 명명된 튜닝 상수 규칙

- 정본에 없는 수치가 필요하면 **발명해서 흩뿌리지 말고**
  `godot/scripts/tower_ascent/tower_ascent_tuning.gd` 단일 튜닝 표에
  명명 상수 + 임시값으로 둔다.
- 임시값을 넣은 상수는 **전부** 보고서의 튜닝 표 섹션에 (상수명, 임시값,
  근거 한 줄)로 목록화한다. 목록에 없는 발명값이 코드에 남으면 페이즈 실패다.
- 정본과 코드 현실의 충돌(4차 리뷰감)을 발견하면 그 항목은 구현을 멈추고
  보고서 "설계 충돌" 섹션에 기록한다.

## 4. 검증·커밋 규율

- 항목별 분리 커밋(§1 번호 단위 권장). 커밋마다: 포커스 스모크(+역방향/부정
  레그), 변경 파일 경고 스캔(`-Paths`), 헤드리스 로드, `git diff --check`.
- **플래그 OFF 무손상 레그 필수**: 각 커밋에 OFF 경로가 기존 동작(점수 비례
  상자, plaza 보석, 스타포인트 즉시 선택)을 그대로 보존함을 단언하는 스모크 포함.
- 공유 파일(`battle_scene_match_flow_driver.gd` 등)은 선행 WIP 헝크 제외 +
  **인덱스 트리 격리 워크트리 스모크 증명** 후 커밋 (슬라이스 1 방식 그대로).
- 플레이 중 검증 신정책(`-AllowDuringPlay`·BelowNormal·finally 복구·고유 로그)
  준수. 검증 전 Godot 로그 디렉터리 백업.
- 전체 스캔 베이스라인 RED(선재 WIP 소속)는 분리 보고, 이번 범위 수리 금지.
- 로컬 커밋만. 푸시 금지.
