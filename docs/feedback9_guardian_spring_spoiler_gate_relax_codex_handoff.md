## 요구

### 반드시 보여라

1. **행동 이름** — `손바닥을 대본다` / `기도한다`.
   `action["label"]` 마스킹을 제거하라.
2. **카드 제목** — `choice["name"]` 도 행동을 알 수 있는 문구로.
   `???` 를 그대로 두지 마라.

### 계속 가려라

- 획득할 **수호령의 정체** — 이름·초상·아이콘·레벨·상세 설명
- `hide_hover_detail` 유지

### ★판정해서 보고하라 — 비용 표시

현재 `action["cost_text"] = ""` 로 **비용도 가려진다.**

기도는 방문마다 비용 램프(0 → 2 → 4 무혼)가 붙는다. **비용을 모르면 선택
자체가 불가능하다.** 관제탑 판단으로는 **비용은 보여야 한다.**

다만 X3 원 요구가 "이름·비용·레벨·설명을 가린다" 였으므로 **임의로 바꾸지
말고**, 현재 동작과 권장안을 함께 보고하고 관제탑 판정을 기다려라.
(구현은 비용 표시를 켜는 쪽으로 준비해 두되 플래그로 갈라 두면 좋다.)

### 빈 카드 본문

행동 이름을 되살려도 **본문이 여전히 공백**이다. 캡처에서 카드 절반이
빈 종이로 보인다.

보상 정체를 밝히지 않으면서 무엇을 하는 행동인지 알려주는 **한 줄 설명**을
넣어라. 예시일 뿐 강제가 아니다.

- 손바닥: `바위가 무엇을 내어줄지는 알 수 없습니다`
- 기도: `정성을 들이면 기운이 오릅니다`

⚠**한국어 카피에 엠대시(—)를 쓰지 마라.** 멈춤은 마침표나 쉼표로.

## 부수 관찰 (같은 화면)

### 종료 버튼 문구

하단 버튼이 **`업무 종료`** 다. `KEY_END_WORK` 공용 문구이고 상점에는
어울리지만 **신비로운 샘터에는 어긋난다.**

Y2 가 이미 `KEY_SHOP_EXIT: "상점 나가기"` 로 노드별 종료 문구 패턴을
만들어 두었다. 같은 방식으로 **샘터 전용 종료 문구**를 제안하고 보고하라.
(예: `샘터를 떠난다`) **관제탑 승인 전 다른 노드의 공용 문구를 바꾸지 마라.**

## ★함정

1. **마스킹은 손바닥·기도 카드에만 걸린다.** 실제 수호령 후보 카드는
   `_build_first_pick_actions` 로 그 앞에서 early return 한다.
   **후보 카드 쪽을 건드리지 마라.**
2. `action["id"]` 는 **절대 마스킹하지 마라.** 실행 라우팅이 그것으로 간다.
3. **GRT-031 반쪽 랜딩** — `description_hidden_by_spoiler_gate` 처럼 계산만
   하고 분기에 안 쓰는 값을 만들지 마라.
4. `runtime_perk_overlay_renderer.gd` 는 **공유 파일**이다(보상·퍽·상점).
   샘터 밖 드로우 결과를 바꾸지 마라.
