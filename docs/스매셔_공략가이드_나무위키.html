1. 캐릭터 개요

스매셔는 핑파이터의 기본 캐릭터로, 모든 플레이어가 처음 게임을 시작할 때 사용하게 됩니다. 탁구 라켓과 방패를 들고 있는 외형으로, 공격과 방어를 균형 있게 수행할 수 있습니다.

발토르가 건설과 방어에 특화되어 있고, 코만도가 화기 운용에 특화되어 있다면, 스매셔는 순수한 탁구 기술과 타이밍 기반 공격에 특화되어 있습니다.

💡 스매셔의 핵심 컨셉
• 퍼펙트 타이밍에 맞춰 기술 발동 → 강력한 공 가속 및 커브
• 드라이브, 파워스매싱, 쇼트의 삼각 구조
• 게이지 관리와 타이밍이 핵심

2.2. 기술 조작

조작 기술 발동 조건

💡 퍼펙트 타이밍이란? 공이 패들에 닿기 직전에 특정 키를 입력하면 발동되는 특수 시스템입니다. 화면에 원형 인디케이터가 표시되며, 이 타이밍에 맞춰 기술을 발동할 수 있습니다.

4. 퍼펙트 타이밍 시스템

스매셔의 모든 핵심 기술은 퍼펙트 타이밍에 맞춰 발동됩니다. 공이 패들에 닿기 직전, 화면에 표시되는 원형 인디케이터가 활성화될 때 키를 입력해야 합니다.

공이 접근 → 인디케이터 표시 → 키 입력 → 기술 발동!
입력 키 발동 기술 필요 게이지 효과
A (왼쪽) 왼쪽 드라이브 150 공이 왼쪽으로 커브
D (오른쪽) 오른쪽 드라이브 150 공이 오른쪽으로 커브
마우스 좌클릭 (홀드) 파워스매싱 350 좌클릭 꾹 누른 채 공 접촉 시 발동
W 쇼트 조건부 짧은 드롭샷 + 보너스 윈도우
⚠️ 주의! 퍼펙트 타이밍이 아닐 때 키를 입력하면 일반 히트로 처리됩니다. 게이지가 부족해도 기술이 발동되지 않습니다.

5. 핵심 기술

5.1. 드라이브 (Drive) 🌀

스매셔의 기본 공격 기술입니다. 퍼펙트 타이밍에 A 또는 D 키를 입력하면 발동됩니다.

스펙 수치 비고
소모 게이지 150 발동 시 즉시 소모
기본 커브량 0.25 ball_spin_strength
최대 커브량 0.6 커브 상한
속도 증가 1.5% 드라이브 성공 시
쇼트 카운터 보너스 속도 1.6배 쇼트 후 보너스 적용 시
보너스 추가 커브 +0.36 쇼트 카운터 보너스 시
퍼펙트 타이밍 + A / D = 드라이브 발동!
💡 드라이브 팁: 드라이브로 공을 쳐서 보스에게 맞히면 연두색 공으로 표시됩니다. 공 속도에 비례하여 추가 커브량이 적용됩니다!
🎯 드라이브 발동 꿀팁!
공이 다가오기 살짝 전에 A 또는 D 키와 마우스 좌클릭을 동시에 입력하면 드라이브가 잘 발동됩니다!

⚠️ 주의: A/D 키나 마우스를 연타한다고 발동되는 것이 아닙니다! 타이밍을 맞춰서 입력해야 합니다.
💡 숙련자 팁: 드라이브는 화면에 표시되는 퍼펙트 타이밍 인디케이터에만 의존하기보다는, 직접 발동 타이밍의 감을 익히는 것이 더 중요합니다. 플레이를 반복하면서 자신만의 타이밍을 체득하세요!

5.2. 파워스매싱 (Power Smashing) 💥

스매셔의 필살기입니다. 게이지 350 이상일 때 마우스 좌클릭을 꾹 누르고 있는 상태에서 공에 닿으면 발동합니다.

🎯 파워스매싱 발동법
마우스 좌클릭을 누른 채로 유지하면서 공이 패들에 닿으면 파워스매싱이 발동됩니다!
스펙 수치 비고
필요 게이지 350 발동 조건
소모 게이지 -350 발동 시 소모
최소 각도 25° 수직 발동 방지용 하한
프리즈 시간 1초 발동 시 잠시 정지 연출
부스트 지속 0.5초 초기 가속 시간
플레이어 반동 22프레임 발동 시 뒤로 밀림
쇼트 카운터 보너스 속도 1.5배 쇼트 후 보너스 적용 시
게이지 350 + 좌클릭 홀드 + 공 접촉 = 파워스매싱!
⚡ 파워스매싱 반동: 발동 시 플레이어가 뒤로 밀리며, 반동 종료 후 짧은 스턴이 적용될 수 있습니다. 발동 위치를 잘 선택하세요!

⚠️ 서브 직후 파워스매싱 금지: 서브 후 0.5초 동안은 파워스매싱을 발동할 수 없습니다!

5.3. 쇼트 (Short Shot) 🎯

보스를 넉백시키고 카운터 보너스 윈도우를 활성화하는 기술입니다.

스펙 수치 비고
광채 지속 12프레임 발동 시 빛나는 효과
보스 넉백 24프레임 넉백 지속 시간
넉백 속도 9.0 px/frame 보스 밀리는 속도
보스 스턴 30프레임 넉백 시 스턴 지속
속도 배율 1.3배 발동 시 공 가속
카운터 윈도우 720프레임 (12초) 보스 반격 후 보너스 지속
✨ 쇼트 카운터 시스템: 쇼트로 친 공을 보스가 반격하면, 12초간 드라이브/대시/파워스매싱에 보너스가 적용됩니다!

6. 콤보 시스템

6.1. 쇼트 카운터 보너스

쇼트로 친 공을 보스가 반격하면 카운터 윈도우가 활성화됩니다. 이 동안 기술을 발동하면 추가 보너스가 적용됩니다.

쇼트 발동 → 보스 피격 → 보스 반격 → 카운터 윈도우! → 보너스 기술!
기술 일반 카운터 보너스
드라이브 속도 기본 1.6배
드라이브 커브 0.25 +0.36 추가
대시 속도 기본 1.3배
파워스매싱 속도 기본 1.5배
💡 고급 콤보: 쇼트 → 보스 반격 → 카운터 드라이브로 이어지는 콤보는 매우 강력합니다! 보스의 반격을 유도하여 카운터 윈도우를 활용하세요.
🔥 숙련자 고급 콤보
실력이 늘면 다음과 같은 고급 콤보도 가능합니다:

• 대시 → 드라이브: 대시로 빠르게 위치를 잡은 후 드라이브 발동
• 대시 → 파워스매싱: 대시로 공에 접근 후 바로 파워스매싱으로 결정타

⚠️ 대시와 기술의 타이밍을 맞추는 연습이 필요합니다!

7. 스킬 트리

💡 대쉬 스킬 트리와의 시너지
스매셔는 전용 스킬 트리는 없지만, 대쉬 스킬 트리와 궁합이 매우 좋습니다. 대쉬로 빠르게 위치를 잡고 드라이브나 파워스매싱을 연계하는 플레이가 가능하기 때문입니다.

8. 공략 가이드

8.1. 초보자 필독 팁

  • 퍼펙트 타이밍을 익혀라! - 원형 인디케이터를 주시하세요
  • 드라이브로 시작하라 - 게이지 150으로 발동 가능한 기본기
  • 게이지 350을 모아 파워스매싱 - 결정타로 활용
  • 쇼트 카운터를 활용하라 - 보스 반격 후 보너스를 노려라
🎮 기본기 숙련의 중요성
드라이브와 파워스매싱 모두 패들의 어느 부위에 공이 맞았느냐에 따라 발사 각도가 미세하게 달라집니다.

• 패들 왼쪽에 맞으면 → 왼쪽으로 휘어지는 경향
• 패들 오른쪽에 맞으면 → 오른쪽으로 휘어지는 경향
• 패들 중앙에 맞으면 → 비교적 직선

이 각도 보정 감각은 게임을 많이 해보면서 직접 터득할 수밖에 없습니다. 연습만이 살길!

8.2. 게이지 효율 운용법

1. 공 히트 (80) → 2. 게이지 150 도달 → 3. 드라이브 발동 → 4. 반복

✓ 효율적인 운용

  • 드라이브를 적극 활용
  • 쇼트 카운터 보너스 활용
  • 게이지 350 도달 시 파워스매싱

✗ 비효율적인 운용

  • 퍼펙트 타이밍 무시
  • 게이지만 모으고 사용 안함
  • 쇼트 카운터 윈도우 놓침
