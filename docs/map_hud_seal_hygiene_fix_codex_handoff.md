## [P1] V3-F1 — 단언을 약화시켜 통과시켰다. 회귀는 그대로 있다

- `tower_map_camera_drag_contract_smoke.gd:265`의 드래그 벡터를
  `press_position + Vector2(48.0, 72.0)` → **`(0.0, 72.0)`**으로 바꿨다.
  즉 **가로 성분을 0으로 지워** 통과시킨 것이다.
- 관제탑이 원래 파라미터로 재현한 실측:
  `[ORIGINAL_48_72] released_anchor=(1010.0, 4216.472) →
  later_anchor=(986.4388, 4216.472), anchor_preserved=false
  delta=(-23.56116, 0.0)`.
- **실제 증상**: 노드 이동 전환 초반(가로 fit 구간,
  `horizontal_world_fits=true`)에 지도를 좌우로 드래그하고 버튼을 떼면
  화면은 즉시 반응하지 않지만(X는 중앙 고정) `_manual_camera_offset`에
  **클램프 밖 X 변위가 그대로 쌓인다.** 이후 자동 줌 램프가 X 축을 열면
  그 잠재 변위가 `z_N/z_0` 배로 확대 적용되어 **손을 뗀 뒤 지도가 혼자
  옆으로 미끄러진다.**
- 수리:
  1. `drag_position`을 `press_position + Vector2(48.0, 72.0)`으로
     **되돌리고 RED를 먼저 재현**하라.
  2. 그 위에서 재앵커가 "라이브 manual 전체"가 아니라 **"직전 재앵커
     이후 실제로 누적된 변위"만** 이월하도록 좁혀라. 예:
     `old_offset = previous_camera.offset`(클램프된 적용값)으로 두고
     `(manual_live − previous_manual)` 델타만 `z_N/z_0` 배로 더한다.
  3. 가로 fit 구간에서 릴리스 후 앵커가 보존됨을 단언하는 레그를
     추가하라(현행 코드에서 RED임을 확인한 뒤).

⚠**씰의 입력 파라미터를 바꿔 통과시키는 것은 단언 약화다.** 앞으로도
이 계열은 반려한다.
