## 1. 배경과 확정 방향

전시 플레이테스트에서 유저들이 패시브아이템을 아이템으로 인식하지 못하고 전부
퍽으로 받아들였다. 퍽과 패시브아이템은 "빌드 강화 + 자동 적용"이라는 같은 인지
슬롯을 놓고 획득 방식만 달라, 학습 비용 대비 이득이 낮다.

### 확정된 결정 (회의 + 리뷰 합의)

1. **체제 간소화: 커맨드 스킬 + 퍽 + 액티브아이템 3축.** 패시브아이템 티어는
   플레이어 노출 체계에서 폐지하고 퍽으로 편입한다.
2. **필드에 스폰되는 아이템은 전부 액티브아이템만.** 패시브/신화의 필드 드랍
   제거.
3. **기존 패시브는 퍽으로 치환, 퍽과 옵션이 겹치는 패시브는 삭제.**
4. **중복 퍽 획득 = 레벨업** (기존 Lv.1~5 인프라 재사용).
5. **신화 아이템 = 매우 희귀한 확률로 등장하는 신화퍽 티어로 통합.**
6. **퍽 슬롯 제한(뱀서식 6~7개)은 채택 방향, 개수는 후반 UI/밸런스에서 확정.**
7. **획득 즉시 상시 적용 의미론.** 퍽에는 장착/해제 토글이 없으므로, 기존
   패시브의 "보유 ≠ 장착" 게이트는 치환 시점에 폐기된다. 장착/해제 UI는 제거
   또는 비노출.
8. **유저 노출 개편은 한 릴리즈 안에서 묶는다.** 이름만 퍽이고 획득 방식은
   아이템인 중간 상태를 길게 노출하지 않는다. 최소 묶음 = 치환 분류 적용 +
   상시 적용 의미론 + 장비 UI 비노출 + 획득 연출 분리(퍽/액티브) + 보상 경로
   재정의.
9. **파생 기능: 오버클럭 난이도 스테이지7+ 보스 아이템 사용.** 아이템 풀이
   순수 액티브가 되면 보스가 수류탄(`grenade`)/조명탄(`flare`)/벽돌(`wall`)
   등을 획득·사용하는 기획이 구현 가능해진다 (별도 슬라이스).

## 2. 현재 코드 기준 시스템 스냅샷

- 아이템 카탈로그: `godot/scripts/items/mythic_item_catalog_build_router.gd`
  (49종 빌드) + `mythic_item_catalog_lists.gd` (`FIELD_SPAWN_ORDER` 52엔트리)
  + `mythic_item_catalog_spawn_metadata.gd` (필드 스폰율)
  + `mythic_item_catalog_roll_definitions.gd` (롤옵션 범위)
- 레거시 아이템 카탈로그 티어 실태: `passive`(37종) / `mythic`(12종) /
  신화 액티브(`elixir_of_mastery`) 2.5개 티어다. 이 12는 아이템 카탈로그
  구성 수이며, 아이템이 아닌 live 전환 신화퍽 카탈로그는 후속
  `angel_blessing` 공개 등록까지 포함해 **13종**이다. Python의 legendary
  티어는 Godot에서 이미 mythic으로 흡수됐다.
- 퍽 카탈로그: `godot/scripts/characters/runtime_perk_catalog.gd` —
  COMMON 18종 + SMASHER/VIPER/SOLDIER 트리 + INSTANT 5종 + 골드변환 +
  링펫 게이트 퍽 2종. 선택지 3장(`BASE_CHOICE_COUNT`), 스타포인트 재화 구동.
- 획득 경로 (Godot 현행):
  1. 필드 스폰 — 패시브 0.001~0.008 / 신화 0.00008 가중치
  2. 스테이지클리어 상자 — normal(액티브15/패시브27/스타포인트57/신화1),
     advanced 20%(패시브62/SP2 25/SP3 10/신화3), guaranteed_mythic 1%
     (`stage_clear_reward_resolver.gd`)
  3. 판도라의 유산 — active/passive/mythic 풀 3택
     (`pandora_legacy_pool_builder.gd`)
  4. 플라자 가챠 — **이미 액티브 전용** (신체계 부합, 무변경)
  5. instant 퍽 `보물탐색` — 신화20%/패시브60%/꽝20%

## 3. 퍽 레벨 수치 규칙

롤옵션 밴드(min~max)를 5레벨 선형 스케일로 치환한다.

- **Lv.3 ≈ 현재 롤 기본값(default)** — 기존 평균 체감 유지
- **Lv.1 ≈ 현재 min의 50~70% 수준** — 완만한 시작
- **Lv.5 ≈ 현재 max 이상** — 폐지되는 연마(롤 효율 +60%) 보정분을 흡수
- reverse 옵션(낮을수록 좋음)은 Lv.1이 크고 Lv.5가 작다.
- ★ = 대표 확정 수치 (2026-07-07 지시). 나머지는 이 규칙으로 산출한 제안치.

## 5. 획득 경로 재편 초안 (D3)

### 5-1. 필드 스폰
- `mythic_item_catalog_spawn_metadata.gd`의 FIELD_CHANCES 소비 경로 제거 →
  필드 스폰은 `active_item_catalog.FIELD_SPAWN_ORDER`(27종) 전용.
- 이 정리가 끝나야 오버클럭 S7+ 보스 아이템 획득(§1-9)이 착수 가능.

### 5-2. 스테이지클리어 상자 (`stage_clear_reward_resolver.gd`)
- normal 상자: 액티브15 / **패시브27** / SP57 / 신화1
  → 액티브 20 / **스타포인트 상향 또는 골드 신설** / 신화퍽 카드 1 로 재배분.
- advanced 상자: **패시브62** / SP35 / 신화3
  → 스타포인트·골드·"퍽 즉시선택권(새로고침형)" 재배분.
- guaranteed_mythic 상자(1%): "신화 아이템 확정" → **"신화퍽 확정 선택"** 상자로 전환.
- 핵심: 스타포인트가 이미 퍽 선택 재화이므로, 패시브 가중치를 스타포인트로
  돌리면 "상자 → 퍽"의 자연스러운 다리가 된다. 신규 재화 불필요.

### 5-3. 판도라의 유산 (신화퍽화 후)
- `pandora_legacy_pool_builder.gd`의 passive/mythic 풀 폐기.
- 3택 후보 = 액티브 아이템 / 스타포인트 묶음 / 골드 (매직찬스 롤은
  액티브 등급·수량 상향으로 재해석).

### 5-4. 신화퍽 등장 채널 (신설)
- 퍽 선택 모달에서 초희귀 확률로 신화퍽 카드 등장 (기존 신화 필드드랍
  0.008%의 정신적 계승. 노출 빈도는 밸런스 슬라이스에서 튜닝).
- guaranteed_mythic 상자·보물탐색 성공이 확정 등장 채널.
- 링코어 강화 카드의 force-include tier-taper 패턴
  (`stage_clear`/퍽 오퍼 게이트)이 구현 선례.

### 5-5. instant 퍽 '보물탐색'
- 현행: 신화 아이템 20% / 패시브 아이템 60% / 꽝 20%
  → 신화퍽 카드 20% / 스타포인트+골드 60% / 꽝 20% 로 재정의.
- 보물지도 퍽의 "+신화 3%/Lv" 레인은 신화퍽 카드 확률로 이관 (§6).

### 5-6. 플라자 가챠
- 이미 액티브 전용 (`grant_item_to_slot`). 무변경.

### 5-7. 플라자 상점 (재고 / 구매 / 판매 / 가격)
- 현행: `plaza_shop_stock.gd`가 `MythicItemCatalog.FIELD_SPAWN_ORDER`에서
  passive/legendary 풀을 구축하고, 구매 시 `plaza_scene.gd`가 비액티브를
  `mythic_item_runtime.acquire_item()`으로 장비 인벤토리에 넣는다.
  이 경로를 방치하면 "필드에서는 패시브가 사라졌는데 상점에서는 계속
  패시브 장비를 사고파는" 반쪽 상태가 남는다 — §1-8 한 릴리즈 묶음에 포함.
- 재편안: 상점 재고 = 액티브 아이템 + 소모품(엘릭서류) + 스타포인트 묶음
  (+ 선택: 퍽 리롤권). 패시브/legendary 풀 빌더 폐기.
- 판매(sell) 측: 패시브 인벤토리 판매 경로 제거. 금괴가 4-D(a)안으로
  액티브 소모품화되면 "사용 시 골드"로 대체되므로 판매 UI 의존도 제거.
- 가격 정책: `plaza_shop_pricing.gd`의 legendary 분류(`is_legacy_legendary`)
  기준 가격표를 액티브·소모품 기준으로 재산정.

### 7-2. 런타임 이펙트 모듈
- 효과 로직 자체는 대부분 유지, **게이트만 `is_*_equipped()` → 퍽 레벨 조회로
  전환**: `hermes_shoes_state`, `celestial_armor_state`, `foul_whistle_state`,
  `revival_state`, `baal_boots_*`(4), `horn_strawberry_*`(5+),
  `mythic_item_*_runtime.gd` 대부분, 각 패시브 효과 소비처
- 수치 조회: `mythic_item_roll_query` / `get_legendary_roll_value` 류 →
  퍽 레벨 기반 공용 헬퍼로 통일 (단일 헬퍼 경로 규칙 준수)
- **S1c 소비자 계약 (S1b 확정)**: `perk_conversion_values.get_value()`는 레벨을
  1..max로 clamp하므로 **레벨 0(미보유)에도 Lv.1 값을 반환**한다. 소비자는
  반드시 `get_effective_converted_perk_level()`(base 0 → 0 반환)로 보유 게이트를
  먼저 통과한 뒤 값을 읽는다. 값 헬퍼를 소유 판정에 쓰지 말 것.
- **라이브 전환(플래그 ON) 체크 (배치③a 발견)**: speedgear/gravitybelt의 이동
  특성은 `battle_scene_player_control_config_builder`가 **매치 시작 시 캡처**
  한다. 플래그 ON 라이브 전환 후 매치 중 해당 퍽을 획득하면 control config
  재빌드가 트리거되는지 S2~S5 릴리즈 묶음에서 확인할 것 (미획득→획득 전이가
  기존에는 매치 중 장비 변경으로만 발생했음).
- 유효레벨 체인: sage_ring / transcendent_crown 의 유효레벨 재계산이
  "퍽이 퍽을 버프"하는 구조로 바뀜 — 두 규칙을 코드로 고정:
  (a) 순환 참조 금지 — 초월자의 관·현자의 계약은 자기 자신과 서로를
  버프하지 않음, (b) **신화퍽 전체는 유효레벨 보너스 수혜 대상에서 제외**
  (D5 — max_level 1 퍽의 가짜 Lv.2 기대 금지 규칙)

### 7-3. UI
- 장비 슬롯 패널(`character_info_overlay` 장비 탭, equipment facade,

  (스탯 패널 row budget 트랩 선례)

  퍽 = 퍽 슬롯/카드 영역 안착 + 캐릭터 주변 변화 (신규)

  신화퍽 11종 + 재설계 4종의 번역 키 추가는 S1 필수 항목** (문구 수정 =

## 8. 구현 슬라이스 순서 (유저 노출은 S2~S5를 한 릴리즈로 묶음)

   + **다국어 키 등록(`localize_perk_data` 경로, §7-3)** (게임 규칙 변화 없음,
   내부 이관)

   + **신규 reward type/grant/결과 UI(§7-4 하위 체크리스트)** + **플라자 상점
   재고·구매·판매·가격 재편(§5-7)**

5. **S4 획득 연출** — 액티브 흡입+하트비트 / 퍽 안착 연출 분리
6. **S5 신화퍽 채널 + 세이브 마이그레이션**
7. **S6 QA 게이트** — 스모크 이식·신설, 밸런스 패스(§3 placeholder 수치 확정),
   픽셀 QA

9. **S8 (후속) 오버클럭 S7+ 보스 아이템 사용**
