## 1. 범위 (각 항목 = 독립 로컬 커밋 필수, 푸시 금지)

1. **영속 기록 스토어 신설**: 최고 도달 층, 클리어 횟수, 가짜 엔딩 클리어
   여부, 진엔딩 클리어 여부, 무패 진엔딩 훈장. plaza/lingpet/guardian_codex
   save store 관례(독립 스토어, 이벤트 시점 즉시 `save()` 크래시 세이프,
   스키마 버전). 리그 필드는 상세 미결이므로 **예약 필드만** 두고 소비하지
   않는다.
2. **9층 판정 + 가짜 엔딩 연출**: 정본 §3.9 확정대로 — 진엔딩 판정은 결산보다
   먼저. 첫 클리어(기록 없음) = STANDARD_CLEAR 종결 커밋 → 결산, 결산 직전
   티저 연출 1회("왕의 시련은 아직 끝나지 않았다" 계열 — 한국어 카피,
   엠대시 금지, 로컬라이제이션 키 등재). 판정·연출 실행 여부는 스냅샷에
   저장해 크래시 재개 중복을 막는다.
3. **등정 계속 선택 모달**: 가짜 엔딩 클리어 기록이 있는 런에서 9층 승리 시
   "하산한다(결산 확정) / 더 오른다(비가역, 10층 진입)" 물리차단 모달
   (GRT-058 개폐 계약, §3.14 셸 재사용). 선택 결과 스냅샷 저장. "더 오른다"
   선택 시에만 페이즈 B의 10~12층 route-lock을 해제한다.
4. **런 결산 화면**: 클리어·패배 공통, 미시 루프(노드 사이)에는 결산 없음
   유지. **잃은 것(런 빌드 요약) 아래 영속 소득 병기**: 도감 신규 발견, 기록
   갱신(최고 층·클리어 횟수·훈장), 해금 재화는 미결이므로 표시 슬롯을 만들지
   않는다(도입 시 확장). 기존 defeat_settlement 계열 화면 자산 재사용 우선.
5. **11층 4천왕 연전 구조**: 정본 §3.3 확정 계약 그대로 — 노드 내부 매치
   리셋(액티브 쿨다운 초기화, 신화 스테이지 진행 미증가, 필드 아이템·무공·
   초식·FX 유지), 패배 시 보석 1 소모 후 해당 대전부터 재개, 판 사이 회복·
   중간 상자 없음, 완주 시 상자 1개(위험 가중 최상), `encounter_index`
   스냅샷. 상대 4명은 페이즈 B 레지스트리의 대역(stand-in)을 그대로 쓴다
   (신규 킷 발명 금지).
6. **12층 진엔딩 결산**: 진엔딩 보스(대역) 격파 시 진엔딩 클리어 기록 + 무패
   훈장 판정(런 전체 패배 0회 기준 — 보석 회복과 무관하게 **패배 횟수**로
   판정) + 전용 결산 변형(문구 구분).
7. **Vulkan 픽셀 QA**: 티저 연출, 선택 모달, 클리어 결산, 패배 결산, 연전
   대전 전환, 진엔딩 결산 — 6장 실캡처 + 육안 검수. 아트는 placeholder 유지.

- 공유 파일은 선행 WIP 헝크 제외 + 격리 스테이징 트리 증명.
