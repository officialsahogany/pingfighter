## 3. S2. 스킬 이름 개명안 ★승인 대기

현행 스킬 id 와 표시 이름을 표로 뽑고 **개명안을 제시하라.**

| 보스 | 스킬 id |
|---|---|
| 거미각시 | `web_trap`, `web_rescue` |
| 지굴왕 | `tunnel_raid`, `spinning_claw` |
| 옥토선자 | `mirror_world`, `size_shift`, `rabbit_projectile` |
| 포웅귀 | `cotton_throw`, `cotton_bomb`, `deadly_hug`, `heart_beam` |

- ★**id 는 바꾸지 마라.** 표시 이름만이다.
- 기존 환격전 스킬 이름의 결을 따르라. 참고: 벽력유성, 경신보, 풍운천선무,
  몽환포영, 광맥결, 봉혼궤. **3~5자 한자어 무공 이름**이 기본이다.
- **소재는 유지한다.** 솜은 솜이고 토끼는 토끼다. 억지로 한국식 소재로
  바꿔 정체성을 잃지 마라.
- 제시하고 **멈춰라.** 승인 없이 반영하지 마라.
