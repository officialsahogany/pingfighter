# 지시문 Z15 — 천안결 융합 옵션 재설계 (희귀율 + 개수 가중)

- **발행**: 관제탑 2026-08-29. 기준선 = 본 트리 HEAD.
- **격리 워크트리 + 격리 브랜치.** 본 트리 편집·통합·푸시 금지.
- **분류**: 사용자 확정 밸런스 재설계.

## 사용자 확정 방향

천안결(`dowsing_goggles`)의 **융합(무공 합일) 옵션**을 다음 둘로 바꾼다.

1. **희귀 상승무공 확률 증가**
2. **상승무공이 더 많이(2~3개) 붙을 확률 증가**

⚠**첫 옵션(무공 선택지 보너스 발동 확률 40/70/100%)은 무변.** 사용자가
언급하지 않았다 — 융합 레인만 교체한다.
⚠기존 "발현 확률 +3/6/9%p" 레인은 **제거**된다(두 신규 효과로 대체).

## ★현행 구조 (관제탑 확정 — 재조사 금지)

`perk_fusion_outcome_rules.gd`
- 융합 결과 기본 가중: 성공 20 / 주화입마 10 / **상승무공 70**.
- 발현 시 개수는 `BYPRODUCT_COUNT_{1,2,3}_SHARE = 4/7, 2/7, 1/7` 로 분할.
- 천안결 +%p 는 `byproduct_chance_bonus_percent` 로 총확률에만 가산
  (`build_outcome_weights`). 이중 촉매(+15%p)도 같은 레인 — **이중 촉매는
  무변.**

`perk_fusion_result_builder.gd`
- 희귀 슬롯: `RARE_SLOT_CHANCE_BY_COUNT = {1: 0.15, 2: 0.25}`,
  **`requested_count >= 3` 이면 마지막 슬롯 희귀 확정**.

소비 경로: `runtime_perk_state.get_perk_fusion_byproduct_chance_bonus_percent`
→ `_fusion_runtime_state`. ⚠`PROGRESSIONS` 에 `dowsing_goggles` 레인이
**현재 없다** — 신규 레인 등록 시 개광결(polish) 증폭 대상 여부를 명시적으로
정해야 한다(아래).

## 관제탑 제안값 (잠정 — 착지 시 사용자 조정 가능, 상수로 빼라)

| Lv | 희귀 슬롯 확률 가산 | 개수 가중 시프트 |
|---|---|---|
| 1 | +5%p (1개 15→20%, 2개 25→30%) | 1개 share 에서 6%p 를 2개(+4%p)·3개(+2%p)로 |
| 2 | +10%p (→25% / 35%) | 12%p 이동 (+8 / +4) |
| 3 | +15%p (→30% / 40%) | 18%p 이동 (+12 / +6) |

- 시프트는 **발현 총확률은 불변**, 개수 분포만 옮긴다. 기본 4:2:1 =
  57.1/28.6/14.3% 기준 Lv3 에서 약 39.1/40.6/20.3%.
- **3개 = 희귀 확정 규칙은 유지** — 개수 가중이 곧 두 효과의 시너지가 된다.
- 캡: 희귀 확률 ≤ 60%, 1개 share ≥ 20% (음수·역전 방지). 유효 경지(Lv.5+
  초과 성장) 적용 시에도 캡 안에서 단조 증가해야 한다.

## 요구

1. `build_byproduct_count_weights` 에 시프트 파라미터를, 희귀 슬롯 판정에
   가산 파라미터를 추가하고 천안결 레벨에서 유도하라. 리터럴 금지 — 레벨별
   상수 표.
2. **이중 촉매·기존 발현 +%p 소비 경로와의 상호작용을 정리하라.** 천안결의
   발현 +%p 기여는 제거하되 이중 촉매의 +15%p 는 그대로 동작해야 한다.
3. `PROGRESSIONS` 레인 등록 여부와 **개광결 증폭 대상 여부를 판정해 보고하라.**
   관제탑 견해: 확률 레인이므로 증폭 대상이 자연스럽다 — 단 캡 안에서.
   ⚠GRT-041/Z5 교훈: 등록만 하고 소비 지점이 원시 레벨을 읽으면 무효다.
   **소비 지점이 증폭 값을 읽는지 실측하라.**
4. 카탈로그 설명(KO) 개정 + **7개 지원 언어 동기화**. 엠대시 금지.
   overflow_descriptions 의 천안결 항목도 갱신.
5. 툴팁/도감 등 표기 표면 전수 확인(GRT-024 유형 — 한 표면만 고치고 형제
   표면을 빠뜨리지 마라).

## 씰 요구

1. ★**분포 씰**: 주입 롤로 Lv0/1/2/3 각각 개수 분포·희귀 슬롯 확률을 단언.
   구현이 아니라 **가중치 표 산출값**으로(시뮬레이션 1만 굴림 표를 보고에
   첨부). 구 설계(발현 +%p) 복원 시 RED 반증.
2. **불변 씰**: 발현 총확률이 천안결 레벨과 무관하게 70(+이중촉매)으로
   유지되는지 · 3개=희귀 확정 유지 · 이중 촉매 +15%p 동작 유지.
3. **캡 씰**: 유효 경지 초과 성장에서 캡 준수·단조성.
4. **CI/pre-push 락스텝** — `comm` 대조 사라진 항목 0.
