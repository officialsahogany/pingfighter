## 승인된 계약 (사용자 확정)

> **비전초식을 하나라도 장착한 상태에서 `vision_modifier`(Shift)를
> 홀드하는 동안, 비전 입력 계층이 전투 입력을 독점한다.**

- 부채던지기 발동 = `vision_modifier` 홀드 + **마우스 우클릭**.
- 우클릭이 비어 있지 않다는 감사 결과(벽력유성·월담야습·해동청 홀드·
  백린 탑승·UI 우클릭)를 전제로, **차단으로 해결**한다.

### 차단 범위 (전투 입력만)

- 방향/이동, 공격, 대시, 좌·우클릭, 코만도 홀드 합성 채널, 그리고
  **스냅샷을 거치지 않고 `Input`을 직접 폴링하는 소비자**(백린 탑승
  토글 등)도 명시적으로 차단한다. 프록시가 방향만 지우는 현행
  구현으로는 부족하다.
- 비전 상태들은 **원본 입력을 먼저** 받는다(달지 Up·연묘 Down·
  청린귀 좌→우→좌 커맨드가 정상 동작해야 함). 캐릭터 컨트롤러에는
  지워진 스냅샷을 전달한다.

### 차단하지 않는 것

- ESC·일시정지·메뉴 등 시스템/UI 입력, 지도 오버레이 토글.
- **비전 미장착 시에는 어떤 변화도 없다**(Shift가 아무것도 막지 않음).

### 필수 안전장치

- ⚠GRT-050: 홀드 해제 시 **눌려 있던 버튼이 뒤늦게 just_pressed로
  새면 안 된다** — 차단 중에도 입력 래치를 계속 갱신해 "폐기"
  의미론을 명시(유예 금지). 계약을 코드 주석에 문장으로 남길 것.
- ⚠GRT-019: 공유 스테이트풀 입력 리더의 스냅샷은 프레임당 멱등이어야
  한다 — 비전 계층이 에지를 먼저 소비해 청린귀 커맨드가 굶지 않도록
  단일 스냅샷을 공유하고, 추가 소비자를 만들지 말 것.
- 코만도 홀드: 차단 중 홀드가 끊긴 것으로 보여 **해제 액션이 오발동
  하면 안 된다** — 홀드 상태를 동결하거나 해제 에지를 억제.
- 청린귀와 동시 보유 시 게이지 잠식 금지(Q4-수정 P0 원안):
  우클릭 발동이 청린귀 커맨드 상태를 건드리지 않을 것.

## 씰 (전부 실 입력 경로 관통)

1. **소비자별 음성 레그**: Shift 홀드 중 우클릭에 스매셔 벽력유성·
   바이퍼 월담야습·코만도 해동청·백린 탑승이 **각각 0회 발동**.
2. **양성 레그**: 같은 입력으로 부채던지기 1회 발동(기력 −80·쿨 5초).
3. **기존 비전 무회귀**: 달지/연묘/청린귀가 Shift+방향으로 정상 발동,
   청린귀 3연 커맨드 완주.
4. **해제 누출 레그**: 우클릭을 누른 채 Shift를 놓아도 벽력유성 등이
   지연 발동하지 않음(폐기 의미론) + RED 반증(래치 갱신 제거 시 발동).
5. **미장착 레그**: 비전 0개일 때 Shift+우클릭이 기존대로 벽력유성을
   발동(계층 미개입).
6. **UI 레그**: 일시정지·캐릭터 정보창 우클릭 동작 불변.
7. 현행 코드가 1·4번에서 RED임을 먼저 확인(반증 선행).
