## 실측 확정 (관제탑 프로브)

**행을 추가하지 않고 가능하다.** T3가 만든 2~8층 3행 7노드(레인 1→2→4)
구조는 관문 1행 + NPC 2행이고, `_build_partial_row_edges`가 만드는 배치가
유일하다(gate→{a0,a1}, a0→{b0,b1}, a1→{b2,b3}). 따라서 **"NPC 행마다 정확히
1마리"** 규칙만 지키면 관문 1 + 추가 2 = **3마리**가 정확히 들어가고, 두
보스를 동시에 피하는 우회로가 **구조적으로 보장**된다.

- 보스 비율 0.206 → **0.238**(상한 0.38, 여유 충분)
- NPC:보스 3.85 → **3.20**(하한 1.65, 여유 충분)
- 보스 간격 계약은 `optional_extra_boss`가 이미 면제 대상이라 위반 없음
- 4~8층은 셸 스탠드인이 같은 키로 접혀 **풀 유도 규칙만으로 자동 0마리** →
  "보류" 요구와 자동으로 일치

⚠★**1층식 확장행 복제는 금지다.** 그 방식은 행 8개를 추가해 지도 드로우콜
예산(현재 최악 1533/1536, **여유 3**)을 깬다. 이것이 아래 안을 택하는
결정적 근거다.

## 작업 A — 생성기 (변경 3곳, 전부 `tower_ascent_boss_registry.gd`)

1. **층당 최대치 1 → 2**: `TEMP_OPTIONAL_EXTRA_BOSS_MAX_PER_FLOOR`.
2. **확률 게이트 → 풀 유도 보장**: 현재 `..._SPAWN_CHANCE_PER_FLOOR = 0.45`
   확률 굴림이라 2·3층도 시드의 절반에서만 나온다. 1층이 쓰는 방식
   (`_floor_one_optional_encounter_enabled`는 rng를 쓰지 않고 **보스 풀
   크기에서 순수 유도**)으로 바꿔라. 그러면 변형이 3종 살아 있는 층은
   항상 3마리, 1종뿐인 4~8층은 항상 1마리가 된다.
3. **행당 1마리 가드**: 한 NPC 행에 두 마리가 몰리면 우회로가 사라진다.
   `_assign_optional_extra_bosses`에 행 단위 상한을 명시하라.

⚠**보스 간격·도달성·우회 경로 검증기를 전부 통과**해야 한다. 특히
`_has_entry_to_terminal_path_avoiding_node`가 각 추가 보스에 대해 성립하는지
확인하라.

  따르되, **기존 2층 카드의 팔레트·프레임·먹선 계열을 맞춰라.** 청린귀
  카드와 나란히 놓았을 때 이질적이면 반려한다.
