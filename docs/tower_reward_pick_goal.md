# 승리 보상 픽 개편 /goal 지시문 (2026-08-18)

- **정본**: `docs/tower_ascent_run_map_plan.md` **v1.8 §3.6** (보상 픽 계약 —
  상자 은퇴). 연쇄 개정된 §2 핵심 루프·§3.2·§3.3·§3.10·§3.11·§3.14·§3.16도
  함께 읽을 것. 전부 사용자 확정 계약이다.
- **목적**: 탑 모드 전투 승리 보상을 상자에서 **보상 픽 화면**(새 카드 4장,
  화면 안 무리롤 소진, 무혼 구매)으로 교체한다.
- **완료 보고**: `docs/tower_reward_pick_report.md`. 푸시 금지.

## 1. 작업 항목 (각각 독립 커밋)

1. **보상 픽 화면 신설 + 흐름 재배선**: 탑 모드 승리 흐름을
   `하이라이트 리플레이 → 보상 픽 → 경로 서브`로 바꾸고 상자 단계를 제거한다.
   픽 화면 = 물리차단 모달 계약(GRT-058). 픽 구매·확정은 §3.9
   `node_resolution_id` 멱등 트랜잭션에 귀속(픽 커밋 후 서브).
2. **카드 규칙**: 매 화면 완전히 새로운 4장(이월 없음). 구매 시 리롤 없이
   나머지가 남고 무혼이 허용하는 한 추가 구매 가능(상한 = 잔고). 계속하기로
   떠나면 잔여 카드 폐기. 카드 종류·가격·등장 규칙은 §3.6 표 그대로, 수치는
   전부 `TEMP_*` 상수. ⚠ 가격 단위는 사용자 화법 기준 "무혼 N개"(픽업 개수
   감각)다 — 내부 무혼 스케일이 다르면 TEMP 환산 계수로 맞추고 보고서에
   환산 근거를 명시하라(발명 금지, 판정 불가 시 중단·보고).
3. **절세무공 전용 창 은퇴**: "절세무공 등장 시 전용 3장 창"을 탑 픽에서
   제거하고 일반 풀 저확률(TEMP) 카드 등장으로 교체. 전용 창 소비자·씰을
   전수 감사해 락스텝 개정한다.
4. **비전초식 = 확정 1장 + 런 소멸**: 상자 `boss_vision_offer_id` 치환 로직을
   은퇴하고, 적격 보스(해당 초식 미보유) 클리어 **직후 화면에만** 비전초식
   카드가 4장 중 1장으로 확정 등장한다(무혼 3). 그 화면에서 구매하지 않으면
   **그 런에서 재등장하지 않는다** — 소멸 상태를 런 스냅샷에 저장하고 재등장
   금지를 씰로 봉인(부정 레그: 미구매 후 다음 전투 픽에 부재).
5. **상자 시스템 은퇴 감사**: 탑 모드에서 승리 상자 UI·지급 경로를 제거하고,
   `guaranteed_mythic` 3% 잭팟은 액티브 카드의 저확률 신화 등급 등장으로
   흡수한다(§3.16 2재화: 액티브 카드 가격 = 골드). 점수 비례 수량 등 승리
   점수 파생 임계값 소비자를 GRT-054 요령으로 전수 감사. 위험 프리미엄
   (정예·광폭화·수문장·층)은 카드 등급 가중 상향으로 이관.
6. **UI**: 기존 선택지 카드 UI를 4장으로 확장 재사용. 잔여 카드 유지 상태의
   렌더와 히트테스트 정합(GRT-022 — 그린 자리≠클릭 자리, 반증은 상단 모서리),
   가격 표기·무혼 부족 시 구매 불가 상태 표기, 카피는 한국어 기본 + 로컬라이
   제이션 키 등재(엠대시 금지).

## 2. 규율

- 로그 백업 선행. 표준 래퍼 `-AllowDuringPlay` 계약. 커밋 분리·푸시 금지.
- 플래그 OFF 레거시(상자·기존 오퍼 창 포함) 무손상 부정 레그 필수.
- 검증: 픽 씰(무리롤 소진·다중 구매·잔여 폐기·비전초식 확정 등장과 런 소멸·
  절세 저확률 등장·상자 부재) + 타워 회귀 세트 + `-Paths` 경고 + 헤드리스 +
  Vulkan 캡처 2장 이상(픽 화면 4장 / 비전초식 카드 등장 화면) +
  `run_tower_mode.ps1` 실플레이 재현.
- 판정 불가 지점이 나오면 중단·보고.

**완료 선언 조건**: §1의 6항목 구현·검증 + 게이트 blocked/unverified 0건 +
보고서 완성.
