작성 2026-06-12. 상태(2026-06-13 종결): **파일럿 완료 — 기술 파이프라인 검증

## 0. 프레이밍 — 3D화 프로젝트가 아니라 "시트 교체 실험"

- 목표: 3D 모델을 현재 게임 카메라 각도에서 베이크한 시트가 인게임에서
  "입체감이 먹히는지"만 검증한다. 실패하면 시트 파일만 빼면 되고,
  성공하면 캐릭터별 점진 적용한다. 실시간 3D(경로 B)는 본 파일럿 범위 밖.
- 범위: **스매셔(미카) 1명. idle + walk L/R + 대표 공격 1개(left 오버헤드
  스윙)만.** dash / victory / defeat / wheel / 스킬 컷인은 2D 유지를 명시
  선언하고 파일럿 평가 항목에서 제외한다.
- 미적 판정 우선순위 (사용자 확정): 예쁘다보다 먼저 —
  1. 공 위치 가독성이 안 떨어지는가
  2. 캐릭터 방향이 헷갈리지 않는가
  3. 작은 화면에서도 실루엣이 사는가
  4. 현재 2D VFX와 어색하게 따로 놀지 않는가
- 분담: 자산 제작·QA·계획 = Claude. **실험 토글 GDScript 배선 = 사용자**
  (§5 배선 브리프 참조). 셰이더로 흉내내는 가짜 2.5D는 기검증 폐기
  (2026-05-24~25 3회 실패) — 재시도 금지.

## 4. VFX 공존 제약 (시트 교체 시 확인 대상)

- **대시 잔상이 walk 시트 셀을 직접 샘플** (`stage1_playfield_renderer.gd:982-1008`)
  — 그리드 동일 유지로 안전하나, 교체 후 잔상 인게임 확인 필수 (상태
  스모크로 안 잡힘).
- 글리치/홀로그램 패스는 현재 source_rect 재샘플 — 그리드 맞으면 안전.
- 상태 글로우는 "바디가 셀 하단 중앙" 가정 (`player_state_glow_renderer.gd:43-49`)
  — 바디 점유율 유지로 안전, 어긋나면 재튠.
- 커스터마이징 오버레이는 베이스와 프레임 단위 포즈 페어링 — 스매셔 상시
  슬롯은 현재 없음(디버그 paddle만), 파일럿에선 비활성으로 두면 무관.
- 파워스매시/고스트샷/워프/그림자는 공·패들 rect 기반 — 안전.
- 전투 외 표면(캐릭선택/결과/컷인)은 전부 별도 경로 — battle_resources
  상수 경로 변경 방식이면 새지 않음.

## 5.1 토글 배선 적대적 리뷰 판정 (2026-06-12, 자산 랜딩 전 필독)

배선 자체(오버라이드 모듈·게터 단일화·2레인+제3 하베스트 레인·idle alias
쌍·all-or-nothing 게이트·attack-right 2D 유지·타 캐릭터 무영향)는 **차단급
결함 없음**. 단:

- **[차단급-확정] 스모크 케이스 2 시한폭탄**: `smasher_25d_sheet_override_smoke.gd:44`
  케이스가 "자산 부재" 전제로 env=1 + 2D 폴백을 단언 → 실 PNG+.import가
  임포트되는 순간 최소 5개 단언이 결정론적 실패. **자산 커밋과 같은 턴에
  이 케이스를 3/4 부분-자산 케이스로 재작성해야 함** (placeholder 3종만
  `store_texture` → 비활성+4키 전부 2D 단언; all-or-nothing 봉인까지 한 수에
  해결). pre-push focused 5종에는 미포함이라 푸시는 안 막히지만 풀 스위트가
  적색이 됨.
- **[권고] 프로브-로더 비대칭**: 가용성 프로브는 imported-전용
  (`texture_resource_exists`), 실로더는 raw-first. raw PNG만 드롭하고 에디터
  임포트를 안 거치면 토글을 켜도 조용히 2D 유지(헤드리스/클린클론 포함).
  최소 수정 = `_is_sheet_path_available`에 `FileAccess.file_exists` 추가,
  또는 ".import 동반 커밋" 핀 유지.
