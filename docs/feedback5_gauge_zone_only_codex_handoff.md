## 사용자 확정 룩 (레퍼런스 필수)

정본: `docs/reference_art/training_gauge_zone_only_reference_20260825.png`.

1. **틱(눈금) 기둥 전면 제거** — 게이지 박스 위아래를 뚫고 나오는
   바늘형 마커가 싫다는 판정. K에서 만든 적1+청4 틱 시스템(적/청 틱
   텍스처·폭 상한·레이아웃 헬퍼)을 은퇴시킨다.
2. 판정 구간은 **트랙 내부의 평평한 색 블록만**으로: 청-적-청 3블록,
   프레임 밖 돌출 0(레퍼런스처럼 트랙 높이에 정확히 맞춤).
3. 중앙 추(pendulum 포인터)는 승인 아트 그대로 **유지** — 이동
   인디케이터는 필요하다. 제거 대상은 고정 눈금뿐.
4. **구간 폭 개정**: 회심(적) 가로 +50% = 기본 2%→**3%**, 훌륭(청)
   각각 −50% = 4%→**2%**(합계 3+2+2=7%). 럭 스케일 규칙(회심
   1~8% 클램프·훌륭=회심×2)은 **비례 유지**할지 상수 재정의할지 —
   현행 GREAT_CELL_MULTIPLIER 2.0을 회심 3% 기준 2/3≈0.667로 바꿔야
   "각 2%"가 성립. 정책 상수 정본(tower_training_timing_judgment_
   policy)에서 개정하고 파생 소비자(상태 모델·렌더러) 락스텝.
