# 지시문 Z13 — 밴드 아트를 세로 타일러블로 만들고 이음매 phase 를 없애라

- **발행**: 관제탑 2026-08-29. 기준선 = 본 트리 HEAD.
- **격리 워크트리 + 격리 브랜치.** 본 트리 편집·통합·푸시 금지.
- **적합 세션**: Z8~Z12 세션. **선행**: Z11(edge-bleed 스크립트 재사용).

## 판정 경위 (합의된 사실)

- A(반사 16px): gutter 0 이지만 **라이브 영상에서 mirror fold 확인** — 승인 불가.
- B(비반사 16px): mirror 감소하나 **entry 가 16px 전진 후 body 첫 텍셀로
  되감기며 jump 16.86** — 불채택.
- ★사용자 영상의 접힘 위치 = 하단 논밭·하천 문양 = **river 밴드의 같은-아트
  세로 반복 구간.** 이것이 표적이다.

## ★재설계 — 크로스페이드를 없애는 것이 정답이다

같은 아트가 세로로 반복될 때 이음매가 필요한 이유는 **아트 하단 ≠ 아트
상단**이기 때문이다. 그렇다면:

### 1. 아트를 세로 타일러블로 (오프라인)

Z11 의 `tools/art/bleed_tower_map_band_edges.py` 를 확장해 밴드 6종의
**상단 밴드와 하단 밴드를 서로 랩-블렌드**하라 — `art[하단 k px]` 가
`art[상단 k px]` 로 자연스럽게 이어지게. 작업 영역은 Z11 이 이미 합성으로
채운 가장자리 밴드(15~26px)이므로 **원본 아트 본체는 여전히 무접촉**이다.

- 내부 RGB SHA 전후 동일 증명(작업 밴드 제외)·매니페스트 갱신·재현 가능.
- **타일러블 지표**: `|art[0..k] − art[H−k..H]|` 평균차를 재고 임계 이하로.

### 2. 렌더러 — 같은-아트 청크 접합은 phase 없이 맞대기

아트가 타일러블이면 같은-아트 청크는 **entry/tail/반사/크로스페이드 전부
불필요**하다. 맞대기(butt joint)로 그려라. mirror fold 는 원리적으로 소멸.

### 3. 다른-아트 경계(층 아트 교체)만 최소 디졸브

asset_key 가 바뀌는 접합만 16px **비반사 순방향** 디졸브를 유지하되,
★**B 의 되감김 단차를 이렇게 고쳐라**: entry 밴드가 다음 아트의 [0..r]
행을 페이드 인했으면 **body 는 r 행부터 이어서** 샘플한다(0 부터 다시
그리지 않는다). C0 연속 — 같은 행을 두 번 그리는 되감김이 단차의 원인
이었다. 양쪽 가장자리가 이제 저디테일 랩-블렌드 밴드이므로 고스트도
미미할 것이다.

## 판정 기준 (셋 동시 충족)

1. **mirror correlation** — 같은-아트 접합에서 무의미 수준(맞대기이므로
   측정 자체가 배경 자기유사 수준이어야 한다).
2. **hard jump ≤ 현행 A(0.00 동급)** — 같은-아트 맞대기·다른-아트 디졸브 모두.
3. **gutter 0px 유지.**
+ 라이브 줌(~2.1x) 이동 재현 캡처에서 접힘 육안 소멸.
