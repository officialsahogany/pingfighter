# 스매셔 착석 라이더(N) 시트 브리프 — S3-b, 1종 선행

작성 2026-08-14. 정본 계약 = `docs/lingpet_topdown_mount_render_contract.md`
(§A-2 N 소유 위치 · §B-3 배치식 · §C-3b 파츠·글로우 이월) +
`docs/lingpet_baekrin_mount_base_asset_brief.md` §2-3(운영 확정값).

이 문서는 **스매셔 1종만** 제작하기 위한 계약이다. 계약 §9 순서:
1. 스매셔 N 1종 → 2. 테스트 오버라이드로 P1~P18 프로토타입 통과 →
3. 나머지 4캐릭터 N → 4. **5종 완비 후에만** `mount_presentation_model: "topdown"` 등재.

역할 분담: 이 문서(정체성 락·구도·수용 게이트)와 누끼/게이트 판정은 Claude,
AutoSprite 실제 생성·에셋 배치·인게임 검증은 구현 에이전트가 이어받는다.
`.claude/skills/sprite-generation/SKILL.md` **precise** 모드 절차를 따른다.

## 1. 규격 (고정)

| 항목 | 값 |
|---|---|
| 소스 시트 | **512×512**, 그리드 **1×1**, `frame_count` **1**(정지 착석 포즈) |
| 운영 draw size | **94** — 소스 크기가 아니다. 카탈로그 `player_mount_rider_sprite_catalog.gd` RIDERS.smasher.draw_size |
| 좌석선(소스 좌표) | 셀 중심 **x = 256**, 기하학적 **y = 460.61702** ( = 512 − 51.38298 ) |
| 좌석선 허용 | 소스 측은 **최근접 픽셀 반올림 허용**(461). 최종 정본은 **운영 합성 오차 ≤ 2px** |
| 텍스처 캐시 키 | `player_mount_rider_seated_smasher` (`PlayerMountRiderSpriteCatalog.get_texture_cache_key`) |
| 자산 성격 | **runtime-only auxiliary · non-anchor** |
| 필수 산출물 | 시트 PNG · **`*_seat_contact_mask.png`**(동일 512×512, 착석 접촉선 픽셀만 255) · 매니페스트 · 밝은/어두운/94px 캡처 |

좌석선의 의미: N 셀의 **하단 모서리**가 M 안장 어셈블리 하단(금 프레임 밑단) =
라이더 rect 하단 = 화면 y **762** 에 정렬된다. 캐릭터의 **엉덩이선(착석 접촉선)** 은
셀 하단이 아니라 그보다 위 — 소스 512 좌표로 **y = 460.61702**, 운영 환산
**9.43359375px** 위 — 에 와야 한다.

⚠️ 흔한 오용: 512 소스에 운영값 9.43 을 그대로 쓰면 5배 넘게 어긋난다.
소스 저작에는 **51.38298**(= 셀 하단에서 위로) 만 쓴다.

### 1-1. 좌석선은 PNG 만으로 자동 검출되지 않는다 — 마스크가 산출물이다

해부학적 엉덩이선(착석 접촉선)을 알파/색에서 기계적으로 찾아낼 규칙은 없다. 그래서
좌석선은 **사람이 지정하고 기계가 확인**하는 구조로 둔다:

- 저작자가 **`*_seat_contact_mask.png`**(시트와 동일 512×512, 접촉선 픽셀만 255)를
  함께 제출한다. 접촉선 = 캐릭터의 엉덩이·허벅지 아래면이 안장에 닿는 띠.
- 검증기는 그 마스크에서 **가로 중앙(x)** 과 **최하단 행(y)** 을 뽑아 계약값
  (256 / 461)과 비교한다 → 여기까지가 기계 확인이다.
- 마스크가 없으면 N2 는 **판정 불가 = FAIL**(육안으로 "대충 맞다"는 통과 근거가
  될 수 없다).

### 2-1. 목운/구름 제외 — 착석 N 한정 예외

탑승 상태에서는 **M(백린)이 이동 기반을 대체**하므로 스매셔의 목운(구름) 이동
요소는 착석 N 에 **그리지 않는다**(구름 픽셀 0).

⚠️ 이 예외는 **착석 N 에만** 유효하다. 일반 스매셔의 정체성 정본(구름 포함)으로
역전파 금지 — walk/idle/attack 계열은 계속 구름을 갖는다.

### 2-2. 이월(의도적 미적용)

`§C-3b`: 착석 프레임의 **장착 파츠·소켓 글로우 0건**. S3 범위 밖이며 씰이 이를
계약으로 단언한다.

| N1 | 규격 | 512×512 · 1×1 · `frame_count` 1 · 운영 draw 94 |
| N2 | 좌석선 | **제출된 `*_seat_contact_mask.png`** 에서 가로 중앙 x = 256(±2), 최하단 행 y = 461(±2, 기하값 460.61702 의 최근접 픽셀). 마스크 미제출 = FAIL. 최종 정본은 **운영 합성 캡처의 안장 오차 ≤2px** |

| N6b | 팔레트(기계) | 5재질 각각 **중심 이동 dE2000 ≤ 2.5** + **최소 점유율**(§3-1 고정표). 후보를 보고 술어·표본을 정하는 것은 금지 — 아래 값은 **생성 전 확정** |

| 방식 | 게이트 |
|---|---|
| **기계 측정** | N1(규격) · N2(제출 마스크 좌표) · N5(구름·백린 픽셀 카운트) · N6b(팔레트 dE·점유율) · N7(4변 알파·코너) |
| **육안(대조군 비교)** | N3(시점) · N4(소품·미러) · N6(정체성) · N8(프린지) · N9(94px 판독) |

⚠️ N8·N9 를 "기계 측정"으로 적으면 수치 술어가 없는데 통과했다고 주장하게 된다.
필요해지면 술어를 **먼저** 정의하고 그때 승격한다.

### 3-1. N6b 팔레트 hard gate — 생성 전 확정값

레퍼런스 = 승인 idle 시트 프레임 0(160×160 셀), **구름 제외**(y < 96), α > 200.
마스크 술어는 **위치와 무관한 색 술어**라 착석 포즈에도 그대로 적용된다(후보에는
구름이 없어 y 컷도 필요 없다).

```
mx, mn  = 채널 최대/최소 ;  chroma = mx - mn ;  L = CIELAB L*
red     = r > g+40 ∧ r > b+25 ∧ r >= 90
cream   = mx >= 190 ∧ chroma <= 45
indigo  = b > r+8 ∧ b >= 40 ∧ ¬cream
brown   = r > b+20 ∧ chroma >= 25 ∧ ¬red
  wood_shield    = brown ∧ L < 36
  bronze_beopgu  = brown ∧ L >= 36
```

| 재질 | 레퍼런스 중심 Lab | 레퍼런스 점유율 | **최소 점유율(=30%)** |
|---|---|---|---|
| indigo_hair_dress | (22.0, 7.4, −15.8) | 55.86% | **≥ 16.76%** |
| cream_sleeve | (87.9, 2.2, 4.3) | 5.40% | **≥ 1.62%** |
| red_accent | (32.0, 20.8, 13.3) | 9.22% | **≥ 2.77%** |
| wood_shield | (24.3, 14.4, 10.5) | 8.28% | **≥ 2.49%** |
| bronze_beopgu | (47.9, 8.2, 15.6) | 11.98% | **≥ 3.59%** |

- 판정: 각 재질의 후보 픽셀 **중앙 Lab** 이 위 중심과 **dE2000 ≤ 2.5**, 그리고
  점유율이 최소선 이상.
- ⚠️ **머리와 복식 본체는 색으로 분리되지 않는다**(둘 다 같은 인디고 계열,
  중심 간 dE < 3). 그래서 한 재질 `indigo_hair_dress` 로 묶었다 — 머리와 복식을
  따로 재는 것처럼 적으면 거짓 정밀도다.
- 중심 간 최소 분리도는 red_accent ↔ wood_shield 의 **dE 7.1** 이다(모두 ≥6).
- 산포(자기중앙 p95)는 red 44.9 · bronze 30.6 처럼 크다(AA 혼합 픽셀 포함) — 그래서
  산포 축은 게이트에 넣지 않고 **중심 이동 + 점유율**만 본다.

## 4. 착수 순서

1. AutoSprite 1회차 — 위 앵커에서 착석 포즈 생성(`removeBg: "ultra"`).
2. 게이트 N1~N10 판정 + 밝은/어두운/94px 캡처 제출.
3. **후보 1장 승인 후에만** 경로 배선(`RIDERS.smasher.path`) → 테스트 오버라이드로
   **P1~P18 프로토타입** 수행(§7).
4. 그전에는 `mount_presentation_model` **미등재**와 **나머지 4종 생성 보류** 유지.

⚠️ 승인 전에는 `RIDERS.smasher.path` 를 **빈 문자열로 유지**한다. 근거는
**미승인 자산이 production-ready 캐시에 들어가거나 스매셔 준비도가 양성으로
오인되는 것을 막기 위함**이다(§A-4 fail-closed).

정정: "경로를 채우면 P18 대조군이 오염된다"는 **틀린 설명이었다**. 온이마루는
`mount_presentation_model != "topdown"` 이라 탑다운 준비도 경로에 애초에 진입하지
않는다 — **P18 온이마루 대조군은 모델 분기상 독립**이며 N 경로 상태와 무관하다.
