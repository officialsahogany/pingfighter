좌석선의 의미: N 셀의 **하단 모서리**가 M 안장 어셈블리 하단(금 프레임 밑단) =
라이더 rect 하단 = 화면 y **762** 에 정렬된다. 캐릭터의 **엉덩이선(착석 접촉선)** 은
셀 하단이 아니라 그보다 위 — 운영 환산 **9.43359375px**, 스매셔 draw 160 기준
소스 512 좌표로 **y = 481.8125** — 에 와야 한다.

⚠️ 흔한 오용 ①: 512 소스에 운영값 9.43 을 그대로 쓰면 3배 넘게 어긋난다.
⚠️ 흔한 오용 ②: **저작 오프셋은 draw 마다 달라진다** — `9.43359375 × 512/draw`.
draw 94 시절의 51.38298 을 draw 160 에 그대로 쓰면 21px 어긋난다. 스매셔는
**30.1875**(= 셀 하단에서 위로) 하나만 쓴다.

### 1-0. draw_size 는 **셀**이지 캐릭터 크기가 아니다

좌석 계약이 엉덩이선 아래 공간을 고정하므로, 다리가 아래로 늘어진 포즈는 셀을
키워도 캐릭터가 그만큼 커지지 않는다. R1 실측(bbox 392×305):

| 셀(draw_size) | 실제 라이더 높이 | M(210) 대비 |
|---|---|---|
| 94 | 56.0px | 0.271 |
| 122 | 72.7px | 0.352 |
| 160 | **95.3px** | **0.461** |

그래서 승인 기준은 draw_size 가 아니라 **실제 라이더 높이 90~98px**(= 512 소스
알파 bbox 높이 288~314px)이다 → 게이트 **N1b**.

⚠️ **160 은 스매셔 프로토타입 전용이다.** 나머지 4종은 각 후보의 bbox 를 보고
같은 **실제 높이** 목표에 맞춰 draw_size 를 보정한다 — 160 을 무조건 복사하지
않는다. 카탈로그의 나머지 4종 94 는 미보정 자리표시자다.

### 1-1. 좌석선은 PNG 만으로 자동 검출되지 않는다 — 마스크가 산출물이다

해부학적 엉덩이선(착석 접촉선)을 알파/색에서 기계적으로 찾아낼 규칙은 없다. 그래서
좌석선은 **사람이 지정하고 기계가 확인**하는 구조로 둔다:

- 저작자가 **`*_seat_contact_mask.png`**(시트와 동일 512×512, 접촉선 픽셀만 255)를
  함께 제출한다. 접촉선 = 캐릭터의 엉덩이·허벅지 아래면이 안장에 닿는 띠.
- 검증기는 그 마스크에서 **가로 중앙(x)** 과 **최하단 행(y)** 을 뽑아 계약값
  (256 / 461)과 비교하고, 마스크가 **이진 · 비어 있지 않음 · 후보 불투명 영역과
  접촉/교차**함을 함께 검사한다 → 여기까지가 기계 확인이다.
- ⚠️ **좌표 확인만으로는 부족하다.** 저작자가 아무 곳에나 (256, 461) 선을 그어도
  기계는 통과시킨다. 그래서 **마스크 오버레이 캡처**를 함께 제출받아 그 띠가 실제
  엉덩이·허벅지 하부 접촉면을 따라가는지 **육안으로 승인**한다 — 이 둘이 모두
  통과해야 N2 다(혼합 게이트).
- 마스크나 오버레이가 없으면 N2 는 **판정 불가 = FAIL**.

### 1-2. 생성 후 배치 보정 — **전체 평행이동 1회만** 허용

AutoSprite 가 해부학적으로 맞는 포즈를 캔버스의 임의 위치에 놓을 수 있다. 보정을
아예 금지하면 N2 가 운으로 결정되므로, **결정적 패킹 1회**만 허용한다:

| 허용 | 금지 |
|---|---|
| 전체 RGBA 와 seat mask 에 **동일한 정수 `(dx, dy)` 평행이동 1회** | 리샘플 · 리스케일 · 트림 후 재중앙 · 부위별(팔·소품) 이동 · 워프 · 회전 |

- 이동은 **1×1 정적 자산의 결정적 패킹**이지 프레임별 재중앙(§2.3.2 금지 항목)이
  아니다 — 프레임이 하나뿐이라 프레임 간 흔들림이 성립하지 않는다.
- `(dx, dy)`, **이동 전/후 SHA-256**, 이동 후 **4변 알파 접촉 0 재검사** 결과를
  매니페스트에 기록한다.
- 형태·팔레트 실패를 이동으로 가릴 수 없다: N3~N6b 는 이동과 무관하게 그대로 잰다.

### 2-1. 목운/구름 제외 — 착석 N 한정 예외

탑승 상태에서는 **M(백린)이 이동 기반을 대체**하므로 스매셔의 목운(구름) 이동
요소는 착석 N 에 **그리지 않는다**(구름 픽셀 0).

⚠️ 이 예외는 **착석 N 에만** 유효하다. 일반 스매셔의 정체성 정본(구름 포함)으로
역전파 금지 — walk/idle/attack 계열은 계속 구름을 갖는다.

계약으로 단언한다.

### 3-1. N6b 팔레트 hard gate — 승인 idle 8프레임 medoid + 실측 반경

**2026-08-15 개정(사용자 판정).** 구 기준(프레임 0 중심 + 평탄 dE ≤ 2.5)은 폐기한다.
그 기준은 레퍼런스 **자기 시트의 f2·f3 을 잘못 탈락**시켰다(bronze 2.97 · cream 2.63).
반경은 임의 상수가 아니라 **관측**에서 나와야 한다.

레퍼런스 = 승인 idle 시트 **8프레임 전부**(160×160 셀), **구름 제외**(y < 96), α > 200.
마스크 술어는 **위치와 무관한 색 술어**라 착석 포즈에도 그대로 적용된다(후보에는
구름이 없어 y 컷도 필요 없다).

```
mx, mn  = 채널 최대/최소 ;  chroma = mx - mn ;  L = CIELAB L*
red     = r > g+40 ∧ r > b+25 ∧ r >= 90
cream   = mx >= 190 ∧ chroma <= 45
indigo  = b > r+8 ∧ b >= 40 ∧ ¬cream
brown   = r > b+20 ∧ chroma >= 25 ∧ ¬red
  wood_shield    = brown ∧ L < 36
  bronze_beopgu  = brown ∧ L >= 36
```

**기준 산출**: 재질별로 기저 프레임 각각의 중앙 Lab 을 구하고, 나머지까지의 **최대**
dE2000 이 가장 작은 프레임을 **medoid**, 그때의 최대 거리를 **실측 반경**으로 삼는다.

**기저 = 승인 아트의 알려진 교란 3축 전부**(2026-08-15 수리):

| 축 | 표본 |
|---|---|
| 프레임 간 | 승인 idle 8프레임 |
| **시트 간** | 승인 `rear_cloud_glide_right` 8프레임 (승인 · 동일 세션 · **동일 생성 경로**) |
| **프로토콜 간** | 512 조상 `.tmp/SET2_idle_raw.png` 6셀을 **후보와 동일한 파이프라인**으로 |

조상 6셀은 출하 8프레임에 실루엣 IoU **0.946~0.966** 으로 대응하며, 중복 프레임
(f2/f3 → cell2, f5/f6 → cell6)이 정확히 접힌다. `.tmp/SET3_idle_R.png` 는 출하 시트와
**바이트 동일**(SHA-256 `AA8C9B92…`)이라 계보가 확정된다.

⚠️ **단일 시트 기저는 계측기로 성립하지 않는다.** 한 시트의 프레임은 독립 표본이 아니라
복제다(f2 = f3, f5 = f6 은 바이트 동일, ICC 기준 n_eff ≈ 1). 그래서 반경이 시트 간 변동이
아니라 프레임 잡음을 재고, 그 결과 **승인 자매 시트 glide_right 가 8/8 탈락**했다.

## 4. 착수 순서

1. AutoSprite R2 — 위 앵커에서 착석 포즈 생성. **무릎·부츠를 아래로 늘어뜨리지 않고

2. 게이트 N1~N1b~N10 판정 + 밝은/어두운/160px 캡처 제출.
3. **후보 1장 승인 후에만** 경로 배선(`RIDERS.smasher.path`) → 테스트 오버라이드로
   **P1~P18 프로토타입** 수행(§7).
4. 그전에는 `mount_presentation_model` **미등재**와 **나머지 4종 생성 보류** 유지.

⚠️ 승인 전에는 `RIDERS.smasher.path` 를 **빈 문자열로 유지**한다. 근거는
**미승인 자산이 production-ready 캐시에 들어가거나 스매셔 준비도가 양성으로
오인되는 것을 막기 위함**이다(§A-4 fail-closed).

정정: "경로를 채우면 P18 대조군이 오염된다"는 **틀린 설명이었다**. 온이마루는
`mount_presentation_model != "topdown"` 이라 탑다운 준비도 경로에 애초에 진입하지
않는다 — **P18 온이마루 대조군은 모델 분기상 독립**이며 N 경로 상태와 무관하다.
