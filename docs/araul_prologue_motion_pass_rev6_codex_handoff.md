## 3. 델타 레이어 추출 계약 (신규 생성 0장)

기존 compose_* 도구 계열의 새 추출 도구(PowerShell, 결정적)로 **런타임 3344×1882
플레이트에서 직접** 추출한다(업스케일 재실행 없음). 산출물은 bbox 크롭 + 오프셋
기록(메모리 절약), `art_sources/araul_prologue/fx_layers/`(원본)와
`godot/assets/ui/story/han_miryang_prologue/`(런타임, `araul_prologue_v3_fx_*.png`)
에 저장, 매니페스트에 SHA-256과 크롭 오프셋 등재. import는 플레이트와 동일 정책
(VRAM 압축+밉맵), LFS는 기존 패턴이 커버.

| 레이어 | 소스 | 추출식 | 검증 |
|---|---|---|---|
| `fx_tablet` | A2 − A1 | 신주 마스크 안 A2 픽셀 + 델타 휘도 알파 | **왕복 재구성**: A1+레이어 ≈ A2 (마스크 안 허용오차, 밖 0) — 씰 대상 |
| `fx_rays` | C1 − A1 | 양수 델타 ∧ 시안 우세(b>r+24 ∧ g>r+24) | 인물 고스트 0: 해원·제관 얼굴 rect 안 레이어 픽셀 = 0 |
| `fx_orb` | B2 − B1 | 허용 마스크(입·목) 안 B2 픽셀 + 글로우 시안 필터 | 왕복 재구성 (마스크 안) |
| `fx_shard` | D2 − D1 | 령편 궤적 마스크 안 시안 델타 | 제관 얼굴 델타 **제외**(회복 연출은 베이스 크로스페이드 담당) |
| `fx_tendril` | A3 − A2 | 기운 통로 마스크 안 델타 | 선택(P2) — 시간 부족 시 드롭 가능 |

마스크 좌표는 rev5 §4의 허용 영역과 매니페스트 기록을 재사용한다.

## 4. 연출 사양 (비트별)

공통: 모든 FX는 오버레이 호스트 내부에서만 그린다. ADD 블렌드가 필요한 레이어는
**별도 CanvasItem 자식**으로(immediate `_draw` 안 `canvas.material` 스왑은 no-op).
신규 CanvasItem 자식은 생성 시 `physics_interpolation_mode = OFF`(GRT-039).
파티클·지터 랜덤은 **독립 RandomNumberGenerator + CINEMATIC_ID 해시 고정 시드**
(게임플레이 RNG 오염 금지, 캡처 재현성 확보).

### 4.1 A1→A2 신주 상승 리빌 (11.2–12.6)
크로스페이드 대신: A1 베이스 고정 → `fx_tablet`을 **아래→위 마스크 와이프**로
1.1초 전개(ease-out) + 영기 글로우 펄스 1회 → 12.6에 베이스를 A2로 스위치
(와이프 완료 상태와 픽셀 동일하므로 무봉합).

### 4.2 무음 비네트 (21.6–23.4)
완전 무음 구간 동안 radial 어두운 비네트 알파 0→0.22→0, 느린 펄스 2회.
"소리가 죽었다"를 화면이 말한다. MIX로 충분.

### 4.3 B2 구체 맥동 (23.6–26.0)
`fx_orb`를 베이스 위에 겹쳐 미세 외측 드리프트(≤14px @3344)+글로우 펄스
(주기 ~0.9s). ⚠️카메라가 다르므로 B2→C1 간 구체 "이동" 연출은 하지 않는다 —
컷 너머 이동은 성립하지 않는다.

### 4.4 C1 섬광 폭발 + 광선 전개 (26.0–29.6) — 이 패스의 주인공
- 플래시: 풀스크린 화이트-시안(#E8FFF8 계열) rect, 26.0→26.15 램프업,
  26.15–26.35 피크(알파 ~0.92), 26.90까지 감쇠. 컷은 피크 아래(26.25).
- 광선: `fx_rays`를 구체 중심(≈ 매니페스트의 C1 광선 중심) 앵커로
  **radial 스케일 0.2→1.0** (26.25→27.4, ease-out) + ADD. 27.4→28.6 알파 1→0
  감쇠(베이스에 구워진 광선으로 무봉합 인계).
- 스파크: 독립 RNG 파티클 30~50개, 중심에서 외측 드리프트, 26.3–29.6.
- 카메라: C1 진입 시 줌 1.10→1.02 풀백(폭발의 "밀려남").

### 4.5 D2 타격 (33.0–34.0)
- 33.00 타격 플래시(짧게, 알파 ~0.5) + 충격 링 1개(공 위치 앵커, 확장+감쇠).
- 셰이크: 33.00–33.35, 진폭 ≤6px(@3344 소스 rect 오프셋) 지수 감쇠.
  **플레이트 draw rect에만 적용 — 자막·화자·스킵 라벨은 절대 흔들지 않는다**(가독성).
- `fx_shard`: 제관 가슴→공으로 곡선 궤적 33.10–33.80(ease-in) 후 소멸.
  베이스 D1→D2 크로스페이드(33.0–34.0)는 유지 — 제관 회복(눈빛·핏줄 소멸)을 담당.

### 4.6 카메라 워크 전면 강화
현행 줌 3.5%는 지각 이하. 플레이트별 줌 델타 ≥6%(권장 8~10%) + 팬 방향 지정:
A1 우상→중앙 / B1 하→상 미세 푸시인 / D1 좌→우. 수용 기준: 각 플레이트
첫/끝 프레임의 소스 rect 폭 차이 **≥4%** (씰로 단언 가능한 수치).

## 7. 함정 준수 (배선 시)

1. immediate `_draw` 안 material 스왑 no-op → ADD는 별도 CanvasItem 자식.
2. 신규 자식 CanvasItem은 `physics_interpolation_mode = OFF` (GRT-039).
3. fx 레이어 4장은 **스트리밍 계약에 등재**: 각자 베이스 플레이트와 같은
   요청/마감 창(fx_rays는 C1과 함께 22.0 마감 등), 사용 종료 시 해제, skip/teardown
   폐기 경로 포함. `LIVE_STREAM_ALLOW_SYNC_FALLBACK` 준수(GRT-005 개정 규칙).
4. 상주 피크 예산: 프리플라이트 실측으로 재산정해 기대값 갱신 — 목표
   **플레이트 4장 + fx 레이어 동시 상주 ≤ 2장 상당(크롭 기준)**. 초과 시 크롭
   bbox를 좁히는 쪽으로 해결(마감 완화 금지).
5. `draw_set_transform`는 캡처-전파 규칙 준수, typed 배열 조건식 리터럴 금지
   (GRT-051), 프리웜 없는 draw-time 텍스처 로드 금지(GRT-003/004).
6. 표시 랜덤은 독립 RNG + 고정 시드.
7. 기존 큐 재사용 외 신규 음원 도입 시 벤더 WAV 컨테이너 절단 검사(GRT-036).
