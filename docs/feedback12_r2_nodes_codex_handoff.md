- 신규 노드/개편 노드는 지도 아이콘·모달·저장/복원·리셋·다국어·씰까지

## N1 — 파계승 개편 (초식 상점 → 클래스 전용 초식 픽)

- 방문 시 **플레이어 클래스 전용 초식**(예: 한미량이면 한미량 전용) 중
  랜덤 2개를 보여준다.
- 1개를 고르면 초식이 추가된다. 초식 슬롯이 가득이면 **초식 교체 UI**가
  나타난다(기존 초식 교체 선례·스왑 역매핑 규칙 준수 — pop 금지).
- 2개 중 1개를 고르면 나머지는 더 고를 수 없고, **1회 방문당 초식 1개**만
  배울 수 있다.
- 획득 비용: 관제탑 확정 = **무료**(방문당 1개 제한이 비용을 대체).
  기존 획득/스왑 비용 상수는 제거하지 말고 미사용 처리 후 보고.
- 씰: 클래스 필터(타 클래스 초식 등장 0) · 2개 제시·1개 선택 후 잠금 ·
  만석 교체 UI 경로 · 방문당 1개 · 미보유 풀 소진 시 축퇴(제시 1개/0개)
  fail-safe.

## N2 — 휴식 노드 → 모닥불 노드 대개편

가운데 모닥불. 클릭 시 불이 활활 타오르는 연출과 독백:
"걸음을 가까이 다가가자 모닥불에 불이 타오르기 시작한다" →
"평범한 모닥불은 아닌 듯 하다" → 선택지 3종. **1개만 선택해도 노드
종료 → 노드 공 선택 화면으로**.

1. **[휴식을 한다]** — "좋은 기운으로 전투에 임할 것 같다" 독백 후
   "다음 전투 진입시 기력이 가득 찬 상태에서 전투를 시작합니다" 메시지.
   다음 전투 1회에 한해 기력 풀 시작(저장/복원 포함, 소모 후 해제).
2. **[바나나 요리를 한다]** — 조건: 액티브 아이템 바나나 1개 이상 소지,
   선택 시 바나나 1개 소모. "가방에서 바나나를 꺼내 꼬챙이에 꿰어 불에
   달구었다" + 오색찬란한 빛이 모닥불에서 뿜어져나오는 연출 → 절세무공
   획득 연출 → **절세무공 '바나나의달인'** 획득: "바나나를 던질때
   바나나가 2개 발사됩니다".
   ★바나나의달인은 **오직 이 경로로만** 획득 가능 — 보상픽·상점·필드·
   융합 등 모든 일반 오퍼 풀에서 제외(등장 0 씰 필수). 아이콘이 필요하면
   만들지 말고 관제탑에 보고(아트 라우팅). 효과는 바나나 투척 경로에서
   실효(2발사) — GRT-053 소비 지점 씰.
3. **[모닥불을 챙긴다]** — 액티브 아이템 모닥불 1개 획득(슬롯 만석 처리
   는 기존 획득 관례).

- 씰: 선택지 3종 각 효과 실효 · 바나나 미소지 시 요리 선택지
  비활성(표시 게이트+실검사 양쪽) · 1선택 후 노드 종료 · 바나나의달인
  전 오퍼 풀 등장 0 + 투척 2발 실효 · 기력 풀 시작 1회성.

## N3 — NPC 노드 태극노인 신설 (무공 교환)

등장 대사(순서 그대로): "내 나이가 여든이 넘었는데" / "집안 대대로
내려오는 무공을 전수할 제자도 자식도 없으니.." / "가만 보니 자네는
총명한 눈을 가졌군" / "그대라면 .. 어쩌면 믿고 전수해줄 수 있을지도" /
"음 그런데 생각해보니 그냥 전수하기엔 좀 아깝고.." / "자네가 익힌 '~'를
나에게 전이해줄 수 있나 ? 죽기전에 익혀보고싶은 무공이군 .."

- '~' = 플레이어 보유 무공 중 **랜덤 1개** 지목.
- 화면: 왼쪽 = 지목된 내 무공 카드 1장, 오른쪽 = 태극노인의 **절세무공
  카드 1장**. "교환하시겠습니까?" [네 / 아니오].
- [네] → 교환 실행(내 무공 제거+절세무공 획득, 성급·슬롯 처리 관례) 후
  "끌끌.. 그대의 여정에 도움이 되었기를..." 노드 종료.
- [아니오] → "이런.. 그대가 이 절세무공의 강함을 느껴보길 원했건만 .."
  노드 종료.
- 제시 절세무공은 미보유·해금분에서 결정론 굴림. 지목 무공이 없을 때
  (보유 0) 노드 축퇴 처리 fail-safe.
- 씰: 교환 원자성(제거+획득 동시, 실패 롤백 — GRT-031) · 아니오 시 무변 ·
  랜덤 지목이 권위 RNG 비소비 판정 분리 · 노드 분포 등재.
