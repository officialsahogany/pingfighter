1. 기본 조작법

핑파이터는 키보드와 마우스를 함께 사용하는 게임입니다. 인게임에서는 마우스 왼쪽 클릭을 주로 사용하며, 키보드는 WASD로 이동합니다.

1.1. 키보드 조작

이동 조작

키 동작 설명
A 왼쪽 이동 패들을 왼쪽으로 이동합니다
D 오른쪽 이동 패들을 오른쪽으로 이동합니다
S 또는 우클릭 대시 A/D 누른 상태에서 입력 시 대시 발동

기타 조작

키 동작 설명
ESC 일시정지 / 뒤로 게임 메뉴를 열거나 이전으로 돌아갑니다
TAB 상태창 보유 아이템, 스킬 트리, 플레이어 능력치 확인
B BGM 토글 배경음악 켜기/끄기

1.2. 마우스 조작

입력 동작 설명
좌클릭 서브 / 주요 액션 서브 공 발사, 메뉴 선택, 건물 클릭
우클릭 대시 A/D 누른 상태에서 우클릭 시 대시 발동
마우스 휠 무기 교체 코만도 캐릭터 전용 - 무기 슬롯 전환
🎮 핵심 조작: 이동은 AD, 서브는 마우스 왼쪽 클릭!

2. 대시 시스템

대시는 핑파이터의 핵심 회피 및 이동 메커니즘입니다. 적절한 타이밍의 대시는 위기 상황에서 벗어나고, 유리한 위치를 선점하는 데 필수적입니다.

2.1. 대시 발동 방법

중요! 반드시 A 또는 D를 먼저 누른 상태에서 대시 키를 입력해야 합니다. S를 먼저 누른 상태에서 방향키를 누르면 대시가 발동되지 않습니다.
조작 설명
A 누른 상태 → S 또는 우클릭 왼쪽 대시
D 누른 상태 → S 또는 우클릭 오른쪽 대시

2.2. 대시 스펙

항목 기본값 비고
쿨타임 8초 경량화 스킬로 감소 가능
게이지 소모 있음 배터리팩 스킬로 감소 가능
기본 토큰 1개 증폭 스킬로 +1 가능
속도 배율 (단거리) 1.30배 하프 대시 시
버스트업 스킬을 배우면 대시할 때 패들 크기가 60% 커집니다. 공을 받아치기 훨씬 수월해집니다!

4. 전설 아이템

전설 아이템은 매우 희귀하지만 강력한 효과를 가진 특별한 아이템입니다. 필드 스폰 확률은 약 0.08%로, 보물지도 스킬로 확률을 높일 수 있습니다.

4.1. 전설 아이템 목록

아이템명 효과 특징
🔨 라그나로크 해머 강력한 넉백 공격 애니메이션 프레임 효과
👟 헤르메스의 신발 초고속 이동, 대시 강화 속도 부스트
🔱 포세이돈의 삼지창 수파 생성, 궤적 영향 수파 이펙트
👼 천사의 가호 다중 버프 옵션 신성 효과
🌿 신성 월계수 신성한 능력 부여 월계관 이펙트

4.2. 전설 아이템 특징

  • 붉은색 테두리와 애니메이션 아이콘
  • 모든 전설 아이템은 패시브로 분류
  • 게임당 1회만 획득 가능 (중복 불가)
  • 게임 오버 또는 메인 메뉴 복귀 시 효과 리셋
'보물지도' 스킬(누적 ★12)로 전설 필드 확률 +350%, 가챠 전설 +7%를 얻을 수 있습니다!

5. 스테이지 및 보스

핑파이터는 여러 개의 스테이지로 구성되어 있으며, 각 스테이지마다 개성 있는 보스가 등장합니다. 보스마다 고유한 패턴과 특수 능력을 가지고 있어 각각 다른 전략이 필요합니다.

5.1. 스테이지별 보스

Stage 1 - 풍악보이

특징: 🎭 한국 전통 풍물패 테마, 초보자용 튜토리얼 역할

스킬:

  • 🎐 상모돌리기 - 상모를 돌려 공을 끌어당기며, 발동 중 보스가 회전
  • 🌀 팽이치기 - 채찍을 휘둘러 팽이 2개를 소환, 팽이는 필드를 돌아다니며 공과 충돌

팁: 상모돌리기는 공을 위로 끌어올리므로 대시로 위치 조정하세요. 팽이는 충돌 후 튕겨나갑니다.

Stage 2 - 악어장군

특징: 🐊 정글 테마, 공격적인 움직임

스킬:

  • 🌋 정글지진 - 강력한 지진을 발생시켜 화면 전체가 흔들리고, 공의 속도가 빨라지며 바위가 낙하

특수 메커니즘:

  • 지진 발동 시 바위 1~2개 즉시 소환
  • 공 속도 1.6배 증가
  • 플레이어 이동속도 일시적 감소

팁: 정글지진 발동 시 바위를 피하며 빨라진 공에 대응하세요. 대시를 적극 활용하세요.

Stage 3 - 멘헤라걸

특징: 💔 감정 기반 패턴, 정서적으로 불안정한 캐릭터

스킬:

  • 💢 사이코볼 - 감정 오버드라이브 발동, 공이 붉게 변하며 추적 능력 강화
  • 💧 눈물샤워 - 하늘에서 눈물이 비처럼 내려와 플레이어 이동속도 감소

특수 메커니즘:

  • 사이코볼 발동 시 화면에 붉은 오버레이
  • 눈물에 맞으면 2초간 슬로우 디버프
  • 연막탄 연기 안에 있으면 눈물샤워 면역

팁: 연막탄이 있다면 눈물샤워에 대비하세요. 사이코볼은 연막으로 강제 해제 가능합니다.

Stage 4 - 퐁크

특징: 🧲 소림사 승려 테마, 자기장 능력 보유

스킬:

  • 🧲 굴절 자기장 - 자기장을 발생시켜 공의 궤적을 휘게 만듦

특수 메커니즘:

  • 자기장 활성화 시 공이 보스 방향으로 휘어짐
  • 발동 중 특수 사운드와 시각 이펙트
  • 배경에 소림사 사원 파괴 연출 (플레이어 3점 획득 시)

팁: 공의 휘어지는 방향을 예측하고 미리 포지셔닝하세요.

Stage 5 - 네메시스

특징: ⚡ 미래형 무기 장착, 체력 게이지 시스템

스킬:

  • ⚡ 레이저 캐논 - 충전 후 직선 레이저 발사, 등대 모드에서는 회전하며 발사
  • 🚀 인터셉터 - 격납고 문이 열리며 유도 미사일 출격 (스타크래프트 캐리어 스타일)
  • 🛡️ 쉴드 안테나 - 일시적으로 방어막 생성, 공을 튕겨냄

특수 메커니즘:

  • 레이저에 맞으면 플레이어 감전 스턴
  • 미사일에 맞으면 넉백 + 스턴
  • 보스 피격 시 0.5초 깜빡임
  • 레이저 쿨타임 12~15초, 인터셉터 쿨타임 10~12초

팁: 레이저 충전 시 미리 회피 준비. 인터셉터는 대시로 회피하세요.

Stage 6 - 홍련

특징: 🔥 화염 속성 보스, 체력 게이지 시스템

스킬:

  • 🔥 화염탄 - 불덩이를 플레이어 방향으로 발사, 맞으면 넉백 + 스턴
  • 🌋 홍련폭염 - 게이지가 차면 발동, 강력한 광역 화염 공격

특수 메커니즘:

  • 용의 신비로운 구슬 형태의 특수 게이지 표시
  • 라운드 시작 2.5초 지연 후 본격 전투
  • 라운드 지속시간 9초 (다른 스테이지보다 김)
  • 화염탄 쿨타임 5초
  • 토르쉴드로 홍련폭염 가드 시 특수 보상

팁: 화염탄은 대시로 회피하고, 홍련폭염 게이지를 주시하며 미리 준비하세요.

Stage 7 - 테트리서

특징: 🧱 블록 기반 보스, 테트리스 스타일

스킬:

  • 🧱 테트로미노 투하 - T(ㅗ) 블록을 필드에 떨어뜨림, 블록에 맞으면 폭발 + 스턴
  • 🏰 가드 블록 - 보스 뒤에 1자 방어 블록 생성
  • 🧱 테트로 벽 - 양쪽 벽에 10개씩 블록을 쌓아 필드 압박

🔥 초인테트리서 (특수 상태):

  • 일정 조건 충족 시 초인발동 상태 돌입
  • 지속시간 15초
  • 테트로미노 투하 속도와 빈도 대폭 증가
  • 패턴이 더욱 복잡해지고 공격적으로 변화
  • 이펙트와 함께 보스의 외형이 변화

특수 메커니즘:

  • 테트로미노 폭발 시 넉백 + 0.5초 스턴
  • 블록은 대시나 무기로 파괴 가능
  • 테트로 벽 쿨타임 30초

팁: 초인발동 시 방어에 집중하고, 블록은 적극적으로 파괴하여 공간을 확보하세요.

Stage 8 - 탁닌자

특징: 🥷 닌자 테마 보스, 고속 이동과 분신

스킬:

  • 👥 그림자 분신 - 여러 분신을 생성하여 혼란 유발, 분신은 홀로그램처럼 소멸
  • ☁️ 연막 대시 - 연막을 남기며 순간이동, 연막 위치에 구름 이펙트
  • 🔪 수리검 게이지 - 게이지 축적으로 특수 공격 발동

⚡ 초각성 상태 (특수 상태):

  • 플레이어 3점 이상 획득 시 초각성 상태 돌입
  • 바람 오오라가 보스 주변에 발생
  • 분신 수가 대폭 증가하여 구분이 더 어려워짐
  • 연막 대시가 더 빠르고 빈번해짐
  • 착지 후 잠시 머무르는 시간 추가
  • 🌀 극정호신 - 초각성 전용 필살기. 어둠 기운 파티클과 잔상을 남기며 극한의 속도로 공격

전설 아이템이 진열되어 있다면 놓치지 말고 구매하세요! 상점에서 확정적으로 살 수 있는 기회입니다.
이 가이드는 핑파이터 게임의 핵심 시스템과 팁을 정리한 문서입니다.
실제 플레이를 통해 자신만의 전략을 개발해 보세요!

마우스 좌클릭 + WASD로 시작하고, 대시를 마스터하세요!
