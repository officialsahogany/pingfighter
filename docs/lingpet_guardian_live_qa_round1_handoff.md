# 수호령 라이브 QA 1차 개선 핸드오프 (Codex 실행용) — 소환 연출·튜닝·라운드 버그·비급·링코어 삭제

작성 2026-07-28. 사용자 라이브 QA 피드백 5건. 정본 =
`docs/lingpet_guardian_duration_redesign_plan.md`. 가드레일·씰 실행 규정은
기존 슬라이스와 동일 (reset/stash 금지·로컬 커밋만·불가침·에디터 유휴 씰).
커밋 순서: **버그(§3) 최우선** → 튜닝(§2) → 연출(§1) → 비급/슬롯(§4) →
링코어·칩 삭제(§5).

## 1. 포켓몬식 소환/수납 연출

로직(최소 유지 6초·수납 정지 계약·가용성)은 불변 — 연출만 추가한다.

- **소환 (Ctrl)**: 캐릭터 몸에서 빛 구체 사출 → 짧은 포물선으로 소환 지점
  이동 → 착지 플래시 + 링 확산 → 수호령 **머티리얼라이즈**(알파 마스크
  디졸브 — 밝기 게이트 금지, 실루엣 알파 게이팅 규칙). 총 ~0.4-0.6s.
- **수납 (Ctrl 재입력)**: 수호령이 빛 실루엣으로 전환 → 빛줄기가 캐릭터
  몸으로 흡입 → 캐릭터 위치 소형 플래시. 소환의 역방향 문법.
- 자산: 신규 시트 금지 — 기존 ghost_blink '퐁' + 슬롯 교체 전환 파티클 +
  3피스 모듈러 VFX(정적 텍스처 + 공유 셰이더 패밀리 프리셋) 절차 조합.
  SFX 훅 배선(에셋 없으면 silent fallback).
- **가용성 정의**: 소환 연출 완료 시점부터 방어 인터셉트·바디히트 활성.
  수납 연출 시작 시점에 즉시 비활성(연출은 잔상일 뿐). 드레인은 소환 연출
  시작~수납 연출 시작 구간.
- **연출 중 토글 재입력**: 무시(연타 방지) — 연출 상태머신이 완료될 때까지
  에지 소비. 만료 강제 수납은 연출을 중단하고 우선한다.
- 씰: 연출 수명주기(연타 무시·강제 수납 우선·가용성 시점) + 픽셀 QA 2장
  (소환 중 빛줄기 / 수납 흡입 중).

## 2. 베이스 지속시간 하향 (튜닝)

- 첫 부화 롤 **60~80초 → 35~50초** (초안 — 사용자 라이브 피드백 "너무
  길다"). 단일 상수 소스(MIN/MAX) 유지, 라이브 튜닝 전제.
- 씰의 롤 범위 단언 갱신 + 반증(범위 원복 시 RED).

## 3. 라운드 전환 지속시간 초기화 버그 (최우선)

- **계약**: `pool_current`/`pool_max`/오버필/만료 락 잔여는 **라운드 경계를
  그대로 이월**한다. 리필은 실제 스테이지 전진에서만. 첫 부화 롤(1회성)도
  라운드 경계에서 재롤되지 않는다.
- 진단 앵커 (Claude 사전 조사): `lingpet_affinity_state.gd` 주석 —
  "(apply_save_snapshot) unconditionally calls reset_for_tests()->
  reset_for_new_run()" 경로가 라운드 전환의 스냅샷 재적용에서 duration을
  초기화하는 것으로 의심. `lingpet_duration_state.reset_run()`(:49) /
  `refill_to_max()`(:193) **소비자 전수 감사** + 라운드 스냅샷/리스토어
  경로에 duration 키가 온전히 실려 왕복하는지 확인
  (`export_run_state`/`import_run_state`·`build_common_snapshot` 계열).
- 씰: 실제 라운드 전환 시퀀스 관통(점수 발생 → 라운드 리셋 → pool 값·
  max·오버필·롤 1회성 불변) — 손제작 dict 주입이 아니라 **실 리셋 경로
  관통** (Projection-분기 공허-GREEN 트랩). 반증 = 라운드 경로에 리필 강제
  주입 시 RED.

## 4. 영혼소환술 비급 등재 + 무공 슬롯 비점유

- **비급 등재**: 초식 비급(책) UI에 영혼소환술을 다른 초식과 동일한 책
  오브젝트로 등재하되, **중립(공용) 초식 전용 책 색상**을 신설 — 5캐릭
  공용임을 색으로 구별. 아트 디렉션: 수호령 테마와 일치하는 **옥색(jade)/
  청록 계열** 권장 (기존 캐릭터별 책 팔레트와 혼동 없는지 확인).
- **캐릭터정보창 무공 슬롯 비점유**: 영혼소환술은 TAB 캐릭터정보창의 무공
  슬롯 예산을 소모하지 않는다 — **`_slot_free_cell` 패턴**(패딩 뒤 append,
  반쪽-랜딩 트랩 문서의 비소모 엔트리 규정) 사용, 슬롯 카운터에서 제외.
  관련 툴팁/카드의 "무공 슬롯 사용" 류 문구 동기 제거(7언어).
- **전투 초식구슬 5칸 중 1칸 점유는 불변** (사용자 지시는 캐릭터정보창
  무공 슬롯에 한정 — 슬롯 만석 씰의 기존 계약 유지).
- 씰: 비급 등재(중립 색 키) + 무공 슬롯 표시-수량(**픽스처는 무공 예산을
  가득 채워** 영혼소환술 포함 시 카운터 불변 단언 — 반쪽-랜딩 트랩 규정) +
  기존 만석 씰 GREEN 유지.

## 5. 링코어·강화칩 조기 삭제 (§9-4 선행분)

- 삭제 대상: 퍽 오퍼 2종(`lingpet_ring_core_upgrade`/`lingpet_affinity_chip`
  — 카탈로그 choices·예약 레인·디스패치·applier), `lingpet_affinity_state`의
  `_run_ring_core_tier`/`_enhancement_chips`/오퍼 쿨다운/칩 획득 배율,
  `lingpet_ring_core_rules.gd`, 캐릭터정보창 링코어 셀·칩 표시
  (ring_core_projection 계열), `lingpet_tutorial_bootstrap` 무료 티어 그랜트,
  세이브 필드(import는 구 키 무시하는 관용 파서), 관련 다국어 카피.
- **교감 레벨 캡**: tier×5 캡 → `MAX_LEVEL` 고정 (교감 시스템 자체는
  §9-4까지 전환기 존치 — 이번에 건드리지 않는다).
- **플라자 링코어 구매 행**: 플라자 파일의 dirty 여부 먼저 조사 —
  클린이면 구매 행 삭제까지, dirty(외래 캠페인)면 구매 경로 **차단 마크**만
  하고 물리 삭제는 플라자 정산 후로 이관 (기존 분기② 패턴). 골드+AP 대체
  싱크는 기존 미결 유지.
- 씰: 링코어/칩 오퍼 미등장·티어/칩 API 부재(또는 0 고정)·캡 고정·정보창
  셀 부재 + **기존 링코어/칩 씰 은퇴 목록 보고** (은퇴 전 각 씰의 트리
  보류 헝크 유무 확인 — 있으면 파일 삭제 금지·재조준).
- owner 스키마: `lingpet_ring_core_tier`/`affinity_chip_count` 쌍 제거
  (쌍 단위 — 부분 삭제 금지).
