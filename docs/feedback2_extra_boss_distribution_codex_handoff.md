## 사용자 확정 설계 (피드백2 ⑧ 원문 의도)

> "일정 지점에서는 무조건 보스 1회(현행 게이트 ✓). 보통 1~2명,
> 낮은 확률로 그 층 보스를 더 만날 수도 있게."

- 2층 이상 각 층에 **확률적으로 추가 보스 노드 최대 1개** 배치.
- 추가 보스는 **우회 가능**해야 함: 그 노드를 지나지 않는 경로가
  반드시 존재(게이트처럼 강제 아님). 어떤 경로는 그 층 보스 1명
  (게이트만), 어떤 경로는 2명.
- 1층 구조(풀 로스터·오프닝=게이트 시드 단일화)는 **불변**.

## 작업

1. **배치 방식 = 기존 NPC 노드 전환**(S4 샘터 보장 패스 전례): 신규
   노드 추가로 토폴로지를 바꾸지 말고, 폭 2 이상 행의 NPC 노드 1개를
   보스 노드로 전환. 노드/간선 수 불변 → 토폴로지 씰 무접촉.
2. 확률·범위는 TEMP 상수(GRT-054): 적용 층 `2..최상층-1`(터미널 행
   제외), 층당 스폰 확률 초기값 `0.45`, 층당 최대 1개. 시드 파생
   결정론(맵 시드 네임스페이스 분리).
3. 전환 노드의 보스 정체성은 **해당 층의 기존 생성 슬롯 풀**에서
   미사용 키 소비(`_assign_boss_slot` 기존 기계 재사용) — 런 내 중복
   금지 계약·`standin_duplicate_gate` 의미론(셸 층) 준수. 풀이 소진된
   층은 스폰 스킵(조용한 실패 금지 — 스킵 카운트 보고).
4. **우회 가능성 보장**: 전환 후보는 해당 노드를 제외해도
   입구→터미널 도달이 성립하는 노드만(그래프 워크 검사). 게이트 행·
  `floor_one_boss_choice`·관문 인접 싱글톤 규칙 무접촉.
5. 전투 진입은 기존 노드 파생 조우 경로(`resolve_battle_encounter`)
   그대로 — 신규 배선 금지(I2 정본). 아이콘·프리웜은 기존
   iconography 자동 해석 확인만(GRT-004).
6. **계약 재보정**(S8 전례): 보스 비율 상한(현 0.34)·NPC:boss≥2가
   전환으로 이동함 — 128시드 실측 후 근거와 함께 상수 개정. draw
