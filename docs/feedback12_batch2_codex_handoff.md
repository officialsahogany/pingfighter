# Z17 — 수련장 개편 (6·7·8항)

1. **수련 비용 등차(6항)**: 같은 수련장 내 1·2회차 무혼 1, 3·4회차 2,
   5·6회차 3 … (2회마다 +1). 수련장을 떠나면 리셋. 상수화.
2. **수납술 특례(7항)**: 수납술(`physique_storage`) 카드가 등장한 수련장
   에서는 **수련 1회만 가능**. 대신 **빨간 눈금(정밀 판정) 성공 시 슬롯
   +2**. 타이밍 미니게임 판정 소유자(`tower_training_timing_*`)와 연결.
   ⚠"1회 제한"의 정확한 범위(수납술만 1회인지, 그 수련장 전체가 1회인지)
   — 사용자 원문 "한 수련장에서 1번만 수련"은 **수련장 전체 1회**로 읽힌다.
   그렇게 구현하되 보고에 명시.
3. **카드 6→4장(8항)**: `tower_ascent_training_offer_builder.gd:22`
   `TRAINING_CARD_COUNT := 6` → 4. 레이아웃(`tower_training_screen_layout_
   smoke`)·포인터 씰 동반 갱신. ⚠씰이 6장을 봉인 중이면 재작성.

⚠Z14(스폰 예산)가 `tower_ascent_tuning.gd` 를 병행 수정 중일 수 있다 —
착지 순서에 따라 3-way. 상수 위치가 달라 충돌은 없을 것.
