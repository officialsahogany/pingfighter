# 지시문 Z7-수정 — 서브 대기 리디자인을 되돌리고 문구만 한글로

- **발행**: 관제탑 2026-08-29. 기준선 = 본 트리 **`732ed5e0f`**.
  **격리 워크트리 + 격리 브랜치.** 본 트리 편집·통합·푸시 금지.
- **선행**: Z7(`732ed5e0f` 직전 커밋). **그 커밋의 시각 리디자인을 되돌린다.**

## 사용자 반려

> 서브할 때 **화면이 너무 크게 바뀌었고 캐릭터를 가린다.**
> 그리고 **"기를 모으는 중…" 이것도 없애고**, 그냥 **이전과 동일한 스타일에
> 글자만 한글로** 바꿔라. (**달지 차례**, **준비중..**) 이런 식으로.

★**관제탑 판단 오류였다.** 원 지시문(Z7)이 "환격전에 맞게 리디자인"을
그대로 받아 시각 재설계를 요구했는데, 사용자가 원한 것은 **한글화뿐**이었다.
세션은 지시문대로 수행했으므로 세션 잘못이 아니다.

## 요구 1 — 시각 리디자인을 되돌려라

Z7 이전 `_draw_boss_serve` 는 이랬다(`601bd7b93^` 참조).

```gdscript
var center := Vector2(width * 0.5, 80.0)
var serve_rect: Rect2 = _draw_text_centered(canvas, center, serve_label, SERVE_FONT_SIZE, Color.WHITE)
_draw_accent_line(canvas, width, serve_rect, accent_color)

var info_text := "Preparing..."
var info_color := Color(0.78, 0.78, 0.78)
if serve_timer >= serve_delay:
	info_text = "Ready"
	info_color = Color(1.0, 1.0, 0.39)
_draw_text_centered(canvas, ..., info_text, INFO_FONT_SIZE, info_color)
```

**텍스트 두 줄 + 강조선 하나가 전부다.** 패널도 게이지도 빛점도 없었다.

**이 구조로 되돌려라.** Z7 이 추가한 것들을 제거한다.

- `BOSS_PANEL_MAX_WIDTH` / `BOSS_PANEL_HEIGHT` / `BOSS_PANEL_TOP` /
  `BOSS_PROGRESS_HEIGHT` 등 보스 패널 레이아웃 상수
- 패널 배경, 모서리 획, 진행 게이지 바, 다겹 충전광, 빛점
- 그에 딸린 헬퍼 함수

⚠**`serve_label` 인자와 호출 계약은 유지하라.** 렌더러 시그니처를 바꾸지 마라.

## 요구 2 — 문구를 사용자 지정으로

| 자리 | 한국어 |
|---|---|
| 제목 | **`달지 차례`** (보스 이름 + ` 차례`) |
| 준비 중 | **`준비중..`** |
| 준비 완료 | 관제탑 제안 **`준비 완료`** — 사용자 미지정이라 잠정값 |

★**"기를 모으는 중…" 은 제거한다.** 사용자가 명시적으로 지웠다.

⚠**제목은 보스 이름이 들어가는 형식**이다. Z7 이 `"%s Serve"` 조립 경로를
찾아 고쳤으니 그 자리를 `"%s 차례"` 형식으로 바꿔라. 하드코딩 금지.

⚠**한국어 카피에 엠대시(—) 금지.** 그리고 **말줄임은 사용자가 쓴 `..`
(마침표 둘) 그대로** 하라. `…`(U+2026) 로 바꾸지 마라.

## 요구 3 — 다국어는 유지하라

**Z7 의 다국어 구조는 되돌리지 마라.** 그건 사용자가 원한 것이다.
7개 지원 언어 키를 유지하되 **한국어 값만 위 문구로 교체**하고, 다른 언어는
원래 영문 표기(`%s Serve` / `Preparing...` / `Ready`)로 두는 것이 맞는지
**판정해서 보고하라.** 관제탑 견해로는 비한국어는 기존 영문 유지가 맞다.

## 요구 4 — 캐릭터를 가리지 않는지 확인하라

사용자 지적의 핵심이다. 되돌린 뒤 **실제 렌더에서 서브 대기 표시가 플레이어·
보스 스프라이트를 가리지 않는지** 픽셀로 확인하라.
`center := Vector2(width * 0.5, 80.0)` 의 y=80 이 원래 값이다.

2. **`기를 모으는 중` 문자열이 코드·로케일 어디에도 남지 않는지** 단언.
