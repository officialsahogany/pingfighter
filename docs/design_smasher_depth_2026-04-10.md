# Design Review - 스매셔 깊이 개선안
**Date**: 2026-04-10  
**Branch**: `feature/refactor-ui`  
**Scope**: 스매셔 캐릭터 게임플레이 다양성 부족 분석 및 개선 제안  
**Status**: Draft (코덱스 리뷰용)

---

## 1. 문제 정의

바이퍼와 비교했을 때 스매셔는 **스킬 간 연결이 없고, 의사결정 포인트가 적어 플레이가 단조롭다**.

### 1.1 현재 상태 비교

| 항목 | 바이퍼 | 스매셔 |
|------|--------|--------|
| 건틀릿 스킬 | 6개 | 5개 |
| 스킬 체이닝 | Shadow Step → Marshal Kick → Phantom Kick (최대 4연쇄), Blade Rush → Nerve Strike | **없음** (모든 스킬 독립 실행) |
| 고유 공간 메카닉 | 제트팩 체공 (공중/지상 분기) | 없음 |
| 리액티브 플레이 | 높이 의존 데미지, 벽 위치 활용 | Cleanse (디버프 해제)만 |
| 레벨링 퍽 | 2개 (제트팩 강화, 킥 강화) | 1개 (레이저 백테일) |
| 상태이상 부여 | 혼란, 수면 | 슬로우만 |
| 플레이 스타일 분기 | 공중 콤보형 vs 그라운드형 | 거의 없음 |

### 1.2 핵심 원인

1. **스킬이 서로 독립적**: 각 스킬이 쿨다운만 관리하면 되고, 조합/순서에 따른 보너스가 없음
2. **판단 차원이 1개**: 게이지/쿨다운 관리만 존재 (바이퍼는 높이, 타이밍, 위치, 체인 분기 등 다차원)
3. **고유 자원 부재**: 바이퍼에게 제트팩 게이지가 있는 반면, 스매셔만의 관리 자원이 없음
4. **성장 퍽 부족**: 레벨링 가능 퍽이 1개뿐이라 빌드 다양성이 제한됨

---

## 2. 디자인 목표

- **"바이퍼 = 공중에서 뭘 할까"** vs **"스매셔 = 바닥에서 뭘 쌓을까"** 대비 구도 확립
- 스매셔 정체성(파워, 임팩트, 지상전) 유지하면서 **의사결정 레이어** 추가
- 기존 스킬 제거 없이 **시너지 시스템**으로 깊이 확보

---

## 3. 제안 시스템

### 3.1 임팩트 존 (Impact Zone) — 스킬 간 시너지

> 바이퍼의 "체인 콤보"에 대응하는 스매셔만의 공간 연결 메카닉

**기본 규칙:**
- Power Smashing 또는 Plasma 적중 시 → 바닥에 **임팩트 존** 생성
- 지속시간: 2~3초 (퍽으로 확장 가능)
- 동시 존재: 최대 2개
- 시각: 바닥에 균열/충격파 이펙트

**임팩트 존 위에서 스킬 사용 시 강화:**

| 기본 스킬 | 존 위 강화 효과 | 판단 포인트 |
|-----------|----------------|-------------|
| Drive (커브샷) | 커브 곡률 2배 + 잔상 분열 (페이크 공 1개) | 존 위에서 커브를 쓸까, 이동해서 다른 스킬을 쓸까 |
| Plasma | 범위 1.5배 + 슬로우 → 속박(0.5초 이동불가)으로 강화 | 존을 Plasma 강화에 쓸까, 다른 스킬에 쓸까 |
| Power Smashing | 충격파 추가 (보스 넉백 + 아이템 드랍률 일시 증가) | 존 2개를 겹쳐서 극대화할까, 분산 배치할까 |
| Recovery | 대시 복귀 시 가장 가까운 임팩트 존으로 순간이동 | 존 위치를 미리 세팅해두는 전략적 활용 |

**왜 필요한가:**
- 스킬을 "언제" 쓰느냐에 더해 **"어디서"** 쓰느냐가 중요해짐
- 존을 만들고 → 활용하는 **2단계 판단**이 매 스킬 사용마다 발생
- 바이퍼의 체인이 "시간축 연결"이라면, 임팩트 존은 **"공간축 연결"**

### 3.2 차지 레벨 (Charge Level) — 타이밍 판단

> Power Smashing에만 있는 홀드 메카닉을 다른 스킬에도 확장

**기본 규칙:**
- 스킬 키 **짧게 탭** → 기본 발동 (현재와 동일, 호환성 유지)
- **길게 홀드** → 차지 Lv.1 → Lv.2 → Lv.3 단계 강화
- 차지 중 **이동속도 50% 감소 + 피격 시 차지 캔슬** (리스크)
- 차지 단계는 패들 주변 이펙트로 표시 (진동 → 발광 → 폭발 대기)

**Plasma 차지 예시:**

| 차지 | 시간 | 효과 | 게이지 소모 |
|------|------|------|------------|
| 탭 | 즉시 | 소형 구체 1개 (현재) | 40 |
| Lv.1 | 0.5초 | 중형 구체, 관통 | 60 |
| Lv.2 | 1.2초 | 대형 구체, 관통 + 착탄 폭발 (범위 슬로우) | 90 |
| Lv.3 | 2.0초 | 궁극 구체, 관통 + 폭발 + 공 흡착 (공을 끌어당김) | 130 |

**Drive 차지 예시:**

| 차지 | 효과 |
|------|------|
| 탭 | 기본 커브샷 (현재) |
| Lv.1 | 커브 곡률 증가 |
| Lv.2 | 이중 커브 (S자 궤적) |
| Lv.3 | 관통 커브 (보스 가드 무시) |

**왜 필요한가:**
- "지금 탭으로 빠르게 쓸까 vs 위험 감수하고 풀차지할까" → 매 상황 리스크/리워드 판단
- 차지 중 피격 캔슬 → 보스 공격 패턴을 읽는 플레이 유도
- 기존 탭 사용은 그대로 유지되므로 **하위 호환성 보장**

### 3.3 레이지 게이지 (Rage Gauge) — 고유 자원 관리

> 바이퍼의 제트팩 게이지에 대응하는 스매셔만의 핵심 자원

**기본 규칙:**
- 공 적중, 스킬 적중, 임팩트 존 활용 시 레이지 축적
- 3단계 시스템, 단계별 패시브 버프 자동 적용
- **실점 시 2단계 하락** → 공격적 플레이로 유지해야 함

| 레이지 단계 | 축적 조건 | 패시브 효과 | 시각 연출 |
|-------------|-----------|-------------|-----------|
| 0 (평온) | 기본 상태 | 없음 | 없음 |
| 1 (흥분) | 3연속 적중 | 이동속도 +10%, 스킬 쿨다운 -15% | 패들 테두리 미세 진동 |
| 2 (격노) | 6연속 적중 | 이동속도 +20%, 스킬 데미지 +30% | 패들 붉은 아우라 |
| 3 (폭주) | 10연속 적중 | **차지 시간 절반 + 임팩트 존 자동 생성** | 패들 주변 화염 이펙트 |

**레이지 3단계 전용 — 버서커 스매시 (궁극기):**
- 조건: 레이지 3단계 + 게이지 400 이상
- 효과: 전방 광역 충격파, 보스 2초 경직 + 공 가속 200%
- 사용 후 레이지 0으로 리셋

**레이지 축적량:**

| 행동 | 축적량 |
|------|--------|
| 일반 공 적중 | +1 |
| 스킬로 공 적중 | +2 |
| 임팩트 존 강화 스킬 적중 | +3 |
| 카운터 성공 (3.4 참조) | +4 |
| 실점 | **-2단계** |
| 시간 경과 (적중 없이 5초) | -1단계 |

**왜 필요한가:**
- 바이퍼는 "제트팩 게이지를 언제 쓸까"를 관리하고, 스매셔는 "레이지를 어떻게 유지할까"를 관리
- 실점 페널티가 크므로 **방어와 공격의 밸런스** 판단이 생김
- 3단계 도달 시 차지 시간 절반 + 임팩트 존 자동 생성 → 3.1, 3.2 시스템과 시너지

### 3.4 가드 임팩트 (Guard Impact) — 신규 건틀릿 스킬

> Cleanse(수동적 디버프 해제)를 보완하는 **공격적 방어** 스킬

**기본 규칙:**
- 보스 투사체/특수공격 타이밍에 맞춰 발동 (타이밍 윈도우: 0.2초)
- 게이지 소모: 100 | 쿨다운: 18초

| 판정 | 타이밍 | 효과 |
|------|--------|------|
| 실패 | 너무 이르거나 늦음 | 자신 0.5초 경직 (큰 리스크) |
| 성공 | ±0.2초 이내 | 투사체 반사 + 보스 0.8초 경직 + 레이지 +2 |
| 퍼펙트 | ±0.05초 이내 | 반사 데미지 3배 + 보스 1.5초 경직 + 레이지 +4 + 임팩트 존 즉시 생성 |

**왜 필요한가:**
- 현재 스매셔에 부족한 **반응형 플레이** 추가
- 숙련도에 따라 천장이 높아짐 (퍼펙트 카운터 → 임팩트 존 → 강화 스킬 콤보)
- 보스 공격 패턴을 읽는 재미 → 바이퍼의 "공중 타이밍"과 다른 축의 스킬 표현

### 3.5 퍽 확장 — 성장 다양성

> 레벨링 가능 퍽 1개 → 5개+로 확장, 빌드 분기 생성

**신규 퍽:**

| 퍽 ID | 이름 | 최대 레벨 | 효과 | 빌드 방향 |
|-------|------|-----------|------|-----------|
| `impact_mastery` | 임팩트 마스터리 | 5 | 임팩트 존 지속시간 +0.5초/레벨 | 공간 제어형 |
| `rage_control` | 레이지 컨트롤 | 5 | 실점 시 레이지 하락량 -10%/레벨 | 안정형 |
| `charge_accel` | 차지 가속 | 5 | 차지 속도 +15%/레벨 | 차지 특화형 |
| `unlock_guard_impact` | 가드 임팩트 해금 | 1 | Guard Impact 스킬 해금 | 카운터형 |
| `crusher_instinct` | 크러셔 본능 | 3 | 보스 HP 30% 이하 시 데미지 +10%/레벨 | 마무리형 |
| `zone_chain` | 존 체이닝 | 3 | 임팩트 존 강화 스킬 적중 시 새 존 생성 확률 +15%/레벨 | 연쇄형 |

**빌드 분기 예시:**
- **존 마스터 빌드**: 임팩트 마스터리 + 존 체이닝 → 존을 깔고 강화 스킬 연쇄
- **풀차지 빌드**: 차지 가속 + 레이지 컨트롤 → 안전하게 풀차지 운용
- **카운터 빌드**: 가드 임팩트 해금 + 크러셔 본능 → 방어적 플레이로 역전

## 4. 시스템 간 시너지 맵

```
            ┌──────────────┐
            │  레이지 게이지  │
            │  (3.3)       │
            └──┬───────┬───┘
    3단계 달성  │       │  축적
    차지↓절반   │       │
  ┌─────────┐  │       │  ┌──────────────┐
  │ 차지 레벨 │←─┘       └──│ 가드 임팩트   │
  │ (3.2)   │               │ (3.4)       │
  └────┬────┘               └──────┬──────┘
       │ 강화 스킬                   │ 퍼펙트 시
       ↓                          │ 존 생성
  ┌──────────────┐                 │
  │ 임팩트 존     │←────────────────┘
  │ (3.1)       │
  └──────┬──────┘
         │ 존 위 스킬 적중
         │ 레이지 +3
         ↓
    레이지 축적으로 순환
```

**핵심 루프:**
1. 공격 → 레이지 축적 → 3단계 도달
2. 3단계에서 차지 스킬 → 임팩트 존 생성
3. 존 위에서 강화 스킬 → 레이지 대량 축적
4. 실점 시 루프 붕괴 → 다시 쌓아올리기

## 5. 개선 전후 비교

| 항목 | Before | After |
|------|--------|-------|
| 스킬 연결 | 없음 | 임팩트 존 → 강화 발동 |
| 판단 요소 | 쿨다운/게이지만 | 차지 레벨 + 존 위치 + 카운터 타이밍 + 레이지 관리 |
| 고유 자원 | 없음 | 레이지 게이지 (3단계) |
| 반응형 플레이 | Cleanse (수동적) | Guard Impact (능동적, 타이밍 기반) |
| 성장 퍽 | 1개 | 7개 (해금 1 + 레벨링 6) |
| 플레이 분기 | 없음 | 존 마스터 / 풀차지 / 카운터 / 하이브리드 |
| 스킬 천장 | 낮음 (최적해 고정) | 높음 (존 배치, 차지 타이밍, 카운터 정확도) |

## 6. 구현 우선순위 (제안)

| 순위 | 시스템 | 이유 | 예상 영향 범위 |
|------|--------|------|---------------|
| 1 | 임팩트 존 (3.1) | 기존 스킬에 시너지만 추가, 새 스킬 불필요 | 스킬 적중 판정, 이펙트 렌더링 |
| 2 | 레이지 게이지 (3.3) | 고유 자원으로 플레이 리듬 변화 | HUD, 공 적중 콜백, 패들 이펙트 |
| 3 | 차지 레벨 (3.2) | 기존 스킬 키 입력에 홀드 분기 추가 | 건틀릿 입력 처리, 이펙트 |
| 4 | 가드 임팩트 (3.4) | 신규 스킬 추가 (가장 큰 변경) | 투사체 충돌, 새 건틀릿 슬롯 |
| 5 | 퍽 확장 (3.5) | 위 시스템 구현 후 퍽으로 조절 | 퍽 시스템, 밸런스 |
