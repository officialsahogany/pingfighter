# 탑 지도 열람 오버레이 /goal 지시문 (2026-08-18)

- **목적**: 탑 런 중 언제든(전투 중 포함) **M 키**로 노드 지도를 열람할 수
  있게 한다. 표기는 **'지도'**. 노드·이벤트 위치와 현재 플레이어 위치 확인용.
- **정본**: v1.6 §3.1(전도 공개: 지도 전체와 노드 아이콘을 처음부터 공개)의
  열람 표면 구현이다.
- **완료 보고**: `docs/tower_map_overlay_report.md`. 푸시 금지.

## 1. 작업

1. **입력·개폐**: 탑 플래그 ON 런 중 M 키로 열고, M 또는 ESC로 닫는다.
   전투 중에도 열 수 있으며, 열림 = **물리차단 모달**(GRT-058 개폐 fanout·
   루프 오디오 정지·재개 시 볼 프리즈·실점 차단 — 기존 모달 계약 그대로).
   일시정지 메뉴·다른 모달과의 중첩 규칙은 기존 모달 우선순위를 따른다.
2. **내용 (열람 전용, 상호작용 없음)**:
   - 오버레이 제목 '지도'. 기존 지도 렌더러(MAP_TRANSITION 표면) 재사용.
   - **현재 플레이어 위치 강조** + 방문·완료 노드와 미방문 노드 구분.
   - **전 노드의 종류 표시**(§3.1 전도 공개 이행): 전투·광폭화·상점·수련장·
     파계승·수호의 샘터·휴식을 아이콘 또는 라벨로 구분. 기존 노드 표시명
     재사용, 신규 명명 금지.
   - 회피로 소멸한 보스 노드는 소멸 표기, 잠긴 10~12층은 잠금 표기 유지.
3. **HUD 힌트**: 탑 런 중 화면 구석에 'M 지도' 힌트 표기(한국어, 엠대시 금지,
   로컬라이제이션 키 등재).
4. **플래그 OFF 무손상**: 레거시 모드에서 M 키는 아무 것도 하지 않는다
   (기존 M 키 바인딩이 있으면 충돌 조사 후 보고).

## 2. 규율

- 커밋 분리(개폐·모달 / 표시 내용 / 힌트), 한국어 제목, 푸시 금지.
- 신규 수치는 `TEMP_*` 튜닝 상수. 신규 `.gd`는 `.gd.uid` 동반.
- 검증: 개폐 스모크(+전투 중 열기, 랠리 정지·재개 안전, OFF 무손상 부정 레그),
  타워 회귀, `-Paths` 경고, 헤드리스, Vulkan 캡처 1장(전투 중 지도 열람).
- 판정 불가 시 중단·보고.

**완료 선언 조건**: §1의 4항목 구현·검증 + 게이트 blocked/unverified 0건 +
보고서 완성.
