# 캐릭터 정보창 개편 — 플레이어 / 링펫 듀얼 레이아웃

상태: 2차 구현 + 패시브 아이콘 연결 완료. 2026-06-01 정리.
대상 런타임: `godot/scripts/hud/character_info_overlay.gd` (TAB 캐릭터 정보 오버레이).

## 1. 목적

현재 링펫 정보는 우측 상단에 짧은 텍스트 패널(`_draw_lingpet_panel`)로만 있어
"부가 설명"처럼 보인다. 개편의 핵심은 **링펫을 플레이어와 나란히 성장하는
동행 캐릭터**로 보이게 하는 것 — 화면을 **플레이어 빌드(좌) vs 링펫 빌드(우)**
비교 구조로 재편한다. 이러면 추후 링펫 성장 / 장비 / 진화 / 친밀도 확장이 쉬워진다.

## 2. 레이아웃

화면을 크게 **플레이어 영역(좌) / 링펫 영역(우)** 으로 나눈다.

```
+---------------------------+---------------------------------------+
| [좌] 플레이어             | [우] 링펫                              |
|                           |                                        |
|  상단: 퍽 그리드          |  상단: 링펫 전신 라투디(원화)          |
|                           |        + 링펫 이름                      |
|                           |        + 액티브/패시브 스킬 아이콘      |
|                           |          (호버 시 스킬 툴팁)            |
+---------------------------+---------------------------------------+
| 하단 능력치 영역 (2분할)                                          |
|   좌: 플레이어 능력치        |   우: 링펫 능력치                     |
+------------------------------+------------------------------------+
```

- **좌(플레이어)**: 상단 퍽 그리드(기존 `_layout_perk_rect`), 하단 능력치 좌측 칸.
  - 플레이어 능력치(기존 유지): 이동 속도, 몸집 크기, 게이지 획득량, 최대 게이지,
    대시 거리, 대시 후딜, 대시 쿨타임, 아이템 쿨타임 등.
- **우(링펫)**:
  - 상단: 링펫 **전신 라투디**(원화) + **이름** + 그 아래 **액티브/패시브 스킬 아이콘**.
    스킬 아이콘 마우스 호버 시 **툴팁**.
  - 하단 능력치 우측 칸: **링펫 능력치**.
- **하단 능력치 탭은 현재 1개 → 2개로 분할**(좌 플레이어 / 우 링펫).

## 3. 링펫 스킬 표기 (마리보)

스킬 아이콘 3개, 호버 시 툴팁. (모두 런타임 구현 완료.)

- **액티브 — 하이드로 스피어**
  - 물의 창을 던져 상대 진영 벽에 닿으면 5초간 **가로로 넓은 둔화 물장판** 생성.
  - 쿨타임 40초. (발사 전 ~1초 창 던지기 준비동작.)
- **패시브 — 공명 증폭**
  - 플레이어가 공을 받아칠 때 **게이지 획득량 +10%**.
- **패시브 — 공명 충전**
  - 마리보가 직접 공을 튕기면 **게이지 +40**. 쿨타임 6초.

아이콘 소스: 액티브는 레일 스킬카드(`maribo_hydro_sphere_skillcard_imagegen_v2.png`)
재활용. 패시브 2종은 imagegen 투명 PNG(`maribo_resonance_boost_passive_icon_imagegen_v1.png`,
`maribo_resonance_charge_passive_icon_imagegen_v1.png`)로 연결 완료.
전신 라투디는 컷인 원화(`maribo_cutin_art.png` / v003 nukki) 재활용 가능.

## 4. 링펫 능력치 항목

우측 하단 "링펫 능력치" 칸. **기존 런타임 값**과 **신규 설계 필요**를 구분한다.

| 항목 | 상태 | 현재 소스 / UI 표기 값 | 비고 |
|---|---|---|---|
| 이동 속도 | ✅ 기존 | **70~135 px/s** (기본 120, 변동 70~135) | 랜덤 패트롤이라 고정값 아님. `COMPANION_PATROL_SPEED_MIN`=70 / `MAX`=135 / 초기 `COMPANION_PATROL_SPEED`=120. UI는 범위로 표기 |
| 몸집 크기 (캐치 범위) | ✅ 기존 | **캐치 범위 100×44 px** | `COMPANION_RADIUS`(16)만으론 체감과 불일치. 공 막는 판정은 패들식 히트박스 ~100×44(`COMPANION_HIT_HALF_WIDTH/HEIGHT`). "캐치 범위 100×44px"로 표기 |
| 게이지 획득량 | ✅ 기존 | **받아치기 +10% / 직접 튕김 +40** | `MARIBO_GAUGE_GAIN_BONUS_PCT`(+10%) + `COMPANION_HIT_GAUGE_GAIN`(+40, 6초 쿨). 2경로 묶어 표기 |
| 액티브 쿨타임 | ✅ 기존 | **40초** (하이드로 스피어) | `COMPANION_SKILL_COOLDOWN_SECONDS` |
| 공명 충전 쿨타임 | ✅ 기존 | **6초** | `COMPANION_HIT_GAUGE_COOLDOWN_SECONDS` |
| 방어율 | ✅ 2차 | **30%** | 하강 공 감지 시 판단 주기마다 30% 확률로 예측 X에 접근. 표시값과 실제 AI가 같은 런타임 상수를 읽음 |
| 대시 토큰 / 대시 쿨타임 | ⏸ 보류 | (이번 개편 제외) | 동행체에 대시 시스템 없음. 지금 넣으면 "있는 기능처럼" 보임. 방어율 체감 후 검토 |

### 방어율 (defense rate) — 신규 스탯 (2차, 실제 AI 연결 완료)
- 의미: 공이 플레이어 진영으로 내려올 때 링펫이 **랜덤 패트롤 대신 공 예상 위치로
  이동해 막으려 시도할 확률**. 높을수록 수비 행동을 더 자주 한다.
- 표시값과 실제 행동값은 같은 런타임 소스(`COMPANION_DEFENSE_RATE`)를 사용한다.
- 구현(2차): `_update_companion_motion`의 패트롤 로직에 분기 추가 —
  하강 공(`ball_vel.y > 0`) 감지 시 판단 주기마다 **30% 확률**로 인터셉트 이동.
  공의 예측 X로 접근하되, 매 프레임 완벽 추적하지 않고 한 번 판단한 목표로 이동한다.
- 툴팁: **"공을 적극적으로 막으러 이동할 확률입니다. 높을수록 수비 행동을 더 자주 시도합니다."**

### 대시 토큰 / 대시 쿨타임 — 보류 (이번 개편 제외)
- 현재 동행체는 대시 시스템이 없다. **지금 넣으면 "있는 기능처럼" 보이고**, 링펫이
  너무 능동적으로 움직이면 **플레이어 패들 역할을 빼앗을** 수 있다.
- 1차/2차에서는 UI 항목에서 제외(또는 필요 시 "−" 표기). 방어율 하나만 먼저 넣고
  체감을 본 뒤, 대시 인터셉트 도입 여부를 별도로 결정한다.

## 4b. 구현 순서 (단계별)

**1차 — 정보창 레이아웃 개편 + 현재 구현된 링펫 스탯만 표시**
- 좌: 퍽 + 플레이어 능력치. 우: 마리보 전신 라투디 + 이름 + 스킬 아이콘 3개 + 링펫 능력치.
- 표시 스탯(전부 기존 런타임): 이동 속도 70~135px/s · 캐치 범위 100×44px ·
  게이지 보너스 +10% / 직접 튕김 +40 · 액티브 쿨타임 40초 · 공명 충전 쿨타임 6초.
- 방어율/대시는 1차에서 **표시하지 않는다**(혼선 방지).

**2차 — 방어율 신규 스탯 + 실제 AI** ✅ 완료
- 방어율 30%를 링펫 능력치에 추가하고, `_update_companion_motion`에 하강 공
  인터셉트 분기를 붙였다. 능력치 표시와 실제 행동은 같은 값을 읽는다.

**3차(보류) — 대시 토큰/대시 쿨타임**
- 방어율 체감 후, 링펫이 패들 역할을 침범하지 않는 선에서만 검토.

## 5. 구현 터치포인트 (`character_info_overlay.gd`)

- 레이아웃: `_layout_perk_rect` / `_layout_lingpet_rect` / `_layout_stats_rect`
  계산부(약 1554~1564행)를 좌(플레이어)/우(링펫) 듀얼 + 하단 stats 2분할로 재편.
- 우측 링펫 패널: `_draw_lingpet_panel`(2164행)을 **전신 라투디 + 이름 + 스킬
  아이콘 행 + 스킬 호버 툴팁**으로 확장. 짧은 title/subtitle/body 텍스트 패널 대체.
- 2026-06-01 추가: 정보창 상단 영역 비율을 키우고, 링펫 원화 박스 계산을 분리해
  720p 기준으로도 마리보 전신 원화가 120px 이상 높이를 확보하도록 조정했다.
- 하단 능력치: `_draw_stats_panel`(2312) / `_build_stats`(2390)를 **2칼럼**으로
  분리 — 좌 플레이어 stats(기존), 우 링펫 stats(신규 항목 빌더).
- 링펫 능력치 행은 호버 툴팁을 가진다. 특히 방어율은 "공을 적극적으로 막으러
  이동할 확률"이라는 실제 인터셉트 의미를 UI에서 설명한다.
- 링펫 stat 값은 `lingpet_egg_runtime.get_snapshot()`에서 노출 — 현재
  `companion_skill_cooldown_duration`(40) / `gauge_gain_bonus_pct`(+10) /
  `companion_hit_gauge_gain`(+40)는 있음. **1차에 추가 노출 필요**: 이동 속도
  범위(`COMPANION_PATROL_SPEED_MIN`=70 / `MAX`=135), 캐치 범위
  (`COMPANION_HIT_HALF_WIDTH`·`HALF_HEIGHT` → 100×44), 공명 충전 쿨(6).
  **2차 완료**: `companion_defense_rate`(방어율) 키 추가 + AI 연결.
- 부화 전(미스터리) 처리 유지: 알 단계에선 우측 링펫 패널이 정체를 노출하지 않아야
  함(전신 라투디·이름·스킬 숨김, "공 충돌 N/2" 부화 진행만). 컷인이 정체 공개.

## 6. 결정 사항

해결됨(보정 반영):
- ✅ 방어율 = **2차에 실제 AI와 함께** 도입(표시용 아님). 대시 토큰/쿨타임 = **보류**.
- ✅ 이동 속도 = **범위 70~135px/s** 표기. 몸집 = **캐치 범위 100×44px** 표기.
- ✅ 패시브 2종(공명 증폭/공명 충전) 아이콘 = imagegen 기반 투명 PNG 생성 및 런타임 연결.
  - `res://assets/sprites/lingpet/maribo_resonance_boost_passive_icon_imagegen_v1.png`
  - `res://assets/sprites/lingpet/maribo_resonance_charge_passive_icon_imagegen_v1.png`

남은 결정:
1. 전신 라투디를 컷인 원화(`maribo_cutin_art.png`) 정적 재활용으로 갈지 / 별도 패널용 포즈를 뽑을지.
2. 2차 방어율 기본값은 30%로 적용. 인터셉트 강도는 실플레이 체감 후 추가 조정.

## 핵심 의도

왼쪽은 플레이어 빌드, 오른쪽은 링펫 빌드. 스킬 3종 아이콘화 + 능력치 비교 구조로
링펫이 동행 캐릭터로 읽히게 하고, 향후 링펫 확장(성장/장비/진화/친밀도)의 골격을 만든다.
