## 1. 목적

현재 링펫 정보는 우측 상단에 짧은 텍스트 패널(`_draw_lingpet_panel`)로만 있어
"부가 설명"처럼 보인다. 개편의 핵심은 **링펫을 플레이어와 나란히 성장하는
동행 캐릭터**로 보이게 하는 것 — 화면을 **플레이어 빌드(좌) vs 링펫 빌드(우)**
비교 구조로 재편한다. 이러면 추후 링펫 성장 / 장비 / 진화 / 친밀도 확장이 쉬워진다.

## 2. 레이아웃

화면을 크게 **플레이어 빌드 영역(좌) / 링펫·퍽·능력치 영역(우)** 으로 나눈다.
기존 장비 슬롯, 장착 스킬, 액티브 아이템, 패시브 보관함은 캐릭터 빌드 편집의
핵심 화면이므로 숨기지 않는다.

```
+---------------------------+---------------------------------------+
| [좌] 플레이어 빌드        | [우] 퍽 + 링펫                         |
|                           |                                        |
|  장비 슬롯                |  상단: 퍽 그리드 | 링펫 전신 원화       |
|  장착 스킬                |        + 링펫 이름 + 스킬 아이콘        |
|  액티브 아이템            |                                        |
+---------------------------+---------------------------------------+
| 우측 중하단: 플레이어 능력치 | 링펫 능력치                            |
+-------------------------------------------------------------------+
| 하단 전체: 패시브 보관함                                           |
+------------------------------+------------------------------------+
```

- **좌(플레이어 빌드)**: 기존 장비 슬롯, 장착 스킬, 액티브 아이템 패널 유지.
- **우(정보/링펫)**: 상단 퍽 그리드 + 링펫 패널, 하단 능력치 2분할.
  - 플레이어 능력치(기존 유지): 이동 속도, 몸집 크기, 게이지 획득량, 최대 게이지,
    대시 거리, 대시 후딜, 대시 쿨타임, 아이템 쿨타임 등.
- **링펫 패널**:
  - 링펫 **전신 라투디**(원화) + **이름** + 그 아래 **액티브/패시브 스킬 아이콘**.
    스킬 아이콘 마우스 호버 시 **툴팁**.
  - 하단 능력치 우측 칸: **링펫 능력치**.
- **하단 전체**: 패시브 보관함 유지.

## 3. 링펫 스킬 표기 (마리보)

스킬 아이콘 2개, 호버 시 툴팁. (모두 런타임 구현 완료.)

- **액티브 — 하이드로 스피어**
  - 물의 창을 던져 상대 진영 벽에 닿으면 5초간 **가로로 넓은 둔화 물장판** 생성.
  - 쿨타임 40초. (발사 전 ~1초 창 던지기 준비동작.)
- **패시브 — 공명 증폭**
  - 플레이어가 공을 받아칠 때 **게이지 획득량 증가**.
  - 공용 패시브 기준: Lv.1 +4% / Lv.3 +10% / Lv.5 +16%.
- **패시브 — 잔광 유출**
  - 링펫이 공을 받아칠 때 바닥에 빛나는 공명 유체를 남긴다.
  - 플레이어 패들이 가까이 가면 유체를 흡수해 게이지를 얻는다.
  - 공용 패시브 기준: Lv.1 총 20pt / Lv.5 총 100pt.
- **패시브 — 순풍 발산**
  - 플레이어의 이동 속도가 증가한다.
  - 공용 패시브 기준: Lv.1 +4% / Lv.3 +10% / Lv.5 +16%.

아이콘 소스: 하이드로 스피어는 레일 스킬카드(`maribo_hydro_sphere_skillcard_imagegen_v2.png`),
물방울트랩은 전용 스킬카드(`maribo_bubble_trap_skillcard_imagegen_v1.png`)와 전용 스킬아이콘
(`maribo_bubble_trap_skill_icon_imagegen_v1.png`)으로 연결 완료. 공명 증폭은 imagegen 투명 PNG
(`maribo_resonance_boost_passive_icon_imagegen_v1.png`)로 연결했고, 순풍 발산은 임시로
`common_swiftness_perk_icon.png`를 재사용한다.
전신 라투디는 컷인 원화(`maribo_cutin_art.png` / v003 nukki) 재활용 가능.

마리보가 직접 공을 튕겼을 때의 **게이지 +40**은 별도 패시브 스킬이 아니라 링펫 공통
기본 능력치로 취급한다. 따라서 "공명 충전" 패시브와 6초 쿨타임 개념은 제거한다.

## 4. 링펫 능력치 항목

우측 하단 "링펫 능력치" 칸. **기존 런타임 값**과 **신규 설계 필요**를 구분한다.

| 항목 | 상태 | 현재 소스 / UI 표기 값 | 비고 |
|---|---|---|---|
| 이동 속도 | ✅ 기존 | **2.00** | 정보창에는 플레이어 능력치처럼 단일값으로 표시. 실제 패트롤은 내부적으로 `COMPANION_PATROL_SPEED_MIN`=70 / `MAX`=135 사이에서 변동하며, 기본값 `COMPANION_PATROL_SPEED_DEFAULT`=120px/s를 60fps 기준 UI 단위로 환산 |
| 몸집크기 | ✅ 기존 | **100×44 px** | `COMPANION_RADIUS`(16)만으론 체감과 불일치. 공 막는 판정은 패들식 히트박스 ~100×44(`COMPANION_HIT_HALF_WIDTH/HEIGHT`). UI 명칭은 "캐치 범위"가 아니라 "몸집크기" |
| 게이지 획득량 | ✅ 기존 | **40pt** | `COMPANION_HIT_GAUGE_GAIN`(+40). 링펫이 공을 직접 튕겼을 때 얻는 공통 기본 능력치로 표기 |
| 액티브 쿨타임 | ✅ 기존 | **40초** (하이드로 스피어) | `COMPANION_SKILL_COOLDOWN_SECONDS` |
| 방어율 | ✅ 2차 | **30%** | 하강 공 감지 시 판단 주기마다 30% 확률로 예측 X에 접근. 표시값과 실제 AI가 같은 런타임 상수를 읽음 |
| 대시 토큰 / 대시 쿨타임 | ⏸ 보류 | (이번 개편 제외) | 동행체에 대시 시스템 없음. 지금 넣으면 "있는 기능처럼" 보임. 방어율 체감 후 검토 |

### 방어율 (defense rate) — 신규 스탯 (2차, 실제 AI 연결 완료)
- 의미: 공이 플레이어 진영으로 내려올 때 링펫이 **랜덤 패트롤 대신 공 예상 위치로
  이동해 막으려 시도할 확률**. 높을수록 수비 행동을 더 자주 한다.
- 표시값과 실제 행동값은 같은 런타임 소스(`COMPANION_DEFENSE_RATE`)를 사용한다.
- 구현(2차): `_update_companion_motion`의 패트롤 로직에 분기 추가 —
  하강 공(`ball_vel.y > 0`) 감지 시 판단 주기마다 **30% 확률**로 인터셉트 이동.
  공의 예측 X로 접근하되, 매 프레임 완벽 추적하지 않고 한 번 판단한 목표로 이동한다.
- 툴팁: **"공을 적극적으로 막으러 이동할 확률입니다. 높을수록 수비 행동을 더 자주 시도합니다."**

### 대시 토큰 / 대시 쿨타임 — 보류 (이번 개편 제외)
- 현재 동행체는 대시 시스템이 없다. **지금 넣으면 "있는 기능처럼" 보이고**, 링펫이
  너무 능동적으로 움직이면 **플레이어 패들 역할을 빼앗을** 수 있다.
- 1차/2차에서는 UI 항목에서 제외(또는 필요 시 "−" 표기). 방어율 하나만 먼저 넣고
  체감을 본 뒤, 대시 인터셉트 도입 여부를 별도로 결정한다.

## 4b. 구현 순서 (단계별)

**1차 — 정보창 레이아웃 개편 + 현재 구현된 링펫 스탯만 표시**
- 좌: 기존 장비 슬롯 + 장착 스킬 + 액티브 아이템 유지. 우: 퍽 + 마리보 전신 라투디
  + 이름 + 스킬 아이콘 2개 + 플레이어/링펫 능력치. 하단 전체: 패시브 보관함 유지.
- 표시 스탯(전부 기존 런타임): 이동 속도 2.00 · 몸집크기 100×44px ·
  게이지 획득량 40pt · 액티브 쿨타임 40초.
- 방어율/대시는 1차에서 **표시하지 않는다**(혼선 방지).

**2차 — 방어율 신규 스탯 + 실제 AI** ✅ 완료
- 방어율 30%를 링펫 능력치에 추가하고, `_update_companion_motion`에 하강 공
  인터셉트 분기를 붙였다. 능력치 표시와 실제 행동은 같은 값을 읽는다.

**3차(보류) — 대시 토큰/대시 쿨타임**
- 방어율 체감 후, 링펫이 패들 역할을 침범하지 않는 선에서만 검토.

- 2026-06-01 추가: 캐릭터 빌드 편집 패널이 사라지는 회귀를 수정해 장비/스킬/액티브/
  패시브 보관함을 다시 표시한다. 링펫 원화 박스 계산은 별도 함수로 유지한다.

- 링펫 stat 값은 `lingpet_egg_runtime.get_snapshot()`에서 노출 — 현재
  `companion_skill_cooldown_duration`(40) / `gauge_gain_bonus_pct`(+10) /
  `companion_hit_gauge_gain`(+40)는 있음. **1차에 추가 노출 필요**: 이동 속도
  표시값(`COMPANION_PATROL_SPEED`=120 → 2.00), 몸집크기
  (`COMPANION_HIT_HALF_WIDTH`·`HALF_HEIGHT` → 100×44).
  **2차 완료**: `companion_defense_rate`(방어율) 키 추가 + AI 연결.
- 부화 전(미스터리) 처리 유지: 알 단계에선 우측 링펫 패널이 정체를 노출하지 않아야
  함(전신 라투디·이름·스킬 숨김, "공 충돌 N/2" 부화 진행만). 컷인이 정체 공개.

## 6. 결정 사항

해결됨(보정 반영):
- ✅ 방어율 = **2차에 실제 AI와 함께** 도입(표시용 아님). 대시 토큰/쿨타임 = **보류**.
- ✅ 이동 속도 = **2.00 단일값** 표기. 몸집 = **100×44px** 표기.
- ✅ 현재 패시브 3종(공명 증폭, 잔광 유출, 순풍 발산) 런타임 연결.
  - `res://assets/sprites/lingpet/maribo_resonance_boost_passive_icon_imagegen_v1.png`
- ✅ "공명 충전" 패시브/6초 쿨타임 제거. 직접 튕김 +40은 링펫 공통 기본 능력치로 표시.

남은 결정:
1. 전신 라투디를 컷인 원화(`maribo_cutin_art.png`) 정적 재활용으로 갈지 / 별도 패널용 포즈를 뽑을지.
2. 2차 방어율 기본값은 30%로 적용. 인터셉트 강도는 실플레이 체감 후 추가 조정.
3. 신규 링펫 추가 시 `lingpet_catalog.gd`에 후보 ID/가중치/스탯/스킬 메타데이터를 먼저 추가하고,
   알 런타임은 카탈로그 후보 중 하나를 랜덤 선택한다.
   - 라이브 후보를 넣기 전에는 `get_hatch_candidates_from_entries()` /
     `pick_hatch_pet_id_from_entries()` 스모크로 다중 후보, 보유 제외, 가중치 선택을 먼저 봉인한다.
   - `validate_catalog(true)`가 통과해야 한다. 새 링펫의 필수 스탯, 알/동행/타격/시전/컷인
     비주얼 경로, 액티브 스킬카드 경로, 효과 텍스트가 빠지면 스모크에서 실패해야 한다.
  - 새 링펫은 카탈로그의 `visuals` 경로(알/금간 알/동행/타격/시전/컷인)와
    `active_skill.card_texture_path`를 채운 뒤 스킬 종류를 `lingpet_skill_dispatcher.gd`에 연결한다.
  - 현재 선택된 링펫의 이름/스탯/스킬/효과 텍스트 조회와 비주얼 접근은
    `lingpet_current_profile.gd`가 담당한다.
  - 카탈로그 `visuals` 경로의 실제 텍스처 로드/캐시는 `lingpet_visual_texture_cache.gd`가 담당한다.
  - 알의 스폰 위치, 플레이어 접촉 흔들림, 공 피격, 서브 공 무시, 부화 카운트는
    `lingpet_egg_field_state.gd`가 담당한다.
  - 알/부화 렌더링(금 간 알 빛, 부화 플래시, 파편 burst)은
    `lingpet_egg_field_renderer.gd`가 담당한다.
  - 마리보 하이드로 스피어처럼 투사체/장판/VFX가 있는 액티브는
    `lingpet_hydro_sphere_skill.gd` 패턴으로 전용 스킬 모듈을 만들고,
    `lingpet_skill_runtime_host.gd`에 prewarm/update/draw/launch 분기를 연결한다.
    `lingpet_egg_runtime.gd`에는 쿨타임/시전 준비/발사 위임만 남긴다.
   - 공통 액티브 상태(쿨타임, 시전 준비, 발사 원점, 플래시, 트리거 카운트)는
     `lingpet_companion_skill_state.gd`가 담당한다.
  - 공통 동행 이동 상태(플레이어 높이 순찰, 랜덤 정지/이동, 방어율 인터셉트,
    순찰 스냅샷 보존)는 `lingpet_companion_motion_state.gd`가 담당한다.
  - 공통 동행 스프라이트 애니메이션(걷기/대기/타격/시전 프레임, source rect, draw offset)은
    `lingpet_companion_sprite_animator.gd`가 담당한다.
  - 공통 동행 렌더링(대기 bob, glow, 걷기/타격/시전 시트 blit, 히트/스킬/게이지 flash)은
    `lingpet_companion_renderer.gd`가 담당한다.
  - 공통 몸체 타격 상태(공 접촉 판정, 반사, 보스 스킬 공 제어 해제, 직접 타격
     게이지 획득, 히트/게이지 플래시)는 `lingpet_companion_body_hit_state.gd`가 담당한다.
  - 소유 링펫 목록, 오너 컬렉션 호환 키, 첫 보유 링펫 자동 동행, 알 부화 후보 선택은
    `lingpet_collection_state.gd`가 담당한다.
  - 획득 컷인의 공개/대기/퇴장 액션 타이밍은 `lingpet_acquire_cutin_state.gd`가 담당하고,
    `lingpet_egg_runtime.gd`는 모달/입력/오버레이용 공개 API만 유지한다.
  - 캐릭터 정보창/HUD/세이브가 읽는 라이브 스냅샷, 저장 스냅샷, `lingpet_*`/`ringpet_*`
    오너 호환 키 동기화는 `lingpet_runtime_snapshot_builder.gd`가 담당한다.

## 핵심 의도

왼쪽은 플레이어 빌드, 오른쪽은 링펫 빌드. 스킬 아이콘화 + 능력치 비교 구조로
링펫이 동행 캐릭터로 읽히게 하고, 향후 링펫 확장(성장/장비/진화/친밀도)의 골격을 만든다.
