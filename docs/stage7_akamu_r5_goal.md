## 1. 착지 순서 (감사 §1 그대로, 고정)

| 순서 | 내용 | 성격 |
|---|---|---|
| L0 | 씰 2종 CI·pre-push 동시 등재 + **RED 베이스라인 숫자 고정** | 행동 변경 0 |
| L1 | 각성 프리즈 컨텍스트 포워딩 복구(R21) | 파리티 복원 |

순서 근거는 감사 §1에 있다. 요지는 둘이다. 게이지 경제를 바꾸는 변경(L2)을
억제 게이트 복구(L1)보다 먼저 넣으면 요구 3의 원인 분리가 불가능해진다.
그리고 L0의 베이스라인 숫자가 없으면 이 영역 씰이 선재 RED라 이후 어느
단계도 GREEN을 증명하지 못한다.

## 2. 확정된 결정 (질문하지 말 것)

감사 §6의 확답 항목 중 아래는 선례·일관성 근거로 **이 지시문이 확정**한다.
감사가 남긴 나머지 근거는 그대로 따른다.

- **황금 굴림은 개체 단위**(감사 해석 A). 세트 단위는 판당 3.7개로 목표
  7~9에 구조적으로 미달한다.
- **`TEMP_GOLDEN_CLONE_CHANCE` 초기값 0.50.** 0.60은 판당 약 10.4개로 목표를
  넘는다. 0.50이면 약 8.7개로 목표 중앙이다. TEMP이므로 라이브 후 조정한다.
- **보스 피격 확률 드랍은 병용하지 않는다.** 초반 수급이 얇은 것은 각성 전
  분신 2기 구조에서 오는 자연스러운 램프로 본다. 라이브에서 초반이 지나치게
  마르면 그때 하한으로 추가한다.
- **라운드 경계 미수거 무혼은 소멸**(스테이지 5 선례). 훅은
  `clear_round_transients()`.
- **서브 대기 중에도 드랍은 계속 낙하**한다(스테이지 5 선례). 득점 직후
  낙하 중이던 무혼이 동결되지 않아야 한다.
- **수거 판정은 원형**(스테이지 5·6 선례).
- **부가 시스템 전부 포함**: 파티클, 별점 다우징, 수호령 별빛 회수 브릿지.
  빠뜨리면 해당 아이템과 수호령 스킬이 스테이지 7에서만 무효가 된다.
- **드랍 스폰 좌표는 분신 몸통 중앙**(`clone_rect.get_center()`).
- **황금 소멸 글리치 팔레트를 금·백금 계열로 교체 승인.** 시안·마젠타·옐로는
  황금 분신에서 정체성이 깨진다.
- **MAX_ENTITIES 8 상한에서 황금 특별 취급 없음.** 다만 잘림이 실제로
  일어나는지 씰 레그로 관측하고 빈도를 보고한다.
- **각성 트리거의 서브 대기 게이트는 유지**하고 원본 이탈로 문서화한다.
  서브 대기 중 3초 전면 동결은 체감이 나쁘다.

## 3. 반드시 지킬 것

- 감사 **§5 함정 예방을 구현 전에 전부 읽고 적용**한다. 특히 다음 넷.
  - **60% 굴림이 퍼프레임이 되면 안 된다**(GRT-011). 굴림은 엔티티 생성
    시점 1회다.
  - 황금 굴림은 **권위 RNG**를 쓰고 해당 엔티티 블록의 **마지막 소비**로
    배치한다. 그래야 기존 시드 고정 씰의 재기준선 범위가 최소화된다.
    영향받는 기대값은 같은 커밋에서 락스텝 갱신한다.
  - **곱연산 틴트만으로는 황금이 어두운 갈색으로 읽힌다**(GRT-047).
    기존 베이크 텍스처를 황금 modulate로 분신 뒤에 깔아 밝은 코어를
    재공급한다. 신규 텍스처 0장. `canvas.material` ADD 스왑은 즉시 `_draw`
    에서 no-op이다(GRT-056).
  - **무혼 드로 좌표계 반쪽 함정**: GPU 슬롯 경로에만 `game_offset`과
    `render_scale` 변환을 적용하고, CPU 폴백에는 변환하지 않은 원좌표를
    넘긴다. 반쪽만 맞추면 부팅 프레임과 헤드리스에서만 틀어지는 잠복
    결함이 된다.
- **수명 만료로 사라지는 분신에는 드랍 훅을 넣지 않는다.** 플레이어 개입
  없는 공짜 파밍이 된다.
- **볼 경로에서 owner 스탯을 바꾸면 프레임 끝 스냅샷이 되돌린다**(GRT-049).
  무혼 수령이 이 함정에 걸리는지 판정하고 보고한다.
- 신규·개정 씰은 `.github/workflows/godot-ci.yml`과
  `godot/tools/run_pre_push_checks.ps1` **두 리터럴 목록에 동시 등재**한다.
- 통과 판정은 배치 종단선 `All Godot smoke tests passed.` + `SCRIPT ERROR`
  0건이다. **이 영역은 선재 RED가 많다**(slice5 30건, pause context 5건).
  L0에서 고정한 베이스라인 숫자와 비교해 보고하고, 줄지 않은 건은 후속
  트랙 귀속을 명시한다.
- 로그 백업 선행. 표준 래퍼 `-AllowDuringPlay`. 커밋 분리·푸시 금지.

## 4. 사용자 확답 대기

**요구 3의 처리 방향 하나만 남았다.** 감사 §6-A 참조.
원본에 시간 게이트가 없다는 사실이 확인됐으므로, L1·L2·L3까지 마친 뒤
계측 결과와 함께 사용자에게 보고하고 지시를 받는다. **L5는 승인 없이
착지하지 않는다.** 유예 초를 발명하지 않는다.

## 5. 검증

- 단계별 씰(감사 §4 그대로) + `-Paths` 경고 + 헤드리스 + `git diff --check`.
- **Vulkan 캡처 3장 이상**: 황금 분신이 일반 분신과 함께 보이는 화면(색 구분
  확인), 보호막에 공이 튕기는 순간, 무혼 드랍이 낙하하는 화면.
- 오오라 배선 후 **전용 사운드가 실제로 재생되는지** 확인한다.
- L3 계측은 라이브 3판. 각성 완료 프레임의 게이지 값과 궁극기까지의 실경과
  시간을 표로 보고한다.
- 판정 불가 지점이 나오면 중단·보고.

**완료 선언 조건**: L0~L4 구현·검증 + 게이트 blocked/unverified 0건 +
L3 계측표 + 보고서 완성. L5는 별도 승인 후 별도 커밋.
