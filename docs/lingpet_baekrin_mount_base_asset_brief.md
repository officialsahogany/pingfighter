## 2. 확정 사항 (사용자 2026-08-13)

| 결정 | 값 |
|---|---|
| M 운영 draw_size | **360** |
| 착석 라이더(N) draw_size | **94** (아트 비율 유지 — 원화 라이더/마운트 길이비 ≈ 0.26) |
| 꼬리 | **길이 유지**. 위·옆으로 감기는 포즈로 **재구성** |
| 바닥 클리핑 | **불가**. 전체 불투명 bbox 가 바닥선 안에 들어와야 한다 |
| 금지 | M 단독 클램프 · 프레임별 재중앙 · 라이더 확대 보정 · 꼬리 단축 · M·N 전체 오프셋 |
| 유지 | 라이더 패들 앵커(§B-1) · 안장 소켓 계약(§B-2) |

### 2-1. 기하가 강제하는 구도 (재구성 브리프의 핵심)

패들 앵커는 고정값이다: `PLAYER_Y = 700`, 패들 높이 `50`, 라이더 rect 는
`y = player_pos.y + paddle.y - draw + 12` 이므로 **라이더 rect 하단 = 762** 로
draw_size 와 무관하게 상수다(§B-5 리프트 0 이라 부양분도 없다).

소켓은 그 762 에 찍힌다. 따라서:

```
마운트 최하단 = 762 + (소켓 아래 불투명 높이)
```

⚠️ **정직한 한계**: 필드 바닥은 750 이고 라이더 rect 하단 762 는 이미 12px 아래다
(현행 플레이어 스프라이트도 동일한 +12 오버행으로 출하 중이다). 그래서 "bbox 가
750 안" 은 소켓을 라이더 앵커에 묶어두는 한 **수학적으로 불가능**하다. 달성 가능한
최선이자 이 브리프의 목표는:

> **소켓 아래 불투명 픽셀 = 0** → 마운트 최하단 = 762 = **현행 플레이어 스프라이트
> 하단과 같은 선**. 즉 탑승이 새로 만드는 바닥 침범은 0 이다.

이것이 "꼬리를 위·옆으로 감아라"의 수치적 정의다: **안장이 실루엣의 최하단**이어야
하고, 꼬리·뒷다리·엉덩이 어느 것도 안장선 아래로 내려가면 안 된다.

### 2-2. 확정 구도에서의 화면 산술

D=360, 셀 512 정사각, 상하 여백 8px 기준:

| 항목 | 값 |
|---|---|
| 마운트 화면 길이(머리~안장) | `504/512 × 360 ≈ 354px` → y **408 ~ 762** |
| 마운트 화면 폭 | 재구성 폭에 비례. 현행 직선꼬리 원화 기준 191px(감아 올리면 더 넓어진다 — 아래 상한 참조) |
| 라이더 rect | 94x94, y **668 ~ 762** (패들 중앙 정렬) |
| 소켓 셀 좌표 | x = 셀 중앙, y = **불투명 bbox 하단** (여백 8 기준 504) |

폭 상한: 플레이필드 760 이고 패들이 좌우 끝까지 이동한다. 마운트 폭이 커질수록
벽 근처에서 화면 밖으로 나간다. **폭 ≤ 260px(= 셀 폭비 0.72)** 을 권고 상한으로
둔다(현행 191 → 감아 올린 꼬리 포함 최대 260).

## 3. 정체성 락 (재구성해도 바뀌면 안 되는 것)

원화 `백린_빈안장_topdown_magenta.png` 가 정체성 앵커다.

| 고정 요소 | 내용 |
|---|---|
| 재질 | 백자 크랙(빙렬) 화이트 몸체 — 미세한 금색 실금 패턴이 몸 전체에 흐른다 |
| 금속 | 금(골드) 하드웨어: 뿔종 2개, 가슴 체인 2줄, 다리 커프 4개, 안장 프레임, 꼬리 고리 |
| 보석 | 청자색(celadon jade) 캐보션 — 가슴 1, 꼬리 끝 1 |
| 안장 | 감청(navy) 비늘 패드 + 금 프레임 + 흰 안감. **탑다운에서 상단이 열린 U 실루엣** |
| 갈기·꼬리 | 백자 소용돌이(운문) 조형. 꼬리는 굵은 S 곡선 + 끝에 고리·보석 장식 |
| 귀/뺨 | 좌우 대칭 늘어진 귀 2장, 볼 소용돌이 |
| 시점 | **정직한 탑다운(바로 위에서)** — 3/4 부감 금지, 원근 왜곡 금지 |
| 대칭 | 좌우 대칭(꼬리만 비대칭 허용). 미러링 없음(8-4) |

바뀌어도 되는 것: 꼬리의 **경로**(위·옆으로 감김), 뒷다리 접힘, 몸통 압축 정도.

## 4. 재구성 구도 스펙 (Codex 생성 브리프)

```
정직한 탑다운(카메라가 바로 위) 단일 스틸 1장, 캐릭터 1체, 라이더 없음(빈안장).
백린은 백자 크랙 재질의 기린형 수호령. 몸은 화면 위쪽을 향하고(머리 위, 안장 아래),
안장이 실루엣의 **가장 아래**에 오도록 몸을 세로로 압축한다.
꼬리는 원화와 같은 길이·굵기·운문 조형을 유지하되, 엉덩이에서 시작해 **몸통 옆으로
붙어 위로 감아 올라가는 경로**로 그린다(고양이가 꼬리를 몸 옆으로 말아 올린 형태).
뒷다리는 안장 옆으로 접어 넣어 안장선 아래로 내려오지 않게 한다.
꼬리 끝 금고리와 청자 보석은 몸통 옆 중단 높이에 놓는다.
평면 마젠타(#ff00ff) 배경. 그림자·바닥 접지 그림자·후광·글로우 없음.
```

금지: 원근 3/4 부감, 머리 방향 회전, 꼬리 단축·굵기 감소, 안장 위치/각도 변경,
새로운 장식 추가, 채도 상승, 페인터리 번짐.
