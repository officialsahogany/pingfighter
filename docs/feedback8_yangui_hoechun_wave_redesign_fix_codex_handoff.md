## [P1] F1 — ★신규 스모크가 단언 실패에도 `: ok` + exit 0 으로 끝난다

`godot/tests/yangui_hoechun_wave_contract_smoke.gd`.

`_expect()`가 `_init` 안에서 **인라인으로 `quit(1)`을 부르는데 그것은
abort 하지 않는다.** 실패한 실행이 exit 0으로 끝나고 `ok` 종단선을 출력한다.

**두 리뷰 레인이 독립적으로 실측 확인했다.**
RED 반증 3회 **전부**에서 재현됐고, **가시성 훅을 지운 상태에서조차**
`[YanguiDrawWiringSeal] visibility=sealed`가 출력됐다.

지금 이 레인을 지키는 건 **래퍼 정규식 하나뿐**이다. 저장소 관례
(`gaksital_vision_input_exclusivity_smoke`)는 `_failed` 플래그가 최종 `ok`와
exit code를 **게이트**한다. **GRT-040 그대로다.**

**수리**: 저장소 관례를 따르라 — `_failed`를 누적하고
`if _failed: push_error(...); quit(1)` / `else: print(... ok); quit(0)`.
`_init`은 deferred runner만 예약하라.

⚠**이걸 고친 뒤 세션이 제출한 모든 종단선을 재실행해 재확인하라.**
지금까지의 GREEN 은 전부 무효로 간주한다.
