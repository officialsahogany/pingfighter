결과보상 "현재무공 강화하기"에서 활주구슬이 강화 가능하게 떠 있다.
진범 성질(관제탑 확정): 활주구슬(dash_amplification)은 **카운트형** —
레벨=구슬 보유 수이고 구슬 하나당 무공 슬롯 1칸을 따로 차지한다

슬롯 소비 없이 무혼만으로 활주 횟수를 올리는 우회가 된다.

요구: 강화 UI에서 카운트형 무공을 강화 대상에서 제외하라. 게이트 기준은
id 하드코딩이 아니라 **성질**(rank_tag "unique" 또는 카운트형 표식)로 —
같은 성질의 무공이 늘어도 자동 적용되게. 상세 열람은 극성 read-only
선례처럼 허용하되 강화 버튼은 비활성(사유 표기). 추가 획득은 기존
보상픽 카드(슬롯 소비) 경로만 유지.
씰: 활주구슬 강화 버튼 비활성+구매 시도 무효·무혼 무차감 · 일반 무공
회귀 없음 · 성질 게이트 역전 RED.
