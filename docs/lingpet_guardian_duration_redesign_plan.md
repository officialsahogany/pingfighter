# 수호령 지속시간 대개편 — 확정 스펙 (기획 단계)

작성 2026-07-28. 기존 수호령(링펫) 진행 시스템 5종을 삭제하고 "지속시간" 단일
자원 + 소환 토글 + 퍽 성장으로 재설계한다. 이 문서가 본 개편의 기획 정본이다.
각 항목은 표기를 따른다: **[확정]** = 사용자 확정, **[위임확정]** = 사용자가
위임하여 Claude가 확정(근거 동반), **[권고]** = 승인 대기 제안.

## 0. 설계 근거

- 수호령이 너무 강력하다: 공 가드(방어 인터셉트) + 보스 무력화 스킬.
- 게임아이콘 서울 전시회 실플레이에서 "밸런스 파괴급, 없애는 게 낫다"는
  피드백을 받음.
- 결정: 삭제도 너프도 아닌 **필드 가동시간 희소성**을 밸런스 레버로 채택.
  파워는 유지하고 시간만 제한하는 궁극기형 소환수 아키타입. 14마리 로스터와
  아트/스킬 자산을 전부 보존하면서 밸런스를 잡는다.
- 튜닝 기준점은 기본 펫이 아니라 **수호령강화가 누적된 런 후반 펫**이다.

## 1. 삭제 대상 [확정]

링코어(티어/구매), 강화칩, 포만도(피딩 4종 포함 — §6에서 1종으로 재목적화),
교감/친밀도(볼히트·클릭 포인트, 레벨업 보상 덱 트리거), 펫 레벨.

단, 삭제 대상 내부의 재사용 부품(포만도 드레인/회복/ε-스냅 레일, 탈진 상태기계,
보상카드 덱, 링코어 퍽 레인, 획득 컷인 호스트)은 §8 이식 맵에 따라 새 소유
모듈로 추출 후 삭제한다. 순서 위반 금지(§9).

## 2. 획득 흐름 [확정]

1. 무공(퍽) 선택지에 공용 초식 **"영혼소환술"** 이 등장한다.
   - 획득 시 초식구슬 5칸 중 1칸을 차지하는 정식 초식.
   - 5캐릭터 공용. 슬롯 만석 시 기존 unlock 계열 스왑 다이얼로그 흐름을
     따르고, 취소는 완전 no-op.
2. **영혼소환술 선택 즉시 필드에 수호령알 1개가 드랍**된다 (스폰풀 RNG 대기
   없음 — 4중 RNG 퍼널 문제의 해법).
3. 알은 **공에 2~4회**(스폰 시 랜덤 롤) 맞으면 부화한다. (기존 1~3에서 상향)
4. 이후 로스터(보유 최대 3마리)에 빈 자리가 있는 동안 수호령알이 기존 액티브
   아이템 스폰풀에서 계속 등장할 수 있다. 영혼소환술 미보유 시 알은 스폰풀에서
   미해금(기존 `can_offer_egg_item` 게이트 확장, 4중 게이트 전부: 스폰풀·픽업·
   deploy·direct-grant).

## 3. 지속시간 (핵심 자원)

- **[확정]** 런 공유 **단일 풀**. 어떤 펫을 꺼내든 같은 배터리를 소모한다.
  펫 3마리를 순환해도 배터리가 늘지 않는다 (펫별 배터리는 가동시간 레버를
  무효화하므로 금지).
- **[확정]** 최대치는 **첫 부화 시 60~80초 랜덤 롤** (런당 1회, 이후 펫 획득은
  재롤 없음). 부화 연출에서 롤 결과를 명시 표기한다.
- **[확정]** 소환 중 실시간 1:1 소모, 수납 중 천천히 회복.
- **[위임확정]** **스테이지 클리어 시 전량 리필.** 근거: 밸런스가 문제되는 곳은
  전투 내부의 가동시간이고, 이월+저속 회복은 런 후반 고갈 확정으로 죽은
  시스템이 되며, 전투 단위 예산 결정("이 보스전 언제 꺼낼까")이 컨셉과 일치.
- **[확정]** 수납 중 회복률 초기값: 드레인의 1/3 (기존 포만도
  `SATIETY_REST_RECOVERY_RATIO` 계승, 라이브 튜닝 전제).
- **[확정]** 만료(0 도달) = **강제 수납** (소멸·KO-in-place 금지). 잔여 ~10초부터
  3단 경고(게이지 점멸 + 전용 사운드 + 펫 모션 변화 — 탈진 텔레그래프 인프라
  재사용). 만료 후에는 **10초 이상 회복되어야 재소환 가능**.
- **[확정]** HUD: 수납 중에도 읽히는 상시 지속시간 게이지 1개
  (기존 vitality/포만도 스트립 재라벨). 수납 중 블라인드 관리 금지.

## 4. 소환 토글 [확정]

- **Ctrl 키** 토글: 소환(캐릭터 몸에서 등장) ↔ 수납(화면에서 사라짐).
  Ctrl은 코드 전체(커밋+WIP, 키코드 4194326·command_or_control 포함) 사용
  0건 검증 완료 — 충돌 없음.
- **[확정]** 패드 매핑: **RT 불승인** — RT는 현재 전투 주 행동 + 확인 입력으로
  사용 중 (`gamepad_input.gd:49-57` 주 행동 트리거, `:87` confirm). 대신 전용
  **`guardian_toggle` 액션을 신설하고 기본 배정 R3** (`JOY_BUTTON_RIGHT_STICK`).
  R3 충돌 검사 완료(2026-07-28): 어떤 액션에도 미배정. 단
  `battle_system_shortcut_input_router.gd:58`이 우스틱 이벤트를 일괄
  억제(`should_suppress_right_stick_event`)하므로 **배틀 라우터에서 R3 버튼
  프레스만 억제 예외(carve-out)** 처리 필요. 메뉴(`main_menu_scene.gd:216`)·
  캐릭터선택(`character_select_screen.gd:405`)의 억제는 유지 (토글은 전투 한정).
- **[확정]** 소환/수납 전환은 기존 슬롯 교체 0.62s 전환 연출
  (`lingpet_companion_switch_state`) + ghost_blink '퐁' VFX 재사용.
- **[확정]** 플리커 봉쇄 2중 잠금 (파괴급 파워를 시간으로 제한하는 설계의
  성립 조건):
  1. **수납 중 정지 대상은 다음 세 가지로 한정한다: 개인/공유 스킬 쿨다운,
     게이지 충전, 신규 시전 준비.** 무력화 스킬은 시전당 가치라서, 쿨다운이
     수납 중에도 돌면 "소환→시전→즉시 수납→쿨 대기→재소환" 플리커로
     지속시간을 거의 안 쓰고 CC 처리량을 전부 뽑아간다.
  2. **최소 소환 유지시간 6초** (소환 후 6초간 수납 불가).
- **[확정]** 수납 시 잔류체 계약: **이미 발사된 스킬·CC·잔류체는 동결하거나
  무료로 지속시키지 않는다** — 수납 시점에 명시적으로 종료·원상복구하고
  루프 오디오를 정리한다. **남은 쿨다운 값과 per-opportunity 롤 락은
  보존**한다 (수납/재소환으로 리셋 금지 — 롤 파밍 차단).
  - 구현 주의: 현재 활성·보관 펫 쿨다운이 모두 계속 감소하고
    (`lingpet_egg_runtime.gd:317`, `lingpet_companion_skill_persistence.gd:86`),
    효과 갱신은 소환 브랜치에 묶여 있어 **단순 게이트만 추가하면 잔류 효과가
    동결**된다 — 정지 게이트와 잔류체 종료 스윕을 같은 슬라이스에 랜딩할 것.
- **[확정]** 수납 상태의 런타임 계약: 수납 = `companion_active` false fold
  (탈진 fold와 동일한 전 콜사이트 ~14곳 목록). 바디히트·방어 인터셉트·스킬
  갱신·레일 카드 전부 정지. 비시각 라이브 상태는 idle-게이트
  생존맵(`is_launch_blocked`) 규칙 준수.

## 5. 성장 — 무공 "수호령강화"

- **[확정]** 볼히트→교감→레벨업 성장 삭제. 대신 무공 선택지에
  **"수호령강화"** 가 가끔 등장. 선택 시 현재 수호령 SD(컷인) 이미지 중앙 +
  강화 연출 재생 후 버프 획득.
- **[확정]** 버프 종류: 액티브스킬 +1 / 패시브스킬 +1 / 지속시간 증가 /
  방어율 증가 / 게이지획득량 증가 / 이동속도 증가 / 액티브스킬 추가해금 /
  패시브스킬 추가해금.
- **[확정]** 등장 메커니즘: 수호령 보유 gate + **최초 보유 후 다음 무공 화면
  1회 확정 예약, 이후 3화면 쿨다운** (기존 링코어 퍽 레인 기계 그대로 재사용).
  퍽 융합 제외 목록에 등재.
- **[확정 — 2026-07-28 라이브 QA 개정]** 보호장치 계약: 롤 전에 **적용
  가능한 버프만 필터** (캡 포화 제외, 비행펫 방어율 no-op 제외 — 비행펫은
  이속→등장률 리맵), 기존 `_can_apply_reward_card()` 계열 재사용.
  - 적용 가능 후보 **0개 → 카드 자체 미등장**.
  - ~~택1 제시~~ → **필터된 풀에서 랜덤 1개 자동 획득** (사용자 라이브 QA
    확정 — 선택 모달 폐기. 지속시간 증가의 희귀 하향 가중은 롤 가중치로 유지).
  - **적용 직전 재검증** 유지: 실패 시 남은 유효 후보 재롤 → 전부 무효 시
    지속시간 +15초 폴백 (무보상 꽝 구조적 금지 불변).
  - 연출: 풀스크린 컷인이 아니라 **컴팩트 패널** — 패널 안에 현재 수호령
    SD 소형 표시, 랜덤 롤 → 결과 배너, 결과 확정 시 해당 수호령 **클릭
    리액션 애니 1회 재생 후 종료** (부화 컷인과 시각적 위계 차별화).
- **[확정]** "지속시간 증가" 버프는 **런 공유 지속시간 owner에 저장**한다 —
  펫별 `reward_counts`에 넣으면 펫 교체 시 최대치가 흔들린다. 나머지 강화
  버프는 펫별 저장 유지. 수치 초안: **+5초, 런당 최대 2회, 희귀 후보**
  (수치는 라이브 튜닝 여지).
- **[확정]** 2번째 액티브/패시브 슬롯 해금은 "추가해금" 버프로 완전 이관
  (기존 스킬레벨합≥5 + 30% 롤 전제조건 폐지, 적용 가능 시 풀에 포함).
- **[확정]** 버프 저장은 기존 교감 보상카드 `reward_counts` 스택 스키마와
  `lingpet_current_profile.get_stat()` 합성층을 그대로 유지하고 트리거만
  교체 (신규 저장 포맷 발명 금지 — 실효 스킬레벨 채널 회귀 방지).
  단, 위 조항대로 "지속시간 증가"만 런 공유 owner 예외.
- **[확정]** 강화 연출은 **획득 컷인 모달 게이트 패턴** (`lingpet_acquire_cutin_
  overlay_host` 포크: 물리 완전 정지 + ungated idle 펌프 + VFX 레인). 신화
  획득류 pause 브랜치(update_effects만 도는)는 owned-ball freeze 트랩으로 금지.
  14펫 컷인 아트 전수 보유 확인 완료.

## 6. 심령수 (피딩 재목적화) [확정]

- 피딩 아이템 4종 삭제 → **"심령수" 1종**으로 단순화.
- 효과: **즉시 지속시간 전량 회복**.
- **[확정]** 스폰은 수호령 보유 시에만 (기존 피딩 게이트
  `LINGPET_OWNED_GATED_ACTIVE_SPAWN_NAMES` 패턴 계승) + **자연 드랍은
  스테이지당 최대 1회** (전량 회복의 강함 감안). 아이콘 1종 신규(또는 기존
  피딩 아이콘 중 1종 재활용).
- **[확정]** 소식가(`lingpet_light_eater`) 패시브는 "지속시간 소모 -%"로
  재목적화. 단 **기존 수치(10~38%) 그대로 이식 금지** — 38% 감소는 가동시간
  최대 약 +61% 증가라 레버를 과도하게 깎는다. 수치는 별도 하향 조정 (미결).

## 7. 리그·경계 조건

- **[확정]** 주니어/오토프레젠트 리그: 영혼소환술 게이트 면제(자동 지급) +
  지속시간 드레인 면제 (기존 포만도 리그 면제 래치 패턴 계승). 시연 중 펫
  소멸 금지.
- 광장 상점: 링코어 구매 행 삭제로 골드+AP 싱크 공석 — 대체 싱크는 별도 결정
  (미결, §10).

## 8. 구현 이식 맵 (기존 → 신규)

| 기존 (삭제 대상 내 부품) | 신규 용도 |
|---|---|
| 포만도 드레인/휴식회복(1/3)/ε-스냅 레일 | 지속시간 소모/회복 엔진 (리네임 추출) |
| 탈진 텔레그래프 1.75s + companion_active fold | 만료 강제수납 + 3단 경고 + 수납 상태 계약 |
| 교감 보상카드 덱 `REWARD_TYPE_*` + 스택 캡 + `get_stat()` | 수호령강화 버프 저장/적용 (트리거만 교체) |
| 링코어 퍽 레인 (owned-gate·예약·3스크린 쿨다운·apply 브리지) | 수호령강화 등장 메커니즘 |
| 획득 컷인 오버레이 호스트 + 모달 게이트 + VFX 레인 | 강화 연출 |
| 슬롯 교체 0.62s 전환 + ghost_blink VFX | Ctrl 소환/수납 전환 연출 |
| 부화 스탯 롤 (`lingpet_hatch_stat_roll_state.ensure_roll`) | 60~80초 최대치 롤 (부화 2경로 모두 커버) |
| `can_offer_egg_item` + 4중 알 게이트 | 영혼소환술 미보유 미해금 |
| 피딩 스폰 게이트 + 아이콘 배선 | 심령수 |
| 포만도/vitality HUD 스트립 | 지속시간 게이지 (재라벨) |
