1. 캐릭터 개요

코만도는 핑파이터의 플레이어블 캐릭터 중 하나로, 화력 기반 원거리 딜러입니다. 권총을 기본 무기로 사용하며, 다양한 화기류를 수집하고 교체하며 싸우는 슈터 스타일 플레이가 특징입니다.

발토르가 건설과 방어에 특화되어 있다면, 코만도는 지속적인 화력과 다양한 무기 운용에 특화되어 있습니다. FPS/TPS 게임을 좋아하는 플레이어에게 추천하는 캐릭터입니다.

2. 조작법

2.1. 기본 조작

조작 동작 설명
A D 좌우 이동 패들 좌우 이동
A/D + S 또는 우클릭 대시 좌우 이동 중 S키로 대시
마우스 좌클릭 화기 발사 현재 선택한 화기 발사
마우스 좌클릭 (탄약 0) 재장전 권총 재장전 (게이지 150 소모)
S / 우클릭 길게 물자보급 1초 홀드 시 물자 항공기 호출 (게이지 350)
S키 빠르게 2번 비상보급 즉시 물자 호출 (게이지 300, 스테이지당 1회)

2.2. 화기 조작

조작 동작 설명
마우스 휠 위/아래 화기 전환 다음/이전 화기로 전환
마우스 휠클릭 권총 ↔ 화기 토글 권총과 이전 화기 빠른 전환
W 누르고 있기 화기 선택 HUD 보유 화기 목록 HUD 표시, 숫자키(1~5) 또는 마우스 클릭으로 화기 선택
휠클릭 토글 시스템: AK-47 사용 중 → 휠클릭 → 권총 전환 → 휠클릭 → AK-47 복귀. 빠른 화기 전환으로 게이지 충전과 화력 사이를 오갈 수 있습니다!

단계 설명

6.3. 물자보급 (Supply Drop) 📦

코만도 전용 스킬로, 아래 방향키 또는 마우스 우클릭을 길게 눌러 발동합니다.

항목 수치 설명
조작 S / 마우스 우클릭 길게 홀드
발동 조건 게이지 350 이상 서브 완료 3초 후부터 가능
홀드 필요 시간 1초 60프레임 (hold_required)
홀드 임계치 0.3초 18프레임 (hold_threshold)
소모 게이지 350 게이지 gauge_cost
드랍 수량 1~3개 랜덤 군용물품 투하
S키 홀드 시작 → 무전기 모션 (0.3초~) → 게이지 바 표시 → 1초 충족 → 물자 항공기 호출!
물자보급 드롭 아이템 목록: 수류탄, 화염병, 조명탄, 거미지뢰, 바주카, AK-47, 그물덫총, 탄약상자, 화력지원, 자폭드론, 도핑물약
⚠️ 격추 주의! 물자보급 비행기가 공에 피격되면 격추되어 추락하며, 물자 투하가 즉시 종료됩니다! 비행기 호출 타이밍에 공의 위치를 잘 파악하세요.

6.4. 비상보급 (Emergency Supply) 🆘

긴급 상황에서 빠르게 물자를 호출하는 코만도 전용 스킬입니다.

항목 수치 설명
조작 S키 빠르게 2번 0.25초 내 더블탭
발동 조건 게이지 300 이상 물자보급과 동일
소모 게이지 300 게이지 물자보급보다 50 적음
사용 제한 스테이지당 1회 각 스테이지 시작 시 초기화
비상보급은 물자보급과 달리 홀드 없이 즉시 발동됩니다! 위급한 상황에서 빠르게 물자를 확보할 수 있습니다.
노후화된 화기에는 비상보급을 사용할 수 없습니다! 탄약상자로만 재장전 가능합니다.

8.1. 초보자 필독 팁

  • 권총으로 게이지를 모아라! - 다른 화기는 게이지 50% 감소
  • 휠클릭으로 빠르게 전환하라 - 권총↔화기 토글로 효율적 운용
  • 권총은 절대 버려지지 않는다 - 최후의 보루
  • 재장전 타이밍을 익혀라 - 탄약 0일 때 좌클릭으로 재장전 (게이지 150 소모)
  • 권총만 수동 재장전 가능! - 다른 화기류는 탄약상자나 비상보급으로만 재장전
  • 비상보급을 기억하라 - S키 빠르게 2번으로 긴급 물자 호출 (스테이지당 1회)

8.2. 게이지 효율 운용법

1. 권총으로 공 반사 → 2. 게이지 50 획득 → 3. 충분하면 화기 전환 → 4. 보스 공격 → 5. 다시 권총 복귀

8.3. 상황별 전략

상황 권장 전략
게이지 부족 권총으로 전환하여 게이지 충전 (50 획득)
보스 공격 타이밍 강력한 화기로 전환하여 집중 공격
물자보급 필요 게이지 350 이상 확보 후 S 홀드
노후화 화기 다수 탄약상자 우선 확보
