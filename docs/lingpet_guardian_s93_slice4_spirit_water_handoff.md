## 1. 심령수 아이템 정의

- id = **`lingpet_spirit_water`**, 표시명 "심령수" (7언어). 액티브 아이템 —
  기존 피딩과 동일한 **슬롯 보관형 사용 아이템** (필드 픽업 → 슬롯 →
  사용 시 발동).
- **사용 효과 = 지속시간 전량 회복, 정의는 정확히
  `pool_current = max(pool_current, pool_max)`** — 재검증 폴백(+15초)으로
  생긴 오버필(pool_current > pool_max)을 **감소시키지 않는다**. 이미 가득/
  오버필이면 no-op(사용은 소모됨 — 사용 여부는 플레이어 판단).
- 수호령 미보유 상태에서 사용 시도: 사용 불가(소모 없음) — 기존 대상-없음
  액티브 아이템 관례를 따름.

## 2. 드랍 정책 (스테이지당 1회 latch)

- **후보 자격 = 수호령 보유 ∧ latch 미소모 ∧ `pool_current < pool_max`.**
  세 조건이 모두 참일 때만 스폰 후보 풀에 진입.
- **latch 소모 시점 = 실제 필드 드랍 성공** (후보 진입·스폰 시도가 아니라
  스폰 성공). 미픽업 디스폰 시에도 latch는 소모 유지(스테이지당 1회는
  "드랍" 기준 — 재드랍 없음).
- **latch 재무장 = 실제 스테이지 전진에서만** — 슬라이스 1의 전량 리필과
  같은 훅(`refill_guardian_duration_for_stage_transition` 경로)에 함께 배선.
  `reset_round` 류 매 라운드 경로로는 절대 재무장되지 않는다 (스테이지 훅
  vs reset_round 트랩).
- **리필×드랍 상호작용 (모호성 봉인)**: 스테이지 전진 시 순서 고정 =
  ①풀 전량 리필 → ②latch 재무장. 직후에는 `pool_current == pool_max`라서
  후보 자격의 세 번째 조건이 거짓 → **리필 직후 드랍은 구조적으로 발생하지
  않는다** (latch 비소모 보류). 풀이 닳기 시작하면(current < max) 그때부터
  후보 진입 — 드랍 낭비가 원천 차단된다. 또한 심령수는 슬롯 보관형이라
  이른 픽업이어도 사용 시점은 플레이어 소유 = 가치 보존.
- **스테이지 도중 최초 보유**: 부화로 스테이지 중간에 첫 수호령을 얻었고
  latch가 아직 미소모라면, 그 시점부터 후보 자격 충족 시 등장 가능(계약).
  미보유 동안은 후보 제외(지분은 기존 skip 패턴으로 자연 재분배).
- 필드 잔류 수명: 기존 액티브 아이템 필드 수명 규칙 그대로(특례 없음).

제거 범위 — **생산자·필드 픽업·표시·임시 +20초 재매핑**:

- 스폰 후보 4종(`lingpet_feed`/`apple`/`melon`/`special`) 제거 — 심령수로
  대체. `LINGPET_OWNED_GATED_ACTIVE_SPAWN_NAMES` 등 게이트 목록 정리.
- 슬라이스 1의 임시 +20초 재매핑 상수·경로 제거.
- `lingpet_feed_controller`/`lingpet_feed_bowl_state` 사용·연출 경로,
  HUD/툴팁 표시, debug 스폰 메뉴 항목 제거.
- **카탈로그 엔트리·플라자 상점 분기**: 먼저 플라자 계열(외래 dirty —
  plaza_shop_stock/pricing/transactions 등)이 피딩 id를 참조하는지 조사.
  ①참조 없음 → 카탈로그 엔트리 4종 삭제. ②참조 있음 → 엔트리는 유지하되
  모든 획득 경로 차단(스폰·오퍼·지급 불가 마크)만 하고, 물리 삭제는
  플라자 정산 후 §9-4로 이관 — 외래 파일 수정 금지.
- 아이콘 PNG 4종은 **삭제하지 않는다** (special = 심령수 placeholder 사용
  중, 나머지는 §9-4 일괄 정리).
- **`lingpet_feed_active_item_smoke.gd` 파일 삭제 금지** — 트리에 보류된
  플라자 헝크가 보존 중이다(삭제=소실). 본문을 "구 피딩 스폰/사용 경로
  0건" 단언으로 재조준하고 **자기 헝크만 커밋**, 플라자 헝크는 트리 보존
  (기존 경계 규율). `lingpet_feed_affinity_smoke`·bowl 계열 씰은 대상
  소멸이므로 은퇴(삭제) 가능 — 트리 보류 헝크 유무 먼저 확인.
