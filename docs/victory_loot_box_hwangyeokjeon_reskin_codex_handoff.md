# 승리 전리품 상자 환격전풍 리디자인 — Codex 핸드오프

작성 2026-07-28 (Claude 아트디렉션 → Codex 생성/후처리/배선 인계.
분담 근거: 리포지토리 표준 분담 — Claude=미적 방향/프롬프트/QA 기준,
Codex=생성·누끼·런타임 반영. `CLAUDE.md` §0.1)

## 1. 목적 / 사용처

보스 격파 승리 전리품 페이즈(`victory_loot_phase_state.gd`)에서 보스 몸에서
떨어지는 보상 상자 3종의 개봉 시트를 **환격전(한국 신화무협) 풍**으로 전면
리디자인한다. 현 시트는 구 결과화면용 사이버 계열이라 세계관과 어긋난다.

교체 대상(동일 경로 드롭인 교체, 런타임 코드 변경 불요):

| kind | 경로 |
|---|---|
| normal (일반 상자) | `godot/assets/sprites/result_boxes/result_box_common_open_16f.png` |
| advanced (고급 상자) | `godot/assets/sprites/result_boxes/result_box_mythic_open_16f.png` |
| guaranteed_mythic (신화 확정 상자) | `godot/assets/sprites/result_boxes/result_box_guaranteed_mythic_open_16f.png` |

소비자는 두 곳: ① 전리품 페이즈 필드 드랍(주 사용처, **화면상 ~78px** —
`victory_loot_phase_state.BOX_DRAW_SIZE`), ② 결과화면 상자 모듈(현재 dormant,
`stage_clear_result_box_draw_helper.gd`).

## 2. 시트 계약 (불변)

- 4x4 그리드, 셀 256x256, 총 16프레임, 좌→우·상→하.
- **frame 0 = 완전히 닫힌 상태.** 낙하·바운스·안착 대기 내내 이 프레임 하나로
  표시되므로 단독 스틸로 완성도가 있어야 한다.
- 개봉 재생 구간: frame 0 → safe last. 현 런타임 상수는 common=12,
  advanced/guaranteed=15 (`BOX_COMMON_SAFE_LAST_FRAME`). 새 common 시트가
  16프레임 전부 유효하면 런타임 상수를 15로 올리는 갱신을 같이 랜딩할 것
  (`victory_loot_phase_state.gd` + `stage_clear_result_box_draw_helper.gd`
  두 곳 — move-together).
- 알파: 코너 완전 투명, 발광/파티클 포함 어떤 픽셀도 셀 에지 미접촉
  (`FRAME_ASSET_GUARD_SCALE 0.90` 여유 전제). 어두운/밝은 배경 프리뷰에서
  프린지 없음.
- **바닥선 고정**: 상자 본체의 접지선이 전 프레임 동일 y — 개봉 중 상자가
  아래위로 미끄러져 보이면 반려(안착 후 재생되므로 특히 눈에 띈다).
- 셀 중심 정렬, 등급 간 본체 크기 위계는 ±10% 이내(획득 판정 rect는 공유).

## 3. 컨셉 방향 (환격전 = 한국 신화무협, 환단고기 소재 배제)

등급 위계가 실루엣과 발광만으로 즉시 읽혀야 한다(78px!).

- **normal — 흑칠 나무 궤**: 소박한 민예 목궤. 먹흑/옻갈색 몸체, 무쇠(어두운
  철) 모서리 장석, 삼베 매듭끈 잠금. 개봉 발광은 은은한 호박색 미광 소량.
- **advanced — 나전칠기 함**: 흑칠 위 자개(진주광) 문양, 놋쇠/청동 장석,
  오방색 매듭술 포인트. 개봉 시 청록+금 미광, 자개 반짝임 파티클 소량.
- **guaranteed_mythic — 신수 금장 궤**: 옻칠 흑금 몸체 + 금장 해태/봉황 문양
  장식, 자주(자금)색 부적 봉인. 개봉 시 부적이 찢기며 강한 금백 발광 기둥 +
  자금 파티클. 셋 중 유일하게 "봉인이 풀리는" 서사를 갖는다.

금지: 사이버/네온/회로 문양, 서양식 보물상자(금화 더미) 클리셰, 문자 각인
(로컬라이즈 문제), 환단고기 고유명.

## 4. 개봉 코레오 (16f 기준)

- f0–f3: 잠금(매듭/장석/부적)이 풀리며 미세 진동 — 본체 실루엣 유지.
- f4–f8: 뚜껑이 뒤로 들리며 틈에서 등급색 빛이 샌다.
- f9–f12(15): 완전 개방 + 발광 기둥/파티클 피크 → 마지막 프레임은 다음
  프레임이 없어도 안정적으로 홀드되는 상태로 마무리(런타임은 마지막 safe
  프레임에서 정지한 뒤 보상 지급·소멸).
- 런타임이 f0~0.55 구간에 자체 흔들림 셰이크를 얹으므로 시트 자체의 초반
  진동은 과하지 않게.

## 5. 생성원 / 후처리 규칙

- 시트 최종본은 **AutoSprite MCP 필수**(리포 표준 — Gemini/FLUX는 컨셉 스틸,
  프롬프트 검토까지만). 컨셉 스틸로 3종 무드를 먼저 고정한 뒤 시트 생성 권장.
- 결정적 후처리 허용: 누끼/알파 정리, 셀 재배치(AutoSprite 출력 → 4x4 256
  재구성), 스케일 정렬, 프리뷰 GIF. 소스 프레임은 AutoSprite 유래 유지 +
  핸드오프에 잡 기록.
- 스테이징 원본은 `images/` 트리에 보존, 채택본만 위 runtime 경로로 복사 +
  `.import` 재생성(`--headless --import`).

## 6. QA 게이트

1. **78px 실사용 스케일 판독**: 3종을 나란히 필드 스케일로 캡처 — 등급 위계
   즉시 구분, 닫힌 프레임의 실루엣 판독.
2. 알파 코너/에지/프린지 검사(어두운·밝은 배경).
3. 바닥선 고정 검사(f0↔마지막 프레임 토글 오버레이).
4. 라이브: 전리품 페이즈에서 낙하→바운스→안착→개봉 풀 사이클 캡처(3종),
   개봉 발광이 하단 HUD를 침범하지 않는지.
5. 기존 스모크 무변 GREEN: `victory_loot_phase_state_smoke`,
   `stage_clear_result_box_*` 계열(시트는 데이터 교체라 GREEN 유지가 정상).
   common safe-frame 상수를 올리는 경우에만 관련 상수 단언 갱신.
