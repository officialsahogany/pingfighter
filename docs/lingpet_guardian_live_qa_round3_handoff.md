# 수호령 라이브 QA 3차 핸드오프 (Codex 실행용) — 강화 재등장 버그·슬롯 비점유 실전 미적용·교감 조기 삭제·툴팁 조작법

작성 2026-07-29. 가드레일·씰 실행 규정 기존과 동일. 커밋 순서:
**④ 재등장 버그 → ② 슬롯 projection → ③ 교감 삭제 → ① 툴팁**.

## ④ 수호령강화 퍽이 첫 1회 이후 재등장하지 않는 버그 (최우선)

- **계약 명확화**: 보유 후 다음 무공 화면 1회 확정 예약 등장 → 이후 **3화면
  쿨다운이 지나면 재등장은 확정**(확률 아님, 적용 가능 후보가 있는 한).
  후보 0일 때만 미등장, 그 화면은 쿨다운을 소모하지 않는다(보류).
- 진단 앵커 (Claude 사전 조사):
  1. `lingpet_guardian_enhance_offer_engine`의 `_cooldown_screens`는 자체
     감소(:134-135)하지만 — **엔진 인스턴스가 무공 화면 간에 지속되는가?**
     상태가 화면마다 재생성되거나 반대로 예약-소진 플래그가 런 상태에
     저장되어 재등장 경로를 영구 차단하는지 확인.
  2. **예약 1회 소진 후 일반 등장 경로가 존재하는가** — 예약 레인만 있고
     비예약 등장 분기가 미구현일 가능성. `_blocked(...)` 사유 로깅으로
     실제 차단 사유를 확인해 보고서에 명시.
  3. cbc186742(링코어 은퇴)가 `tick_lingpet_ring_core_offer_cooldown`
     콜백을 삭제했다 — 강화 쿨다운이 그 공유 틱에 의존했는지 상호작용 확인.
- 씰: **다화면 시퀀스 실 open_flow 관통** — 보유 → 화면1 등장 →
  획득/미획득 각각 → 화면2~4 쿨다운 → 화면5 재등장 → 반복 1사이클 더.
  반증 = 재등장 분기 차단 시 RED.

## ② 무공 슬롯에 영혼소환술이 여전히 자리잡는 문제 (실전 미적용)

- 유력 원인 = **퍽 표시 Projection-분기 트랩** (`docs/godot_runtime_traps.md`
  등재): 라이브 스냅샷은 보유 퍽이 있으면 항상 융합 display projection을
  실어 오므로 **TAB 퍽 표시의 실전 경로는 100% projection 분기**다.
  c4880dce0의 `_slot_free_cell` 처리가 일반 분기에만 랜딩됐는지 검사하라 —
  스모크만 GREEN이고 실전에서 죽는 전형.
- 수정 규정(트랩 문서 그대로): 공용 헬퍼 관통 + **실 `get_snapshot()` 레그**
  + projection 비어 있으면 fail-closed 가드. 슬롯 카운터와 표시 양쪽 모두
  projection 분기에서 비점유.
- 씰: projection 분기 관통(손제작 일반 분기 dict 금지) + **무공 예산 가득
  픽스처**에서 영혼소환술 추가 시 카운터 불변·오버플로 미발생 단언.
- Vulkan 픽셀 QA 1장: 무공 슬롯 영역 — 영혼소환술이 슬롯 밖(비소모 셀)에
  표시되고 슬롯 수가 실제 무공 수와 일치.

## ③ 교감 수치 조기 삭제 (§9-4 교감 청크 선행)

- **삭제**: 교감 포인트/레벨/보상 덱 트리거(레벨업→보상 지급 경로),
  수입 파이프라인 전부(볼히트·클릭 포인트·라운드 커밋·부화·승리·스테이지
  클리어·비행 배율), TAB 교감 미터·"다음 보상" 행, '교감 Lv.N!' 플로팅
  라벨·레벨업 차임, 관련 다국어 카피. 세이브 구 키는 읽고 폐기(관용 파서).
- **유지**: 클릭 리액션(코스메틱 반응만 — 포인트 없음), hatch 헤드스타트
  롤(펫 개성 롤 — 저장 위치 이전은 §9-4), `lingpet_enhancement_buff_store`
  (이제 **수호령강화 퍽이 유일 성장 트리거**), '하트 공명' 타이틀 등
  영구 수집 표면은 §9-4에서 일괄 판단.
- 2번째 슬롯 해금은 이미 추가해금 버프로 이관됐으므로 교감 트리거 삭제로
  고아화되는 소비자가 없는지 전수 확인 (실효 스킬레벨 채널은 buff store
  소유 — 회귀 금지).
- 씰: 교감 계열 씰 은퇴(각 파일 보류 헝크 확인 후 .gd/.uid 쌍) + "볼히트
  N회에도 성장 이벤트 0건 + 수호령강화만 성장" 단독화 단언.
