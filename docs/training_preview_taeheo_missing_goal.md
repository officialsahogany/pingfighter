## 0. 배경 `[확인]`

태허심법은 `physique_training_catalog.gd` 에서 `source_perk_id: fuel_pouch`
이며 **최대 기력**을 올린다. 능력치 띠에 `최대 기력` 행이 실재한다.

★**태허심법만 다른 경로를 탄다.** 다른 8종과 달리 예측값이
`mythic_item_owner_syncer.gd` 의 `build_fuel_pouch_gauge_projection()` 을
거친다. `ee7a95661` 이 그 헬퍼를 추출해 만든 경로다.

용의자는 셋이다. **실측으로 가려라.**

- **가.** projection 이 현재 값과 같은 값을 돌려준다 → 증가분 0 → 미표시.
- **나.** 행 인덱스 매칭이 실패한다 → `row_index = -1` → 미표시.
- **다.** 호버 판정에서 태허심법이 제외된다 → 모델 자체가 비어 있다.

★**정적 분석으로 확정하지 마라.** 실제 호버 경로를 태워
`row_index`, `current_fill_ratio`, `projected_fill_ratio` 를 찍어 보라.
