## 사용자 확정 요구

### 1. 현재무공 탭 = 제자리 강화 (핵심)

- 탭 라벨 "현재 무공" → **"현재무공 강화하기"** (2항).
- 슬롯의 무공 **호버 시 기존 툴팁(image4) 아래에 "클릭하여 강화하기"** 추가.
- **클릭 시 강화 화면(image2)**:
  - 좌 = 현재 성급 카드(한지 크림톤), 우 = 강화 후 카드(청백톤),
    중앙 황금 화살표. 우측 수치에 **증가분 녹색 (▲n%)** 병기.
  - 하단: **"모든 무공 단계 보기" 체크박스** → 체크 시 1성/2성/극성 전
    단계 나란히(image3).
  - 그 아래 **뒤로가기 / 강화** 버튼. 좌상단 뒤로 화살표.
  - ⚠극성(최대 성급) 무공 클릭 시의 처리(비교 대상 없음)를 판정해 보고.

### 3. 보상 픽 = 미획득 무공만

- 승리보상 무공 카드에서 **보유 무공의 상위 성급 카드를 제거** — 항상
  신규 무공만 등장. (강화는 1항의 제자리 강화로 이동했으므로.)
- **무공 슬롯 만석 시**: 보상 무공 클릭 → **교체 UI** (현행 초식 슬롯 교체
  UI 와 같은 패턴 — X1 의 `guardian_spring_chosik_swap` 오버레이가 선례).
- ⚠Y8 이 착지시킨 "보상 초식 카드"(reward_pick_kind=chosik)와의 공존 확인.
- ⚠`perk_offer_owned_upgrade_priority_smoke` 등 **보유-업그레이드 우선
  씰이 현행 반대 동작을 봉인 중일 수 있다** — 설계 뒤집기이므로 씰 동반
  재작성(기준선 RED 목록에 이미 있는지 먼저 확인).

### 4. 강화 비용 = 스테이지 내 등차수열

- 첫 강화 무혼 3, 둘째 4, 셋째 5 … (**무공 불문 스테이지 내 공유 카운터**).
- **다음 스테이지 보스 클리어 시 3부터 리셋.** (스테이지 내 몰아 강화 방지
  경제 장치 — 사용자 원문 예시 그대로.)
- 상수로: `BASE=3`, `STEP=1`. 표기(강화 버튼·카드)에 현재 비용 노출.

### 5. '가방확장' 고유 카드 신설

- 활주구슬(dash_amplification)과 같은 **기타/고유 카드류**.
- 비용 **무혼 2**, 선택 시 **액티브 아이템 슬롯 +1**, **무공 슬롯 미차지**.
- 슬롯 증가는 기존 `active_item_slot_capacity` 합성 계약
  (`runtime_perk_state.get_active_item_slot_capacity`)에 가산 — Y2 상점
  슬롯 UI 가 자동 추종하는지 확인.
- 카드 아이콘: 기존 자산 재사용 우선, 신규 필요 시 별도 보고(아트 스킬
  라우팅·`.import` 규칙).

### 12. '새로고침' 카드 가끔 등장

- 승리보상 카드 풀에 **낮은 확률**로 새로고침 카드 등장(제안: 15%,
  상수로). 선택 시 현재 오퍼를 재굴림. 비용 판정(제안: 무혼 1) 후 보고.
- ⚠**결정성**: 오퍼 시드가 `resolution_id` 고정이므로 재굴림은 **재굴림
  카운터를 시드에 포함**해 세이브스커밍 없이 결정적으로.
- ⚠Y8 의 OFFER_VERSION 관례 — 카드 종류·RNG 소비가 바뀌므로 버전 승급.
