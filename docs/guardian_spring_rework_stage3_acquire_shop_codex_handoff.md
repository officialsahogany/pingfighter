- **금지**: 본 트리 직접 편집·푸시·통합. 보고 후 대기.

  아트 브리프 준비). 기능 정본을 먼저 세운다.

## 손바닥을 대본다 (무료 · 첫 수호령 즉시 획득)

1. 플로우: 실행 → 영혼소환술 습득(기존 SOUL_SUMMON_ART_UNLOCK 퍼크
   경로 그대로 — 알 스킬은 추가 수호령 채널로 존속) → 초식 인수 연출
   재사용(카드선택화면 인수 연출 정본) → **3마리 랜덤 제시** → 1마리
   선택 → 기존 획득 컷인(lingpet_acquire_cutin) → 즉시 귀속·활성.
2. 3픽 규칙: 로스터에서 중복 없는 3종, 결정론 시드
   hash('tower_spring_first_pick_v1:map_seed:node_id')(강화 롤과 시드
   네임스페이스 분리). 전원 **무강화 기본체**.
3. 첫 픽 정보 수위(사용자 확정): 호버=교감 라투디+이름+한 줄 소개만.
   스킬/수치 숨김. 살핀다와 툴팁 빌더 공유하되 blind 플래그로 차단.
4. 즉시 합류: 교체 활성화 전례(`activate` 계약 — 컴패니언 활성+순찰
   초기화+지속풀 리필)를 신규 귀속에 재사용. 다음 전투 즉시 동행 단언.
5. 획득 순간 S2의 `prayer_locked` 발동.

## 수호령들을 살핀다 (무료 브라우즈 · 금화 구매 교체 · 반복)

1. 3마리 제시하되 **엘리트 롤**: 각각 랜덤 강화 상태(액티브1/2 레벨,
   패시브 레벨, 기동/방어/게이지 스택, 2슬롯 해금 — 기존
   enhancement_buff_store 어휘 그대로)를 붙여 생성. 롤 예산은 층수
   파생: `roll_count = clampi(현재층, 1, 10)` 회의 강화 롤을
   기존 apply_guardian_enhance 룰로 적용(⚠GRT-054: 상수 파생·튜닝
   TEMP_ 네이밍). 시드 hash('tower_spring_browse_v1:map_seed:node_id:
   sequence') — 살핀다 재실행마다 sequence 증가(리롤 = 재실행).
2. **가격 = 기계 산정**: `기본 80금화 + 적용된 강화 롤 1회당 40금화`
   (TEMP 상수 2개). 경제 실측 기준: 상점 60~300금화·전투당 랠리 수입
   수백 — 층 심화 시 300~480금화 밴드로 후반 상점 유효.
3. 호버=전체 정보(스킬 레벨·능력치·교감 라투디). 클릭 → **기존 교체
   비교창 재사용**(좌 현재/우 후보, overflow compare 정본) → 확정 시
   금화 차감+교체. **기존 수호령은 소멸**(commit_overflow_replace 망각
   의미론 재사용 — 사용자 확정: 엘리트 롤 구조라 유리한 거래 가능).
   ⚠빈 활성 슬롯 메움 금지 규칙은 비교창 기존 계약 유지.
4. 구매 트랜잭션: `tower_ascent_node_action_transaction.apply_once` +
   롤백(금화 환불·수호령 상태 원복) — 기존 spring 롤백 인프라 재사용.
5. ⚠GRT-058: 비교창을 샘터 진입점에서 열 때 기존 개폐 훅(우선 입력
   라우터·물리 차단) 상속 확인 — 새 진입점 훅 누락 검증 레그 필수.
