## [P2] F2 — 패들 결합 제거 씰이 공허

- 바운스 후 무조건 재정규화하므로 outgoing은 항상 serve_speed —
  `incoming ≈ outgoing` 단언은 항등식이 되어 전투 min-rally/accel을
  되돌려도 GREEN이다(⑨-1이 코드로만 존재, 봉인 없음).
- 수리: 재정규화를 우회한 프로브(또는 리졸버 반환 원본 속력)로
  전투 결합 부재를 직접 단언하거나, 방향/영어(각도) 보존까지 포함해
  관측 가능한 실패를 만들 것. 여의치 않으면 "⑨-2 재정규화가 단독
  보증"임을 씰 주석과 보고에 명시.
