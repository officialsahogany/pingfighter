## 사용자 확정 룩 (원문 기획)

1. 샘터 입장 = 신비로운 샘터 배경 + 중앙에 손을 올릴 수 있는 **조선풍
   신비로운 바위석상**.
2. 석상에 마우스 호버 → **빛나며 반응**. 클릭 → 대사
   "바위에서 영험한 기운이 흘러나옵니다" + 선택지 노출(수호령 없음=
   [손바닥을 대본다/기도한다], 보유=[수호의 신과 영접한다/수호령들을
   살핀다] — 메뉴 규칙은 착지 정본 그대로).
3. 손바닥 선택 → **3.4초 상승 + 0.4초 공개 + 무기한 확인 + 3.0초 흡수 + 0.4초 충격** + 바위에서 **영혼소환술 초식
   아이콘이 아래에서 위로 점점 떠오름** → 기존 초식 인수 연출(카드
   선택화면의 나에게 들어오는 연출)로 흡수 → 3픽 화면.
4. 3픽·살핀다의 수호령 제시 = 카드가 아니라 **수호령 캐릭터를 감싼
   캡슐이 천천히 부유**, 호버 시 교감 라투디(+S3 정본 툴팁 규칙:
   첫픽=이름·한줄만, 살핀다=전체 정보+가격).
