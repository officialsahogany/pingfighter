# 지시문 Z11 — 밴드 아트 가장자리 gutter 를 원천 제거해 접힘을 회복하라

- **발행**: 관제탑 2026-08-29. 기준선 = 본 트리 HEAD (Z9 A2 착지 이후).
- **격리 워크트리 + 격리 브랜치.** 본 트리 편집·통합·푸시 금지.
- **선행**: Z9 A2. **적합 세션**: Z8·Z9 를 작업한 세션(코드·측정 하네스 보유).

## 배경 (관제탑 판정 기록)

Z9 A2 는 gutter 0px 을 지켰지만 그 대가로 **반사 폭이 16→48px** 로 늘어
접힘 개선이 14.3%(120.4→103.2px)에 그쳤다. 라이브 카메라 줌(~2.1배)에서
접힘이 여전히 옅게 읽힌다.

★**근본 원인은 밴드 아트 텍스처의 상·하단 가장자리에 있는 밝은 gutter
띠(6~8px 추정)다.** 그것만 없으면 guard 가 필요 없고, 반사 폭이 16px 로
돌아가 접힘 ~34px(후보 A 실측)을 얻는다.

## 요구

1. **gutter 실측**: 밴드 아트 6종(human 3 + immortal 3, `_x4.png`)의 상·하단
   가장자리에서 밝은 띠의 실제 폭·밝기 프로파일을 측정해 보고하라.
   `common_hanji_paper_x4.png` 도 확인하라.
2. **edge-bleed 정리**: gutter 띠를 **인접 안쪽 행의 복제/클램프**로 덮어라.
   - ★**아트 본체(내부 픽셀) 무접촉.** 가장자리 gutter 는 생성 부산물이지
     승인된 아트가 아니다. 내부를 한 픽셀이라도 바꾸면 identity 위반이다.
   - 프로그래매틱 처리(스크립트)로 하라. 재생성·리드로우 금지.
   - ★**원본 보존**: 수정 전 원본을 `images/` 계열 보존 경로에 커밋하거나,
     git 이력이 원본을 보존함을 확인하라(추적 자산이면 이력으로 충분).
3. **guard 축소**: 정리 후 `source-edge guard` 를 0~8px 로 줄이고 반사 폭을
   16px 유지. **목표: 접힘 ≤40px + gutter 합계 0px + hard jump 0 동시 충족.**
4. **PNG 교체의 재임포트**: 격리 트리에서는 `.import` 사이드카 경로가 그대로
   이므로 사이드카 수정은 불필요하다. 착지 후 본 트리 에디터 **포커스
   재임포트**(X3 선례)로 재료화한다 — 보고에 명시만 하라.
   **헤드리스 --import 금지. 에디터 종료 요구 금지.**
