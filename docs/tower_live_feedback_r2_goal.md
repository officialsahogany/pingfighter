# 탑 라이브 2런 피드백 /goal 지시문 (2026-08-18)

- **정본**: `docs/tower_ascent_run_map_plan.md` **v1.7** (§3.1 지도 전체화면·
  노드 페이즈 2분할, §3.2 자동 서브 금지·상단 벽 반사, §3.3 페이즈 매핑,
  §4 페이즈별 아트 방향). 사용자 라이브 2런 피드백으로 개정된 계약이다.
- **완료 보고**: `docs/tower_live_feedback_r2_report.md`. 푸시 금지.

## 1. 작업 항목 (각각 독립 커밋, 번호 순서 권장)

1. **첫 무혼 획득 프리즈 수정**: 라이브에서 첫 스폰 무혼 획득 순간 화면이
   잠깐 멈춘다(로딩 체감). 원인 진단 먼저 — 유력 후보는 획득 연출/모달의
   콜드 lazy init(GRT-003) 또는 경량 값을 위한 무거운 모듈 콜드 생성
   (GRT-042). 첫 획득 경로의 콜드 비용을 계측해 범인을 특정하고, 부트/스테이지
   진입 프리웜으로 이동한다. 디스크 쓰기(해금 저장 등)가 범인이면 지연/배치
   쓰기로 옮긴다. 씰 = 콜드 첫 획득 경로 계측 레그.
2. **경로 서브 자동 발사 금지** (§3.2 v1.7): 상자 보상 후 ROUTE_AIM 서브
   대기에서 몇 초 뒤 자동으로 공이 발사되는 현행 동작을 제거한다. 발사는
   오직 플레이어 입력으로만. 일반 전투의 자동 서브 타이머는 불변(부정 레그).
3. **경로 서브 상단 벽 반사** (§3.2 v1.7): 표적을 빗맞힌 공이 상단 벽에
   닿아도 재서브 리셋하지 않고 튕겨 되돌아온다. 좌우 벽 반사 유지, 되돌아온
   공은 플레이어 패들로 재타격해 재조준 가능(기존 패들 반사 물리 재사용),
   비행 중 표적 명중 시 그 시점 확정. 공이 하단 밖으로 나가면 그때 재서브
   대기(수동)로 복귀. 볼 소유권·GRT-049 스냅샷 계약 준수.
4. **지도 전체화면 전환** (§3.1 v1.7): 노드 지도(M 열람 + 이동 연출 모두)를
   전투 플레이필드 창 안이 아닌 **화면 전체(레터박스 포함)** 표면으로
   승격한다. GRT-044(viewport rect 기준 사이징)·GRT-058(모달 개폐 계약
   유지)·GRT-045(클립 경계 재점검) 준수. 구도는 정본 §4의 "아래에서 위로
   올라가는 성" 세로 등정 레이아웃으로 재배치하고, **노드마다 그림 슬롯**을
   추가한다 — 보스 노드는 기존 보스 초상/스프라이트 재사용, 시설 노드는 기존
   아이콘 재사용. 신규 비트맵 아트는 이 목표 범위 밖(후속 아트 트랙)이며
   미존재 아트 경로를 퍼프레임에 배선하지 말 것(GRT-004).
5. **노드 페이즈 2분할** (§3.1·§3.3 v1.7): `phases` 배열을 2원소로 승격 —
   페이즈 1=인간계(1~9층, 9층이 꼭대기), 페이즈 2=신선계(10~12층). 평시 런은
   페이즈 1 지도만 사용하고 9층 클리어=엔딩(기존 §3.9 판정 불변). 진엔딩
   등정 확정 시 페이즈 2 지도로 전환 후 10층 시작. 페이즈 2 배경은 신선계
   컨셉(구름·절벽·암석)의 임시 톤 구분까지만(TEMP), 실물 아트는 후속. 지도
   생성기·런 스냅샷·9층 판정·지도 열람의 페이즈 인지를 일관 갱신하고, 구
   스냅샷과의 호환(또는 명시적 리셋 규칙)을 보고서에 기록한다. 페이즈 1
   지도에서 10~12층은 §3.1대로 잠금 암시 표기만 남긴다.

## 2. 규율

- 로그 백업 선행(logs 통째 복사). 표준 래퍼 `-AllowDuringPlay` 계약 준수.
- 신규 수치는 `TEMP_*` 튜닝 상수. 신규 라벨(신선계 진입 배너 등)은 한국어
  기본 + 로컬라이제이션 키 등재(엠대시 금지).
- 검증: 타워 회귀 세트 + 항목별 씰(자동 서브 부정 레그, 벽 반사 왕복,
  페이즈 전환, 전체화면 사이징) + `-Paths` 경고 + 헤드리스 + Vulkan 캡처
  3장 이상(전체화면 페이즈 1 지도 / 페이즈 2 지도 / ROUTE_AIM 벽 반사 순간).
  `run_tower_mode.ps1` 실플레이 재현 가능해야 한다.
- 플래그 OFF 레거시 무손상 부정 레그. 커밋 분리·푸시 금지·판정 불가 시
  중단 보고.

**완료 선언 조건**: §1의 5항목 구현·검증 + 게이트 blocked/unverified 0건 +
보고서 완성.
