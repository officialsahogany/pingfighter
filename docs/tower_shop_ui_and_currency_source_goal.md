## 0. Fable이 확정한 원인 — 2번은 "같은 이름의 다른 재화"다 `[확인]`

`stage1_pillar_hud_scene_drawer.gd:588`

```gdscript
func _build_gold_hud_amount(context: Dictionary, registry: Object) -> int:
	return maxi(0, _get_cached_plaza_gold(context, registry) + _get_runtime_gold(context, registry))
```

**필러 HUD 는 광장 골드 + 런타임 골드의 합**을 보여준다(스크린샷의 616).

**상점 모달은 탑 런 경제를 읽는다.** `tower_ascent_flow_economy_progress.gd`가
`_run_state.export_economy()` 를 `_node_modal_state.set_balances(...)` 로
넘긴다. 새 런이 시작되면 그 값은 0 이다(스크린샷의 0).

즉 **버그가 아니라 두 재화가 같은 이름으로 표시되고 있는 것**이다.
플레이어는 둘을 구분할 수 없다.

### ★이것은 제품 결정이 필요하다

세 갈래이며 **판정 전에 구현하지 마라.**

- **가. 탑 런은 자기 경제만 쓴다.** 필러 HUD 가 탑 모드에서는 **런 경제**를
  보여주도록 바꾼다. 광장 골드는 탑 안에서 보이지 않는다.
  → 런의 자족성이 지켜진다. 로그라이크 규약에 맞는다.
- **나. 광장 골드를 탑에서 쓴다.** 상점이 광장 골드를 소비한다.
  → 런 간 이월이 생기고 밸런스가 통째로 달라진다. **큰 변경이다.**
- **다. 표기를 갈라 둘을 구분한다.** 예: 런 재화는 금화, 광장 재화는 다른 이름.
  → 최소 변경이지만 이름을 새로 정해야 한다.

**Fable 권고는 가**다. 탑은 런 단위로 닫힌 경제여야 하고, 정본
`docs/tower_ascent_run_map_plan.md` §1 이 "무작위성을 계획 재료로" 만드는
구조를 전제한다. 광장 골드가 흘러들면 그 계산이 무너진다.

**S1 에서 판정 결과를 제시하고 멈춰라.** 사용자 확정 전에는 2번을 고치지 마라.

## 2. 계약

### S2. 상점 UI 재구성

현재는 글자 행이다. 수련장·파계승이 **3x2 카드 그리드**로 가는 작업이
별도 진행 중이다(`docs/tower_training_node_card_ui_goal.md`).

- ★**그 작업과 같은 카드 드로어를 쓰라.** 상점만 따로 만들면 세 화면이
  갈린다. 그쪽이 먼저 착지하면 **재사용하고, 아직이면 재사용 가능한 형태로
  설계**하라. 착수 전에 그 브랜치 상태를 확인하라.
- 상점 품목은 **액티브 아이템 위주**다. 사용자 요구가 그렇다.
  현재 목록에 귀물 진열·액티브 캡슐·기회의 보석이 섞여 있으니, 무엇을
  카드로 보이고 무엇을 다른 형태로 둘지 판단하고 근거를 적어라.
- 카드에 **아이콘·이름·가격**이 들어간다. 가격은 어느 재화인지 읽혀야 한다.
- ★**GRT-022**: 글자 행에서 카드로 바꾸면 히트박스가 통째로 달라진다.
  `action_rects` 소비자를 전수 확인하고 **반증은 카드 상단 모서리**로 재라.
- ★**GRT-021**: 설명이 길면 드로어가 조용히 행을 버린다. 최장 문구에서
  실제 append 된 행 수를 단언하라.
- 모달 크기에 들어가는지 확인하라. 넘치면 **플레이필드를 침범하지 마라.**

### S3. 재화 표시 정합 (S1 승인 뒤에만)

- 승인된 방향대로 구현한다. 승인 전에는 **손대지 마라.**
- 어느 방향이든 **필러 HUD 와 모달이 같은 값을 보여야 한다.** 그것이 이
  슬라이스의 성공 기준이다.
- 내부 식별자 `gold` 는 호환 식별자다. 바꾸지 마라. 표시 문구만 다룬다.

### S4. 비전투 아레나 내부

`2944e9326`이 비전투 노드 배경을 배선했다. **필러와 바깥은 그 장소로 바뀌지만
플레이필드 내부는 여전히 이전 스테이지의 아레나와 보스를 보여준다.**

- 먼저 **플레이필드 내부를 무엇이 그리는지** 파일:줄로 지명하라.
  아레나 바닥, 보스, 조명이 각각 다른 소유자일 수 있다.
- ★**보스가 남아 있는 것이 특히 문제다.** 비전투 노드에 이전 보스가 서 있으면
  장소가 바뀌지 않은 것으로 읽힌다. 스크린샷에서 상단에 보스가 보인다.
- 판정 후 범위를 정하고 **근거와 함께 제시하라.** 셋 중 하나일 것이다.
  - 내부도 비전투 배경으로 덮는다
  - 보스만 숨기고 아레나는 중립 상태로 둔다
  - 노드별 아레나 아트가 별도로 필요하다(그러면 후보 제시 후 멈춰라)
- ★**전투 노드로 이동하면 정상 복귀**해야 한다. `2944e9326`이 이미 해제
  경로를 만들었으니 그것을 재사용하라. 새로 만들지 마라.

### S5. 씰

- 필러 HUD 와 모달의 재화 값이 **같은 소스에서 나오는지** 단언하라(S1 승인 뒤).
- 상점 모달이 **카드 그리드**로 배치되는지 단언하라.
- 카드 rect 와 히트테스트 rect 가 같은 값인지 단언하라(GRT-022).
- **비전투 노드에서 이전 보스가 그려지지 않는지** 단언하라. 픽셀 판정이
  필요하면 비헤드리스 캡처로 하라.
- **전투 노드 복귀** 부정 레그를 둬라.

## 3. 규율

- 슬라이스마다 헝크 분리 커밋 1개. 각 슬라이스는 **단독으로 씰 GREEN**이어야 한다.

  **최신 HEAD 기준으로 시작**하고, 수련장 6카드 작업과 순서를 조율하라.
