1. 개요

발토르는 건설과 방어에 특화된 캐릭터입니다. 토르쉴드라는 우산형 방어막을 펼쳐 공을 막으면서 높은 게이지를 획득하고, 이 게이지로 포탑과 디바인스톤을 건설하여 점점 강력해지는 플레이 스타일을 가집니다.

💡 발토르의 핵심 컨셉
• 토르쉴드로 공 방어 → 게이지 축적 → 구조물 건설 → 더 강한 공격력
• 게임이 진행될수록 점점 강해지는 "성장형" 캐릭터
• 게이지 관리와 멀티태스킹이 핵심

3. 게이지 시스템

발토르는 상황에 따라 게이지 획득량이 달라집니다. 토르쉴드 사용 여부, 디바인스톤 건설 여부에 따라 획득량이 크게 차이납니다.

3.1. 기본 게이지 획득량

상태 획득 게이지 설명
기본 패들 (망치) 30 토르쉴드 미사용 시
토르쉴드 기본 60 디바인스톤 없음
토르쉴드 + 디바인스톤 80 디바인스톤 활성
토르쉴드 + 강화 디바인스톤 100 최대 효율
💡 TIP: 토르쉴드를 적극 활용하면 기본 패들 대비 2~3배 이상의 게이지를 획득할 수 있습니다. 디바인스톤을 먼저 건설하면 게이지 효율이 크게 향상됩니다.

5.4. 번개 요격 ⚡

디바인스톤은 일정 시간마다 자동으로 번개를 발사하여 보스의 공을 요격합니다.

구분 디바인스톤 강화 디바인스톤
번개 쿨타임 15~25초 13~23초
게이지 획득 +40 +50
발동 조건 (HP) HP 최대일 때만 (3/3) HP 2 이상 (2/3 이상)
번개 비활성화 조건:
• 기본 디바인스톤: HP가 최대(3/3)가 아니면 번개가 발사되지 않음
• 강화 디바인스톤: HP가 1 이하가 되면 번개가 발사되지 않음
• 디바인쉴드 과부하 상태에서도 번개 비활성화

6. 해머쇼크 (Hammer Shock) ⚡

마우스 좌클릭을 길게 눌러 충전하고, 놓으면 발동됩니다. 충전 시간에 따라 단계가 올라가며 더 강력한 효과를 발휘합니다.

⚠️ 발동 조건: 해머쇼크는 디바인스톤이 건설되어 있어야만 사용할 수 있습니다. 디바인스톤을 먼저 건설하세요!
단계 충전 시간 소모 게이지 비고
1단계 1초 200 기본 충격파
2단계 2초 260 강화 충격파 (범위 증가)
3단계 (MAX) 3초 320 강화 디바인스톤 필요!
📌 3단계 해금 조건:
• 기본 디바인스톤: 1~2단계까지만 사용 가능
• 강화 디바인스톤: 3단계까지 사용 가능
• 디바인쉴드 과부하 상태: 1단계만 사용 가능

1단계 12개 2회 0.4초
2단계 19개 4회 0.7초
3단계 25개 6회 1.0초
💡 크랙 효과:
• 크랙 지속시간: 3초

• 단계가 높을수록 더 많은 크랙이 생성되어 보스 이동을 방해

7. 발토르 전용 아이템 🎒

발토르만 사용할 수 있는 특수 아이템입니다. 다른 캐릭터가 획득해도 사용할 수 없습니다.

7.1. 수리키트 🔧

건설한 포탑이나 디바인스톤의 HP를 회복합니다. 손상된 구조물을 신속하게 수리할 수 있습니다.

수리키트는 발토르 전용입니다. 다른 캐릭터가 이 아이템을 사용하려 하면 "수리키트는 발토르 전용 아이템입니다" 메시지가 표시됩니다.

7.2. 벽돌 (발토르 전용 효과) 🧱

일반적으로 벽돌은 바닥에 설치되지만, 발토르가 건물(포탑/디바인스톤) 위에서 사용하면 건물 3면(위/좌/우)을 감싸는 방어진이 구축됩니다!

항목 일반 사용 건물 위에서 사용
설치 형태 바닥에 단일 벽돌 건물 3면 방어진
내구도 2히트 3히트 (공유)
파괴 시 해당 벽돌만 파괴 3면 동시 파괴
발동 조건: 발토르가 포탑 또는 디바인스톤과 겹친 상태에서 벽돌 아이템 사용
보호 범위: 건물의 위, 좌, 우 3면을 감싸는 ㄷ자 형태의 방어벽 생성
활용: 디바인스톤이나 포탑을 공격으로부터 보호하여 내구도 유지
발토르는 게임 시작 시 방어용 벽돌 1개를 기본 보유합니다. 초반에 디바인스톤을 건설한 직후 방어진을 구축하면 안정적입니다.

8.1. 운영 페이즈 (게임 진행 단계)

발토르의 게임은 크게 4단계로 나뉩니다. 각 단계별 목표를 명확히 하세요.

📌 Phase 1: 축적기 (0~330 게이지)
목표: 디바인스톤 건설 비용(330) 확보
핵심: 토르쉴드를 최대한 활용하여 게이지 60씩 획득
주의: 이 단계에서는 포탑이나 해머쇼크를 자제하고 오직 게이지 축적에 집중
📌 Phase 2: 기반 구축 (디바인스톤 건설)
목표: 디바인스톤 완성 → 토르쉴드 효율 60→80 상승
핵심: 청사진 배치 후 공 막으면서 틈틈이 망치질
효과: 이후 모든 게이지 획득량 +33% 증가, 번개 자동 요격 시작
📌 Phase 3: 화력 증강 (포탑 + 강화)
목표: 포탑(220) → 강화 포탑(+250) → 강화 디바인스톤
핵심: 포탑의 자동 사격 + 유도탄으로 보스 압박
우선순위: 강화 디바인스톤 > 포탑 강화 (검기 해금이 더 강력)
📌 Phase 4: 완성형 (공세 운영)
목표: 강화 디바인스톤 + 강화 포탑 완성 상태
핵심: 토르쉴드 스윙마다 검기 발사 + 해머쇼크 3단계 활용
운영: 게이지 100 획득 + 검기(-50+30) + 포탑 수동 발사(-60)로 공격적 플레이

8.2. 구조물 우선순위

순위 구조물 비용 이유
1순위 디바인스톤 330 게이지 효율 +33%, 번개 요격, 해머쇼크 해금
2순위 강화 디바인스톤 +250 검기 해금, 게이지 100, 해머쇼크 3단계
3순위 포탑 220 자동 사격으로 보스 견제
4순위 강화 포탑 +250 유도탄 3발 + 오버드라이브
⚠️ 흔한 실수: 포탑을 먼저 짓는 것. 디바인스톤 없이 포탑만 있으면 게이지 효율이 낮아 유지가 어렵습니다. 반드시 디바인스톤 먼저!

8.3. 전투 운영법

공격 콤보: 검기 + 해머쇼크

강화 디바인스톤 완성 후 가능한 콤보:
  1. 토르쉴드 스윙으로 공을 막음 → 게이지 +100, 검기 발사 (게이지 -50)
  2. 검기가 공 타격 → 게이지 +30 회수 (실질 -20)
  3. 게이지가 320 이상이면 해머쇼크 3단계 충전
  4. 해머쇼크 폭발 → 크랙 25개 생성, 보스 1초 스턴
  5. 스턴 동안 포탑 수동 발사 연타 (광폭물약 시 0.15초 쿨)

방어 운영: 토르쉴드 + 번개

게이지가 부족하거나 위기 상황에서의 운영법:
  • 토르쉴드를 상시 전개하여 공 방어 + 게이지 축적
  • 디바인스톤 번개가 13~25초마다 자동으로 공 요격
  • 내구도 5 소진 시 토르쉴드 접고 대시로 회피
  • 4~6초 후 내구도 회복되면 다시 토르쉴드 전개
💊 광폭물약 활용 전략

광폭물약 15초를 최대한 활용하는 방법:

타이밍 활용법 효과
게이지 550+ 확보 후 디바인스톤 + 포탑 연속 건설 15초 내 두 구조물 완성 가능
강화 포탑 완성 후 포탑 수동 발사 연타 쿨타임 0.15초로 초당 6발 발사
보스 체력 위험 시 해머쇼크 + 수동 발사 콤보 최대 DPS로 마무리
광폭물약 사용 시 토르쉴드 게이지 획득도 3배! 100 → 300 획득으로 게이지가 급속히 찹니다.
🎮 상황별 대처법
🔴 게이지가 100 이하로 떨어졌을 때:
모든 공격 행동을 중단하고 토르쉴드 방어에만 집중. 검기/해머쇼크/수동발사 자제. 디바인스톤이 있다면 80~100씩 빠르게 회복됩니다.
🔴 토르쉴드 내구도 0일 때:
4~6초간 내구도 회복을 기다려야 합니다. 이 동안 대시로 회피하거나, 포탑이 있다면 수동 발사로 시간을 벌어주세요.
🔴 디바인스톤 HP가 1일 때 (강화 전):
번개가 발사되지 않습니다! 수리키트가 있으면 즉시 사용하고, 없다면 빠르게 강화하여 HP 조건을 완화하세요.
🔴 디바인쉴드 과부하 상태:
검기 발사 불가, 해머쇼크 1단계만 가능, 번개 발사 불가. 과부하가 풀릴 때까지 기본 방어 플레이만 하세요.

9. 고급 테크닉 🎓

9.1. 게이지 손익 계산표

발토르의 모든 행동은 게이지와 직결됩니다. 효율을 계산하여 운영하세요.

행동 게이지 변화 효율 사용 시점
토르쉴드 히트 (강화 디바인) +100 ⭐⭐⭐ 항상 최우선
토르쉴드 히트 (디바인) +80 ⭐⭐⭐ 디바인스톤 완성 후
토르쉴드 히트 (기본) +60 ⭐⭐ 초반 축적기
기본 패들 히트 +30 ⭐ 최후의 수단
번개 요격 (강화 디바인) +50 ⭐⭐⭐ 자동 (13~23초)
검기 (공 타격 시) -50 +30 = -20 ⭐⭐⭐ 공격+방어 동시
검기 (공 미스) -50 ⭐ 피해야 함
포탑 수동 발사 -60 ⭐⭐ 보스 스턴 중, 여유 시
해머쇼크 1단계 -200 ⭐⭐ 빠른 견제
해머쇼크 3단계 -320 ⭐⭐⭐ 결정타, 크랙 25개
🔄 이상적인 게이지 사이클:
토르쉴드(+100) → 검기 공타격(-20) → 토르쉴드(+100) → 검기(-20) → ... → 게이지 충분 → 해머쇼크 3단계(-320)

9.2. 멀티태스킹 마스터

숙련된 발토르 플레이어는 방어, 건설, 공격을 동시에 수행합니다.

🔧 건설하면서 방어하기
  1. 청사진을 플레이어 이동 경로 근처에 배치
  2. 토르쉴드로 공을 막아 게이지 획득
  3. 공이 반대편으로 날아가는 ~2초 여유 동안
  4. 청사진 위치로 이동 → S 눌러 망치질 (게이지 소모)
  5. 공이 돌아오면 즉시 토르쉴드 전개
  6. 반복하여 건설 완료
디바인스톤(330게이지, ~7.3초)은 약 4~5회 사이클, 포탑(220게이지, ~4.9초)은 약 3회 사이클로 완성됩니다.
⚔️ 공격하면서 방어하기 (완성형)
  1. 토르쉴드 스윙으로 공 방어 (게이지 +100)
  2. 스윙 0.4초 후 검기 자동 발사
  3. 검기가 공 타격 시 추가 게이지 +30
  4. 공이 보스에게 날아가는 동안 더블클릭으로 포탑 수동 발사
  5. 게이지 320+ 확보 시 해머쇼크 3단계 충전
토르쉴드 전개 중에는 포탑 수동 발사가 차단됩니다. 스윙 후 쉴드를 접은 상태에서 더블클릭하세요!

💎 디바인스톤 HP 관리

디바인스톤 HP에 따라 번개 발사 여부가 결정됩니다. HP 관리가 중요합니다!

상태 HP 조건 번개 발사 대응
기본 디바인스톤 3/3 (최대) ✅ 가능 정상 운영
기본 디바인스톤 2/3 이하 ❌ 불가 수리키트 사용 or 강화 우선
강화 디바인스톤 2/4 이상 ✅ 가능 정상 운영
강화 디바인스톤 1/4 이하 ❌ 불가 수리키트 필수
기본 디바인스톤은 HP가 1이라도 떨어지면 번개가 멈춥니다. 빠르게 강화하면 HP 2까지 번개가 유지되어 훨씬 안정적입니다!
