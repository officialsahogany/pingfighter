# 경로 서브 재작업 /goal 지시문 (2026-08-18, 라이브 피드백 대응)

- **정본**: `docs/tower_ascent_run_map_plan.md` **v1.6** (§3.2 경로 서브 계약,
  §3.14 업무 모달 시점 교정). 사용자 라이브 1런 피드백으로 개정된 계약이다.
- **목적**: 현행 "지도 위 조준 발사 화면"을 폐지하고, 전투 씬 그대로 실제
  서브로 다음 노드를 정하는 v1.6 계약으로 재작업한다.
- **완료 보고**: `docs/tower_serve_route_rework_report.md`. 푸시 금지.

## 1. 작업 항목 (독립 커밋)

1. **별도 발사 화면 폐지**: 지도판 위 조준선·선택구·조준 안내 UI 제거.
   ROUTE_AIM은 **전투 씬 안**에서 진행한다 — 승리 연출(하이라이트 리플레이 →
   상자)이 끝난 상태, 보스 패배 시트 재생 유지.
2. **실제 서브로 선택**: 플레이어 캐릭터의 기존 서브 메커닉(서브 공 발사)을
   그대로 사용한다. 조준 보정·확정 선택 UI 금지 — **서브 물리가 결과를
   정한다** (랜덤성이 계약이다). 표적 명중까지 재서브 무제한, 명중한 표적의
   노드로 확정. 공 재사용 시 볼 소유권 체크리스트 준수.
3. **표적 표시**: 다음 행 후보가 2개면 좌/우, 1개면 중앙 배치. 표적에 실제
   노드 이름 라벨(청린귀·수호의 샘터 등 — 기존 노드 표시명 재사용, 신규 명명
   금지). ROUTE_AIM 동안 전투 요소(보스 AI·득실점·타이머·전투 RNG·루프
   오디오)는 페이즈 D까지의 정지 계약 그대로 유지하되, 서브 공 물리와 표적
   충돌 판정만 활성한다.
4. **업무 모달 시점 교정**: 승리 직후 현재 자리에서 노드 업무 모달(샘터 등)을
   여는 슬라이스 데모 잔재를 제거한다. 업무 모달은 **지도 이동이 끝나 해당
   비전투 노드에 도달했을 때만** 연다. 상태 순서 재정의:
   `COMBAT → (승리 연출·상자) → ROUTE_AIM(전투 씬 서브) → MAP_TRANSITION →
   도착 노드(COMBAT 또는 NODE_MODAL)`.
5. **지도 화면 = 이동 연출 전용**: 명중 후 지도로 전환해 캐릭터가 선택된
   간선을 따라 이동하는 연출만 담당. 도착하면 노드 화면으로 진입.
6. **탑 모드 결과화면 미등장 재확인**: 하이라이트 리플레이 → 상자 → 서브
   흐름에서 레거시 결과화면(광장·다음 스테이지 버튼)이 절대 등장하지 않음을
   부정 레그로 봉인. (플래그 OFF 레거시는 기존 그대로.)

## 2. 규율

- **씰 개정은 정본 v1.6 근거의 락스텝만**: 기존 ROUTE_AIM·수직 슬라이스·노드
  모달 씰 중 "조준 확정" 계약을 단언하던 것은 v1.6 계약으로 개정하고, 구 계약
  주입 RED 반증을 남긴다. 트랜잭션(§3.9)·스냅샷·회피 규칙 계약은 불변.
- `node_resolution_id` 파이프라인 순서 유지: 상자 지급 커밋 후 서브.
- 플래그 OFF 무손상 + 타워 회귀 세트 + 픽셀 QA: 전투 씬 표적 등장(라벨 포함),
  서브 명중, 지도 이동 연출 각 1장 이상. `run_tower_mode.ps1` 경로로 실플레이
  재현 가능해야 한다.
- 발명 금지: 표적 크기·위치 등 새 수치는 `TEMP_*` 튜닝 상수.
- 판정 불가 지점이 나오면 중단·보고.

**완료 선언 조건**: §1의 6항목 구현·검증 + 필수 게이트 blocked/unverified
0건 + 보고서 완성. 이후 Claude(Fable)가 검증하고 사용자가 라이브 재확인한다.
