# §9-3 슬라이스 3R 핸드오프 (Codex 실행용) — 수호령강화 랜덤화 + 컴팩트 패널 연출 개편

작성 2026-07-28. **사용자 라이브 QA 피드백에 따른 슬라이스 3 개편** (정본
§5 개정 반영 — `docs/lingpet_guardian_duration_redesign_plan.md`). 스크린샷
2장 기준: ①3택 카드 모달 → 랜덤 1개 자동 획득 ②부화식 풀스크린 SD 컷인 →
패널 내 소형 SD + 클릭 리액션 종료.

## 0. 공통 가드레일 (기존 슬라이스와 동일)

- git reset / checkout / stash 금지. `git add -A` 금지. 로컬 커밋만.
- 불가침·CI·ledger 규정, 씰 실행 규정(에디터 유휴·RED 단독 2회 재실행) 동일.

## 1. 랜덤화 (택1 모달 폐기)

- `lingpet_guardian_enhance` 퍽 선택 시 **선택 모달 없이** 사전 필터된
  후보 풀에서 **랜덤 1개 자동 획득**.
- 유지되는 것: 사전 필터(캡 포화·비행펫 no-op 제외·이속 리맵), 후보 0개 시
  카드 미등장, 지속시간 증가의 희귀 **롤 가중 하향**, 적용 직전 재검증
  (실패 → 남은 유효 후보 재롤 → 전부 무효 → +15초 폴백 — "제시 순서" 개념만
  제거하고 기존 체인 재사용), 지속시간 증가의 duration owner 저장 예외.
- 제거되는 것: 3카드 제시·선택 UI(`lingpet_guardian_enhance_choice_overlay_
  host`의 선택 상호작용), "강화 확정" 버튼 흐름, <2/2/3 제시 계약.
- 결정 시점: 랜덤 롤·재검증·버프 적용은 **연출 시작 전에 완결** (연출은
  표시일 뿐 — 기존 계약 유지).

## 2. 컴팩트 패널 연출 (풀스크린 컷인 대체)

- **부화(acquire) 컷인과 같은 풀스크린 표현 금지** — 시각 위계 차별화가
  목적이다. 획득 컷인 = 풀스크린 대형, 강화 = 컴팩트 패널.
- 패널 구성 (기존 choice overlay host를 결과 패널로 개조 권장):
  1. 타이틀 "수호령강화"
  2. **현재 수호령 SD 소형 표시** — 패널 안에 작게(컴패니언 스케일보다
     조금 큰 정도, 풀스크린 컷인 시트 재사용 금지). 소스 = 컴패니언
     라투디/클릭 리액션 시트 계열.
  3. 짧은 롤 연출(글로우/셔플 등 가벼운 기대감 연출 — 과장 금지)
  4. 결과 배너 "○○○ 획득"
  5. **결과 확정 시 해당 수호령의 클릭 리액션 애니메이션 1회 재생**
     (`*_companion_click_reaction` 계열 시트) **재생 완료 후 종료**.
     클릭/ESC는 즉시 스킵·종료. 클릭 리액션 시트가 없는 펫은 idle 시트
     1루프 폴백 (단일 격자 가정 금지 — 펫별 오버라이드 존중).
- 모달 게이트·물리 정지·수명주기 계약(강제 취소·라운드 전환 정리·오디오/
  VFX 정리)·프리웜은 슬라이스 3 계약 그대로 승계.
- 풀스크린 `lingpet_guardian_enhance_cutin_overlay_host` 계열은 컴팩트
  패널로 대체 — 재사용 개조 또는 은퇴(은퇴 시 씰·프리웜·모달 게이트 등록
  해제까지 한 커밋, 죽은 코드 방치 금지).

## 3. 씰 개편

- `guardian_enhance_choice_revalidate_smoke`: 택1 레그 제거 → 랜덤 롤
  (결정론 RNG 주입) + 재검증 재롤 체인 + 폴백 + "모달 없는 자동 진행"
  단언으로 재작성.
- `guardian_enhance_cutin_lifecycle_smoke`: 컴팩트 패널 수명주기(버프
  선적용·클릭 리액션 1회 재생 후 자동 종료·스킵·라운드 전환 정리·오디오
  정리·클릭 리액션 부재 펫 폴백)로 재작성.
- offer engine·buff apply 씰은 불변 GREEN 유지. 반증검증 각 1회
  (예: 리액션 재생 종료 훅 제거 → 자동 종료 단언 RED).
- **Vulkan 픽셀 QA**: 컴팩트 패널 1장 + 클릭 리액션 재생 중 1장 — 부화
  컷인과 한눈에 구별되는 크기 위계인지 확인, 캡처 경로 보고 첨부.

## 4. 커밋 순서 (원자)

1. 랜덤화 (모달 폐기·자동 롤·재검증 체인 유지) + 씰 재작성 1
2. 컴팩트 패널 연출 + 클릭 리액션 종료 + 풀스크린 호스트 처분 + 씰 재작성 2
   (+픽셀 캡처)

## 5. 완료 보고 형식

커밋 해시별 요약 / 씰 원문 / 반증검증 기록 / 풀스크린 호스트 처분 방식
(개조/은퇴) / 클릭 리액션 시트 보유 펫 커버리지(폴백 대상 목록) / 픽셀
캡처 경로 / 미결·발견 사항.
