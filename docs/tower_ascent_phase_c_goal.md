## 2. 검증용 임시 가격표 (확정 수치 아님 — 전부 `TEMP_PHASE_C_*` 상수)

아래 값은 **검증용 임시**이며 `tower_ascent_tuning.gd`에 `TEMP_PHASE_C_*`
접두 상수로만 존재해야 한다. 지시문에 없는 가격·횟수를 발명하지 않는다.

| 상수 | 값 | 의미 |
|---|---:|---|
| `TEMP_PHASE_C_SHOP_COMMON_ACTIVE_PRICE` | 60 골드 | 일반 진열 액티브 1개 |
| `TEMP_PHASE_C_SHOP_LEGENDARY_ACTIVE_PRICE` | 180 골드 | 프리미엄 슬롯(전설) |
| `TEMP_PHASE_C_SHOP_MYTHIC_ACTIVE_PRICE` | 300 골드 | 프리미엄 슬롯(신화) |
| `TEMP_PHASE_C_SHOP_CAPSULE_PRICE` | 80 골드 | 캡슐 뽑기 1회 |
| `TEMP_PHASE_C_SHOP_CHANCE_GEM_PRICE` | 150 골드 | 기회의 보석 1개(고가 계약) |
| `TEMP_PHASE_C_MONK_CHOSIK_ACQUIRE_COST` | 8 무혼 | 파계승 초식 획득(2~3택 중 1) |
| `TEMP_PHASE_C_MONK_CHOSIK_SWAP_COST` | 10 무혼 | 파계승 초식 교환 |
| `TEMP_PHASE_C_MONK_CHOSIK_REMOVE_COST` | 12 무혼 | 파계승 초식 제거(획득보다 고가 계약) |
| `TEMP_PHASE_C_TRAINING_STAT_COST` | 5 무혼 | 수련장 능력치 수련 1회 |
| `TEMP_PHASE_C_TRAINING_MUGONG_COST` | 10 무혼 | 수련장 무공 서가 1회 |
| `TEMP_PHASE_C_SPRING_ENHANCE_COST` | 6 무혼 | 샘터 수호령 강화 1회 |

무료·횟수 규정 (역시 `TEMP_PHASE_C_*` 상수로):

- 영혼소환술 최초 획득 = 무료, 런 1회. 샘터 교체·흡수 = 무료.
- 휴식 보석 회복 = 무료, `TEMP_PHASE_C_REST_RESTORE_PER_NODE = 1`.
- 파계승 = 방문당 획득 1회·교환 1회·제거 1회
  (`TEMP_PHASE_C_MONK_*_PER_VISIT = 1`).
- 수련장 = 방문당 총 `TEMP_PHASE_C_TRAINING_USES_PER_VISIT = 2`회.
- 상점 = 진열 재고 소진까지 (재고 수량은 §1-2, 스냅샷 소유).
- 상자 내용물의 골드·무혼 지급량을 페이즈 A가 아직 소유하지 않았다면
  `TEMP_PHASE_C_CHEST_GOLD_REWARD_MIN = 40`, `_MAX = 70`,
  `TEMP_PHASE_C_CHEST_MUHON_REWARD = 2`로 같은 규칙 처리. **이미 A 구현이
  지급량을 소유하면 그 값을 쓰고 중복 상수를 신설하지 않는다.**

## 3. 잔액 부족·문구 규약

- 잔액 부족 시: 해당 버튼 **비활성** + 필요 재화와 부족량 표시. 모달은 열림
  유지, 트랜잭션 미발행. 부분 결제·외상·재화 자동 환전 금지.
- 결제 성공 시 잔액 즉시 갱신, 같은 `node_resolution_id` 재실행 중복 지급 0.
- 플레이어 표면 문구는 한국어 우선, **엠대시(—) 금지**. 신규 문구는 기존
  로컬라이제이션 카탈로그에 키 등재(타 언어 번역 공백은 보고서에 목록화,
  번역 완성은 후속 트랙 허용).
