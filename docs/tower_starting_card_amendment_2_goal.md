# 시작 카드 개정 2 — 하단 패널 제거 (2026-08-19)

- **요구**: 시작 카드 화면에서 **하단 무공 슬롯 원장과 능력치 띠를 표시하지
  않는다.** 카드 3장만 단독으로 보인다.
- **근거**: 런 시작 시점에는 빌드가 없어 두 패널이 빈 껍데기로 자리만 차지한다.
  보상 픽 화면(런 중)은 비교할 빌드가 있으므로 **그대로 유지**한다.
- **정본**: `docs/tower_ascent_run_map_plan.md` §3.17. 이 지시문 착지 후
  §3.17에 "시작 카드는 카드만 단독 표시" 문장을 추가한다.
- **완료 보고**: `docs/tower_starting_card_amendment_2_report.md`. 푸시 금지.

## 1. 범위

**시작 카드 화면에만 적용한다.** 보상 픽 화면과 퍽 선택 모달은 건드리지 않는다.

| 화면 | 카드 | 슬롯 원장 | 능력치 띠 |
|---|---|---|---|
| 시작 카드 | 표시 | **숨김** | **숨김** |
| 보상 픽 | 표시 | 표시(유지) | 표시(유지) |
| 퍽 선택 모달 | 표시 | 표시(유지) | 표시(유지) |

## 2. 착지 지점

`godot/scripts/hud/runtime_perk_overlay_renderer.gd`의
`draw_tower_start_card()`(`:462`)가 `_draw_stats_band()`를 `:553`에서 호출한다.
슬롯 원장(`"◆ 현재 무공"`, `:2069` 계열)도 같은 경로에서 그려진다.

**형제 호출부를 건드리지 마라.** `_draw_stats_band`는 `:443`(퍽 선택 모달),
`:553`(시작 카드), `:697`(보상 픽) 세 곳에서 호출된다. **`:553` 하나만**
제거 대상이다. 함수 내부를 고치면 세 화면이 함께 사라진다.

## 3. 레이아웃 계약

패널 두 개가 빠지면 세로 공간이 크게 남는다. 아래를 지킨다.

- 카드는 **화면 세로 중앙에 오도록 재배치**한다. 위에 붙은 채로 아래가 비면
  화면이 무너져 보인다.
- 카드 크기는 **키우지 않는다.** 보상 픽과 같은 크기를 유지해 두 화면이 같은
  문법으로 읽히게 한다.
- 제목("첫 길을 고르십시오")과 하단 안내("3장 중 1장을 고르십시오")는 유지하되
  카드 배치 변경에 맞춰 간격을 재계산한다.
- **레이아웃 값은 그린 자리와 클릭 자리 양쪽을 먹인다.** 카드 rect 산출과
  히트테스트가 같은 정본을 읽는지 확인하고, 반증은 카드 중심점이 아니라
  **상단 모서리**로 잰다(GRT-022).

## 4. 씰 계약

- `godot/tests/tower_start_card_smoke.gd`에 레그를 추가한다.
  - 시작 카드 뷰모델에 슬롯 원장·능력치 띠가 **포함되지 않는다**.
  - **반전 대조군**: 보상 픽 뷰모델에는 **여전히 포함된다**.
    이 대조군이 없으면 세 화면을 함께 끈 회귀를 잡지 못한다.
  - 재배치 후에도 카드 히트테스트가 성립한다(상단 모서리 기준).
- `godot/tests/tower_reward_pick_smoke.gd`가 기존 기대를 유지하는지 확인한다.
- 개정 씰이 CI·pre-push 두 리터럴 목록에 등재되어 있는지 확인한다.
