## 0. 감사가 정정한 것 — 발동 조건은 결함이 아니다

사용자 제보는 "거미줄 구출이 안 보인다"였고, Fable은 **거리 판정 누락**을
의심했다. **그 의심은 틀렸다.**

원본에도 거리 조건이 없다. 원본 트리거는 다섯뿐이다.
구조 비활성, 공 상단이 득점선 25px 안(`BALL.top < 25`), 공이 위로 진행,
게이지 50 이상, 마지막 사용 후 25초. 보스-공 거리도 도달 가능성 판정도 없다.

포팅본 조건도 동일하며 득점 좌표 표현만 다를 뿐 의미가 같다.
**따라서 발동 로직은 고치지 마라.** 원본 파리티가 이미 맞다.

**진짜 원인은 연출과 표시다.** 아래 S1이 이 목표의 핵심이다.

## 2. 슬라이스별 계약

### S1. 구조 5페이즈 연출 복원 ★핵심

**현행 `[확인]`**: 상태는 `arachne_web_rescue_phase`와
`arachne_web_rescue_progress`를 draw context에 싣는다
(`stage2_arachne_boss_state.gd:191-205`). 그런데 렌더러
`stage2_variant_boss_renderer.gd:190-196`은 **그 둘을 읽지 않고**
모든 페이즈에 직선 3개와 공 주위 원 하나만 그린다.

**원본의 페이즈별 연출**(감사 §거미줄 스킬 두 종 판정 참조):

| 페이즈 | 원본 연출 |
|---|---|
| shoot (15f) | 굵은 주실 + 보조 5가닥 + 선두 발광 + 트레일 + 입 스파크 + 표적 십자 |
| hold_wait (60f) | 공 포박 표현 |
| pull (50f) | 보스 잔상 |
| hold (60f) | 방사형 망 |
| strike (8f) | 2중 충격파 + 파편 8개 |

**계약**

1. 렌더러가 `phase`와 `progress`를 **읽어 분기**하게 하라. 그것이 이 결함의
   핵심이다. 상태 쪽은 이미 정확한 값을 보내고 있으므로 **상태를 고치지 마라.**
2. 원본 페이즈 구조를 보존하되 **닫힌 둘레 선만으로 끝내지 마라.** 이 저장소의
   VFX 규율은 절차 `_draw`의 싸구려 외곽선을 금지하고 채움 다겹과 광대를
   요구한다. 선 3개를 선 8개로 늘리는 것은 개선이 아니다.
3. **화면 최상단에서 벌어진다는 점을 설계에 반영하라.** 구조는 공이 득점선
   25px 안에 있을 때 발동하므로 연출 대부분이 화면 가장자리에 걸린다.
   보스 쪽 앵커와 공 쪽 앵커를 모두 쓰고, 위쪽으로 잘리지 않는지 픽셀로
   확인하라.
4. 신규 텍스처를 만들지 마라. 절차 드로우로 복원한다(원본도 절차형이다).
5. **씰**: 페이즈별로 드로우 호출이 실제로 갈라지는지 단언하라.
   `active` 플래그만 보는 레그는 이 결함을 그대로 통과시킨다(현행이 그랬다).

### S2. HUD 키 계약

**두더지왕과 완전히 같은 결함이다.** 상태는 `active`/`cooldown_progress`를
내보내는데 공용 렌더러는 `status`/`ready`/`progress`를 읽어 카드가 0%로 남는다.

- **생산자 쪽을 계약에 맞춰라. 공용 렌더러를 고치지 마라.**
  청린귀·두더지왕과 공유한다.
- ⚠ **두더지왕 수정이 같은 문제를 이미 고쳤을 수 있다.** 착수 전에 두더지왕
  결과를 확인하고, 이미 공용 해법이 들어갔으면 **중복 구현하지 말고 그것을
  따르라.** 형제가 서로 다른 방식으로 고치면 다음 보스에서 또 갈린다.

### S3. 상호작용 누락

- **파워 스매싱 해제**: 원본에 있고 현행에 없다. 감사 본문의 근거를 확인하고
  원본 조건 그대로 복원하라.
- **카오스 스피어 흡수**: 같다.
- 두 항목 모두 **원본에 실제 호출 경로가 있는지 먼저 확인**하라. 상수만 있고
  소비되지 않는 항목은 포팅하지 않는 것이 옳다(GRT-053). 실제로 감사가
  공 감속 0.70과 방향 왜곡 0.15 rad를 그런 이유로 미포팅이 정당하다고
  판정했다.

### S4. 광폭화 장판 겹침 회피

원본은 광폭화 장판 3발의 X를 정할 때 **기존 거미줄과 최대한 멀어지는 지점을
20회 표본으로** 고른다. 현행에 이 로직이 없어 장판이 겹칠 수 있다.

- 표본 수와 거리 평가식을 원본 그대로 옮겨라. 발명 금지.
- RNG는 게임플레이 RNG를 쓰되 소비 순서를 바꾸면 기존 시드 고정 씰이
  깨진다. 영향받는 씰을 락스텝 갱신하라.

### S5. 거미 정체성 연출

원본 아라크네는 "4마디 다리, gait cycle, 고대비 복부 무늬"를 정체성으로
선언한 절차형 보스다. 다리 8개가 이동 속도와 방향에 따라 비선형 위상으로
움직이고, 몸이 bob하며, 정지 시 다리가 떨리고, 피격 0.45초에 방향성 반동과
독액 파티클 6~10개가 난다.

- **이번 범위는 보행과 피격까지**로 한정한다. 팔레트와 실루엣 전면 재작화는
  아트 트랙이다.
- 신규 텍스처 0장. 절차 드로우로 한다.
