## 사용자 확정 사양 (B안)

> 공이 바닥으로 나가면 같은 x에서 천장으로 재진입해 계속 흐르고,
> **정해진 비행 시간이 지나면 자동으로 회수되어 재조준으로 돌아간다.**

기각된 대안: A안(발사당 wrap 1회) — 한 번은 이어지고 두 번째는 끊겨
규칙이 플레이어에게 읽히지 않는다. C안(무제한 + 회수 키) — 새 입력 학습
비용이 요청 대비 과하다.

## 계약

1. **wrap 조건**: 공이 하단(`y > 750`)을 넘으면 **같은 x**로 천장에
   재진입한다(`y = 공 반지름`). **속도 벡터를 그대로 보존**한다 —
   감속·재가속·재정규화 금지. 지금 하단 이탈이 `boss_scored` → MISS로
   변환되는 경로(`tower_ascent_route_serve_runtime.gd:349` 계열)를
   wrap으로 대체하되, **MISS 개념 자체를 없애지는 마라**(3번 참조).
2. **천장은 그대로 반사**한다. 하단만 wrap이다. 기존 반사 로직
   (y를 반지름으로 고정 + `velocity.y` 반전 + 411px/s 파생 정규화)을
   건드리지 마라.
3. **비행 예산**: 발사 시점부터 **기본 6.0초**. 소진되면 회수하고
   재조준(현행 수동 serve-wait)으로 복귀한다. 회수는 MISS와 같은 취급이다
   (시도 횟수 의미론은 4번).
   - 6.0초는 관제탑 기준값이다. 411px/s로 세로 750px 통과에 약 1.8초라
     **약 3회 통과** 분량이다. 실측 후 조정이 필요하면 **근거와 함께
     제안**하라(임의 변경 금지).
   - 상수는 `tower_ascent_tuning.gd`에 `TEMP_ROUTE_AIM_FLIGHT_BUDGET_SEC`
     같은 이름으로 **단일 정본**을 두고 파생값은 전부 거기서 유도하라
     (GRT-054).
4. **시도 횟수**: 현행 의미론을 유지한다 — 하단 이탈 자체로는 증가하지
   않고, **다음 클릭 발사 때만** 증가한다. 회수도 마찬가지다. 즉
   "한 번 발사 = 한 시도"이고 그 안에서 wrap이 몇 번이든 시도는 1이다.
   ⚠씰의 "실패 후 두 번째 실제 발사가 시도 2" 단언이 그대로 성립해야 한다.
5. **회수 예고(필수)**: 아무 신호 없이 공이 사라지면 "왜 회수됐지?"가 된다.
   회수 직전 **짧은 예고**를 넣어라 — 공 알파/스케일 램프 등 기존 표현
   계통 안에서. 잔여 시간 게이지는 화면을 어지럽히니 **넣지 마라**.
   예고 길이는 0.4~0.6초 범위에서 정하고 근거를 적어라.
6. **바람**: 비행 중 x 누적은 현행 그대로 둔다. 측벽 검사가 상·하단
   판정보다 먼저 도는 순서도 유지하라.

## ⚠씰 — 조사에서 지목된 것들

세션이 정확히 짚었다. 아래를 **삭제하지 말고 새 계약으로 갱신**하라.

- **"하단 이탈은 MISS이고 수동 재발사로 복귀한다"** → 새 계약:
  "하단 이탈은 같은 x로 천장 재진입한다. 비행 예산 소진 시에만 회수되어
  수동 재조준으로 복귀한다."
- **"실패 후 두 번째 실제 발사가 시도 2"** → 4번대로 **그대로 유지**되어야
  한다. 유지되는지 실행으로 확인하라.
- **"바람 스윕은 첫 MISS/HIT에서 측정을 종료한다"** → 이제 첫 하단 이탈이
  종료가 아니다. **새 비행 예산 기준으로 재측정**하라.
- ★**`wind_materiality ... margin_px=59.953`은 그대로 인용할 수 없다.**
  wrap이 여러 번이면 바람이 기존 "첫 비행"보다 오래 작용한다. **새 예산
  기준으로 재측정해 새 값을 봉인**하고, 마진이 커졌다면 그 자체를 보고하라
  (바람이 체감상 세지는 것이므로 사용자 판단이 필요할 수 있다).
- **천장 반사 레그는 유지**된다(조사 결론대로).
- ★기존 강풍 역반증 궤적이 **후속 순환에서 노드를 맞을 수 있다.**
  반증 레그가 여전히 RED인지 확인하고, 아니면 새 반증 궤적을 세워라.

## 추가 씰 레그

- **wrap 연속성**: 하단을 넘은 프레임의 x와 천장 재진입 프레임의 x가
  **동일**하고 속도 벡터가 보존됨.
- **예산 종료 보장**: 최악 케이스(무풍·수직 궤도)에서 **반드시 회수**되어
  재조준에 도달함. RED 반증: 예산 검사를 제거하면 무한 루프.
- **명중 우선**: 예산 만료 프레임과 노드 명중이 겹칠 때 **명중이 이긴다**
  (회수로 명중을 잡아먹지 않음).
- **회수 예고 레그**: 회수 전 예고 구간이 실제로 존재하고 길이가 상수와
  일치.
- **픽셀 QA**: wrap 순간 연속 캡처(바닥 직전 / 천장 직후) + 회수 예고
  프레임 1장.
