## 1. 착지 순서 (고정)

앞 슬라이스가 GREEN이 아니면 다음에 착수하지 않는다. 슬라이스마다 헝크 분리
커밋 1개, 씰 개정 파일은 슬라이스당 스모크 1개로 제한한다.

| 순서 | 슬라이스 | 요구 | 감사 절 |
|---|---|---|---|
| S0 | 절세무공 획득 연출 2페이즈 클릭 복구 | 2 | §1 S0 |
| S1 | 경로 서브 진입 arm 봉인 + 전량 구매 자동 전환 | 3 | §1 S1 |
| S2 | 보상 픽·노드 모달 스크린 공간 승격 + 노드 절차 배경 | 1 전제 + 6 | §1 S2 |
| S3 | 보상 픽에 무공 슬롯 원장·능력치 띠·호버 배선 | 1 | §1 S3 |
| S4 | 노드 이동 6구간 연출 + 지도 내용 비례화 | 5 | §1 S4 |
| S5 | 각도 게이지 아트 교체 | 4 | §1 S5 · §3 |

**S0을 먼저 두는 이유**: 6건 중 유일한 영구 정지 버그다. REVEAL 대기 중 게임이
멈춘 채 클릭이 도달하지 않으므로 이 상태로는 나머지 어느 것도 라이브 체감
검증이 불가능하다. 수정 지점이 S1·S3과 같은 함수라 뒤에 섞으면 회귀 귀속이
불가능해진다.

**S4-a를 S4-b·c보다 먼저 두는 이유**: 현행 봉인이 1280x800 한정이라 레이아웃
상한 4개가 전부 미포화이고 결함이 원리적으로 관측되지 않는다. 실 해상도
(2020x1246) 씰을 먼저 넣어 RED를 만든 뒤 고친다. 또한 표시 시간을 늘리기
**전에** 드로우 경로의 딥카피를 제거해야 스스로 상시 비용을 만들지 않는다.

## 2. 반드시 지킬 것

- 감사 문서 **§4의 함정 예방 24항을 구현 전에 전부 읽고 적용**한다. 요약본이
  아니라 원문을 따른다. 특히 다음 넷은 이번 반경에서 재발 이력이 있다.
  - 그린 자리와 클릭 자리를 분리하지 말 것. 반증은 **상단 모서리**로 잰다.
  - arm 게이트는 입력을 **버린다**. 미뤘다 만료 시 발사하면 그것이 자동 서브다.
  - 새 전체화면 표면은 `canvas.get_viewport_rect().size`를 1순위로 쓴다.
    game size로 폴백하면 좌상단 일부만 덮고 나머지에 라이브 전투가 남는다.
  - 아트 파일과 배선은 **같은 슬라이스**에서 랜딩한다. 매 프레임 그려지는
    표면에 미존재 경로를 예약하면 조용히 프레임 예산을 갉아먹는다.
- **픽스처가 결함을 가린다**는 것이 이번 감사의 반복 결론이다. FakeRegistry에
  키가 없어 라우트가 null로 빠지는 공허 GREEN이 최소 1건 실측됐다. Fake를
  채우고 **반전 대조군**을 반드시 함께 둔다. 소스 텍스트 씰을 개정할 때는
  행위 씰로 옮긴다.
- 신규·개정 씰은 `.github/workflows/godot-ci.yml`과
  `godot/tools/run_pre_push_checks.ps1` **두 리터럴 목록에 동시 등재**한다.
- 통과 판정은 마지막 `ok`가 아니라 배치 종단선
  `All Godot smoke tests passed.` + `SCRIPT ERROR` 0건이다.
- 신규 수치는 전부 `TEMP_*` (감사 §1 상수표 그대로). 카피는 한국어 기본 +
  `LanguageSettings` 7언어 등재, 엠대시 금지.
- 로그 백업 선행. 표준 래퍼 `-AllowDuringPlay`. 커밋 분리·푸시 금지.

## 5. 사용자 확답 (2026-08-18 회신 반영)

감사 §5의 3건에 대한 확정이다.

1. **연출 총 길이** — 감사의 기본값(약 2.73초)으로 **진행 확정**. 라이브 체감
   후 TEMP 상수로 조정한다.
2. **자동 종료 범위** — 감사의 (b)안으로 **확정**(정본 v1.12 §3.6).
   판정 술어를 `spent_flags` 전량 true가 아니라 **"미구매 카드 중
   `reward_pick_cost <= 무혼 잔고`인 것이 0장"** 으로 구현한다. 전량 구매와
   잔고 부족을 한 규칙이 덮는다. **계속하기 버튼은 유지**한다(살 수 있는데도
   아껴 두고 떠나는 선택이 유효하다). 감사 §1 S1의 나머지 계약(배치 위치,
   1회 시도 래치, 빈 보드 유지 구간, 1프레임 지연, 융합 모달 활성 중 미발화)은
   그대로 지킨다. 씰의 4레그에 **잔고 부족 자동 종료 레그**와 **살 수 있는
   카드가 남은 상태에서는 자동 종료 0건**인 부정 대조군을 추가한다.
3. **10·11층 층 배경 계약** — 사용자가 후속 검토로 유예. 이번 범위 밖이며
   S2의 절차 배경은 비전투 노드에만 적용한다.
