## 1. 후보 엔진 (논리 커밋 1)

- 퍽(무공) id = **`lingpet_guardian_enhance`** (표시명 "수호령강화", 7언어).
  퍽 융합 제외 목록 등재.
- 등장 게이트: **수호령 1마리 이상 보유** 시에만. 등장 리듬: **보유 후 다음
  무공 화면 1회 확정 예약**(링코어 레인 reserve 패턴 재사용), 이후 **3화면
  쿨다운**. 예약·쿨다운 카운터는 기존 offer-cooldown-screens 틱 경로 재사용.
- **버프 후보 풀** (정본 §5): 액티브스킬 +1 / 패시브스킬 +1 / 지속시간 증가 /
  방어율 증가 / 게이지획득량 증가 / 이동속도 증가 / 액티브스킬 추가해금 /
  패시브스킬 추가해금.
- **사전 필터** — 롤 전에 적용 가능한 후보만 남긴다
  (`lingpet_enhancement_buff_store`의 적용가능성 검사 재사용·확장):
  - 캡 포화 제외 (스킬 Lv.5 하드캡, 방어 스택캡, 게이지 캡, 기동 캡,
    지속시간 증가 런당 2회 캡, 추가해금은 미해금 슬롯 있을 때만)
  - 비행(sortie_flight) 펫: 방어율 증가 제외(defense_rate 영구 0 no-op),
    이동속도 증가는 등장률(appearance) 리맵으로 유효 취급
- **제시 계약**: 필터 후 후보 **<2 → 카드 자체 미등장** / **2개 → 둘 다
  제시** / **3개 이상 → 중복 없이 3개 제시**. 지속시간 증가는 희귀 가중
  (제시 확률 하향), 수치 +5초·런당 최대 2회.
- 전환기 정책: **구 교감 레벨업 보상 트리거는 이번 슬라이스에서 건드리지
  않는다** (§9-4 삭제 대상 — 전환기 동안 성장 채널 2개 공존을 명시 허용,
  동작 보존 원칙).

## 2. 택1 모달 + 적용 직전 재검증 (논리 커밋 2)

- 카드 선택 시 후보 2~3개 중 **택1 모달** (신비의 주사위 modal_input/
  overlay_renderer 패턴 참조 — 전용 모달, 확정 버튼, 리롤 없음).
- **적용 직전 재검증**: 선택 순간 적용가능성을 한 번 더 검사. 실패 시
  처리 체인 (보상 소실·모달 고착 금지):
  1. 같은 제시 세트의 **다른 유효 후보로 자동 대체** (제시 순서 우선),
     대체 사실을 피드백 텍스트로 표기.
  2. 전부 무효 → **폴백 = 지속시간 현재치 +15초 회복** (pool_current만,
     pool_max 불변 — 캡 개념이 없어 항상 적용 가능. "지속시간 증가" 버프의
     런당 2회 캡과 별개 취급).
  3. 어느 경로든 **모달은 정상 종료** — 취소·실패로 모달이 열린 채 남거나
     퍽 픽이 무보상으로 끝나는 상태는 구조적으로 불가능해야 한다.
- 모달 중 물리 정지는 기존 퍽 모달 흐름에 편승 (새 pause 브랜치 발명 금지).

## 3. 버프 적용 + 공유 owner 예외 (논리 커밋 3)

- **`lingpet_enhancement_buff_store.gd`가 유일 owner** — 병렬 상태 저장소
  신설 금지. 적용은 기존 reward 적용 경로(스택·캡·NO_REWARD 폴백)를 그대로
  관통하고, 트리거만 퍽 디스패치(`runtime_perk_choice_dispatch` 액션 +
  신규 applier 모듈)로 추가.
- **예외 계약**: "지속시간 증가"만 펫별 buff store가 아니라 **런 공유
  duration owner(`lingpet_duration_state`)에 저장** — pool_max +5초(동시에
  pool_current +5초), 런당 2회 카운터도 duration owner 소유.
- 실효 스킬레벨(base+bonus) 채널·`get_stat()` 합성이 퍽 트리거 경유로도
  동일하게 반영되는지 확인 (divergent 케이스).
- **필수 씰 레그**: ①지속시간 증가 후 **펫 교체(L사이클)에도 pool_max 유지**
  ②**스테이지 전진 리필이 증가된 pool_max 기준으로 전량 회복**
  ③펫별 버프(스킬+1 등)는 대상 펫에만 귀속 ④런당 2회 캡 초과 시 사전
  필터에서 제외됨.

## 4. SD 컷인 강화 연출 (연출 커밋 — 논리와 분리 랜딩)

- **게임 상태와 분리**: 버프 적용(§3)은 연출 시작 전에 완결된다. 연출은
  표시일 뿐 — 연출 스킵·실패·에셋 미스트리밍이 보상에 영향 주지 않는다.
- 구현 기반: `lingpet_acquire_cutin_overlay_host` **포크** — 물리 완전 정지
  모달 게이트(`battle_scene_modal_gate_controller` 등록) + ungated idle
  펌프 + 현재 수호령 SD(컷인 시트, 14펫 전수 보유) 중앙 + `cutin_vfx_anim`
  추가 VFX 레인에 강화 이펙트 + 획득 버프 결과 배너.
  **신화 획득류 pause 브랜치(update_effects만 도는) 사용 금지** (owned-ball
  freeze 트랩).
- **수명주기 계약**: ①클릭/확인으로 정상 종료 ②강제 취소(ESC 등) 허용 —
  즉시 정리 ③라운드 전환·매치 종료가 연출 중 발생해도 고아 오버레이/타이머
  잔존 금지 ④종료·취소 시 루프 오디오 stop + VFX/타이머 정리
  (`gameplay_loop_audio_cleanup` STOP_METHODS 등재 대상이면 등재, 모달 블록
  루프 오디오 트랩 준수) ⑤펫별 컷인 시트 격자 이형(8x4/32f 기본, 4x4/16f
  레거시 오버라이드) 존중 — 단일 격자 가정 금지 ⑥프리웜: 컷인 프리웜 스텝
  재사용, 첫 오픈 프레임 히치 금지(hot-path lazy-init 트랩).
- 연출 커밋의 QA = 논리 씰(수명주기 씰, 헤드리스) + **Vulkan 픽셀 캡처
  별도**(SD 중앙 배치·VFX 레인·배너 가독 — 캡처 경로 보고 첨부).
