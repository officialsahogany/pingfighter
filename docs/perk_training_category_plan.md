## 1. 배경·목적

- 활주 거리·이동속도 같은 **감각 스탯**은 최적값이 극성 아래에 있는데, 무공 슬롯
  경제(저레벨 보유도 슬롯 1칸)가 극성을 강제해 조작 감각을 깨뜨린다.
- 해법: 직접 신체·조작 능력치는 **수련** 카테고리로 이관 — 별 경지 없음, 무공 슬롯
  비소모, 소액 반복 습득으로 플레이어가 원하는 지점에서 멈춘다(복용량 조절).
- 무공 풀은 조건부 발동·상호작용·규칙 변경(반탄심법·기령심법·역천호신·회선철수류)
  중심으로 정체성을 좁힌다.
- **분류 정의(확정)**: 수련 = 상시 적용되는 기본 능력치 성장. 무공 = 조건부 발동·
  상호작용·특수 규칙. 단 v1에서는 이 정의로 "모든 직접 수치를 자동 이전"하지 않고,
  §3의 9종만 **명시적 화이트리스트**로 확정한다(잔여 수치형은 §6의 별도 감사 트랙).

## 2. 확정 계약 (v2)

### 2.1 오퍼 파이프라인 (순서 고정)

1. 기본 선택지 생성 — **3장** (즉시 효과 포함), 천안결(dowsing_goggles) 발동 시 4장.
2. 합일 교체 판정 — 기본 레인의 replaceable 카드 1장 교체 (기존 메커니즘 불변).
3. 천안결 보너스 표식 — **target_choice_count 기준으로 재작성**. 현행
   `runtime_perk_choice_offer_modifiers.gd:25-28`은 골드 카드 전제가 둘이다:
   수락 게이트 `choices.size() < target_choice_count + 1`의 `+1` 자체가 골드
   카드이고, `bonus_card_index = size - 2`는 "마지막 = 골드" 전제다. 골드 제거 시
   표식이 어긋나는 게 아니라 **보너스 수락이 통째로 거부**되므로 재작성 필수.
   보호 레인 스탬프(`offer_lane="dowsing_bonus"`, `offer_protected`)는 유지.
4. 보조 레인 판정 — 주사위(임시 25%, 런 3회 유지) → **실패 시에만** 수련(조건부
   확률) → 성공한 1장을 배열 끝에 append.
5. 주사위·수련 동시 등장 불가. 합일과 보조 레인은 레인이 달라 공존 가능(현행 유지).

### 2.2 골드변환 카드

- **평상시·고갈 시 모두 완전 제거. 숨은 폴백 없음.** (전투·결과 상자 선택은
  `exclude_instant=false`로 열려 즉시 효과 카드가 항상 후보에 있으므로 풀이 비지
  않고, 아카데미는 결제 전 `no_academy_choices` 차단이 이미 있다 — "후반 탈출구"
  주장은 검증 결과 거짓.)
- 단 `convert_to_gold` **표시 지원 코드**(by-id 조회, `is_gold_conversion` 분기)는
  보존해 기존 씰(mythic_perk_acquisition_cinematic / perk_single_level_tag)을
  불변으로 유지한다.
- 주사위는 "골드 카드 교체" 방식에서 "보조 레인 append" 방식으로 재배선.

### 2.3 수련 규칙

- 별 경지 없음, 무공 슬롯 비소모, 무공 선택권 1회를 소모하는 카드로 등장.
- 내부 ID 프리픽스 **`physique_*`** (기존 `common_training`(조식심법)과의 grep
  충돌 회피 — `training_*` 금지).
- 별도 `training_state`: 능력치별 습득 횟수·누적량·상한, 런 시작/종료 훅에서
  초기화(‼ `reset_round` 금지 — 실점마다 재발동), 저장·복원 왕복 지원. owner 동기
  키를 쓴다면 `BattleSceneState.DEFAULT_VALUES` 선언 필수(미선언 `set()` = 무음
  no-op 트랩).
- 카드에 **현재값 → 적용 후 값** 표시 (예: `활주 거리 210px → 216px`).
- 능력치별 상한 + 런 전체 수련 횟수 상한 병행. **상한 도달 시 카드 등장 자체 중단**
  (선택해도 효과 없는 죽은 카드 금지).
- 확률 표기 계약: 수련 확률은 조건부로 기록하고 체감률 병기 —
  체감 = (1 − 주사위 확률) × 조건부 확률.

### 2.4 제외 계약

- 개광결 증폭 **제외** (개광결 툴팁 제외 문구에 "수련" 명시).
- 만법귀일·한계돌파 등 유효 경지 보너스 무관(경지 없음).
- 합일 후보 **제외**, 한계돌파 대상 **제외**.
- 능력치 패널 원인표기(stat tooltip source breakdown)에 "수련" 소스 라인 추가.

## 3. 수련 카탈로그 v1 (이관 9종 + 신규 1종)

회당 수치는 **사용자 임시안**. "5회 도달"은 현행 무공 성 환산(재검증된 실테이블 기준).

| 수련 (대체 무공) | 대체 ID | 현행 1성~5성 | 회당(임시) | 5회 도달 | 판정 |
|---|---|---|---|---|---|
| 회기보 (활주 재충전) | dash_lightweight | −12~−60% | −4% | −20% ≈ 1.7성 | 적정 |
| 수세결 (활주 후딜) | dash_module_control | −18~−90% | −6% | −30% ≈ 1.7성 | 적정 |
| 비천보 (활주 거리) | dash_jump | +7~+35% | +3% | +15% ≈ 2.1성 | 적정 |
| 유운보 (이동속도) | common_swiftness | +6~+30% | +2% | +10% ≈ 1.7성 | 적정 |
| 철심공 (자세보정) | bulletproof_hat | +6/11/15/20/24% | +4% | +20% = **4성값** | ⚠ 조정 |
| 철산공 (패들 크기) | common_bulk_up | +6~+30% | +2% | +10% ≈ 1.7성 | 적정 |
| 태허심법 (최대 기력) | fuel_pouch | +40/65/90/115/140 | +20 | +100 ≈ 3.4성 | ⚠ 경미 |
| 격기심법 (타격 기력) | bluetooth_ring | +6/11/15/20/24% | +4% | +20% = **4성값** | ⚠ 조정 |
| 순환결 (액티브 쿨감) | item_cooldown_mastery | −13~−65% | −5% | −25% ≈ 1.9성 | 적정 |
| 행낭 수련(가칭) — 액티브 슬롯 +1 | (신규) | — | +1 슬롯 | — | 결정 3건 |

- **이상치 2건**: 철심공·격기심법은 회당 +4%가 현행 1성(+6%)의 2/3라, 5회면 슬롯
  없이 현행 4성값 — "절반 × 다회" 반려 사유가 재현된다. **권장 수렴(리뷰 3차):
  회당 +3%(5회 +15% = 현행 3성값)**. +2%(5회 +10% ≈ 1.9성, 타 수련과 성 환산
  균일)도 가능 범위 — 최종은 사용자 확정.
- **태허심법**: 현행 테이블은 선형이 아니다(증분 40→25). +20×5 = +100은 3.4성급
  으로 약간 높음 — 회수 상한 4회(+80 ≈ 2.6성급) 권장(리뷰 3차 동의).
- **순환결**: 최종 하한("기본값의 5% 미만 불가", catalog:120)은 수련이 별도로
  구현할 계약이 **아니다** — `active_item_cooldown_composer.gd`가 퍽 → 신화 →
  최종 하한(`cooldown_floor_policy`) 단일 체인으로 자동 강제한다. 수련 감소는
  `runtime_perk_effective_stat_query_surface.get_active_item_cooldown_msec`의
  퍽 단계에 합산할 것. **합성기 우회 금지, 별도 하한 재구현 금지.**
- **행낭 수련(가칭 — 기물 계열 명명 권장, 예: 수납술 수련)**: 신규 인프라 불필요 —
  capacity 체인은 `get_active_item_slot_capacity` = 기본 3 + 합일 부산물 보너스
  (수리건곤 +1, 연환병장 +연환보 경지). 가방 확장 무공(item_bag_expansion)은
  **은퇴 확인**(스모크가 캐릭터 정보 비노출을 단언). 계약(리뷰 3차 권장 채택):
  **런당 1회 한정, 일반 수련보다 낮은 등장 확률, 획득 후 재등장 금지, 총 슬롯
  상한 신설은 보류**(신설 시 연환병장 간접 너프). 라이브 최악 스택: 3 + 1 + 3 =
  7칸, 수련 포함 8칸. ⚠ 스모크의 "연환보 5단계 → 단독 8칸" 레그
  (`perk_fusion_active_item_slot_byproducts_smoke.gd:101-102`)는 raw 레벨 5를
  픽스처로 직접 대입한 견고성 레그다 — 연환보는 max 3·레벨부스트 제외(사용자
  확정)·한계돌파 비대상(CLASS_SYSTEM_CHOICE)이라 **라이브 도달 불가 경로이며
  밸런스 근거로 인용 금지.**

## 4. 이관 9종 호환 정책 (확정)

- 카탈로그 데이터·ID **보존** (기존 런의 카드명·설명·합일 기록 조회 유지).
- **신규 일반 제안 생성에서만 제외** (flag 게이트).
- 기보유 레벨의 효과·표시 유지 (런 종료까지).
- 기존 합일 기록·상승무공 payload 유지.
- 신규 합일·한계돌파 재료 후보 제외 — 신규 런은 보유 자체가 불가해 자연 제외.
  기보유 런은 한계돌파 대상 유지 권장(제거 시 죽은 한계돌파 발생).
- 디버그 피커 노출 여부는 별도 결정.
- 구현 시 반쪽-랜딩 거울상 트랩 주의: 계열을 끄는 flag는 그 계열을 스케일하던
  소비자를 조용히 0으로 만든다. grep은 flag가 아니라 **제거되는 9개 ID 각각**으로,
  후보 수를 세는 소비자의 빈-그룹 가드 확인, 씰은 flag-ON 레그로.

## 5. 감사 결과 (2026-08-05 세션, 실코드 확인)

1. **합일 고정 레시피 없음** — `perk_fusion_catalog.gd`는 클래스 기반 후보 판정만
   한다(`is_candidate`: 만렙 + slot_cost 1 + 후보 클래스). 상승무공(부산물)은 풀
   추첨이며 재료 ID 쌍에 고정된 결과 테이블이 없다. 부산물 효과 중 9종 ID 직접
   참조 0건(연환병장은 연환보 참조 — 연환보는 무공 잔류라 무관). → **9종 제외로
   도달 불가가 되는 고정 상승무공은 없다.** 레시피 처리 정책 추가 결정 불필요.
2. **9종 전원 `LIMIT_BREAK_ELIGIBLE_IDS` 등재 확인** (fusion_catalog:43-79, 철심공
   포함). §4의 제외·유지 정책이 9종 전체에 적용된다.
3. **수치 재검증** — 태허심법 40/65/90/115/140(비선형), 격기심법·철심공
   6/11/15/20/24(체감형). §3 표는 실테이블 기준.
4. 부수효과: 신규 런에서 개광결의 수치형 대상 풀이 9종 줄어든다(밸런스 참고).

리뷰 3차(코덱스, 2026-08-05) 사실 검증 추가:

5. **액티브 쿨감 공용 합성기 확인** — `active_item_cooldown_composer.gd`가 슬롯
   컨트롤러(판정)·전투 HUD(웻지)·TAB 정보창이 같은 값을 읽는 단일 지점이며, 최종
   하한은 `cooldown_floor_policy`(base>0 → 최종 ≥ base 5%). §3 순환결 계약의 근거.
6. **슬롯 수용량 체인 확인** — 기본 3 + 합일 부산물 보너스만(`runtime_perk_
   effective_stat_query_surface.get_active_item_slot_capacity`). 스모크 7칸 레그
   (3+수리건곤1+연환병장3) 확인. 가방 확장 무공은 은퇴(비노출 단언).
7. **"연환보 5단계 단독 8칸" 레그는 픽스처 전용 판별** — raw 레벨 5 직접 대입
   (smoke:101-102). 라이브 도달 경로 없음(§3 행낭 항목 참조). 코덱스의 "경로가
   존재" 표현은 스모크 레그 존재로 읽어야 하며 라이브 밸런스 근거가 아니다.

## 6. 잔류 수치형 무공 확인 목록 (사용자 확인 대기)

이관 후 dash 트리 잔류: 대붕전익(활주시 조건부 패들 확대)·연환보(횟수+슬롯 소모)·
감응보(자동 활주)·비각축기(짧은 활주 타격 기력)·폭혼보(기력 완전 활주)·축기결
(발동형 무료 활주) — 모두 조건부/발동형이라 무공 잔류가 §1 원칙과 정합적.

단 **조식심법(common_training, 모든 초식 쿨타임 8~40%)** 은 §1 정의를 엄격 적용하면
수련 후보다. **v1 권장(리뷰 3차 수렴): 자동 이전하지 않고 잔류** — 9종 화이트리스트
밖 수치형(조식심법, 아이템 출현·지속시간류 등)은 이후 별도 분류 감사 트랙으로
넘긴다. (이관하게 되면 §2.3의 `training_*` ID 충돌 주의가 실제 사례가 된다.)

## 7. 씰 최소 세트

- 보조 레인 배타성: 화면당 골드 없음 + 주사위/수련 중 최대 1장, 주사위 우선.
- 천안결: 3장/4장(+보너스 표식) 재작성 후 target_choice_count 기준 레그.
- 갱신 대상 기존 씰: `mystic_dice_offer_rotation_smoke`(골드 탐색·교체 계약 전체),

## 9. 남은 사용자 결정

리뷰 3차 이후 각 항목에 권장 기본값이 붙었다 — 이견 없으면 기본값으로 확정.

1. 이상치 2건 수치 — 철심공·격기심법 회당 수치. **권장 +3%** (+2%도 가능 범위).
2. 능력치별 회수 상한 — **권장: 기본 5회, 태허심법 4회, 행낭 1회** (§3 표).
3. 수련 카드명 정책 — 무공명 승계(예: 『회기보』 수련) vs 신규 수련명. 승계 시
   기보유 런의 동명 무공과 원인표기에서 구분 표기 필요. 행낭 수련은 기물 계열
   명명 권장(수납술 수련 등).
4. 주사위 확률 — 임시 25%, 런당 적격 화면 수 계측 후 확정.
5. 수련 조건부 확률 (체감률 병기 기준) + 런 전체 수련 획득 총량.
6. 행낭 수련 — **권장 계약 확정됨**(런당 1회·희귀·재등장 금지·총 슬롯 상한 보류,
   §3). 승인만 대기.
7. 조식심법 — **권장: v1 잔류**(§6, 별도 분류 감사 트랙). 디버그 피커의 9종 노출
   여부는 별도 결정.
