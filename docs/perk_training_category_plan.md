## 1. 배경·목적

- 활주 거리·이동속도 같은 **감각 스탯**은 최적값이 극성 아래에 있는데, 무공 슬롯
  경제(저레벨 보유도 슬롯 1칸)가 극성을 강제해 조작 감각을 깨뜨린다.
- 해법: 직접 신체·조작 능력치는 **수련** 카테고리로 이관 — 별 경지 없음, 무공 슬롯
  비소모, 소액 반복 습득으로 플레이어가 원하는 지점에서 멈춘다(복용량 조절).
- 무공 풀은 조건부 발동·상호작용·규칙 변경(반탄심법·기령심법·역천호신·회선철수류)
  중심으로 정체성을 좁힌다.
- **분류 정의(확정)**: 수련 = 상시 적용되는 기본 능력치 성장. 무공 = 조건부 발동·
  상호작용·특수 규칙. 단 v1에서는 이 정의로 "모든 직접 수치를 자동 이전"하지 않고,
  §3의 9종만 **명시적 화이트리스트**로 확정한다(잔여 수치형은 §6의 별도 감사 트랙).

## 2. 확정 계약 (v2)

### 2.1 오퍼 파이프라인 (순서 고정)

1. 기본 선택지 생성 — **3장** (즉시 효과 포함), 천안결(dowsing_goggles) 발동 시 4장.
2. 천안결 보너스 표식 — **target_choice_count 기준으로 재작성**. 현행
   `runtime_perk_choice_offer_modifiers.gd:25-28`은 골드 카드 전제가 둘이다:
   수락 게이트 `choices.size() < target_choice_count + 1`의 `+1` 자체가 골드
   카드이고, `bonus_card_index = size - 2`는 "마지막 = 골드" 전제다. 골드 제거 시
   표식이 어긋나는 게 아니라 **보너스 수락이 통째로 거부**되므로 재작성 필수.
   보호 레인 스탬프(`offer_lane="dowsing_bonus"`, `offer_protected`)는 유지.
3. 합일 교체 판정 — 기본 레인의 replaceable 카드 1장 교체 (기존 메커니즘 불변).
   **순서 정정(2026-08-05 구현 리뷰)**: 초기 계약은 합일→천안결이었으나, 합일
   플래너가 `offer_protected`를 존중하므로 **표식이 먼저**여야 다우징 보너스
   카드가 합일 교체로부터 보호된다. 구현(`runtime_perk_choice_open_flow` 주입
   순서)이 옳고 이 문서가 정정됐다.
4. 주사위 판정(임시 25%, 런 3회 유지) — 성공 시 카드를 배열 끝에 **append**
   (4장째). 구 골드 레인의 후계로서 선택지를 잠식하지 않는 출하 경험을 유지한다.
5. 수련 판정(주사위 실패 화면에서만, 조건부 40%) — **v3 변경(2026-08-05 사용자
   결정)**: append가 아니라 **기본 레인의 replaceable 카드 1장을 수련 카드로
   교체**한다. 화면은 항상 기본 장수(3장, 천안결 시 4장)로 고정되고, 수련은
   무공·초식과 경쟁하는 진짜 선택이 된다("공짜 4번째 카드" 문제 해소 — 슬롯을
   안 쓰는 수련이 추가 카드로 오면 매번 보너스처럼 느껴진다는 판단).
   - 교체 술어는 합일과 **단일 소스 공유**(`is_choice_replaceable` —
     `offer_protected` 존중). 천안결 보너스·수호령 강화·초식 교체·시야 예약 등
     보호 레인은 잠식 불가.
   - 권장 기본값: **합일이 이미 교체한 화면에서는 수련 판정 스킵**(시스템 교체
     화면당 1장 — 기본 3장 중 2장이 시스템 카드가 되는 화면 방지). replaceable
     잔여가 없으면 no-op(죽은 교체 금지). 스킵·no-op 화면은 수련 적격 계측에서
     제외한다.
6. 주사위·수련 동시 등장 불가(기존 유지). 합일·주사위 공존 가능(현행 유지).
   **주사위=append·수련=교체 비대칭은 의도된 결정** — 주사위는 런 3회 희귀
   시스템 카드로 기존 경제(선택지 비잠식)를 유지하고, 수련은 상시 성장 선택이라
   기회비용을 부여한다.

### 2.2 골드변환 카드

- **평상시·고갈 시 모두 완전 제거. 숨은 폴백 없음.** (전투·결과 상자 선택은
  `exclude_instant=false`로 열려 즉시 효과 카드가 항상 후보에 있으므로 풀이 비지
  않고, 아카데미는 결제 전 `no_academy_choices` 차단이 이미 있다 — "후반 탈출구"
  주장은 검증 결과 거짓.)
- 단 `convert_to_gold` **표시 지원 코드**(by-id 조회, `is_gold_conversion` 분기)는
  보존해 기존 씰(mythic_perk_acquisition_cinematic / perk_single_level_tag)을
  불변으로 유지한다.
- 주사위는 "골드 카드 교체" 방식에서 "보조 레인 append" 방식으로 재배선.

### 2.3 수련 규칙

- 별 경지 없음, 무공 슬롯 비소모, 무공 선택권 1회를 소모하는 카드로 등장.
  **v3: 화면 장수를 늘리지 않는 교체형** — 기본 레인 1장을 대체한다(§2.1-5).
- 내부 ID 프리픽스 **`physique_*`** (기존 `common_training`(조식심법)과의 grep
  충돌 회피 — `training_*` 금지).
- 별도 `training_state`: 능력치별 습득 횟수·누적량·상한, 런 시작/종료 훅에서
  초기화(‼ `reset_round` 금지 — 실점마다 재발동), 저장·복원 왕복 지원. owner 동기
  키를 쓴다면 `BattleSceneState.DEFAULT_VALUES` 선언 필수(미선언 `set()` = 무음
  no-op 트랩).
- 카드에 **수련 보정 누적치 before → after** 표시 (예: `이동 속도 수련 보정
  +2% → +4%`). **문언 정정(2026-08-05 구현 리뷰 P2-①)**: 초기 계약의 실측값
  예시(`활주 거리 210px → 216px`)는 기각 — 실측 표기는 일시 버프·타 배율까지
  카드 카탈로그가 런타임 상태에 의존하게 만든다. 실측 최종값은 TAB 능력치
  패널(원인표기)이 담당하고, 카드는 "무엇의 보정인지" 라벨(`수련 보정`)로
  명확화한다.
- 능력치별 상한 + 런 전체 수련 횟수 상한 병행. **상한 도달 시 카드 등장 자체 중단**
  (선택해도 효과 없는 죽은 카드 금지).
- 확률 표기 계약: 수련 확률은 조건부로 기록하고 체감률 병기 —
  체감 = (1 − 주사위 확률) × 조건부 확률.
- **카드 카피 계약(2026-08-05 리뷰 P3)**: 등장 확률·체감률·런 총량 같은 튜닝
  상수는 플레이어 카드 카피에 노출하지 않는다 — 설계 문서·계측 로그 전용.
  수련 카드 detail 표준 문구는 "무공 슬롯을 차지하지 않는 기초 수련입니다."
  (7언어 동기). 주사위 카드도 동일 원칙(25% 노출 금지, 런당 3회는 게임플레이
  계약이라 표기 유지).

### 2.4 제외 계약

- 개광결 증폭 **제외** (개광결 툴팁 제외 문구에 "수련" 명시).
- 만법귀일·한계돌파 등 유효 경지 보너스 무관(경지 없음).
- 합일 후보 **제외**, 한계돌파 대상 **제외**.
- 능력치 패널 원인표기(stat tooltip source breakdown)에 "수련" 소스 라인 추가.

## 3. 수련 카탈로그 v1 (이관 9종 + 신규 1종)

회당 수치·상한은 **확정값(2026-08-05 사용자 승인)**. "상한 도달"은 현행 무공 성 환산(재검증된 실테이블 기준).

| 수련 (대체 무공) | 대체 ID | 현행 1성~5성 | 회당(확정) | 상한 도달 | 판정 |
|---|---|---|---|---|---|
| 회기보 (활주 재충전) | dash_lightweight | −12~−60% | −4% | −20% ≈ 1.7성 | 확정 |
| 수세결 (활주 후딜) | dash_module_control | −18~−90% | −6% | −30% ≈ 1.7성 | 확정 |
| 비천보 (활주 거리) | dash_jump | +7~+35% | +3% | +15% ≈ 2.1성 | 확정 |
| 유운보 (이동속도) | common_swiftness | +6~+30% | +2% | +10% ≈ 1.7성 | 확정 |
| 철심공 (자세보정) | bulletproof_hat | +6/11/15/20/24% | +3% | +15% = 3성값 | 확정 |
| 철산공 (패들 크기) | common_bulk_up | +6~+30% | +2% | +10% ≈ 1.7성 | 확정 |
| 태허심법 (최대 기력) | fuel_pouch | +40/65/90/115/140 | +20 | 4회 +80 ≈ 2.6성 | 확정 |
| 격기심법 (타격 기력) | bluetooth_ring | +6/11/15/20/24% | +3% | +15% = 3성값 | 확정 |
| 순환결 (액티브 쿨감) | item_cooldown_mastery | −13~−65% | −5% | −25% ≈ 1.9성 | 확정 |
| 수납술 수련 — 액티브 슬롯 +1 | (신규) | — | +1 슬롯 | 1회 +1 | 확정 |

- **이상치 2건 확정**: 철심공·격기심법 **+3%/회**(5회 +15% = 현행 3성값). 기각
  기록: 최초안 +4%는 5회에 현행 4성값 도달("절반 × 다회" 반려 사유 재현), +2%
  (성 환산 균일)도 검토됐으나 +3% 채택.
- **태허심법**: 현행 테이블은 선형이 아니다(증분 40→25). +20×5 = +100은 3.4성급
  으로 약간 높음 — 회수 상한 4회(+80 ≈ 2.6성급) **확정**.
- **순환결**: 최종 하한("기본값의 5% 미만 불가", catalog:120)은 수련이 별도로
  구현할 계약이 **아니다** — `active_item_cooldown_composer.gd`가 퍽 → 신화 →
  최종 하한(`cooldown_floor_policy`) 단일 체인으로 자동 강제한다. 수련 감소는
  `runtime_perk_effective_stat_query_surface.get_active_item_cooldown_msec`의
  퍽 단계에 합산할 것. **합성기 우회 금지, 별도 하한 재구현 금지.**
- **수납술 수련(확정 명칭, 액티브 슬롯 +1)**: 신규 인프라 불필요 —
  capacity 체인은 `get_active_item_slot_capacity` = 기본 3 + 합일 부산물 보너스
  (수리건곤 +1, 연환병장 +연환보 경지). 가방 확장 무공(item_bag_expansion)은
  **은퇴 확인**(스모크가 캐릭터 정보 비노출을 단언). 계약(확정):
  **런당 1회 한정, 선택 가중치 0.5**(일반 수련 1.0 대비 — 10종 전원 후보 시
  수련 카드 내 비중 0.5/9.5 ≈ 5.3%, 별도 확률 게이트 불필요), **획득 후 재등장
  금지, 총 슬롯 상한 신설은 보류**(신설 시 연환병장 간접 너프). **신규 프로덕션 획득 경로 기준**
  최대 3 + 1 + 3 = 7칸, 행낭 수련 포함 8칸 — 단 최종 합성은 퍽 계층 뒤에 **신화
  아이템 계층**이 붙으므로(`character_info_overlay_owner_state.active_item_slot_
  capacity`), 기존 저장·디버그의 레거시 배낭(`slot_add`) 장착 상태는 롤옵션만큼
  추가 가산된다 — **별도 호환 범위로 계산**(씰: `bag_expansion_mugong_removal_
  smoke` 레거시 아이템 3→5 레그). ⚠ 스모크의 "연환보 5단계 → 단독 8칸" 레그
  (`perk_fusion_active_item_slot_byproducts_smoke.gd:101-102`)는 raw 레벨 5를
  픽스처로 직접 대입한 견고성 레그다 — 연환보는 max 3·레벨부스트 제외(사용자
  확정)·한계돌파 비대상(CLASS_SYSTEM_CHOICE)이라 **라이브 도달 불가 경로이며
  밸런스 근거로 인용 금지.**

## 4. 이관 9종 호환 정책 (확정)

- 카탈로그 데이터·ID **보존** (기존 런의 카드명·설명·합일 기록 조회 유지).
- **신규 일반 제안 생성에서만 제외** (flag 게이트).
- 기보유 레벨의 효과·표시 유지 (런 종료까지).
- 기존 합일 기록·상승무공 payload 유지.
- 신규 합일·한계돌파 재료 후보 제외 — 신규 런은 보유 자체가 불가해 자연 제외.
  기보유 런은 한계돌파 대상 유지 권장(제거 시 죽은 한계돌파 발생).
- 디버그 피커: §9-7 확정안 — 은퇴 9종은 일반 목록에서 숨기고 레거시 호환 주입
  경로만 유지, 신규 수련은 별도 '수련' 그룹으로 노출.
- 구현 시 반쪽-랜딩 거울상 트랩 주의: 계열을 끄는 flag는 그 계열을 스케일하던
  소비자를 조용히 0으로 만든다. grep은 flag가 아니라 **제거되는 9개 ID 각각**으로,
  후보 수를 세는 소비자의 빈-그룹 가드 확인, 씰은 flag-ON 레그로.

## 6. 잔류 수치형 무공 확인 목록 (사용자 확인 대기)

이관 후 dash 트리 잔류: 대붕전익(활주시 조건부 패들 확대)·연환보(횟수+슬롯 소모)·
감응보(자동 활주)·비각축기(짧은 활주 타격 기력)·폭혼보(기력 완전 활주)·축기결
(발동형 무료 활주) — 모두 조건부/발동형이라 무공 잔류가 §1 원칙과 정합적.

단 **조식심법(common_training, 모든 초식 쿨타임 8~40%)** 은 §1 정의를 엄격 적용하면
수련 후보다. **v1 권장(리뷰 3차 수렴): 자동 이전하지 않고 잔류** — 9종 화이트리스트
밖 수치형(조식심법, 아이템 출현·지속시간류 등)은 이후 별도 분류 감사 트랙으로
넘긴다. (이관하게 되면 §2.3의 `training_*` ID 충돌 주의가 실제 사례가 된다.)

## 9. 확정 결정 (2026-08-05 사용자 승인)

리뷰 3~4차 권장 기본값이 전건 승인됐다. 아래가 구현 시작값이다.

1. 철심공·격기심법 — **+3%/회**.
2. 회수 상한 — **기본 5회, 태허심법 4회, 수납술 1회** (§3 표).
3. 카드명 — **기존 명칭 승계 + '수련' 접미사**(회기보 수련·철심공 수련), 신규만
   수납술 수련. 기보유 런의 동명 무공과 원인표기에서 구분 표기.
4. 주사위 — **25% (계측용 기본값)**, 런당 적격 화면 수 계측 후 재확정 여지.
5. 수련 확률·총량 — **조건부 40%, 런 전체 6회 상한 (초기 튜닝값).** 체감률은 두
   구간 분리 계측: 주사위 소진 전 75%×40% = 30%, 3회 소진 후 40%.
6. 수납술 계약 — **런당 1회, 선택 가중치 0.5, 재등장 금지, 총 슬롯 상한 보류**
   (§3).
7. 조식심법 — **v1 잔류**(§6, 별도 분류 감사 트랙). 디버그 피커 — **은퇴 9종
   일반 목록 숨김 + 레거시 호환 주입 경로 유지, 신규 수련은 별도 '수련' 그룹.**
