## 0. 현행 6구간 계약 `[확인]`

정본 `docs/tower_ascent_run_map_plan.md` §3.1이 이미 6구간을 정의한다.

```
1. 전투 화면 암전   2. 전체화면 지도 등장   3. SD 캐릭터 이동(smoothstep)
4. 도착 소멸        5. 지도 암전            6. 도착 표면 등장
```

`32e193319`가 2번을 확대·추적 상태 등장으로 바꾸고 3번에서 카메라가 따라가게
했다. **사용자 요구는 2번과 3번 사이에 줌 구간을 하나 더 넣는 것이다.**

## 1. 요구 사양

- 목적지 확정 후 지도가 등장하면 **카메라가 1초 동안 플레이어 캐릭터로
  줌인**한다.
- 줌인이 끝나면 **캐릭터 시점 고정**으로 전환하고 카메라가 캐릭터를 따라간다.
- 그 뒤에 캐릭터가 선을 따라 이동한다.

즉 순서가 이렇게 된다.

```
2. 지도 등장 (현행 추적 배율)
2-b. ★신규 — 1초 줌인 (캐릭터로 좁혀 들어감)
3.  캐릭터 이동 (줌인된 시점 고정 + 추적)
```

## 2. 슬라이스

| 순서 | 슬라이스 | 내용 |
|---|---|---|
| S1 | 구간 삽입 계약 | 6구간에 2-b 를 넣는 방식 |
| S2 | 줌 곡선 | 1초 동안의 배율 변화 |
| S3 | 시점 고정 전환 | 줌 종료 후 추적 인계 |
| S4 | 씰과 캡처 | 회귀 차단 |

## 3. 계약

### S1. 구간 삽입

- ★**새 페이즈를 만들지 마라.** 정본 §3.1이 "새 페이즈를 만들지 않고
  `MAP_TRANSITION` 진척 곡선을 구간으로 해석한다"고 명시한다.
  같은 방식으로 2-b를 진척 곡선 안의 구간으로 넣어라.
- **시계는 물리 틱에 둔다**(정본 조항). 벽시계나 `_process` delta 누적을 쓰지 마라.
- 1초는 물리 72Hz 기준이다. `/60.0` 규약과 실제 틱 수를 보고서에 적어라.
- 6구간 전체 길이가 1초만큼 늘어나는지, 아니면 기존 구간에서 빌려오는지
  판단해서 정하고 **근거를 적어라.** 전체가 늘면 전환이 느려진다.

### S2. 줌 곡선

- 시작 배율은 `32e193319`의 지도 등장 배율이다. 끝 배율은 판단해서 정하고
  근거를 적어라. **너무 좁히면 경로가 안 보여 다음 목적지를 잃는다.**
- 등속이 아니라 가속 후 감속(smoothstep)이 정본의 어법이다(3번 항목 참조).
- ★**GRT-039**: 전역 물리 보간 환경에서 카메라 호스트를 새로 만든다면
  `physics_interpolation_mode = OFF`를 명시하라. 스폰 프레임 글라이드가 난다.

### S3. 시점 고정 전환

- 줌인이 끝나는 프레임과 이동이 시작되는 프레임 사이에 **튐이 없어야 한다.**
  두 구간의 경계에서 배율과 카메라 중심이 C0 연속이어야 한다.
- 이동 중 캐릭터가 화면 밖으로 나가면 안 된다(`32e193319`가 이미 보장).
- 줌인된 상태에서도 **최하층·최상층 경계 처리**가 유지되어야 한다.

### S4. 씰

- 2-b 구간이 **정확히 1초(물리 틱 환산값)** 지속하는지 단언하라.
- 줌 시작 배율과 종료 배율, 그리고 **경계에서의 연속성**을 단언하라.
  구간 경계 직전·직후 프레임의 배율 차가 임계 이하여야 한다.
- 6구간 전체 진척이 여전히 단조 증가하는지 단언하라.
- 줌 종료 후 추적이 인계되는지, 캐릭터가 화면 안에 유지되는지 단언하라.

## 4. 규율

- 슬라이스마다 헝크 분리 커밋 1개. 각 슬라이스는 **단독으로 씰 GREEN**이어야 한다.
- 신규·개정 씰은 두 리터럴 목록에 동시 등재. **실패하는 씰을 넣지 마라.**
- ⚠ `tower_ascent_flow_renderer.gd`와 `tower_ascent_map_camera_model.gd`를
  다른 작업과 공유할 수 있다. **최신 HEAD 기준으로 시작**하라.
- 정본 §3.1의 6구간 문구를 고쳐야 하면 그 문서를 갱신하고 보고서에 적어라.
- 통과 판정은 배치 종단선 `All Godot smoke tests passed.` + `SCRIPT ERROR` 0건.
- 로그 백업 선행. 표준 래퍼 `-AllowDuringPlay`. 푸시 금지.
