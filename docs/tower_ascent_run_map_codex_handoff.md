## 3. 2차 재리뷰 이후 신규 확정 (이번 검증 리뷰의 중점)

### §3.15 수호령 계약 (사용자 확정)

- 수호령 = **런 귀속** (현행 `lingpet_guardian_run_state` 계약과 일치). 영속은
  도감·최초 발견 기록만.
- **친밀도 시스템 폐지.** 코드 잔존분(교감 키·affinity 스토어·UI) 정리는 별도
  폐지 슬라이스.
- 수호의 샘터: 런 내 최초 방문 = **영혼소환술 획득**, 이후 방문 = 강화·교체·흡수.
- 수호령 알: 전투 중 획득, **파괴 시 정체만 공개**(즉석 교체·유지·흡수 결정
  제거), **봉인 상태로 보관** → 샘터에서 처리.
- 봉인 수호령은 캐릭터 정보창 수호령 탭에 추가되되 **표시 전용** — 컴패니언
  런타임(스킬·바디히트·HUD 슬롯) 미등록 (GRT-015/016 VISIBLE≠LIVE 주의).
- 런 스냅샷 필드: 영혼소환술 획득 여부, 현재 수호령 상태(강화 포함), 봉인
  수호령 목록.

### §3.16 재화 체계 (사용자 확정)

- 런 내 재화 = **골드 + 무혼 2종 고정**. "몸에 남는 것 = 무혼(파계승·수련장·
  샘터), 손에 쥐는 것 = 골드(상점·보석)". 환전 금지, 제3 런 재화 금지.
- **스타포인트 폐지 → 무혼 흡수.** 현행 즉시 퍽 선택 모달이 §3.7 "전투 중
  선택 모달 금지"와 충돌. 무공 획득 = 절세무공상자(운) + 수련장 무공 서가(선택).
- 상점 선반: 일반 액티브 3~4종 진열 + **전설·신화 독점 고가 슬롯** + 캡슐
  뽑기 + 기회의 보석.
- 액티브 등급 분리: 필드 스폰 = **일반 등급 한정, 판당 기대 0.5~1개**
  (기회당 1회 굴림, GRT-011). 상자 = 일반~희귀. 상점 = 확정 선택 + 상위 등급 독점.
- 재고 실사 반영: 현행 액티브 ~35종 rarity 무필드, 신화 = 대성영단 1종(0.001
  가중·챔피언 게이트), 전설 = 0종 → **카탈로그 rarity 스키마 정식화**(스폰
  풀·상자·상점이 단일 필드 필터) + 전설·신화 확충 콘텐츠 트랙(수직 슬라이스
  이후). 유물(법보) 신설은 무공과 역할 중복이라 보류.

## 4. 착수 시 핵심 구현 계약 (정본 상세 참조)

- 신규 flow owner 모듈, 기능 플래그, 광장 R3식 원자적 전환. `main.gd`
  오케스트레이션 전용 유지 + 소유권 원장 기록.
- 노드 해소 = `node_resolution_id` 멱등 트랜잭션 (§3.9). 보석 =
  `run_state.chance_gems` 소유, plaza 스토어 즉시-save 경로 재사용 금지 (§3.8).
- 런 스냅샷 필수 필드와 저장 시점(노드 커밋 후) = §5. 해금은 Godot 신설 스토어
  (`unlocked_items`는 Python 전용) = §3.10.
- 지도 아트 = 아라울 프롤로그 화풍(한지·먹선·인장 노드). 고휘도 바탕이라 ADD
  발광 금지 계열 주의 (§4, GRT-047 역변종).
