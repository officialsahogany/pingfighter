## Atlas Grid Authority (multi-cell sheets)

The following PNGs are atlas sheets read via `draw_texture_rect_region`
slicing. Renderers MUST use these exact `(cols, rows)` grids per-asset, not a
shared `SHEET_COLS = 4 / SHEET_ROWS = 4` assumption. Slicing a 2x1 mirror
asset as 4x4 produces a square fragment surrounded by stray cells which reads
in-game as a "box with sticks" overlay (not a runtime error). Reference
failure: Stage 5 holyun left-pillar wallmount, 2026-05-18. See
AGENTS.md "Atlas sheet grid authority" and
`.claude/skills/ui-hud-generation/SKILL.md` §7 atlas grid declaration.

|---|---|---|---|
| `stage5_hongryun_vase_lantern_sprites_imagegen_v2.png` | 2 x 1 | 2 | left/right mirror pair |
| `stage5_hongryun_snake_pot_lotus_pulse_sheet_v1.png` | 8 x 1 | 8 | lotus pulse loop |

`<NAME>_ROWS`, `<NAME>_FRAMES` constants.
