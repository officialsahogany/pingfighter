## 0. ★반려 사유 — 폐기된 자산을 레퍼런스로 삼았다

후보 A 는 스타일 레퍼런스로 이것을 썼다.

```
godot/assets/sprites/stage3/menhera_boss_skill_cards_imagegen_v1.png
```

**그 파일은 리브랜딩 이전 자산이며 코드 어디에서도 읽지 않는다.**
`godot/scripts/` 전수 검색 결과 참조 0건이다.

런타임이 실제로 읽는 것은 이것이다. `stage3_boss_skill_hud_assets.gd:3`

```

```

**★이것만이 정본이다.** 이 브리프의 모든 판정 기준은 이 파일이다.

### 두 아틀라스는 완전히 다른 언어다

| | 정본 (연묘) | 후보 A |

| 팔레트 | 먹빛·비취·주사·황동 | 마젠타·바이올렛·시안 |

카드 레일에 나란히 걸릴 때 리듬을 만든다. 후보에는 그것이 없어 레일에서
혼자 튄다.

## 2. 아트 계약

**소재는 그대로 둔다.** 보스는 여전히 테디베어와 엘리스이며
`stage_boss_variant_catalog.gd` 에 그 이름으로 등재돼 있다.
**바꾸는 것은 렌더링 언어다.**

### 필수

- 레퍼런스는 **정본 아틀라스**다. `menhera_*` 를 보지 마라.
- ★**칸마다 황동·칠기 장식 테두리와 모서리 금구**를 넣는다. 정본의 테두리
  형태·두께·금구 위치를 실측해 맞춰라.
- 팔레트는 **먹빛 바탕 + 비취·주사 강조 + 억제된 황동/금**이다.
  ★**네온 마젠타·바이올렛·시안 금지.**
- 발광은 억제한다. 정본은 영기가 은은하다. 후보 A 처럼 화면을 태우지 마라.
- 글자·숫자·로고·워터마크·UI 라벨 금지. 초점 기호 하나.
- **256 x 96 으로 줄였을 때 읽혀야 한다.** 판정은 축소 상태에서 한다.

### 소재 재해석 — 판단하되 근거를 적어라

| 스킬 | 후보 A | 재해석 방향(예시) |
|---|---|---|
| `cotton_throw` | 솜뭉치 | 삼베·목화 뭉치, 먹빛 궤적 |
| `cotton_bomb` | 네온 폭발 | 터지는 목화 다래, 주사빛 불티 |
| `deadly_hug` | 곰 팔 + 네온 하트 | 감싸 안는 팔, 금 간 주사빛 심장 |
| `heart_beam` | 마젠타 광선 | 주사빛 심기 세줄기 |
| `mirror_world` | 서양 거울 | **청동경**, 뒤집힌 회랑 |
| `size_shift` | 체스말 토끼 | **옥토끼**, 대소 대비 |
| `rabbit_projectile` | 봉제 토끼 | 옥토끼 부적, 먹빛 궤적 |

★**예시일 뿐이다.** 서양 소재를 억지로 한국식으로 바꿔 정체성을 잃지 마라.
테디베어는 테디베어다. **팔레트와 틀이 환격전이면 된다.**

## 3. ★아틀라스 격자 — 함께 결정하라

7종을 더하면 **11칸**이 필요하다. 현행 4칸으로는 안 된다.

- 격자를 정하고 근거를 적어라. 3행 4칸(12) 또는 그 밖.
- ★**`SKILLCARD_ATLAS_COLUMNS := 4` 와 실제 격자가 어긋나면 엉뚱한 칸이
  잘려 나온다. 런타임 오류가 아니라 조용한 오작동이다.**
- 소유 모듈에 `_COLS` / `_ROWS` / `_FRAMES` 를 **명시 상수로 선언**하라.
  치수에서 추론하지 마라(AGENTS "Atlas sheet grid authority").
- ★**기존 3종의 색인이 바뀌면 안 된다.** 연묘 카드가 엉뚱한 그림이 된다.
  기존 0·1·2 를 유지하는 배치를 택하라.
- 확장 아틀라스에서도 **기존 4칸의 픽셀이 보존**되는지 확인하라.
  재생성하지 말고 이어 붙여라.

## 4. 반려 기준

- `menhera_*` 계열 팔레트가 남아 있다.
- 장식 테두리·모서리 금구가 없다.
- 네온 발광이 정본보다 밝다.
- 256 x 96 으로 줄이면 안 읽힌다.
- 연묘 3종과 나란히 놓았을 때 계열이 갈린다.
- 글자·숫자·로고가 들어갔다.
- 기존 3종의 색인이나 픽셀이 바뀌었다.

## 5. 검증

- **접촉 시트** — 7종 후보
- ★**정본 나란히 비교** — 연묘 3종과 신규 7종을 **한 줄로 이어 붙인** 이미지.
  이것이 이 브리프의 핵심 판정이다. 계열이 갈리는지 한눈에 보게 하라
- ★**256 x 96 축소 판정 컷** — 실제 카드 크기. 여기서 읽히는지 본다
- **확장 아틀라스 전체** — 격자 선이 보이게 표시
- **기존 3종 픽셀 보존 증거** — 확장 전후 해시 또는 차분

**완료 선언 조건**: 7종 후보 + 제출 4종 + 격자 판정 근거.
승격과 배선은 사용자 승인 뒤에만.
