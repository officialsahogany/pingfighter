- **정본**: `docs/tower_ascent_run_map_plan.md` §3.1. **보스는 항상 자기 고유

  소스 SHA-256과 `.import` 설정 해시가 모두 일치하는 캐시만 선별 복사하라.
  통짜 복사 금지. 콜드 전체 임포트는 29GB이고 두 번 `0xC0000005`로 죽었다.
- **완료 보고**: `docs/tower_map_iconography_report.md`. 푸시 금지.
  **통합하지 말고 보고 후 대기하라.**

## 1. 슬라이스

| 순서 | 슬라이스 | 내용 |
|---|---|---|
| S1 | 아이콘 계약 | 런타임이 아이콘을 받을 자리 마련. 아트 없이 |
| S2 | 아이콘 생성 | IMAGEGEN 한 계열로 전량 |
| S3 | 지도 배선 | 이름 글자 제거, 아이콘 표시 |
| S4 | M 힌트 필러 이전 | 플레이필드 밖으로 |
| S5 | 씰과 캡처 | 회귀 차단 |

**S1을 먼저 하는 이유**: 아트가 없어도 계약과 폴백을 먼저 세워두면, 아이콘이
빠져도 지도가 죽지 않는다. 오늘 자산 누락으로 스크립트가 통째로 파싱 실패한
사례가 있었다.

## 2. 슬라이스별 계약

### S1. 아이콘 계약과 폴백

- 노드 아이콘 경로를 **`kind`와 `boss_id`에서 결정론적으로 해석**하는 단일
  소유자를 만들어라. 렌더러가 경로를 리터럴로 알면 안 된다.
- ★**`const preload`를 쓰지 마라.** 파일이 없으면 스크립트가 통째로 파싱
  실패한다. 런타임 `load` + 존재 검사로 하고, **없으면 현행 글자 라벨로
  폴백**하게 하라.
- ★**GRT-004**: 없는 경로를 매 프레임 드로에 물리면 프레임마다 파일시스템을
  재조회한다. 해석 결과를 캐시하고 미스도 캐시하라.
- 이 슬라이스는 **아트 0장**으로 끝난다. 폴백이 동작하는 것까지 씰로 잠근다.

### S2. 아이콘 생성 (IMAGEGEN)

**한 계열로 통일된 세트**를 만들어라. 낱장을 따로 뽑으면 계열이 흩어진다.

- **비전투 5종**: 상점, 수련장, 파계승, 수호의 샘터, 휴식
- **보스**: `FLOOR_BOSS_SLOTS`의 실보스 전량. 임시(shell) 슬롯은 제외한다.
- **지도 아이콘 1종**: S4의 M 힌트용

**아트 방향**

- 환격전 신화무협. 먹선과 한지, 옻칠과 황동, 비취와 주사.
  ⚠ 사이버펑크·네온·SF는 이 저장소의 전역 기본이 아니다.
- 지도 위 작은 원 안에 들어간다. **작게 줄여도 실루엣으로 구분되어야 한다.**
  세부 묘사보다 실루엣 대비가 우선이다.
- 보스 아이콘은 **정체를 알려주지 않되 인상은 남긴다.** 이름을 유추하게 하는
  글자·문양은 넣지 마라.
- 글자·숫자 금지. 워터마크 금지.
- 배경은 평면 `#00ff00` 크로마키로 뽑고
  `.claude/skills/sprite-generation/chroma_key.py`로 누끼한다.
  ⚠ `remove_bg.py`는 크로마 소스에 쓰면 전부 불투명으로 남는다.

**절차**

1. 비전투 5종 + 지도 1종을 **먼저** 한 세트로 뽑아 보여라. 승인 대기.
2. 승인 뒤 보스 전량을 같은 프롬프트 계열로 확장한다.
3. 사용자 부재 시 **후보를 보고서에 정리해 두고 멈춰라.** 임의 승격 금지.

**승격 시**

- 크기·격자·명명 규칙을 정하고 보고서에 표로 남겨라.
- `.import` 사이드카가 생긴 것을 폴링으로 확인한 뒤 다음으로 간다.
  헤드리스 `--import`는 에디터가 열려 있으면 금지다.

### S3. 지도 배선

- `tower_ascent_flow_renderer.gd:979-995`의 이름 문자열을 아이콘으로 바꾼다.
- **보스는 항상 고유 아이콘을 보여준다.** 발견 여부로 가르지 않고 미지
  아이콘도 두지 않는다(정본 §3.1).
- 비전투 노드도 이름 대신 아이콘으로 간다.
- ★**GRT-022**: 라벨 자리가 사라지면 노드 히트박스가 달라질 수 있다.
  `get_node_index_at` 계열 소비자를 전수 확인하고, **반증은 노드 원의
  상단 모서리**로 재라. 중심점으로 재면 밀림이 통과한다.
- ⚠ **경로 서브(ROUTE_AIM) 표적의 라벨은 이번 범위 밖이다.** 백로그 §9-b가
  아직 결정 대기다. 지도만 바꾸고 표적은 그대로 두어라.

### S4. M 힌트를 필러로 이전

- 현재 `TEMP_MAP_HINT_RECT`가 플레이필드 안(y 698)이다. **좌측 필러 배경으로
  옮겨라.**
- ★**플레이필드는 760x750 전체 캔버스다. 레거시 80px 인셋을 적용하지 마라.**
  필러 크롬은 그 바깥 레터박스에 있다. 좌표계가 다르다.
- ★**GRT-045**: 게임 좌표 오버레이와 스크린 공간은 클리핑 호스트가 다르다.
  소유자를 옮길 때 어느 드로어에 붙일지 먼저 확정하라.
  현재 소유자는 `battle_playfield_scene_drawer.gd:433`이다.
- 표시는 **지도 아이콘 + `M`** 형태다. 플레이어가 "M을 누르면 지도가 뜬다"를
  읽을 수 있어야 한다.
- 전투 화면을 가리지 않는 것이 이 슬라이스의 성공 기준이다. **픽셀로 확인하라.**

### S5. 씰

- 노드 종류마다 **해석된 아이콘 경로가 서로 다른지** 단언하라. 한 경로로
  전부 폴백되면 이 결함이 그대로 통과한다.
- **자산이 없을 때 글자 폴백으로 떨어지는 부정 레그**를 둬라.
- **M 힌트가 플레이필드 rect 밖에 있는지** 좌표로 단언하라.
- 보스 이름 문자열이 지도에 그려지지 않는지 확인하라.

## 3. 규율

- 슬라이스마다 헝크 분리 커밋 1개. 각 슬라이스는 **단독으로 씰 GREEN**이어야
  한다.
- 신규·개정 씰은 `.github/workflows/godot-ci.yml`과
  `godot/tools/run_pre_push_checks.ps1` **두 리터럴 목록에 동시 등재**한다.
  ⚠ **실패하는 씰을 그 목록에 넣지 마라.** 필수 통과 목록이다.
- 한국어 카피에 엠대시(—) 금지.
- 내부 식별자(`kind` 값, `boss_id`, 슬롯 id)는 바꾸지 마라.
- 통과 판정은 배치 종단선 `All Godot smoke tests passed.` + `SCRIPT ERROR` 0건.
- 로그 백업 선행. 표준 래퍼 `-AllowDuringPlay`. 푸시 금지.

**완료 선언 조건**: S1·S3·S4·S5 구현·검증 + S2 후보 제시 + 게이트
blocked/unverified 0건 + 보고서 완성. 슬라이스별 중간 보고 허용.

⚠ **S2 아이콘 승격은 사용자 승인 뒤에만 한다.** 승인 전에는 S1의 글자 폴백이
살아 있으므로 지도는 정상 동작한다.
