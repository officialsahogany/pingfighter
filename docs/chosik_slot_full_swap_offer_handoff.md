# 초식 슬롯 만석 시 교체용 초식 퍽 희귀 등장 핸드오프 (Codex 실행용)

작성 2026-08-01. 사용자 지시: **초식 슬롯이 가득 찬 뒤에도 다른 초식 퍽이
드물게 등장해 교체할 수 있어야 한다** — 현재는 영혼소환술이 있을 때만
가능하고, 일반 초식만으로 채우면 초식 퍽이 아예 안 뜬다.
가드레일·씰 실행 규정 기존과 동일. **5캐릭터 공통 시스템**이므로 수호령
트랙과 별개다.

## 1. 현재 동작 (실측 원인)

`runtime_perk_catalog._filter_unlock_slot_budget(:1896~1917)`:

```
if chosen_unlocks < budget: return choices          # 여유 있으면 통과
# 만석이면 아래 필터
for choice in choices:
    if choice.id == SOUL_SUMMON_ART_UNLOCK_ID: filtered.append(choice); continue   # ← 예외
    if choice.unlocks_skill == "": filtered.append(choice)                          # unlock 계열 전부 제거
```

- `UNLOCK_SLOT_BUDGET`만큼 unlock 퍽을 이미 가졌으면 **`unlocks_skill`이 있는
  모든 초식 퍽이 후보에서 제거**된다.
- **영혼소환술만 id 하드코딩 예외**로 통과한다(초식구슬은 먹지만
  `UNLOCK_SLOT_BUDGET` 계산에서 빠지는 공용 초식이라 넣은 예외).
- ⇒ 사용자가 본 현상 그대로: 영혼소환술이 있으면 교체 기회가 있고, 일반 초식만
  채우면 교체 자체가 불가능해 **빌드가 조기에 고정**된다.
- `soldier`는 함수 진입부에서 즉시 return이라 이 필터를 애초에 안 탄다(공유
  화기 슬롯 체계) — **이번 변경에서도 건드리지 말 것.**

## 2. 변경 계약

- **만석 상태에서도 unlock 초식 퍽이 후보에 남을 수 있게 한다. 단 희귀하게.**
- **확률 초안: 무공 화면당 0.15** (리포 선례 참고 — mythic jackpot 0.1 /
  dash_token_boost [0.25,0.10,0.05] / owned_upgrade_partial 0.5). 상수 1개로
  단일 소스화해 라이브 튜닝 가능하게 할 것.
- 굴림 단위: **화면당 1회**. 굴림 성공 시 그 화면의 만석 필터를 통과시키고,
  실패면 지금처럼 전부 제거. ⚠️ **후보마다 굴리면 안 된다**(만석인데 초식 퍽이
  여러 장 뜨는 그림이 됨 — per-frame/per-candidate 확률 트랩).
- 통과 시 제시 개수: **1장으로 제한** 권고(교체는 한 번에 하나면 충분하고,
  일반 퍽 슬롯을 잠식하지 않는다). 2장 이상 필요하다고 판단되면 근거와 함께
  보고할 것.
- **영혼소환술 예외는 유지** — 지금처럼 확률과 무관하게 항상 통과
  (슬롯 예산 밖 공용 초식이라 성격이 다르다).
- **선택 시 동작은 기존 스왑 흐름 그대로** — 슬롯 만석 → 교체 다이얼로그 →
  **취소는 완전 no-op**(레벨·해금·소유·무기 인벤토리 아무것도 쓰지 않음).
  이건 이미 있는 계약이니 재확인만.
- `soldier` 조기 return, `budget >= 99` 조기 return은 불변.

## 3. 주의 (기존 트랩)

- **`_filter_perk_slot_budget`(:1919, 퍽 슬롯 예산)과 혼동 금지** — 이번 건은
  `_filter_unlock_slot_budget`(초식 해금 예산)이다. 두 필터는 대상이 다르다.
- 스왑 취소 no-op은 이 리포에서 이미 한 번 어긋난 적이 있는 계약이다 —
  씰로 재확인할 것.
- 확률 도입 시 **결정론 RNG 주입 경로**를 반드시 열어둘 것(씰 필수).

## 4. 씰

- **만석 + 굴림 성공** → unlock 초식 퍽이 후보에 **1장 존재**.
- **만석 + 굴림 실패** → unlock 초식 퍽 **0장**(기존 동작 보존).
- **여유 있음** → 확률과 무관하게 기존대로 등장(조기 return 경로 불변).
- **영혼소환술** → 만석·굴림 실패 상태에서도 통과(기존 예외 유지).
- **soldier** → 필터 자체를 안 탐(불변).
- **스왑 취소 no-op** → 취소 후 `runtime_skill_levels`·해금 플래그·장착 목록이
  모두 원상.
- 각 레그 결정론 RNG 주입. 반증 1회(확률을 0으로 만들면 "굴림 성공" 레그 RED).
- 회귀: `perk_slot_limit_smoke`, `soul_summon_art_skill_contract_smoke`,
  `runtime_perk_unlock_swap_flow_smoke` GREEN 유지.
