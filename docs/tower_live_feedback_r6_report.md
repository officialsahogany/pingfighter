## 카드 부제 판정과 개선안

렌더러 계약상 퍽 철심공은 시작 카드에서 `2성`, 수련 철심공은 수련 카드에서
`기초 수련`으로 표시된다. 두 부제는 데이터 종류가 다르다는 정보를 담지만,
사용자가 실제로 `철심공`을 보고 수련 카드로 판단한 제보가 있으므로 현재
구분력은 충분하지 않다고 판정한다. 이름이 겹치는 다음 네 쌍에 같은 문제가
재현될 수 있다.

- 철심공 / 철심공 수련
- 유운보 / 유운보 수련
- 순환결 / 순환결 수련
- 태허심법 / 태허심법 수련

권고안은 이름이나 내부 ID를 바꾸지 않고, 기존 성급 또는 수련 부제와 별개인
종류 배지를 카드 상단에 추가하는 것이다.

- 퍽 카드: `무공` 배지 + 기존 `2성`
- 수련 카드: `수련` 배지 + 기존 `기초 수련`
- 좁은 레이아웃 대안: `무공 · 2성`, `수련 · 기초 수련`

한국어 엠대시는 사용하지 않는다. 확정 시 표시 문구만 7개 로케일에 등재하고
`bulletproof_hat`, `physique_posture`, `runtime_perk_*` 같은 호환 ID는 그대로
둔다. 문구와 배지 배치는 사용자 확정 전이므로 구현하지 않았다.
